# 요구사항: 월간보고 PPT (AI 요약, 내 양식 고정)

> 기능 ID: `ai-report` · 형식: 요구사항은 `### REQ-001: 제목`, 수용 기준은 `- AC-001.1: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다.

## 배경 / 목표
- 근거: `docs/ai-report-plan.md` §1·§2·§3·§4, 쪽 배치는 검토용 PPT 목업(https://claude.ai/artifact/Amc46niE2pgiJos22MmQdN, 9쪽), 색·크기·움직임·표지 영상은 2026-10-29 사용자 결정(색 고르기에서 4번 '모노 + 1색'을 골라 다시 만든 목업 https://claude.ai/artifact/8Wv7gQRATVgSGiVHCMeyon). plan.md §2-2·§2-3·§2-9·§4·§5·§6-1·§6-2·§6-6·§8
- **원칙: 모양은 코드가, 글은 AI가.** 쪽 크기·쪽 순서·색·글꼴·글자 크기·움직임·글자 수 한도는 양식 정의 한 곳에 고정한다. 숫자·늘고 준 폭·그래프·표·그래프 결론 줄은 코드가 계산한다. AI는 '한눈에' 발견 4개(정해 둔 꼬리표 + 문장)와 다음 할 일 1~3개(문장 + 근거 줄)만 JSON으로 쓴다
- **이 명세는 1단계다: 로그인·화면·서버가 없어도 되는 로직만.** main에는 아직 로그인·DB 표·앱 틀·Tailwind가 없다(`feat-auth`가 합쳐지면 생긴다)
- 입력은 stats-core가 만드는 달 숫자(`MonthPayload` v2, `lib/payload/validate.ts`를 통과한 것)다. 환자 줄·차트번호·파일 이름은 이 기능에 들어오지 않는다
- 코드는 `src/lib/report/`에 둔다. 환자 자료 구역 밖이고, 구역 울타리(ESLint)를 고치지 않는다
- 색 벌은 5개이고 기본은 `mono`다. REQ-006·REQ-011·REQ-012에 적은 색 값은 mono 기준이며, 다른 벌은 같은 역할의 그 벌 값이다(색 고르기 페이지 https://claude.ai/artifact/MRDV9G2jugvKoEY3Bjt3oU)
- 크기는 1920×1080 캔버스 기준 px로 정하고 PPT(13.333 × 7.5인치)에는 비례로 옮긴다: 1px = 0.5pt = 1/144인치
- 첫 버전 숫자는 환자 통계 집계만 쓴다(외래·신환·재진·신환율·7일·14일 재방문율·처방군 신환). 매출·급여는 그 기능이 생기면 칸을 늘린다

## 요구사항

### REQ-001: 양식 정의 (한 곳에 고정, AI가 바꿀 수 없음)
- AC-001.1: Given `TEMPLATE`, When 읽으면, Then 쪽 크기는 16:9(13.333 × 7.5인치)이고 쪽 순서는 표지 → 한눈에 → 핵심 숫자 → 그래프(그래프마다 한 쪽: 외래 꺾은선 → 신환 막대 → 처방군 꺾은선) → 요약 표 → 다음 할 일 → 계산 기준이다
- AC-001.2: Given `TEMPLATE.palettes`, When 읽으면, Then 색 벌 5개가 있다: `violet` 보라 · `blue` 블루 · `teal` 청록·민트 · `mono` 모노+1색(기본) · `warm` 웜. 벌마다 역할 색 — 바탕·카드·테두리·기준선·글자 3단(글자·보조·흐린 글자)·강조·올해·작년·신환·처방군 1~4·늘었음·줄었음 — 이 모두 `#` 없는 6자리 16진수이고 색 고르기 페이지(https://claude.ai/artifact/MRDV9G2jugvKoEY3Bjt3oU) 값 그대로다. 예: mono = 바탕 #0D0E10 · 카드 #15171A · 테두리 #26292E · 기준선 #3A3E45 · 글자 #F2F3F5 / #C4C8CE / #8E939B · 강조 #60A5FA · 올해 #0486D3 · 작년 #5F6368(점선) · 신환 #0486D3 · 처방군 #0486D3 / #D1D5D9 / #9EA2A6 / #66696E · 늘었음 #60A5FA · 줄었음 #F59E0B. warm의 줄었음은 산호색 #E85F61이다. 잠정 글자 #F6D55C · 잠정 바탕 #1A1810은 모든 벌이 같이 쓴다. 표지 영상이 있는 벌은 mono뿐이다(mono 표지 바탕 #0A0E17). 밝은 바탕 색과 #0E7490은 없다
- AC-001.3: Given 벌마다 그래프 줄 역할의 색, When 보면, Then 그래프마다 강조 줄은 하나다(외래 = 올해 색, 신환 = 신환 색, 처방군 = 첫 처방군 색). 강조 줄만 6px · 아래 위→아래로 옅어지는 채움(불투명도 22% → 0%) · 마지막 점 표시를 갖고, 나머지 줄은 2.5px이며 작년(점선)이나 처방군 2~4 색으로, mono는 밝기로(#D1D5D9 > #9EA2A6 > #66696E), 다른 벌은 색으로 갈린다. 글자 크기·글꼴·쪽 순서·그래프 규칙(강조 한 줄, 끝 이름표, 부호·화살표)·움직임은 모든 벌이 같다(벌은 색만 바꾼다)
- AC-001.4: Given `TEMPLATE`, When 읽으면, Then 글꼴은 맑은 고딕 하나(이름 `맑은 고딕`)이고 굵기는 보통·굵게(700) 둘뿐이다. 그림자 없음 · 선 1px · 모서리 둥글기 10px이다. 글자 크기(px)는 제목 60 굵게 · 그래프 결론 36 굵게 · 본문 28 · 계산 기준 26 · 큰 숫자 88 굵게 · 카드 이름 24 · 비교 줄 22 · 증감 28 굵게 · 표 24 · 표 머리 20 · 축 20 · 끝 이름표 22 굵게 · 꼬리표 20 · 설명·바닥글 18 이고 18보다 작은 것이 없다
- AC-001.5: Given `TEMPLATE.limits`와 `TEMPLATE.findingTags`, When 읽으면, Then AI 칸 한도(발견 정확히 4개·문장 각 70자, 다음 할 일 1~3개·문장 각 60자·근거 각 50자)와 발견 꼬리표 목록(외래·신환·재진·신환율·처방군·재방문, 이 6개뿐), 코드 칸 한도(처방군 이름 12자, 병원 이름 30자, 처방군 그래프 최대 4줄, 처방군 그래프·카드 작은 선 6달)가 있다
- AC-001.6: Given `TEMPLATE`, When 안의 값을(깊은 곳 포함) 바꾸려 하면, Then 바뀌지 않는다(얼려 둠 — strict 모드에서 TypeError)
- AC-001.7: Given 고정 문구, When 읽으면, Then 쪽 꼬리표(`MONTHLY REPORT`·`SUMMARY`·`KEY NUMBERS`·`TABLE`·`NEXT`·`NOTES`), 카드 꼬리표(`VISITS · 외래`·`NEW · 신환`·`RETURN · 재진`·`RATE · 신환율`), 표지 범위 줄 "외래 · 신환 · 재진 · 처방군 · 월별(달력 기준)", 개인정보 줄 "환자 이름·차트번호 없음 · 숫자만 담았습니다", 예시 표시("예시 · 숫자는 모두 가짜예요"·"예시 숫자"), AI 없음 안내 "AI 요약 없이 숫자 결론만 담았어요", 근거 머리 "근거 · ", 계산 기준 메모(모두 "· "로 시작)가 있다
- AC-001.8: Given 벌마다 글자에 쓰는 색(글자·보조·흐린 글자·강조·늘었음·줄었음·잠정 글자), When 바탕·카드·잠정 바탕 위 대비를 재면, Then 모두 4.5:1 이상이다. 큰 숫자(88px 굵게)의 올해·신환 색은 카드 위 3:1 이상이다. 값 꼬리표 글자는 그 줄 색 위에서 바탕색과 #FFFFFF 중 대비가 큰 것이고 4.5:1 이상이다(mono는 #0D0E10, 4.9:1). 잠정 금색 #A16207은 어두운 바탕에서 3.9:1이라 쓰지 않는다
- AC-001.9: Given `TEMPLATE.motion`과 `TEMPLATE.cover`, When 읽으면, Then 쪽 전환은 페이드 0.5초 이하, 효과 하나는 0.5초 이하, 쪽마다 효과 합 3초 이하, 효과는 모두 자동(앞 효과 뒤·함께)이다. 표지 영상은 H.264(avc1) MP4·8MB 이하, 정지 그림은 PNG 1920×1080·500KB 이하, 글자 쪽 덮개는 쪽 너비의 1/3 이상·불투명도 70% 이상이다
- AC-001.10: Given 벌 이름 글자, When `paletteOf`로 찾으면, Then 다섯 이름 중 하나면 그 벌이고, 아니면(빈 글자·'Mono'·'red') null이다(기본 벌로 몰래 바꾸지 않는다). 기본 벌(`TEMPLATE.defaultPalette`)은 `mono`다

### REQ-002: 숫자·늘고 준 폭 글자
- AC-002.1: Given 0 이상의 정수, When 개수 글자로 바꾸면, Then 천 단위 쉼표 글자다(1234567 → '1,234,567', 0 → '0')
- AC-002.2: Given 이번 3412·비교 3060, When 증감률을 만들면, Then '+11.5%'·늘었음이다. 이번 413·비교 454이면 '−9.0%'(빼기는 U+2212)·줄었음이다. 퍼센트는 소수 첫째 자리까지 반올림한다(둘째 자리가 5 이상이면 올림, 음수는 절댓값을 반올림하고 부호를 붙인다. 1 vs 3 → '−66.7%')
- AC-002.3: Given 이번과 비교가 같으면 '0.0%'·변화 없음, 비교가 0이고 이번 > 0이면 '신규', 둘 다 0이면 '0.0%' 변화 없음이다. 차이가 있는데 반올림으로 0.0이 되면 부호는 차이를 따른다(10001 vs 10000 = 0.01% → '+0.0%'·늘었음)
- AC-002.4: Given 분자·분모, When 비율을 만들면, Then 0.1% 단위로 반올림한 값이다: 413/3412 → '12.1', 반올림 경계 1/16 = 6.25% → '6.3', 201/2000 = 10.05% → '10.1'(실수 계산이면 10.049999…라 '10.0'이 되는 값), 1/8 = 12.5% → '12.5'. 분모가 0이면 없음(null)이다
- AC-002.5: Given 반올림해 표시한 두 비율, When %p 증감을 만들면, Then 두 표시 값의 차 그대로 '+0.6%p'·'−2.7%p'·'0.0%p'이고 따로 반올림하지 않는다(표에 보이는 두 숫자를 빼면 늘 맞는다. 12.1과 14.8 → '−2.7%p')
- AC-002.6: Given 반올림 경계의 증감 10005 vs 10000(+0.05%)·9995 vs 10000(−0.05%)과 나누어떨어지는 값 2200 vs 2000, When 계산하면, Then '+0.1%'·'−0.1%'·'+10.0%'이다. 계산은 정수(몫·나머지)로 해서 1.005 같은 경계에서 부동소수점 오차가 없다. 금액 규칙(원 미만 버림, plan §5)은 그대로이고 이 기능은 금액을 다루지 않는다
- AC-002.7: Given 증감, When 보이는 글자를 만들면, Then 늘었음·줄었음은 언제나 부호와 화살표를 함께 단다('+11.5% ↑'·'−9.0% ↓'·'−2.7%p ↓'·'+0.0% ↑'). 변화 없음은 '0.0%'(화살표 없음), 신규는 '신규'다. 색이 없어도 뜻이 읽힌다

### REQ-003: 월간 숫자 계산 (코드가 계산)
- AC-003.1: Given 보고 달이 들어 있지 않은 입력, 검사(`validateMonthPayload`)를 통과하지 못한 달이 섞인 입력, 같은 달이 두 번 있는 입력, When 계산하면, Then `E-REPORT-NO-DATA`다
- AC-003.2: Given 보고 달 M·지난달 M−1·작년 같은 달 M−12가 모두 완전한 달, When 계산하면, Then 핵심 숫자 카드는 외래 → 신환 → 재진 → 신환율 4개이고, 카드마다 이번 값·지난달 값과 증감·작년 같은 달 값과 증감(REQ-002 글자, 신환율은 %p)·M−5~M 여섯 달 작은 선 값(저장 안 된 달은 null)이 있다
- AC-003.3: Given M이 완전하지 않은 달(`partial`), When 계산하면, Then 보고서가 잠정이고 M의 값마다 잠정 표시가 붙으며, 지난달·작년 대비 증감은 내지 않는다(까닭: 잠정. 완전한 달끼리만 비교)
- AC-003.4: Given M−1 또는 M−12가 없거나 완전하지 않음, When 계산하면, Then 그 비교만 '비교 없음'이다. 재방문 수가 null(집계 중)이면 그 비율 칸은 '집계 중'·잠정이고 비교하지 않는다. 재방문 집단이 0명이면 비율 칸은 '—'다
- AC-003.5: Given 저장된 달들, When 외래·신환 그래프 숫자를 만들면, Then 가로 칸은 M이 든 해의 1월~M('1월'…'10월', 완전하지 않은 달은 '10월 잠정')이고, 작년 같은 달 줄과 올해 줄 두 줄(이 순서, 올해가 위에 그려짐)이며, 저장되지 않은 달은 빈 점(null)이다. 외래는 꺾은선, 신환은 막대이고 강조할 칸은 마지막 칸(M)이다
- AC-003.6: Given 처방군 목록, When 처방군 그래프를 만들면, Then 앞 4개만 이 순서(= 색 순서, 첫 처방군이 파랑)로 M−5~M 여섯 달의 처방군 신환 수 한 줄씩이다. 저장된 달에 그 처방군이 없으면 0, 저장되지 않은 달은 null이다. 5번째부터는 그리지 않고 계산 기준에 한 줄 알린다. 이름은 12자를 넘으면 12자 + '…', 비면 '이름 없음'이다. 처방군 목록이 비면 처방군 그래프가 없다
- AC-003.7: Given 그래프, When 한 줄 결론을 만들면, Then 외래는 작년 같은 달과('외래 3,412명 · 작년 같은 달 3,120명보다 +9.4% ↑'), 신환은 지난달과('신환 413명 · 지난달 454명보다 −9.0% ↓'), 처방군은 지난달보다 가장 많이 늘어난 처방군 하나와('체외충격파 신환 84명 · 지난달 71명보다 +18.3% ↑', 신규 먼저, 같으면 목록 순) 비교하고, 끝의 증감 글자에 늘었음·줄었음 표시가 있다. 같으면 '…과 같아요', 비교가 0이면 '… 0명 → 신규', 비교 없음이면 '… 숫자가 없어요', 잠정이면 '…(잠정) · 달이 끝나지 않아 비교하지 않아요'다

- AC-011.4: Given 영상 또는 정지 그림 위, When 표지를 보면, Then 왼쪽 1/3 이상을 덮는 #0A0E17 덮개 상자(불투명도 70% 이상)가 영상 위·글자 아래에 있고, 제목·꼬리표·병원 이름·기간 카드·만든 시각이 모두 그 상자 안에 있다

- AC-011.6: Given 맞는 표지 영상이 없는 벌(violet·blue·teal·warm), When 표지를 만들면, Then 표지 자산을 주어도 쓰지 않고 영상·그림·재생 노드 없이 그 벌 바탕색 위에 강조 색 단순 선 도형 3개(오른쪽 2/3, 불투명도 60%·35%·15%, 글자와 겹치지 않음)를 둔다

## 범위 밖 (2단계: 로그인 작업이 main에 합쳐진 뒤 명세에 더하고 다시 승인)
- 보고서 화면과 [PPT 내려받기] 버튼(앱 틀·Tailwind 안, 목업 승인 뒤). 버튼을 누를 때 `pptxgenjs`를 불러오고 표지 자산을 같은 origin에서 받아 브라우저에서 파일을 내려받는다
- 화면 보고서의 인쇄용 CSS(A4)와 월간 PDF 화면(plan §2-9)
- `app/api/ai/` 서버 경로: 승인된 사용자 확인 → DB에서 달 숫자 읽기 → `validate.ts` → 이 기능의 계산·AI 요청 만들기 → Claude 호출 → 답 검사(거부면 한 번 다시) → `ai_usage` 기록. 오류 번호 `E-AI-BUSY`·`E-AI-LIMIT`·`E-AI-FAILED`
- DB 표(`months`·`rx_groups`)와 저장(`lib/storage`). 처방군 이름은 `rx_groups`에서 붙인다
- 모델 고르기와 비용. 실제 API를 부르는 시험은 부르기 전에 사용자에게 묻는다
- 표지 영상 만들기 자체(히글스필드로 한 번, 이 명세 밖에서). 보고서마다 새로 만들지 않는다. mono 밖의 벌에 맞는 영상을 만드는 것은 따로 비용이 드는 히글스필드 작업이라 범위 밖이다
- 앱 설정 화면에서 PPT 색 벌 고르기(2단계)
- 매출·급여 숫자 칸, 채팅, 표지 로고
- 사용자별 AI 호출 제한 등 plan.md §10

- 한눈에 발견마다 **꼬리표**: AI가 양식에 정해 둔 목록(외래·신환·재진·신환율·처방군·재방문)에서 고르고, 목록 밖이면 검사기가 거부 → REQ-001·REQ-005·REQ-006

- 잠정 달 비교: **완전한 달끼리만 비교**(plan §2-2 사용자 결정 그대로). 목업의 잠정 10월 비교는 예시일 뿐 → REQ-003
- PPT는 **어두운 '모노 + 1색'**: 그래프마다 파랑 한 줄, 나머지는 밝기로 가른 회색, 모든 줄에 끝 이름표, 증감은 늘 부호·화살표 → REQ-001·REQ-002·REQ-012. 잠정 금색은 어두운 바탕에서 읽히는 #F6D55C(바탕 #1A1810)로 바꿨다(#A16207은 3.9:1)
- 글자 크기(1920×1080 px), 18px 아래 없음, 굵기 700만 → REQ-001·REQ-006
- **움직임**: 쪽 페이드, 카드·작은 선 차례로, 그래프는 줄별·칸별로 지어짐, 발견 차례로. 모두 자동·0.5초 이하·쪽마다 3초 이하 → REQ-010
- **표지 영상**: 히글스필드로 한 번 만든 반복 영상을 달마다 다시 쓴다(보고서 만들 때 비용 없음) → REQ-011
- **그래프 생동감**: 파랑 줄 6px + 아래에만 옅어지는 채움, 회색 줄 2.5px, 마지막 점 둘레 빛 + 값 꼬리표, 작년 막대는 회색 점선 상자, 이번 달 막대는 테두리, 카드마다 최근 6달 작은 선 → REQ-012
- **바탕 색은 4번 회색 계열**: 바탕 #0D0E10 · 카드 #15171A · 테두리 #26292E · 글자 #F2F3F5 · #C4C8CE · #8E939B. 표지는 영상 정지 그림 색(#0A0E17)이라 다른 쪽과 조금 달라도 된다 → REQ-001·REQ-006
- **색 벌 5개, 바꿀 수 있게**("그 색감도 내가 원할 때 바꿀 수 있게 리스트업 해놔"): 색 고르기 페이지의 5벌(보라·블루·청록·민트·모노+1색·웜)을 모두 양식에 두고 기본은 mono. PPT를 만들 때 벌 이름을 주고, 모르는 이름은 오류로 막는다. 표지 영상은 mono뿐이고 다른 벌은 선 도형 표지 → REQ-001·REQ-006·REQ-007·REQ-011
- **표지 영상 부호**: 히글스필드가 준 HEVC(H.265, 1920×1080, 24fps, 5.04초)는 Windows PowerPoint가 따로 산 코덱 없이는 못 틀 수 있어, H.264(yuv420p)로 다시 묶고 0.5초 겹쳐 넘기기로 이음매 없이 이었다(4.54초, 340KB, faststart, 소리 없음). 정지 그림은 2688×1520(3.0MB)을 1920×1080·500KB 이하로 줄여 넣는다 → REQ-011
