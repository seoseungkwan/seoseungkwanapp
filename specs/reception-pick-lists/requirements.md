## 요구사항

### REQ-3501: 고르기 목록 저장·나눠 주기 (도우미)
- AC-3501.1: Given 목록 파일이 없음, When 읽으면, Then 기본값이다: C-ARM 시술 목·등·허리·리덕션(리덕션만 약재 없음)·약재 TP·하프·기본, SONO 부위 20개(시안 차례 목~기타)·부위 없이 소독·S/O·봉합·같이 하는 것 DNA·채혈. 파일이 깨졌으면 기본값 + 기록 E-STORE-BROKEN 한 번이다
- AC-3501.2: Given 목록 모양 검사, When 받으면, Then 이름은 앞뒤 빈칸을 뺀 1~10글자·"|"와 제어 글자 없음·무리 안 겹침 없음이고, SONO 부위와 부위 없이는 서로 겹치지 않으며, 개수는 시술 1~12·약재 0~12·부위 0~40·부위 없이 0~12(둘 합 1 이상)·같이 0~12, 약재 없음 표시는 시술에만 있다. 어긋나면 받지 않는다
- AC-3501.3: Given `POST /api/lists`(몸은 판 `picks`와 같은 모양), When 보내면, Then 쓰기 검사가 틀리면 403, 모양이 틀리면 400, 맞으면 `data\reception-lists.dat`(머리 + DPAPI, 날짜와 상관없음)에 쓰고 204다
- AC-3501.4: Given 어레인지 칸을 보내는 판, When `GET /api/board`, Then 맨 위 칸 `picks` = `{ carm: { procs: [{ n, noDrug }], drugs }, sono: { parts, plains, withs } }`(지금 목록)가 있고, 어레인지를 보내지 않는 판에는 없다

### REQ-3502: 칸 표시·쓰기
- AC-3502.1: Given 칸 표시 파일, When 쓰고 읽으면, Then SONO·C-ARM `part`는 줄을 "|"로 이은 글, 새 `tags`는 글 목록이다. `tags`는 비지 않을 때만 쓰고 `tags`가 없는 옛 파일도 읽힌다. 읽을 때 part·tags는 모양만 본다(목록에 있는지는 보지 않음)
- AC-3502.2: Given 판의 어레인지 칸, When 받으면, Then 칸마다 `tags`(늘 배열)가 있고 `part`는 null 또는 "|"로 이은 글이다
- AC-3502.3: Given `POST /api/arrange`의 sono·carm `add`·`part`, When 새 칸 `t`(tags를 "|"로 이음, 없어도 됨)와 함께 받으면, Then 지금 목록으로 본다: C-ARM은 v = 시술 하나·t = 약재 0~1개(약재 없음 시술이면 t 없음), SONO는 v = 겹침 없는 1~6줄(부위 없이 글·부위·"오른|왼|양 + 빈칸 + 부위")·t = 같이 하는 것의 겹침 없는 일부. 어긋나면, 다른 op·칸에 t가 있으면, v가 "부위는 나중에"면 400이다
- AC-3502.4: Given 쓰기 몸, When 받으면, Then 읽기 한도는 4096바이트(넘으면 413)이고, 쓰기 검사 전에 `/api/xray` 256·`/api/arrange` 1024·`/api/lists` 4096바이트를 넘으면 413이다
- AC-3502.5: Given 화면 `api.js`, When 판을 읽고 쓰면, Then 칸 `tags`·판 `picks`(없으면 받음) 모양이 틀리면 shape 실패이고, `setArrange(k, op, col, v, t)`·`setLists(picks)`는 몸이 그 길 한도를 넘으면 보내지 않는다(input)

### REQ-3503: C-ARM 넣기 (화면)
- AC-3503.1: Given 빈 C-ARM 칸 또는 [시술 고르기], When 누르면, Then 창 "C-ARM 넣기"에 판 `picks`의 시술 줄·약재 줄과 [닫기]·[넣기]가 있고 "부위는 나중에"는 없다. 시술을 고르기 전에는 [넣기]가 꺼져 있고, 고른 단추를 다시 누르면 풀리며, 고른 값은 저절로 다시 그리기에도 남는다
- AC-3503.2: Given 약재 없음 시술을 고름, When 그리면, Then 약재 줄이 흐려 눌리지 않고 "{시술}은 약재 없이 넣어요"(시술 끝 글자에 받침이 없으면 "는", Claude 결정)가 보이며 약재를 보내지 않는다
- AC-3503.3: Given [넣기 · 허리 TP], When 누르면, Then 빈 칸이면 `add`, [시술 고르기]에서 열었으면 `part`로 v="허리"·t="TP"를 보낸다
- AC-3503.4: Given C-ARM 칸, When 그리면, Then 시술이 큰 글·약재가 둥근 이름표이고, 시술이 없는 준비·준비완료 칸은 [시술 고르기]다. 열 머리 작은 글은 "시술·약재·순서"다

### REQ-3504: SONO 넣기 (화면)
- AC-3504.1: Given 빈 SONO 칸 또는 [부위 고르기], When 누르면, Then 창 "SONO 넣기"에 고른 것·쪽(오른쪽·왼쪽·양쪽)·부위·부위 없이·같이 하는 것(체크) 줄과 [닫기]·[넣기]가 있고 "부위는 나중에"는 없다
- AC-3504.2: Given 쪽을 고르고 부위를 누름, When 담으면, Then "오른 어깨"(쪽이 없으면 "어깨")를 고른 것에 더하고, 부위 없이 글은 그대로 더한다. 담은 것을 다시 누르거나 고른 것 이름표를 누르면 뺀다. 여러 개 담을 수 있다
- AC-3504.3: Given 고른 것이 하나 이상, When 그리면, Then [넣기 · 오른 어깨 · 왼 무릎 + DNA]가 켜지고 누르면 `add`(빈 칸)·`part`([부위 고르기])로 v="오른 어깨|왼 무릎"·t="DNA"를 보낸다. 같이 하는 것만 고르면 꺼져 있다. 고른 값은 저절로 다시 그리기에도 남는다
- AC-3504.4: Given SONO 칸, When 그리면, Then 고른 줄마다 한 줄 + 같이 하는 것 이름표다. 쓰는 법 글은 시안 그대로 "(SONO는 [부위 고르기], C-ARM은 [시술 고르기]로 골라요)"를 더한다

### REQ-3505: 목록 고치기 (화면)
- AC-3505.1: Given 어레인지 탭 머리, When 그리면, Then 오른쪽에 [☰ 목록 고치기]가 있고(접수 현황 탭에는 없음) 누르면 창 "고르기 목록 고치기"가 열린다: 탭 C-ARM(시술·약재)·SONO(부위·부위 없이·같이 하는 것 + 쪽 고정 안내), 줄마다 ▲ ▼ ✕(시술은 [약재 없음]도), 무리마다 글 칸 + [더하기], 아래 안내 글, [취소]·[저장]
- AC-3505.2: Given 창, When [더하기]·▲·▼·✕·[약재 없음]을 누르면, Then 창 안 초안만 바뀐다. 도우미 목록 규칙에 어긋나는 이름은 더하지 않고, 마지막 시술과 SONO 마지막 부위(부위 + 부위 없이)의 ✕는 꺼진다. 저절로 다시 그리기에도 창·초안·적던 글이 그대로다
- AC-3505.3: Given [저장], When 누르면, Then 초안 전체를 `setLists`로 보내 204면 창을 닫고 띠 "목록을 저장했어요", 아니면 창을 두고 띠 "목록을 저장하지 못했어요"다. [취소]·창 바깥은 저장하지 않고 닫는다
- AC-3505.4: Given 화면 파일, When 살피면, Then SONO·C-ARM 목록 글을 갖고 있지 않고 판 `picks`만 쓴다(없으면 두 넣기 창·목록 고치기가 열리지 않음). 목록을 브라우저 저장소에 두지 않는다(울타리 그대로)
