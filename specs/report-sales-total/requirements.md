# 요구사항: 월간 보고서 매출 = 총진료비 그대로

> 기능 ID: `report-sales-total` · 형식: 요구사항은 `### REQ-NNNN: 제목`, 수용 기준은 `- AC-NNNN.n: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다. 결정 기록: `docs/mockups/report-sales-total/notes.md`.

## 배경 / 목표
- 2026-11-19 사용자: "월간 보고서 매출금액은 그냥 총 진료비 그대로 나오게 해", "참고금액 상관없이".
- 지금 통계 탭 월간 보고서(stats-insights)의 매출은 날마다 총진료비(sales_days.total)를 더하되 '확인 필요'인 날(total 없음)은 빼고, 만 원 단위로 잘라 보인다(예: "1억 1,000만 원").
- 사용자 결정(2026-11-19 "둘 다"): 확인 필요한 날도 그날 총진료비(참고 금액, sales_days.rough_total)를 구분 없이 그냥 더하고, 원 단위까지 다 보인다(예: "13,021,450원").

## 요구사항

### REQ-6901: 보고서 매출은 날마다 총진료비를 다 더한 값
- AC-6901.1: Given 저장된 날 줄(total, roughTotal), When 보고서가 하루 매출을 고르면, Then 그날 값은 total이 있으면 total, total이 null이고 roughTotal이 있으면 roughTotal(음수도 그대로), 둘 다 null이면 그날은 뺀다(지금처럼 '모르는 날').
- AC-6901.2: Given 확인 필요한 날이 든 달, When 월간 보고서를 보면, Then 한 달 요약 '매출', 목표 '매출', 달라진 것 '매출'이 모두 AC-6901.1로 고른 값의 합이다(앞 달 견주기도 같은 규칙, 두 달 다 고른 날이 하나 이상일 때만 견준다 — 지금 조건 그대로).

### REQ-6902: 보고서 매출은 원 단위까지
- AC-6902.1: Given 매출 합 n원, When 월간 보고서를 그리면, Then 한 달 요약 '매출' 칸 값은 `formatWon(n)`(예: `13,021,450원`)이다.
- AC-6902.2: Given 매출 목표, When 목표 줄을 그리면, Then `매출 <formatWon(값)> / 목표 <formatWon(목표)> · <달성률>%`이다(달성률 식 그대로).
- AC-6902.3: Given 앞 달과 견줄 수 있는 매출, When '달라진 것' 줄을 그리면, Then 괄호 안 두 금액은 `formatWon`이다(`(<앞 달> → <이번 달>)`, 퍼센트·문장 그대로).
- AC-6902.4: Given 신환 1명당 매출 칸(비트 답), When 그리면, Then '신환 1명당 평균 (90일)'·'한 번 올 때 평균'은 지금처럼 만 원 단위 그대로다(총진료비 합이 아니라 평균이라 바꾸지 않는다).

## 범위 밖

- 보고서 인쇄·PDF 모양(같은 값을 그리므로 따로 고치지 않는다).
