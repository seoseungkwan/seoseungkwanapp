# 요구사항: 설정 안쪽 메뉴 이름 '청구'로

> 기능 ID: `settings-tab-name` · 형식: 요구사항은 `### REQ-001: 제목`, 수용 기준은 `- AC-001.1: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다.

## 배경 / 목표
- 설정 화면의 안쪽 메뉴 첫 칸 이름이 '청구·연락'이다. '연락'(환자 연락 문자 문구, precheck REQ-025·REQ-026)은 만들지 않았고 안에는 청구 설정만 있다.
- 2026-11-17 사용자: "청구만 둬" → 이름을 '청구'로 바꾼다. 글자 하나만 바뀌므로 시안 대신 사용자 말이 승인이다(바꿀 글자를 사용자가 정함).

## 요구사항

### REQ-5201: 안쪽 메뉴 첫 칸 이름 '청구'
- AC-5201.1: Given 설정 화면 `/settings`, When 그리면, Then '설정 안 메뉴'의 칸은 차례대로 [청구](지금 화면, aria-current="page") · [비트 PC 연결]이고 화면 어디에도 '청구·연락' 글자가 없다
- AC-5201.2: Given 비트 PC 연결 화면 `/claim/setup`, When 그리면, Then '설정 안 메뉴'의 칸은 [청구](`/settings` 링크, 모양은 지금 그대로) · [비트 PC 연결](지금 화면)이고 '청구·연락' 글자가 없다

## 범위 밖
- 안쪽 메뉴의 모양·주소·차례, 설정 칸들의 내용은 그대로
- 환자 연락 기능(문자 문구·연락 화면)은 만들지 않는다
- 옛 명세·시안 문서와 코드 주석 속 '청구·연락' 글은 고치지 않는다(기록)
