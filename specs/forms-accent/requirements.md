# 요구사항: 휴진 안내 글자 색 직접 고르기 (forms-accent)

- 배경: 2026-11-15 forms-themes(AI 배경) 배포 뒤 사용자가 크리스마스 AI 배경에서 '휴진' 글자가 금색으로 나온 것을 보고 "휴진이니 빨간 글씨면 좋겠다" → "글자 색 내가 정하게 못해?". 고른 답: **강조색 전체**('N월'·날짜 띠·카드 아래 글)를 **아무 색이나(색상판)** 직접 고른다. 처음 고른 "'휴진' 글만 늘 빨강"은 직접 고르기와 부딪혀 빼기로 함
- 승인 시안: `docs/mockups/forms-accent/screen.html`(`?s=color|light`, 나머지 상태는 forms-themes 시안 그대로)과 `notes.md`(승인 줄)
- 기준: forms(휴진 안내), forms-themes(테마 그림·AI 배경·내 배경). 강조색은 지금 테마 강조색 또는 배경에서 뽑은 색(forms-themes REQ-4605)

### REQ-4701: '글자 색' 칸
- AC-4701.1: Given 휴진 안내 만들기 칸, When 보면, Then '배경' 칸 맨 아래에 제목 '글자 색', 묶음 단추 [자동]·[직접 고르기](묶음 읽는 이름 '글자 색'), 색 고르기 칸(`<input type="color">`, 읽는 이름 '글자 색 고르기'), 지금 색 글, 도움말 "'<안내 달>월'·날짜 띠·카드 아래 글이 이 색이에요. 자동은 테마·배경에 맞춰 골라요"가 있다
- AC-4701.2: Given 새 안내문이거나 글자 색이 없는 저장 안내문, When 보면, Then [자동]이 눌려 있고, 색 고르기 칸은 지금 자동 색(미리보기에 쓰이는 테마·배경 강조색)을 보이며 흐리게(누를 수는 있다) 보이고, 지금 색 글은 '자동 #rrggbb'다
- AC-4701.3: Given 색 고르기 칸, When 색을 고르면, Then 글자 색이 그 색(소문자 `#rrggbb`)이 되고 [직접 고르기]가 눌리며 지금 색 글이 '#rrggbb'가 된다. [자동]일 때 [직접 고르기]를 누르면 글자 색이 지금 자동 색이 되고 색 고르기 창을 연다. [자동]을 누르면 글자 색이 없어진다(자동)
- AC-4701.4: Given 직접 고른 글자 색, When 흰색과의 대비가 4.5 미만이면, Then "옅은 색이라 흰 글자·흰 카드 위 글이 잘 안 보일 수 있어요"가 경고색으로 보이고, [저장]·[인쇄·PDF]·[그림 파일]은 막지 않는다. 4.5 이상이거나 [자동]이면 보이지 않는다

### REQ-4702: 안내문 그림에 쓰기
- AC-4702.1: Given 글자 색이 있는 안내문, When 그리면(미리보기·인쇄 사본·그림 파일), Then 'N월'·날짜 띠·카드 아래 글이 모두 그 색이고, 테마 그림·AI 배경(저장 전 만든 배경 포함)·내 배경 어느 것 위에서도 같다. 그 밖의 글자·카드·로고·배경 그림은 그대로다
- AC-4702.2: Given 글자 색이 없는 안내문(자동), When 그리면, Then 지금처럼 배경이면 배경 강조색, 아니면 테마 강조색이다(지금 그림과 글자 하나까지 같다)
- AC-4702.3: Given `Poster`가 받은 글자 색이 `#`+소문자 16진수 6자리 모양이 아니면, When 그리면, Then 그 값을 쓰지 않고 자동 색으로 그린다

### REQ-4703: 저장·열기
- AC-4703.1: Given 글자 색을 고른 안내문, When [저장]하면, Then 보내는 몸통에 `accent`(소문자 `#rrggbb`)가 들어가고, 자동이면 `accent: null`이 들어간다(칸이 빠지지 않는다)
- AC-4703.2: Given 저장한 안내문, When 열면, Then 그 글자 색(없으면 자동)으로 열리고, 글자 색을 바꾸면 '저장하지 않은 내용이 있어요'가 되며, 처음 색으로 되돌리면 사라진다. [새로 만들기]는 자동으로 시작한다
- AC-4703.3: Given 표에서 읽은 줄, When `accent`가 null이면, Then 글자 색 없는 안내문(자동)으로 읽고, 모양이 틀리면(대문자·3자리·`#` 없음 등) 그 줄을 읽지 않는다(지금 다른 칸 규칙과 같다)

### REQ-4704: DB 칸 (운영 SQL)
- AC-4704.1: Given 마이그레이션 `20261115030000_form_notices_accent.sql`, When 실행하면(두 번 실행해도), Then `form_notices`에 `accent text` 칸(null 또는 `^#[0-9a-f]{6}$`)이 있고, 로그인한 사용자는 이 칸을 넣고 고칠 수 있으며(칸 권한), 그 밖의 칸 권한·RLS 규칙은 그대로다
- AC-4704.2: Given 이 칸, When anon이 읽거나 쓰려 하거나, 다른 병원 줄의 글자 색을 고치려 하면, Then 막힌다. 모양이 틀린 값(대문자·`red`·8자리)은 DB가 거부한다

## 범위 밖
- '휴진' 글만 따로 색, 카드마다 다른 색, 'N월'과 날짜 띠를 다른 색으로
- 최근 고른 색 목록·색 이름 저장, 정해 둔 색 단추
- 환자 안내문(`form_guides`) 글자 색
- 옅은 색을 막기(경고만 한다)
