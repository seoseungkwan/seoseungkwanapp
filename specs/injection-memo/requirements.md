# 요구사항: 주사 차수 → 비트 접수메모(당일) 채우기

> 기능 ID `injection-memo` · REQ-7501~7506 · MVP 최소안. 결정: 기억 `injection-count-memo-plan.md`·`~/.claude/state/handoff/injection-memo.md`. 기준: 승인 시안 `docs/mockups/injection-memo/`(화면 글자는 notes.md 그대로), 규칙 근거 `notes/eval-30days.md`(지난 30일 314건: 번호 일치 255·완전 일치 124, 여유 3일), 화면 칸 `notes/reception-fields.md`, 엑스레이 부위·코드 `notes/xray-parts.md`.

## 배경
접수 직원이 비트 접수 화면에서 환자를 불러온 뒤, 원장님 증상 기록의 'N차 주사'를 보고 '접수메모(당일)'에 손으로 쓰던 것을 단추(또는 단축키) 한 번으로. PT 후 진료 종이 프로그램(`Precheck.PtSlip`)에 더한다. 비트 DB는 읽기만, 메모는 화면 칸에 글자로 넣고 저장은 직원이 한다. 우리 의원만, 접수 PC 여러 대.

## 요구사항

### REQ-7501: 차수 규칙
- AC-7501.1: Given 주사 차수 줄, When 메모 글을 만들면, Then `<좌우>)<부위·약> N차` — '주사' 말·차수 뒤 덧붙이('+ FNB' 등)·신경차단 이름(FNB·SNB·MBB·SSNB·ANB·TPI)은 빼고, 좌우는 `오)`·`왼)`·`양)`, 목·허리처럼 가운데 부위만이면 좌우 없음, 영어 부위 말은 우리말(neck→목, knee→무릎 …). 차수 앞말에서 부위·약 이름으로 읽히지 않는 말(전·많이·좋아지면·및 …)은 버린다. 앞말에 약 이름만 있으면 부위는 AC-7501.3 차례(주사 말 줄 → 다른 줄)로 찾아 `왼)무릎 DNA 2차`, 끝내 없으면 약 이름만. 앞말에 좌우가 있고 약 이름만인데 찾은 부위가 목·허리 같은 가운데 부위뿐이면 그 부위는 붙이지 않고 좌우를 남긴다(`양)아라간 2차` — 다른 주사(C-MBB 등)의 부위, 90일 대조에서 좌우가 빠지던 62건). 좌우 있는 부위와 같이 나오면 AC-7501.6대로 다 쓴다. 부위를 끝내 못 찾으면 좌우도 쓰지 않는다(2026-11-20 오후 바꿈: 90일 대조에서 부위를 빠뜨린 186건 중 105건이 약 이름만인 때)
- AC-7501.2: Given 차수 말, When 번호를 정하면, Then 그날 한 것은 +1, 다음 계획('N차 주사 합니다'·요일·간격·'다음')은 그대로, 번호가 둘이면 앞 번호, 'N차까지'만이면 30일 안 지난 접수 메모의 주사 차수 +1(그게 N을 넘으면 `끝남`, 지난 메모에 번호가 없으면 `기록 없음`)
- AC-7501.3: Given 환자의 오늘 앞 30일 내원들(날짜순 증상 줄·접수 메모), When 고르면, Then 주사 차수(ESWT·도수·충격파 빼고)가 적힌 **마지막** 내원 하나를 쓰고, 없으면 `기록 없음`. 부위는 차수 줄 앞말 → 없으면 같은 내원의 주사 말이 든 줄 → 그래도 없으면 다른 줄, 여러 개면 쉼표로
- AC-7501.4: Given 그 내원 기록에 간격(`숫자 + 주·주일·일·개월·달·wk·week + 뒤·후·간격·마다`)이 있으면, When 오늘이 (그 내원 날 + 간격) − 3일보다 앞이면, Then `일찍 옴`(계획 날짜와 함께), 간격이 없으면 넣는다
- AC-7501.5: Given 지난 30일 대조에서 나온 모양별 지어낸 예(notes 모양 그대로, 실제 글 아님), When 규칙을 돌리면, Then 예마다 정한 글·결과가 나온다
- AC-7501.6: Given 주사 부위가 둘 이상(예: 주사 말 줄 `Rt SSNB ANB + C-MBB`), When 글을 만들면, Then 모두 쓰되 좌우 있는 부위를 먼저, 목·허리 같은 가운데 부위는 뒤에, 좌우 말은 맨 앞 한 번(`오)어깨,목 3차`). 목 쪽 차단 주사 이름 C-MBB는 목, L-MBB는 허리, IMPAR·GANG는 꼬리뼈, CMC는 손가락으로 읽는다(CPB·PDNB·SPLINT는 부위로 안 읽음 — 대조에서 나빠짐이 더 많음, 2026-11-20 오후 더함, 90일 직원 메모 '오)어깨,목' 142건·규칙이 목을 빠뜨린 124건 중 116건이 C-MBB 줄 탓)

### REQ-7502: 비트 읽기
- AC-7502.1: Given 차트번호·오늘, When 읽으면, Then 허용 목록의 읽기 전용 SELECT 두 개(그 환자의 오늘 앞 30일 외래 내원과 접수 메모 `OcmRefCmt`, 그 내원들의 증상 줄 `EmrInf` `EmrShtTyp='S'`)를 `@cht`·`@from`·`@to` 매개변수로 5초 안에, 잇기는 메모리에서. 실패·시간 지남은 `읽기 실패`

### REQ-7503: 메모 넣기
- AC-7503.1: Given 메모 칸 글과 새 글, When 합치면, Then 비었으면 새 글, 있으면 `있던 글/새 글`, 이미 주사 'N차'가 있으면 안 넣고 `이미 있음`
- AC-7503.2: Given 비트 접수 화면이 맨 앞, Then '접수메모(당일)' 칸 오른쪽에 [주사 차수] 단추가 붙어 따라다니고 단축키(기본 F8)가 듣는다. 아니면 단추는 숨고 단축키는 놓는다. 누르면 화면 차트번호 칸을 읽어(비었으면 `환자 없음`) 계산하고, 넣을 때는 메모 칸 끝에 글자를 넣기만 한다(비트 DB 쓰기·저장 없음, 확인 창 없음). 칸·라벨은 `notes/reception-fields.md`대로 라벨 글로 찾는다. 칸이 꽉 차(50자)거나 잠겼거나 윈도우가 막으면 아무것도 넣지 않고 `넣지 못함`
- AC-7503.3: Given 결과, When 알리면, Then 2~3초짜리 작은 알림(넣었음·기록 없음·끝남·일찍 옴·이미 있음·환자 없음·읽기 실패·넣지 못함, [엑스레이] 알림은 AC-7505.4) 글은 시안 그대로. 환자 값·메모 글은 파일·로그에 남기지 않는다

### REQ-7505: 엑스레이 경과 (2026-11-20 더함, 오후에 [엑스레이] 단추로 바꿈)
- AC-7505.1: Given 오늘 앞 30일 모든 내원의 증상 줄(30일 안에 증상 줄 있는 내원이 없으면 그 전 마지막 내원 하나의 증상 줄, 기간 제한 없음), When 부위를 모으면, Then `notes/xray-parts.md` 표에 있는 부위 말(영어 부위 말 포함)을 '메모에 쓰는 부위'로 바꿔 나온 차례대로 중복 없이 모은다. 좌우는 가리지 않고, 표에 없는 부위와 설정에서 고르지 않은 엑스레이(AC-7505.5)의 부위는 보지 않는다. 한 글자 부위(발·손·목·등·팔)는 부위가 아닌 말(발생·발병·발현·발작·발급·발견·발적·발열·발기·발전·손상·손해·손톱·등산·등록·등급·등등·목욕·목발·목적·목표·목요일)의 첫 글자면 부위로 보지 않고, 붙여 쓴 '팔저림'·'목통증'은 부위로 본다(주사 차수 부위에도 같이). 좌우 말·다른 부위 말에 붙여 쓴 부위('양무릎'·'우측어깨'·'발뒤꿈치')도 부위로 본다
- AC-7505.2: Given 부위와 그 환자의 영상 처방 코드 앞 3글자별 마지막 날짜, When 판정하면, Then 무릎은 (오늘 − 1년), 다른 부위는 (오늘 − 2년)보다 뒤에 그 부위의 인정 코드가 하나라도 있으면 경과 아님, 없으면(아예 없어도) 경과
- AC-7505.3: Given [엑스레이]를 눌렀을 때의 메모 칸 글과 경과 부위들, When 넣을 글을 만들면, Then 칸 글의 마지막 '/' 뒤 조각에 주사 'N차'가 있고 그 조각의 부위가 하나이며 경과면 그 뒤에 띄어 `xr1년경과`(무릎)·`xr2년경과`(그 밖), 나머지 경과 부위는 `<부위> xr1년경과`·`<부위> xr2년경과`를 띄어 나온 차례대로 붙인다. 마지막 조각이 주사 차수가 아니면 `<부위> xrN년경과 …`를 MemoMerge 규칙(빈 칸은 그대로, 글이 있으면 '/')으로 붙인다. 칸에 이미 `xr`(대소문자 무시)이 있으면 `엑스레이 이미 있음`, 경과 부위가 없으면 `경과 없음`. 합친 칸 글이 50자를 넘으면 뒤쪽 경과 조각부터 빼서 맞추고, 하나도 안 들어가면 넣지 못함(직접 적을 글)
- AC-7505.4: Given 접수 화면, When 보이면, Then [엑스레이] 단추는 [주사 차수] 바로 오른쪽에 붙어 같이 움직이고 같이 숨는다. [주사 차수]·단축키는 엑스레이를 보지 않고(주사 차수만), [엑스레이]를 누를 때만 경과를 넣는다. 알림은 시안 글 그대로(넣음 초록, 경과 없음·이미 있음 노랑, 환자 없음·읽기 실패·넣지 못함 빨강)
- AC-7505.5: Given 설정, When 읽으면, Then '메모에 넣을 엑스레이'는 `notes/xray-parts.md` 표의 20개 부위 가운데 고른 것들(처음엔 팔·허벅지·다리·종아리만 끔). `memo-settings.json`에 함께 두고, 모르는 부위 이름은 버리며, 깨진 값은 처음 값. PT 종이 설정 창 맨 아래 묶음에서 체크로 고른다(칸마다 찍은 것으로 치는 처방 이름)

### REQ-7506: 영상 처방 읽기 (2026-11-20 더함)
- AC-7506.1: Given 차트번호·오늘, When 읽으면, Then 허용 목록의 읽기 전용 SELECT 하나(`OdrInf`, `OdrIncCod=30`, 삭제·취소 아님, `LTRIM(RTRIM(OdrChtNum))=@cht`, `@from`(오늘 − 2년) ≤ `OdrDtm` < `@to`(오늘))로 코드 앞 3글자별 마지막 날짜를 DB 안에서 묶어 5초 안에 읽는다. 30일 안에 증상 줄 있는 내원이 없을 때만 SELECT 하나 더(그 환자의 `@from` 전 외래 내원 중 증상 줄 있는 마지막 하나의 `EmrInf` `EmrShtTyp='S'` 줄). [엑스레이]를 누를 때만 읽고, 실패·시간 지남이면 `읽기 실패`

### REQ-7504: 설정
- AC-7504.1: Given 설정 없음, When 읽으면, Then 단축키 F8·단추 자리 0. 단축키는 F4·F8·F10·F11만(비트가 쓰는 F1·F2·F3·F5·F6·F7·F9·F12 안 됨), 단추 자리 -400~400px. `%LOCALAPPDATA%\PtSlip\memo-settings.json`, 깨진 파일은 기본값. PT 종이 설정 창 맨 아래 주사 차수 묶음에서 고친다
- AC-7504.2: Given 비트가 관리자 권한으로 돈다(이 PC 확인), When 설치하면, Then 관리자 '예'를 한 번만 받아 로그온 때 PT 종이 프로그램을 높은 권한으로 켜는 예약 작업을 등록하고(그 뒤 묻는 창 없음, 옛 시작프로그램 바로가기는 지움), 지우기는 그 예약 작업도 지운다
