# 요구사항: 통계 기간 고르기 (일별·주별·월별 + 달·해 고르기 + 직접 날짜, 바로 전·작년 비교)

> 기능 ID: `stats-period` · 형식: 요구사항은 `### REQ-1701: 제목`, 수용 기준은 `- AC-1701.1: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다.
> 사용자: "계획은 최소화해" — 짧게 쓴다. 시험의 오늘은 `2026-11-06`(금), 어제는 `2026-11-05`다.

## 배경 / 목표
- 통계 탭은 지금 [최근 7일][최근 30일][최근 90일][최근 12개월]만 있다. 총괄은 "10월"처럼 딱 정한 달·해를 일별·주별·월별로 보고, 바로 전 기간과 작년 같은 기간을 함께 견주고 싶다
- 승인 시안: 디자인 캔버스 `BEpX6zDbmmBmvBhZqCKmno`(PC 일별·주별·월별·직접 날짜, 휴대폰 일별·월별·직접 날짜). 숫자는 지어낸 것이다
- 서버 표·API·마이그레이션을 더하지 않는다. 저장된 일 숫자(`readDays`)·덮은 기간(`readCoverage`)·비트 불러오기를 그대로 쓴다

## 이미 정한 것 (다시 묻지 않는다)
1. 빠른 단추 넷은 그대로이고 지금과 똑같이 셈한다(비교 하나). 옆에 [일별][주별][월별] + `◀ 2026년 10월 ▶`(월별은 `◀ 2026년 ▶`) + [직접 날짜]
2. 비교는 둘: 바로 전 기간(10월 → 9월, 직접 날짜 → 바로 앞 같은 날 수)과 작년 같은 기간(작년 10월, 직접 날짜 → 작년 같은 날짜). 월별(해)은 둘이 같아 하나(2025년)
3. 통계 탭 전체가 고른 기간을 따른다. 원장님 보고 문장에는 [고른 기간 보고]를 맨 앞에 더하고 옛 넷은 그대로 둔다
4. 한 주는 월–일. 기간 끝에서 잘린 주·끝나지 않은 달은 '일부 기간'. 끝나지 않은 기간은 같은 날까지만 견준다(11월 1–5일 ↔ 10월 1–5일 ↔ 작년 11월 1–5일). 직접 날짜 일별은 92일까지. 끝 < 시작은 오류. 앞으로 올 달·해·날은 못 고른다. 자료 없는 기간·비교는 '–'와 "자료가 없어요"이고 0이 아니다. 휴진한 날은 막대가 없다
5. 끝난 날: 오늘은 '오늘 진료 끝'으로 저장했을 때(덮은 기간에 오늘이 듦)만, 아니면 어제까지
6. 처음 열면 최근 30일이고, 고른 것은 저장하지 않는다. 휴대폰은 한 줄씩 전체 폭·44px, 직접 날짜 판은 단추 바로 아래에 붙는다
