# 비트(DrBIT) → ERP 마감일지 칸 후보 제안표

조사일 2026-11-10. **비트 DB는 읽기만 했다**(SELECT만, READ UNCOMMITTED 트랜잭션은 끝에 되돌림, 접속은 도우미와 같은 방식 = `BITDataBaseCommon.bitGetConnection`).
결과는 코드·코드 이름·칸 이름·합계 숫자만 적었다(환자 이름·차트번호·주민번호·연락처·생년월일은 읽어 내보내지 않음).

- "최근 60일" = 2026-09-11 ~ 2026-11-10 접수. 기준 내원 = 외래(`OcmPatTyp='O'`)·접수취소 아님(`OcmRsuYon<>'O'`)·진료 끝난 상태(`OcmComStt IN (HN,PN,TN,VN,OE,WN,OB)`). 도우미의 기존 조건과 같다. 처방은 `OdrDelFlg='N' AND OdrCanYon='N' AND OdrOutCod<>'99'`.
- 표의 "줄/내원/환자/날" = 처방 줄 수 / 내원 수 / 서로 다른 환자 수 / 처방이 나온 날 수 (60일 합계).
- 확신 정도: **확실** = DB 값이나 비트 자체 화면 코드로 직접 확인함. **추정** = 이름·쓰임새를 보고 짐작함. **모름** = 비트에 근거가 없음.
- 근거 파일: 시험 프로그램 `q.cs`/`q.exe`(SELECT만 통과시키는 검사 포함), 질의 `q1.sql`~`q9.sql`, 결과 `o1.tsv`~`o9.tsv`(모두 이 폴더). 비트 수납집계 화면(BITReceiptSummary) 코드 풀이 = `..\out\rcpsum_all.txt`.

## 사용자에게 물어볼 것
1. 리푸스·손발톱케어·CT는 비트에 코드가 없다. 비트 밖(종이·다른 장비)에서 하는가, 다른 이름으로 처방하는가?
2. 수술: `+op 수술료` 묶음 11개 코드로 셀까? 창상봉합(SB021)·골절 도수정복(N05~N07)도 넣을까?
3. ESWT Standard/Radial: 장비가 몇 대이고 타수 코드(2000/3000/4000/6000타)와 장비가 맞물리는가? 아니면 비트로는 못 가른다.
4. 주사: '주사'에 LA 신경차단·KK 관절강내·PROLO 증식치료를 넣을까? 약만 놓은 날도 넣을까? '주사1회환자'는 '그날 1부위만'인가 '처음 맞은 환자'인가? '신환주사건수'는 부위(처방 줄) 수인가?
5. 도수: 비급여 MA4(30분)도 도수에 넣을까? 코드 '.'(도수상담)을 ERP 도수상담으로 쓸까? MS11(199원, 늘 MM010과 함께)은 무엇인가?
6. 물리치료내원: 비트 진찰구분 '7 물리치료내원'은 안 쓴다. '진찰료 산정안함 + 물리치료 처방'으로 셀까?
7. 감액·MOU 감액: 비트 할인 기능은 2024-05 이후 안 쓴다. 지금은 어떻게 깎아 주는가(가격 낮춘 코드, '-S' 이벤트 코드, 안 함)?
8. 환불: 비트 환불(TPR) 기록이 한 번도 없다. 환불은 어떻게 처리하는가? 수납 변경(TFC) 음수를 환불로 볼까?
9. 진료수납액: 그날 진료비로 받은 돈(현금+카드+계좌)만인가, 미수입금까지 넣는가?
10. 예약: 주사·경과·진료예약은 어디서 받는가(똑닥·종이 등)? 비트에 없으면 빈칸으로 둘까? '변경'을 예약 변경 기록(2026-07부터)으로 셀까?
11. 신환경로: 비트 내원경로 칸(목록 '소개' 하나)을 접수 때 채우게 할까, ERP에 손으로 넣을까?
