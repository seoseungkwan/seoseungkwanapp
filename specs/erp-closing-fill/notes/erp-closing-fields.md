## 5. '자동' 표시와 '파일 값' 표시 모양 (확실)

- **자동 표시**(업무일지 1 칸 이름 옆, 업무일지 2는 '연령별' 제목 옆): `<span class="af-badge" aria-label="자동 입력 - (출처)(파일명) 파일에서 자동으로 채운 칸입니다. 고쳐 저장하면 직접 입력 값으로 바뀌고, 같은 파일을 다시 올려도 바꾸지 않습니다.">자동</span>`. 고치고 저장 전이면 흐리게(투명도 0.45), 마우스를 올리면 '(저장하지 않은 수정 - 저장하면 직접 입력 값)'.
  - 출처 이름: 일일집계, 기간별통계, 소모통계, 일일 환자현황, 의사랑 …
- **파일 값 표시**(입력칸 아래 작은 글): `<span class="af-note af-note--diff">파일 값 1,234</span>` = 파일에서 계산한 값이 저장값과 다를 때. 마우스 올리면 '… 값과 저장값이 다릅니다 - 입력한 값은 바꾸지 않았습니다'. SONO는 '파일 값 N · 처방 N' 꼴.
  - 그 밖의 안내 글: `af-note--ref`(회색 참고, 예: '파일 할인액 N원', '물리치료내원 · 진찰료 산정안함 제외'), `af-note--warn`(빨강 경고, 예: '환불 N건 - 금액 확인', '…미연결 코드… 처방 항목에 연결하면 자동으로 채워집니다' + '연결하러 가기' 링크).
- 업무일지 2 연령표 다를 때: '기간별통계 파일 값과 다른 칸: 20대 신환 3 · …'.
- 업무일지 2 고정 표시: `span.cdf-fill-tag` '업로드 시 생략 가능'(씨암·SONO·도수·충격파 금액).
- 고쳤지만 저장 안 한 업무일지 1 칸은 테두리가 주황(`--color-status-warn`)으로 바뀌고 그 줄 '이 항목만 저장' 단추가 진해짐.

## 6. 화면 만든 방식과 값 넣는 법

| 항목 | 내용 | 확실/추정 |
|---|---|---|
| 도구 | React 18.3.1 (Vite로 묶음, `div#root`), React Router v6, axios, 날짜는 react-datepicker | 확실 |
| 칸 관리 방식 | 모든 칸이 React '통제 칸'(value를 React가 쥐고 onChange로만 바꿈). 그냥 `el.value = 5`만 하면 화면엔 보여도 React 기억에 안 들어가 저장 때 빠짐 | 확실 |

| 금액칸(`input.money-input`) | 자체 제작 칸. onChange 때 이전 표시값과 새 값을 비교해 숫자만 남기고 쉼표를 다시 붙임, `beforeinput`·커서 위치·한글 입력 상태도 봄. 위 방법(값 설정 + input 이벤트)으로도 계산상 맞게 들어감. 더 안전하게는 ① 먼저 '' 로 비우고 input 이벤트 ② 숫자만(쉼표 없이) 넣고 input 이벤트 ③ `blur()` (떠날 때 표시 정리). 또는 칸에 focus → 전체 선택 → `document.execCommand('insertText', false, '123456')` (진짜 타자와 같은 길) | 추정(코드 분석, 실측 못함) |

| 날짜칸 | react-datepicker 글자칸. 값 설정 + input 이벤트로 바뀔 가능성 있으나 실측 못함. 1절의 pushState 방법이 대안 | 추정 |

## 9. 참고: ERP가 이미 받는 비트 파일 ('파일 업로드' 메뉴, 확실)

왼쪽 메뉴 '파일 업로드'(창으로 열림)에 비트 관련 종류가 이미 있음. 새 확장 프로그램이 같은 칸을 겹쳐 채우지 않게 설계 때 고려할 것.
- '업무일지 금액(비트 일일집계)': 그날 업무일지 1 **외래 수입·카드·현금·계좌 칸 중 빈 칸**을 채움(외래환자분석엔 저장 안 함). 나중에 기간별통계(외래완료)를 올리면 바뀜.
- 'EMR 외래 목록'(비트): 업무일지 환자 칸(신환·90일초진·재진…)을 채움. 비트의 물리치료내원·진찰료 산정안함은 재진으로 셈.
- 'EMR 소모통계': 씨암·SONO·도수치료·체외충격파·관절조영 건수와 업무일지 2 치료별 매출의 씨암·SONO·도수·충격파 금액(처방 항목에 코드가 이어진 경우 관절조영·물리치료·기타1~4 금액도).
- 업로드로 **안 채워지는 것**(직접 입력 필요, 화면 안내문 그대로): 운영 지표의 치료사별 건수 · ESWT · 주사 칸, 이벤트 진행, 특이사항.

## 10. 막힌 점·남은 확인
