# 요구사항: 환자 서류 한 번에 인쇄

> 기능 ID `doc-print` · REQ-7401~7406 · MVP 최소안. 기준: 승인 시안 `docs/mockups/doc-print/`(화면 글자는 notes.md 그대로), 서류 모양은 비트 견본 PDF(이 PC에만, 저장소에 안 넣음), 비트 칸은 `notes/bit-docs.md`.

## 배경
비트에서 서류마다 메뉴를 따로 들어가 기간 출력하던 것을, PT 후 진료 종이 프로그램(`Precheck.PtSlip`)의 [서류] 단추 하나로: 환자 → 기간·날짜 → 서류 체크 → [인쇄]. 비트 DB는 읽기만. 우리 의원만.

## 요구사항

### REQ-7401: 설정·기록
- AC-7401.1: Given 설정 없음, When 읽으면, Then A4 프린터 빈칸(=윈도우 기본 프린터), 묶음 `실손보험용`=[진료비 영수증, 진료비 세부내역서, 진료확인서] 하나, 용도 `보험회사 제출용, 회사 제출용, 학교 제출용`
- AC-7401.2: Given 묶음·용도 글, When 바꾸면, Then 빈 이름·겹침은 빼고 묶음은 1~8개·이름 1~10글자·서류 1개 이상, 용도는 1~10개·1~20글자만. JSON으로 쓰고 읽으면 같은 값, 깨진 파일은 기본값
- AC-7401.3: Given 인쇄를 보냄, When 기록하면, Then `%LOCALAPPDATA%\PtSlip\doc-log.tsv`에 날짜·시각·차트번호·이름·서류 이름들·기간·장 수 한 줄(접수 PC 안에만). [뽑은 기록 보기]는 최근 것부터

### REQ-7402: 환자 찾기
- AC-7402.1: Given [서류]를 누름, When 비트에서 보던 환자의 차트번호를 알 수 있으면, Then 그 환자가 채워지고, 모르면 빈 칸에 커서
- AC-7402.2: Given 찾기 글, When 숫자만이면 차트번호(앞 0 빼고 1~14자리), 아니면 이름(2글자 이상)으로 비트 DB를 매개변수로 읽기만 하고(5초), Then 한 명이면 바로 채우고, 여러 명이면 생년월일·성별·마지막 내원일로 고르는 목록, 없으면 `찾는 환자가 없어요`, 오류면 `비트에서 환자를 읽지 못했어요. 비트가 켜져 있는지 봐 주세요.`

### REQ-7403: 기간·날짜
- AC-7403.1: Given 오늘 날짜, When 빠른 단추를 누르면, Then 오늘·이번 달(1일~오늘)·지난 달(1일~말일)·최근 3개월(오늘-3개월+1일~오늘)·전체(첫 내원~오늘)
- AC-7403.2: Given 기간, When 내원을 읽으면, Then 외래 내원 날짜를 오래된 것부터, 다 체크. 수납 전인 날은 `수납 전`으로 표시하고 체크를 풀어 둔다. 같은 날 두 번은 한 줄(서류는 그날 내원 모두)

### REQ-7404: 서류 고르기
- AC-7404.1: Given 묶음 단추, When 누르면, Then 6개 체크가 그 묶음 서류만 켜진 상태로 바뀐다
- AC-7404.2: Given 통원확인서나 진료확인서가 켜짐, When 고른 날짜의 상병을 읽으면, Then 병명 목록(코드·이름, 겹침 없이)에 주상병만 체크, 용도는 첫 용도(직접 쓰기 가능, 1~20글자)
- AC-7404.3: Given 고른 날짜·서류, When 장 수를 세면, Then 영수증은 날짜마다 1장, 처방전은 처방 있는 날만, 나머지는 그린 쪽 수. [인쇄]는 날짜 1개·서류 1개 이상이고 확인서면 병명 1개 이상일 때만

### REQ-7405: 서류 자료 읽기
- AC-7405.1: Given 환자·날짜, When 서류 자료를 읽으면, Then `notes/bit-docs.md`의 표·칸만 읽기 전용 매개변수 문장(허용 목록)으로 읽어 서류 6종 각각의 값 묶음(병원 정보·환자·날짜별 금액·항목·상병·처방·진료 기록)을 만든다
- AC-7405.2: Given 금액, When 합계를 내면, Then 원 단위 정수, 항목 금액의 합(반올림 없음)이 견본과 같다

### REQ-7406: 그리기·인쇄
- AC-7406.1: Given 값 묶음, When A4에 그리면, Then 서류마다 견본 PDF와 같은 칸·글자 자리·직인 그림 자리(가짜 값 PDF를 견본 옆에 놓고 맞춤). 영수증은 날짜마다 한 장, 세부내역서·확인서는 비트 기간 출력 모양, 처방전·진료기록부는 날짜마다
- AC-7406.2: Given [인쇄], When 설정 프린터로 대화상자 없이 보내면, Then 서류별로 묶어(진료비 영수증 → 세부내역서 → 통원확인서 → 진료확인서 → 처방전 사본 → 진료기록부, 서류 안은 날짜순) 한 인쇄 작업으로 보내고 `n장 보냈어요`, 실패면 창을 두고 `프린터로 보내지 못했어요(<프린터 이름>). 프린터가 켜져 있고 종이가 있는지 보고 다시 눌러 주세요.`
- AC-7406.3: Given PT 종이 단추, When 비트 창이 맨 앞이면, Then [서류] 단추가 [PT 먼저] 왼쪽에 붙어 같이 움직이고 같이 숨는다. 환자 값은 기록 파일 말고는 파일·로그에 안 남긴다
