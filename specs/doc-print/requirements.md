# 요구사항: 환자 서류 한 번에 인쇄

> 기능 ID `doc-print` · REQ-7401~7406 · MVP 최소안. 기준: 승인 시안 `docs/mockups/doc-print/`(화면 글자는 notes.md 그대로), 서류 모양은 비트 견본 PDF(`바탕화면\서승관웹앱\서류견본`, 이 PC에만·저장소에 안 넣음), 비트 칸은 `notes/bit-docs.md`.

## 배경
비트에서 서류마다 메뉴를 따로 들어가 뽑던 것을 PT 후 진료 종이 프로그램(`Precheck.PtSlip`)의 [서류] 단추 하나로: 환자 → 기간·날짜 → 서류 체크 → [인쇄]. 서류 4종: 진료비 영수증·진료비 세부내역서·처방전 사본·진료기록부. 비트 DB는 읽기만. 우리 의원만.

## 요구사항

### REQ-7401: 설정·기록
- AC-7401.1: Given 설정 없음, When 읽으면, Then 서류 프린터 빈칸(=윈도우 기본 프린터), 묶음 `실손보험용`=[진료비 영수증, 진료비 세부내역서] 하나. PT 종이 설정 값은 그대로
- AC-7401.2: Given 묶음, When 바꾸면, Then 이름 앞뒤 빈칸을 빼고 1~10글자·겹침 없음·서류 1개 이상, 묶음 1~8개만. JSON으로 쓰고 읽으면 같은 값, 깨진 파일은 기본값
- AC-7401.3: Given 인쇄를 다 보냄, When 기록하면, Then `%LOCALAPPDATA%\PtSlip\doc-log.tsv`에 날짜·시각·차트번호·이름·서류 이름들·기간·장 수 한 줄(탭·줄바꿈은 빈칸으로). [뽑은 기록 보기]는 최근 것부터, 차트번호·이름으로 거른다

### REQ-7402: 환자 찾기
- AC-7402.1: Given [서류]를 누름, When 맨 앞 비트 창 제목의 `차트번호 :` 뒤 숫자를 읽을 수 있으면(숫자만 꺼내고 제목은 저장·로그 안 함), Then 그 차트번호 환자가 채워지고 `비트에서 가져옴` 표시, 못 읽으면 빈 찾기 칸에 커서
- AC-7402.2: Given 찾기 글, When 숫자만이면 차트번호(앞 0 빼고 1~14자리), 글자가 있으면 이름(앞뒤 빈칸 빼고 2~20글자)으로 비트 DB를 매개변수로 읽기만 하고(5초), Then 한 명이면 바로 채우고, 여러 명이면 생년월일·성별·마지막 내원일 목록(마지막 내원일 최근 순)에서 고르고, 없으면 `찾는 환자가 없어요`, 오류면 `비트에서 환자를 읽지 못했어요. 비트가 켜져 있는지 봐 주세요.`

### REQ-7403: 기간·날짜
- AC-7403.1: Given 오늘, When 빠른 단추를 누르면, Then 오늘·이번 달(1일~오늘)·지난 달(1일~말일)·최근 3개월(오늘의 3개월 전 다음 날~오늘)·전체(첫 내원~오늘). 창을 열면 이번 달
- AC-7403.2: Given 기간, When 내원을 읽으면, Then 외래 내원(`OcmPatTyp='O'`, `OcmRsuYon<>'O'`, 취소 빼고) 날짜를 오래된 것부터 한 날 한 줄로, 다 체크. 그날 내원이 하나라도 수납 전(`OcmComStt<>'PN'` 또는 영수증 줄 없음)이면 `수납 전` 표시·체크 풀림, 처방전 있는 날은 `처방` 표시

### REQ-7404: 서류 고르기·장 수
- AC-7404.1: Given 묶음 단추, When 누르면, Then 4개 체크가 그 묶음 서류만 켜진 상태가 된다
- AC-7404.2: Given 고른 날짜·서류, When 장 수를 세면, Then 서류마다 그린 쪽 수(영수증은 날짜마다, 처방전은 처방 있는 날만)와 모두 N장. [인쇄]는 날짜 1개·서류 1개 이상이고 N>0일 때만

### REQ-7405: 서류 자료 읽기
- AC-7405.1: Given 차트번호·날짜들, When 서류 자료를 읽으면, Then `notes/bit-docs.md`의 표·칸만 허용 목록의 읽기 전용 매개변수 문장으로 읽어 병원 정보(`HspMst`·직인 그림)·환자·날짜별 영수증 금액(`OrpInf`·`OdlInf`·`OrcInf`)·세부 줄(`OdrInf`, 원외약 빼고)·처방전(`OutInf`·원외약 줄)·진료 기록(`EmrInf`·상병·처방·수납) 값 묶음을 만든다. 금액은 비트에 저장된 값을 그대로 쓰고 다시 셈하지 않는다(원 단위 정수)

### REQ-7406: 그리기·인쇄·단추
- AC-7406.1: Given 값 묶음, When A4에 그리면, Then 서류마다 견본 PDF와 같은 칸·글자 자리(직인 그림은 견본에 있는 자리만, 진료기록부 도장은 그리지 않음). 같은 환자·날짜를 이 PC에서 PDF로 뽑아 견본과 금액·글자가 같다
- AC-7406.2: Given [인쇄], When 서류 프린터로 대화상자 없이 보내면, Then 서류별로 묶어(진료비 영수증 → 진료비 세부내역서 → 처방전 사본 → 진료기록부, 서류 안은 날짜순) 한 인쇄 작업으로 보내고 기록을 남긴 뒤 창을 닫는다. 실패면 창을 두고 `프린터로 보내지 못했어요(<프린터 이름>). 프린터가 켜져 있고 종이가 있는지 보고 다시 눌러 주세요.`
- AC-7406.3: Given PT 종이 단추가 뜨는 때, Then [서류] 단추가 [PT 먼저] 왼쪽에 붙어 같이 움직이고 같이 숨는다. 설정은 탭 `PT 종이`·`서류`·`단추 자리`. 환자 값은 기록 파일 말고는 파일·로그에 안 남긴다

## 범위 밖
