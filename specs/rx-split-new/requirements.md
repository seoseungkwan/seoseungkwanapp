# 요구사항: 처방별 신환·재진: 우리 병원 첫 방문 날만 신환

> 기능 ID: `rx-split-new` · 형식: 요구사항은 `### REQ-001: 제목`, 수용 기준은 `- AC-001.1: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다.

## 배경 / 목표
- 통계 화면 '처방별 신환·재진' 표(30일 기간)의 재진진찰료 줄에 신환 60명이 나왔다. 지금 `rxVisitSplit`은 우리 병원 최초 내원일(f)이 기간 첫날 이후인 환자를 기간 내내 신환으로 센다. 그래서 기간 안에 처음 오고 다시 온 환자가 다시 온 날 받은 재진진찰료도 신환에 든다
- f = 도우미가 비트에서 읽는 '같은 병원 유효 외래·입원 첫 내원일'(`helper/src/Precheck.Core/Stats/StatsReport.cs:194`). 못 찾으면 도우미가 null을 주고 Worker는 `''`로 둔다(`helperData.ts:365`)
- **사용자 결정(2026-11-12)**: "우리병원 방문자체가 처음이면 신환으로해". 예시 확인: 환자 A가 10/15 우리 병원에 처음 오고(초진진찰료) 10/20 다시 오면(재진진찰료), 30일 표의 재진진찰료 줄에서 A는 **재진**이다(사용자 선택 "재진으로"). 사용자 말: "처방받은날이 아니라 아예 우리병원 최초내원" — 기준은 비트 기록상 우리 병원 최초 내원일(f)이다
- 목표: 처방 줄마다 '그 처방을 받은 방문이 우리 병원 최초 내원일(f)의 방문이었나'로 나눈다. 우리 병원 최초 내원일(f)에 받은 처방이면 신환, 아니면 재진

## 요구사항

### REQ-3801: 기간 처방 줄은 우리 병원 최초 내원일(f)에 받은 처방만 신환으로 센다
- AC-3801.1: Given 기간 2026-10-01~2026-10-30, 환자 A의 f가 2026-10-15이고 진료 줄이 10-15 처방 X(초진진찰료 자리의 가짜 코드)·10-20 처방 Y(재진진찰료 자리의 가짜 코드), When `rxVisitSplit`, Then X 줄은 신환 1·재진 0, Y 줄은 신환 0·재진 1이다
- AC-3801.2: Given 환자 A가 같은 처방 X를 기간 안 f 날과 그 뒤 다른 날 모두 받은 진료 줄, When `rxVisitSplit`, Then X 줄은 신환 1·재진 0·합계 1이다(한 환자는 한 줄에서 신환이나 재진 한쪽에만, 합계 = 서로 다른 환자 수). '고른 처방 중 하나라도' 줄도 같다: f 날 진료 줄이 하나라도 있는 환자는 신환, f가 기간 안이어도 f 날 진료 줄이 없고 다른 날만 있는 환자는 재진이다
- AC-3801.3: Given f가 빈 글자인 줄, f가 기간 첫날 전인 환자의 줄, When `rxVisitSplit`, Then 모두 재진이다(지금 규칙 그대로)
- AC-3801.4: Given 도우미 답의 진료 줄(AC-3801.1과 같은 모양, 다른 환자 몇 명)과 날짜별 합계, When `splitJob`으로 30일 기간을 고르면, Then Y 줄은 신환 0·재진 1이고, 머리 줄 숫자(`visits`·`patients`·`newPatients`·`returning`, `headline`)와 날짜별(`days`) 결과는 지금 규칙으로 낸 값과 같다

### REQ-3802: 원본과 일부러 다른 곳을 골든 머리 knownDiffs에 적는다
- AC-3802.1: Given `rx-visit-split-summary.json`·`rx-visit-split-text.json`, When 골든 시험, Then 머리 `knownDiffs`에 이 차이(`what`·`why`·`cases`) 한 줄이 있고 `cases`에는 숫자가 바뀌는 사례 `five-codes`만 있다(요약은 '도수' 줄 신환 0·재진 2·합계 2, '고른 처방 중 하나라도' 줄 신환 3·재진 4·합계 7 / 글은 그 두 줄이 바뀐 `text`). 적은 사례·칸만 적은 값과 견주고 나머지는 원본 결과와 순서까지 같다. 골든 몸통(`cases[]`의 원본 결과)과 `rx-visit-split-days.json`은 바꾸지 않는다

## 범위 밖

- 머리 줄의 기간 신환 수(날짜별 신환 합)와 날짜별 표(`rxVisitSplitDays`, 이미 '그날이 f인 환자'가 신환)
