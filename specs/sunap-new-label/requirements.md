# 요구사항: 수납일지 '초진' 글을 '신환'으로

> 기능 ID: `sunap-new-label` · 형식: 요구사항은 `### REQ-001: 제목`, 수용 기준은 `- AC-001.1: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다.

## 배경 / 목표
- 2026-11-17 사용자(수납일지 장부·카드 사진 둘): "초진은 다 신환으로 바꿔".
- 앱의 다른 화면(대시보드·통계)은 이미 '신환'이라 쓰고, 수납일지와 통계 탭의 수납일지 칸만 '초진'이라 쓴다. 뜻(그날이 첫 내원일)과 숫자는 그대로, 보이는 글자만 바꾼다. '90일초진'은 다른 뜻이라 그대로 둔다.

## 요구사항

### REQ-5601: 보이는 '초진'을 '신환'으로
- AC-5601.1: Given 수납일지 화면, When 그리면, Then 장부 구분 칩·고르기 판 머리의 구분(`VISIT_LABEL.new`)은 `신환`, 거르기 칩은 `신환 N`, 내원 카드 줄은 `신환`, 예약 카드는 `신환 예약률`·`신환 N명 중 M명 · …`·`신환+Block`이다
- AC-5601.2: Given 원장님별 표(수납일지·통계 탭 같은 부품), When 그리면, Then 칸 제목은 `원장님`·`내원`·`신환`·`90일초진`·`Block`·`물리치료`·`신환+Block`·`90일+Block`·`재진+Block`이고 아래 글은 `신환·90일초진·Block·물리치료 % = 그 원장님 내원 중`, `신환+Block % = 신환 중 · 90일+Block % = 90일초진 중 · 재진+Block % = Block 받은 사람 중(엑셀과 같음)`이다
- AC-5601.3: Given 통계 탭 수납일지 칸, When 그리면, Then `신환 예약률`·`신환`·`신환+Block`이고 [어떻게 세나요?]의 Block 줄은 `신환+Block % = 신환 중 · 90일+Block % = 90일초진 중 · 재진+Block % = Block 받은 사람 중(엑셀과 같음)`이다
- AC-5601.4: Given 수납일지 설정 판, When 그리면, Then 다음 예약 종류 설명 둘째 줄은 `예약률 ○ 넣음인 종류만 신환·90일 예약률에 세요. 주사치료·진료(경과)·기타는 기본 종류라 이름은 바꿀 수 있지만 지울 수는 없어요.`이고, 수납일지 화면과 통계 탭 수납일지 칸 어디에도 '90일초진'이 아닌 '초진' 글자가 없다
