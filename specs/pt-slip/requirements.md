# 요구사항: PT 후 진료 종이 뽑기

> 기능 ID `pt-slip` · REQ-6401~6403 · MVP 최소안. 기준: 승인 시안 `docs/mockups/pt-slip/`(notes.md의 결정 전부), 화면 글자는 시안 그대로.

## 배경
접수 PC 비트 창에 붙은 [PT 먼저] 버튼 → 차트번호·항목·부위 고르기 → 빅솔론(폭 100mm 롤)에 'PT 후 진료' 종이 1장. 새 PC 프로그램 `Precheck.PtSlip`. 웹앱·도우미·접수현황은 안 고친다.

## 요구사항

### REQ-6401: 설정·목록
- AC-6401.1: Given 설정 파일 없음, When 읽으면, Then 항목 `HP, ICE, ICT, 초음파, 레이저, 견인, 도수, 충격파`, 부위 `목, 어깨, 팔꿈치, 손목, 허리, 골반, 무릎, 발목`, 프린터 빈칸, 종이 길이 60mm, 버튼 자리 0
- AC-6401.2: Given 목록 글(한 줄에 하나), When 바꾸면, Then 빈칸·빈 줄·겹침을 빼고, 1~10글자 아님·`,` 포함·부위에 `오른/왼/양`인 줄은 줄 번호와 함께 거절, 1~16개만. 종이 길이 40~150mm, 버튼 자리 -400~400px만
- AC-6401.3: Given 설정, When JSON으로 쓰고 읽으면 같은 값, 깨진 파일은 기본값

### REQ-6402: 고르기·이름 찾기
- AC-6402.1: Given 차트번호 글, When 정리하면, Then 숫자만·앞의 0 빼고 1~14자리만 찾는다
- AC-6402.2: Given 항목·부위 버튼, When 누르면, Then 항목은 켜고 끄며, 쪽(오른·왼·양)을 누른 뒤 부위를 누르면 `오른 어깨`로 들어가고 쪽은 풀린다. 겹치면 안 들어가고 ✕로 뺀다. 종이 글은 누른 차례로 `, `로 잇는다
- AC-6402.3: Given 번호, When 비트 DB를 읽으면, Then `dbo.PbsInf`의 `LTRIM(RTRIM(PbsChtNum))=@cht`인 이름을 매개변수로 읽기만 하고(5초), 글은 빈칸 `차트번호를 넣으면 이름이 나와요` · 찾음 `<이름>` · 없음 `없는 차트번호예요` · 오류 `비트에서 이름을 읽지 못했어요. 비트가 켜져 있는지 봐 주세요.`
- AC-6402.4: Given 결과, When [뽑기] 상태를 정하면, Then 이름을 찾았을 때만 눌린다(항목·부위는 비어도 됨)

### REQ-6403: 종이·프로그램
- AC-6403.1: Given 폭 100·길이 L(mm), When 그리면, Then 여백 4mm, 줄 높이 머리 26%·부위 20%·항목 20%·특이사항 나머지, 이름표 칸 30%. 머리 `PT 후 진료 ( <차트번호> / <이름> )`, 특이사항은 늘 빈칸. [시험 1장]은 빈 양식
- AC-6403.2: Given 긴 글, When 칸에 맞추면, Then 큰 글씨부터 줄여 한 줄, 안 되면 두 줄, 그래도 넘치면 최소 크기에서 `…`
- AC-6403.3: Given 비트 프로그램(`BIT`·`DrBIT`로 시작 또는 `pBITNewMenu`, `DrBitExport` 제외)의 가로 600px 이상 창이 맨 앞일 때, Then 버튼이 그 창 오른쪽 끝에서 150px+버튼 폭+버튼 자리만큼 왼쪽·위 4px에 뜨고, 아니면 숨는다. 오른쪽 클릭 `설정`·`끝내기`
- AC-6403.4: Given [뽑기], When 설정 프린터(빈칸이면 `BIXOLON` 든 첫 프린터)로 대화상자 없이 1장 보내면 창을 닫고, 실패하면 창을 두고 `프린터로 보내지 못했어요(<프린터 이름>). 프린터가 켜져 있고 종이가 있는지 보고 다시 눌러 주세요.` 이 문서의 종이 크기만 정한다. 설정은 `%LOCALAPPDATA%\PtSlip\settings.json`
- AC-6403.5: Given 두 번 켜면 하나만 돈다. 환자 값은 파일·로그에 안 남긴다
