# 요구사항: PT 후 진료 종이 뽑기

> 기능 ID: `pt-slip` · 형식: 요구사항은 `### REQ-6401: 제목`, 수용 기준은 `- AC-6401.1: Given/When/Then`.
> 각 AC는 시험 하나 이상으로 검증하고 시험 이름에 AC ID를 넣는다. 화면·인쇄·비트 창(REQ-6405)은 빌드와 이 PC 실행(PDF 프린터)으로 보고, 실제 빅솔론은 의원 PC에서 본다(tasks.md).
> 번호: REQ-6401~6405(다른 명세와 겹치지 않게 64xx). MVP 최소안이다.

## 배경 / 목표
- 대기 많을 때 접수 직원이 환자를 물리치료 먼저 보내며 손으로 쓰던 'PT 후 진료' 종이를, 비트 창에 붙은 버튼 하나로 빅솔론 라벨프린터(끈끈이 없는 이어진 롤, 폭 약 10cm)에 뽑는다. 환자가 종이를 들고 물리치료실에 낸다
- 승인 시안: `docs/mockups/pt-slip/index.html`·`notes.md`(2026-11-17 사용자 승인). 화면 글자는 시안과 같다
- 새 PC 프로그램(`Precheck.PtSlip`, net48 WinForms)이다. 웹앱·확장·도우미·접수현황은 고치지 않는다. 비트 DB 읽기는 `Precheck.Windows`의 기존 부품을 다시 쓴다

## 이미 정한 것 (다시 묻지 않는다)
사용자(grill-me 2026-11-17)와 시안 '제가 정한 부분'이 기준이다(`docs/mockups/pt-slip/notes.md`). 줄이면:
1. 프린터 달린 접수 PC 1대에만 깐다. 버튼은 비트 창 오른쪽 위(최소화 단추 왼쪽)에 붙어 따라다닌다
2. 차트번호를 쳐서 환자를 정하고, 이름은 비트 DB에서 읽어 보여 준다. 이름이 나와야만 뽑힌다
3. 항목·부위를 각각 여러 개 고른다. 목록은 이 프로그램 것(설정에서 고침). 오른·왼·양은 늘 있다
4. 종이는 지금 양식 그대로, 특이사항은 늘 빈칸. [뽑기]는 바로 1장, 창 닫힘. 기록 없음
5. 종이 폭 100mm, 길이 기본 60mm(설정). 프린터의 다른 설정은 바꾸지 않는다

## 요구사항

### REQ-6401: 설정과 목록
- AC-6401.1: Given 설정 파일이 없을 때, When 설정을 읽으면, Then 항목 `HP, ICE, ICT, 초음파, 레이저, 견인, 도수, 충격파`, 부위 `목, 어깨, 팔꿈치, 손목, 허리, 골반, 무릎, 발목`, 프린터 이름 빈칸, 종이 길이 60, 버튼 자리 0이다
- AC-6401.2: Given 설정 창의 목록 글(한 줄에 하나), When 목록으로 바꾸면, Then 앞뒤 빈칸을 빼고 빈 줄·겹친 이름(처음 것만 남김)을 빼며, 1~10글자가 아닌 줄·`,`가 든 줄은 받지 않고 그 줄 번호를 알린다. 항목·부위는 각각 1~16개다(넘거나 0개면 받지 않는다). 부위 이름은 `오른`·`왼`·`양`일 수 없다
- AC-6401.3: Given 종이 길이·버튼 자리, When 저장하면, Then 종이 길이는 40~150(mm, 정수), 버튼 자리는 -400~400(px, 20씩) 안만 받는다
- AC-6401.4: Given 저장한 설정, When JSON으로 쓰고 다시 읽으면, Then 같은 값이다. 깨진 파일·모양이 틀린 파일은 AC-6401.1 기본값으로 읽는다(프로그램이 멈추지 않는다)

### REQ-6402: 고르기 규칙
- AC-6402.1: Given 차트번호 칸 글, When 고르면, Then 숫자만 남기고 앞의 0을 빼며, 남은 것이 1~14자리일 때만 찾을 번호다(아니면 '빈칸' 또는 '없는 번호'로 본다)
- AC-6402.2: Given 항목 버튼, When 누르면 켜지고 다시 누르면 꺼지며, Then 종이 글은 켠 차례대로 `, `로 잇는다
- AC-6402.3: Given 쪽(오른·왼·양) 버튼, When 쪽을 누른 뒤 부위를 누르면, Then `오른 어깨`처럼 들어가고 쪽 고르기는 풀린다. 쪽 없이 누르면 `허리`처럼 들어간다. 같은 쪽 버튼을 다시 누르면 쪽 고르기가 풀린다
- AC-6402.4: Given 고른 부위, When 같은 글(쪽 포함)을 또 고르면 더 들어가지 않고, ✕를 누르면 빠진다. 종이 글은 들어간 차례대로 `, `로 잇는다
- AC-6402.5: Given 이름 찾기 결과, When [뽑기] 단추 상태를 정하면, Then 이름을 찾았을 때만 눌린다. 항목·부위는 비어도 된다

### REQ-6403: 차트번호로 이름 찾기
- AC-6403.1: Given 찾을 번호, When 비트 DB를 읽으면, Then `dbo.PbsInf`에서 `LTRIM(RTRIM(PbsChtNum))`가 그 번호인 한 줄의 `RTRIM(PbsPatNam)`을 매개변수로 읽는다(글자를 SQL에 붙이지 않는다, 읽기만, 시간 한도 5초)
- AC-6403.2: Given 읽은 결과, When 결과를 정하면, Then 줄이 있고 이름이 빈칸이 아니면 '찾음(이름)', 줄이 없으면 '없음', 읽기 오류(BitException 등)면 '못 읽음'이다
- AC-6403.3: Given 결과, When 창 글을 정하면, Then 빈칸 `차트번호를 넣으면 이름이 나와요`, 찾음 `<이름>`, 없음 `없는 차트번호예요`, 못 읽음 `비트에서 이름을 읽지 못했어요. 비트가 켜져 있는지 봐 주세요.`다

### REQ-6404: 종이 배치
- AC-6404.1: Given 폭 100mm·길이 L mm, When 칸을 나누면, Then 바깥 여백 4mm 안에 표를 그리고, 줄 높이는 머리 26%·치료부위 20%·치료항목 20%·특이사항 나머지, 이름표 칸 폭은 표의 30%다
- AC-6404.2: Given 머리 줄, When 글을 만들면, Then `PT 후 진료 ( <차트번호> / <이름> )`이고, [시험 1장]이면 `PT 후 진료 (      /      )`이며 값 칸은 모두 빈칸이다. 이름표 글은 `치료부위`·`치료항목`·`특이사항`(글자 사이를 띄워 그림), 특이사항 값은 늘 빈칸이다
- AC-6404.3: Given 값 글과 칸 크기, When 글씨 크기를 정하면, Then 기본 크기부터 한 줄에 들어가는 가장 큰 크기를 쓰고, 최소 크기에서도 안 들어가면 두 줄로 나눠 들어가는 크기를 쓰며, 그래도 넘치면 최소 크기 두 줄에서 끝을 `…`로 줄인다(글 재기는 바깥에서 받은 함수로 한다)

### REQ-6405: 프로그램 (비트 창 버튼·고르는 창·설정·인쇄)
- AC-6405.1: Given 비트 프로그램(이름이 `BIT`·`DrBIT`로 시작하거나 `pBITNewMenu`, `DrBitExport` 제외)의 보이는 창 가운데 가로 600px 이상인 창이 맨 앞일 때, When 버튼 자리를 정하면, Then 노란 [PT 먼저] 버튼이 그 창 오른쪽 위(오른쪽 끝에서 150px + 버튼 폭 + 설정의 버튼 자리만큼 왼쪽, 위에서 4px)에 뜨고, 비트 창이 맨 앞이 아니거나 최소화되거나 없으면 숨는다(이 프로그램 창이 맨 앞일 때는 그대로 둔다)
- AC-6405.2: Given [PT 먼저]를 누르면, When 고르는 창이 열리면, Then 시안 ②~⑤처럼 차트번호 칸에 커서가 있고, 칠 때마다 이름을 찾으며(0.3초 기다린 뒤), 미리보기가 같이 바뀐다. 버튼을 오른쪽 클릭하면 `설정`·`끝내기` 메뉴가 나온다
- AC-6405.3: Given [뽑기], When 설정의 프린터(빈칸이면 이름에 `BIXOLON`이 든 첫 프린터)로 폭 100mm·설정 길이 종이로 1장 보내면, Then 대화상자 없이 뽑고 창을 닫는다. 보내지 못하면 창을 닫지 않고 `프린터로 보내지 못했어요(<프린터 이름>). 프린터가 켜져 있고 종이가 있는지 보고 다시 눌러 주세요.`를 보이며, 프린터를 못 찾으면 `<프린터 이름>` 자리에 `프린터 없음`을 쓴다. 이 문서의 종이 크기만 정하고 프린터 기본 설정은 바꾸지 않는다
- AC-6405.4: Given 설정 창(시안 ⑦), When [저장]하면, Then REQ-6401 검사를 통과할 때만 `%LOCALAPPDATA%\PtSlip\settings.json`에 쓰고, 틀린 줄이 있으면 저장하지 않고 이유를 보인다. [시험 1장]은 빈 양식(AC-6404.2)을 뽑는다. 버튼 자리 ◀ ▶는 20px씩 바꾸고 바로 버튼에 보인다
- AC-6405.5: Given 프로그램을 두 번 켜면, When 시작하면, Then 하나만 돈다. 환자 이름·차트번호는 파일·로그에 남기지 않는다
