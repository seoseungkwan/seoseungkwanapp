# 요구사항: 서식 탭 — 휴진 안내(테마·AI 정리·저장·인쇄·그림 파일)

> 기능 ID: `forms` · 형식: 요구사항은 `### REQ-3501: 제목`, 수용 기준은 `- AC-3501.1: Given/When/Then`.
> 각 AC는 시험 하나 이상으로 검증하고, 시험 이름에 AC ID를 넣는다. 테마 그림이 시안과 같은지·화면 모양은 화면 확인 TASK가 사진으로 본다(tasks.md).
> 번호: REQ-3501~3511(다른 명세와 겹치지 않음: 33xx stats-load-range·reception-arrange, 34xx helper-stats-speed).

## 배경 / 목표
- 서식 탭(`/forms`)은 지금 '준비 중' 화면이다(tab-frame). 계획(`docs/tab-frame/plan.md`): "대충 적으면 AI가 양식에 맞게 정리하고, 인쇄·PDF와 그림 파일로 뽑는다"
- 이번 판은 **휴진 안내 한 장**만 만든다. 의원이 지금 쓰는 8월 안내문(광복절, 사용자가 2026-11-10 보여 줌)의 틀을 따르고, 공휴일·달마다 그 날에 맞는 테마 그림을 입힌다
- 승인 시안: `docs/mockups/forms/index.html`(5월 어린이날 휴진 안내, 2026-11-10 사용자 "좋아"). 서식 탭 화면 시안 `docs/mockups/forms/screen.html`, 테마 23개 시안 `docs/mockups/forms/themes.html`은 승인받은 뒤 그 모양을 그대로 만든다
- 서버 쪽은 AI 리포트와 같은 길을 쓴다: 서버 코드는 `app/api/ai/` 안의 경로 하나를 더할 뿐이고, 저장은 브라우저 + Supabase RLS다(ADR-004). 다만 **이 경로는 사용자가 적은 글을 Claude로 보낸다** — 집계만 보낸다는 규칙의 예외라서 ADR-028로 남긴다(REQ-3511)

## 이미 정한 것 (다시 묻지 않는다)
사용자 결정(2026-11-10 질문·답):
1. 첫 판은 '진료일정·휴진 안내'만. 환자 안내문·직원 공지·회의록·근무표·보고서는 다음 판
2. 만드는 법: 대충 적으면 AI가 정리한다. 적은 글이 우리 사이트 서버를 거쳐 Claude로 가고, 전화·주민번호·메일 모양 글자가 있으면 보내지 않는다(질문에 이렇게 설명하고 받은 답)
3. 만든 안내문은 저장해 두고 목록에서 다시 열어 고친다
4. 뽑는 모양: A4 인쇄·PDF와 그림 파일(PNG). 그림은 A4와 같은 세로 모양
5. 병원 정보(이름·전화·진료시간)는 붙이지 않는다
6. 디자인: 8월 안내문을 분석해 만든 어린이날 시안을 승인("좋아"). 시안 맨 아래에 더했던 "N일부터 정상 진료합니다" 줄은 뺀다
7. 테마는 날마다 그 날에 맞게: "광복절이면 태극기 건곤감리·무궁화, 추석이면 추석, 삼일절이면 삼일절" — 각 공휴일 또는 각 달을 대표하는 그림. 수는 **공휴일 11개 + 달마다 12개**
8. 날짜 카드 아래 글은 '휴진' 말고도 적을 수 있다(정상진료·오전진료·13시까지 같은 짧은 글)

이 명세에서 Claude가 정한 것(`design.md` '정한 것과 까닭'):
9. 카드는 한 장에 1~4장. 이어서 쉬는 날은 카드 한 장(시작~끝, 31일까지)으로 묶는다
10. 카드 이름은 1~10자, 아래 글은 1~6자(처음 값 '휴진'). 날짜 글의 요일은 앱이 계산한다
11. 연도: 적은 글에 연도가 없으면 그 날짜가 오늘(한국 날짜)보다 30일 넘게 지났을 때 다음 해로 본다
12. 테마는 카드 이름의 공휴일 낱말로 저절로 고르고(없으면 안내 달의 달 테마), 직접 바꿀 수 있다
13. 안내 달(제목의 'N월')은 가장 이른 카드의 달로 정해지고, 직접 바꿀 수 있다
14. 그림 파일은 1588×2246 픽셀(시안 크기의 2배). 파일 이름 `휴진안내_YYYY-MM.png`
15. 대충 적은 글은 저장하지 않는다(정리한 카드·달·테마만 저장)
16. AI 모델은 AI 리포트와 같은 Claude Opus 5.5, 생각 깊이(effort)는 low. 한 번에 약 1~2센트
17. 안내문 글꼴은 Pretendard 굵은 두 굵기(700·900)를 더해 안내문 그림 안에서만 쓴다

## 요구사항

### REQ-3501: 서식 탭 열기
- AC-3501.1: Given 승인된 사용자, When 탭 목록의 [서식]을 누르면, Then `/forms`로 가고 준비 중 화면이 아니라 서식 화면이 열린다(`menu.ts`의 서식 항목 `ready: true`·`href: '/forms'`)
- AC-3501.2: Given 대시보드 기능 목록과 준비 중 목록, When 서식 항목을 보면, Then 기능 목록의 서식은 `status: 'ready'`이고 준비 중 목록(`notReadyFeatures.ts`)에는 `/forms`가 없다. 설명은 '휴진 안내를 테마 그림으로 만들어 인쇄·그림 파일로'다
- AC-3501.3: Given 서식 화면, When 열리면, Then 맨 위 도구 단추 줄에 [휴진 안내] 하나가 눌린 상태로 있고, 탭 이름(metadata title)은 '서식'이다

### REQ-3502: 대충 적고 AI로 정리하기 (화면)
- AC-3502.1: Given 글 칸에 "5/5 어린이날 휴진"을 적고, When [정리하기]를 눌러 AI 답(카드 1장: 2027-05-05 · 어린이날 · 휴진)이 오면, Then 카드 칸이 그 답으로 바뀌고 안내 달은 2027년 5월, 미리보기가 바로 바뀐다
- AC-3502.2: Given 글 칸, When 글자를 적으면, Then 500자까지만 들어가고 'n/500'이 보이며, 빈 글(공백만 포함)이면 [정리하기]가 막혀 있다
- AC-3502.3: Given 글에 전화번호·주민번호·메일 주소 모양이 있으면, When [정리하기]를 누르면, Then 아무것도 보내지 않고 글 칸 아래에 E-FORMS-PRIVATE 문구가 보인다
- AC-3502.4: Given [정리하기]를 누른 뒤 답을 기다리는 동안, When 화면을 보면, Then 단추는 '정리하는 중…'으로 막혀 두 번 보내지 않고, 적은 글과 카드 칸은 그대로다
- AC-3502.5: Given AI 경로가 E-AI-BUSY·E-AI-LIMIT·E-AI-FAILED·E-FORMS-NO-DATE로 답하거나 연결이 끊기면, When 답을 받으면, Then 그 번호의 오류 문구(무엇이·어떻게 고치나·번호)가 보이고 적은 글과 카드 칸은 그대로다(연결 끊김은 E-AI-BUSY로 보인다)
- AC-3502.6: Given AI 답에 카드가 4장을 넘었다는 표시(`truncated: true`)가 있으면, When 카드 칸을 채우면, Then "카드는 4장까지라 앞의 4장만 넣었어요" 한 줄이 보인다
- AC-3502.7: Given 글 칸 아래, When 화면을 보면, Then "전화번호·주민번호·메일 주소는 적지 마세요. 적은 글은 정리할 때만 AI로 보내고 저장하지 않아요" 안내가 늘 보인다

### REQ-3503: 안내 내용 직접 고치기
- AC-3503.1: Given 카드 칸, When 카드 하나를 보면, Then 시작 날짜·끝 날짜(선택)·이름·아래 글 네 칸과 [빼기]가 있고, 새 카드의 아래 글은 '휴진'이다
- AC-3503.2: Given 카드가 4장이면 [카드 더하기]가, 1장이면 [빼기]가 막혀 있다
- AC-3503.3: Given 카드 하나, When 날짜 글을 만들면, Then 하루는 "5월 5일(수)", 같은 달 이어진 날은 "10월 3일(토)~5일(월)", 다른 달로 넘어가면 "1월 31일(일)~2월 2일(화)"이고 요일은 `lib/analytics/dates.ts`의 `weekdayOf`로 계산한다
- AC-3503.4: Given 카드 칸 값, When 검사하면, Then 시작 날짜는 있는 날짜, 끝 날짜는 비었거나 시작보다 뒤이고 시작부터 31일 안, 이름은 1~10자, 아래 글은 1~6자, 둘 다 제어 문자·전화·주민번호(붙여 쓴 13자리 포함)·메일 모양이 없어야 한다. 어긋난 칸은 그 칸 아래에 까닭이 보이고 [저장]·[인쇄·PDF]·[그림 파일]이 막힌다
- AC-3503.5: Given 카드 날짜를 바꾸면, When 안내 달을 직접 고른 적이 없으면, Then 안내 달은 가장 이른 시작 날짜의 연·월로 따라 바뀐다. 직접 고른 뒤에는 그대로다. 새 안내문(카드에 날짜가 없음)의 안내 달은 오늘(한국 날짜)의 달이다
- AC-3503.6: Given 안내문 그림, When 카드를 그리면, Then 적은 차례와 상관없이 시작 날짜 차례로 그린다

### REQ-3504: 테마
- AC-3504.1: Given 테마 목록, When 보면, Then 공휴일 11개(신정·설날·삼일절·어린이날·부처님오신날·현충일·광복절·추석·개천절·한글날·성탄절)와 달 12개(1월~12월)로 모두 23개이고, 열쇠는 겹치지 않는다
- AC-3504.2: Given 테마를 '저절로'로 둔 안내문, When 테마를 고르면, Then 시작 날짜 차례로 카드 이름에서 공휴일 낱말(design.md '테마 낱말 표')을 찾아 처음 찾은 공휴일 테마를 쓰고, 없으면 안내 달의 달 테마를 쓴다(예: 광복절 + 대체공휴일 → 광복절, 학회 하나뿐인 7월 → 7월)
- AC-3504.3: Given 테마 고르기 칸, When 사용자가 테마 하나를 고르면, Then 카드를 바꿔도 그 테마가 그대로이고, '저절로'를 다시 고르면 2번 규칙으로 돌아간다. 칸에는 '저절로(지금: 어린이날)'처럼 지금 쓰이는 테마 이름이 보인다
- AC-3504.4: Given 각 테마의 강조색, When 흰 글자와 견주면, Then 명암비가 3:1 이상이다(날짜 띠의 흰 큰 글자)
- AC-3504.5: Given 테마 그림 파일 23개(`public/poster/themes/<열쇠>.svg`), When 검사하면, Then 모두 있고 `viewBox="0 0 794 1123"`이며 글자(`<text>`)·스크립트·바깥 주소(`href`가 `#`로 시작하지 않는 것)·이벤트 속성(`on…=`)이 없고, 한 파일이 60KB 이하다

### REQ-3505: 안내문 그림(A4 세로)
- AC-3505.1: Given 안내문, When 그림을 그리면, Then 794×1123 SVG 하나에 테마 그림, 강조색 'N월', '진료일정안내', 두 줄 안내 "N월 진료일정을 안내드리오니 / 진료 및 내원에 참고해주시길 바랍니다", 날짜 카드가 시안의 자리·크기대로 있고 병원 정보는 없다
- AC-3505.2: Given 카드 수, When 배치하면, Then 1장은 가운데, 2장은 가로 둘, 3장은 가로 셋, 4장은 2×2이고 모든 카드가 794×1123 안, 테마 그림이 비워 둔 글자 자리(design.md '글자 자리') 안에 있다
- AC-3505.3: Given 카드 글(날짜 범위·10자 이름·6자 아래 글), When 글자 크기를 정하면, Then 어림 폭이 카드 안쪽 폭을 넘지 않을 때까지 줄이고(시안 크기에서 시작, 가장 작게 18px), 그 크기로 그린다
- AC-3505.4: Given 카드가 하나도 다 채워지지 않은 안내문(시작 날짜 없음), When 미리보기를 보면, Then 카드 자리에 "날짜를 적으면 여기에 카드가 생겨요" 점선 상자가 보이고 뽑기·저장 단추가 막혀 있다

### REQ-3506: 뽑기 — 인쇄·PDF와 그림 파일
- AC-3506.1: Given 검사를 통과한 안내문, When [인쇄·PDF]를 누르면, Then 브라우저 인쇄 창이 열리고 인쇄 면에는 A4 세로 한 장(여백 0)에 안내문 그림만 나온다(메뉴·단추·목록은 안 나옴). PDF는 인쇄 창의 'PDF로 저장'으로 만든다(ADR-011)
- AC-3506.2: Given 검사를 통과한 안내문, When [그림 파일]을 누르면, Then 1588×2246 PNG 하나가 `휴진안내_2027-05.png`(안내 달)로 내려받아진다
- AC-3506.3: Given 그림 파일을 만들 때, When SVG를 그림으로 바꾸면, Then 테마 그림과 글꼴 두 개를 data: 주소로 넣은 SVG 글을 쓴다(바깥 주소를 남기지 않는다). 만들다 실패하면 E-FORMS-IMAGE-FAILED 문구가 보인다

### REQ-3507: 저장·목록
- AC-3507.1: Given 검사를 통과한 새 안내문, When [저장]을 누르면, Then `form_notices`에 줄 하나(연·월·카드·테마)를 넣고 목록 맨 위에 나타나며 '저장됨'이 보인다. 연 안내문을 고쳐 저장하면 그 줄을 고친다(새 줄 아님)
- AC-3507.2: Given 저장한 안내문들, When 서식 화면을 열면, Then 목록에 최근 고친 차례로 최대 100개가 "2027년 5월 · 어린이날"(카드 이름 앞 둘을 '·'로)과 고친 날짜로 보이고, 누르면 그 안내문이 열린다. 하나도 없으면 "아직 저장한 안내문이 없어요"
- AC-3507.3: Given 저장하지 않은 바뀐 내용이 있을 때, When 다른 안내문을 열거나 [새로 만들기]를 누르면, Then "저장하지 않은 내용이 있어요. 버릴까요?" 확인을 묻고, [취소]면 그대로 둔다
- AC-3507.4: Given 저장한 안내문을 연 상태, When [지우기]를 누르고 확인하면, Then 그 줄을 지우고 새 안내문 화면이 된다
- AC-3507.5: Given 저장·지우기·목록 읽기가 실패하면, When 답을 받으면, Then 적은 값은 화면에 그대로 두고 E-FORMS-SAVE-FAILED(저장·지우기)·E-FORMS-READ-FAILED(목록)와 [다시 저장]/[다시 읽기]가 보인다
- AC-3507.6: Given 서버에서 읽은 줄, When 화면에 넣기 전에, Then 저장할 때와 같은 검사(AC-3503.4)를 하고 못 넘는 줄은 목록에서 뺀다(고쳐 쓰지 않는다)
- AC-3507.7: Given 저장할 값, When 서버로 보내면, Then 보내는 칸은 `year`·`month`·`cards`(카드마다 `start`·`end`·`name`·`status`)·`theme`뿐이고, 대충 적은 글은 보내지 않는다

### REQ-3508: 저장 표와 권한(DB)
- AC-3508.1: Given migration `form_notices`, When 적용하면, Then RLS가 켜지고 anon·authenticated의 기본 권한을 모두 거둔 뒤 authenticated에 select·delete와 insert·update(`year`·`month`·`cards`·`theme` 칸만)만 준다
- AC-3508.2: Given 승인된 병원 사용자, When 읽기·넣기·고치기·지우기를 하면, Then 자기 병원 줄만 되고 `hospital_id`는 DB가 정하며(`my_hospital_id()`) 바꿀 수 없다. 다른 병원 줄은 보이지도 고쳐지지도 않는다. 승인되지 않은 사용자와 anon은 아무것도 못 한다
- AC-3508.3: Given 표 제약, When 값을 넣으면, Then `year` 2020~2100·`month` 1~12·`cards`는 길이 1~4의 배열이고 글로 4,000바이트 이하·`theme`은 비었거나 `^[a-z0-9-]{1,32}$`만 들어가고, `updated_at`은 고칠 때마다 DB가 지금 시각으로 바꾼다

- 다른 서식(환자 안내문·직원 공지·회의록·근무표·보고서) — 다음 판
