# 요구사항: 통계 엔진: 파일럿 계산 이식 + 새 지표

> 기능 ID: `stats-core` · 형식: 요구사항은 `### REQ-001: 제목`, 수용 기준은 `- AC-001.1: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다.

## 배경 / 목표
- plan.md 2-2·4·5절. 파일럿(`seoseungkwan/tonggye-bunseok`, main `fbb303a`)의 파일 읽기·계산·저장 모양·Worker 코드와 시험을 이 저장소로 옮긴다. 옮긴 시험의 `describe` 이름 앞에 아래 AC ID를 붙인다
- 새 지표를 더한다: 신환율·재진율, 처방별 재진 수, 처방코드 그룹, 신환 7일·14일 재방문율
- 주민번호 검사를 보강한다: 붙여 쓴 13자리도 잡는다
- 서버에 저장할 모양을 v2로 바꾼다: 달 숫자(`MonthPayload`) + 일 숫자(`DayPayload`). 이 기능은 모양을 만들고 검사하는 데까지만 한다(실제 저장은 하지 않는다)
- 환자 자료(차트번호·환자 줄·파일 이름)는 이 코드 밖으로 나가지 않는다. 결과에는 몇 명인지만 남는다

## 요구사항

### REQ-001: 환자 자료 구역 울타리 (파일럿 이식)
- AC-001.1: Given `src/lib/parsers`·`src/lib/analytics`·`src/lib/payload`·`src/workers` 안의 파일, When `fetch`·`XMLHttpRequest`·`WebSocket`·`EventSource`·`importScripts`·`sendBeacon`을 쓰면(`window`·`self`·`globalThis`·`navigator`를 거쳐도), Then ESLint 오류(severity 2)가 난다
- AC-001.2: Given 같은 구역, When `react`·`next`·`@supabase/*`·services·supabase·`lib/auth`·`lib/storage`를 import하거나(동적 `import()` 포함, 글자로 고정하지 않은 동적 import 포함) JSX를 쓰면, Then ESLint 오류가 난다
- AC-001.3: Given 같은 구역, When `console`(다른 이름으로 받아도)·`localStorage`·`sessionStorage`·`indexedDB`를 쓰면, Then ESLint 오류가 난다
- AC-001.4: Given 구역 밖 파일, When 같은 코드를 쓰면, Then 구역 규칙 오류는 나지 않는다. 어느 파일에서든 `dangerouslySetInnerHTML`은 오류다

### REQ-002: 날짜 계산 (파일럿 이식)
- AC-002.1: Given 'YYYY-MM-DD' 글자, When 날짜를 더하고 빼고, 주(월~일)·달 범위를 구하면, Then `TZ=Asia/Seoul`에서도 하루 밀리지 않은 글자가 나온다
- AC-002.2: Given 엑셀 날짜 숫자나 여러 날짜 글자 모양, When 날짜 칸을 읽으면, Then 'YYYY-MM-DD'가 나오고, 없는 날짜는 null이다
- AC-002.3: Given 어떤 시각, When 오늘 날짜를 구하면, Then 한국 날짜가 나온다

### REQ-003: 파일 읽기 공통·오류 번호 (파일럿 이식)
- AC-003.1: Given UTF-8(BOM 있음·없음)·CP949 CSV, BIFF .xls, 속이 HTML 표인 .xls, .xlsx, When 읽으면, Then 확장자가 아니라 내용으로 형식을 정하고 같은 모양의 표(Grid)가 나온다
- AC-003.2: Given 50MB 또는 100만 줄을 넘는 파일, When 읽으면, Then `E-PARSE-TOO-BIG`. 표로 읽을 수 없는 바이트는 `E-PARSE-UNREADABLE`
- AC-003.3: Given 주소 글자, When 지역으로 바꾸면, Then 시·도 + 시·군·구 + 동·읍·면·가·리까지만 남고(도로명 주소는 구까지), 빈 주소는 null
- AC-003.4: Given 모든 오류 번호, When 문구를 찾으면, Then '무엇이'와 '어떻게 고치나'가 빈 글자가 아니다

### REQ-004: 비트 '환자별 소모 통계' 읽기 (파일럿 이식 + 주민번호 검사 보강)
- AC-004.1: Given 위 20줄 안의 머리줄, When 읽으면, Then 허용 칸 8개만 읽고, 꼭 있어야 하는 칸이 없으면 `E-PARSE-COLUMN`과 없는 칸 이름을 돌려준다
- AC-004.2: Given 합계·소계·반복 머리줄·필수값이 빠진 줄·표에 없는 초재진 값·입원 줄, When 읽으면, Then 합계류는 건너뛰고, 필수값 오류 줄은 빼서 센다(invalidRows), 초재진은 알 수 없음, 입원은 표시만 한다. 외래 줄이 0개면 `E-PARSE-EMPTY`
- AC-004.3: Given 여러 파일의 차트번호, When 한 묶음으로 읽으면, Then 같은 차트번호는 같은 번호(1, 2, 3…)가 되고, 원래 차트번호는 결과 어디에도 없다
- AC-004.4: Given 허용 칸에 붙임표가 있는 주민번호 모양(숫자6-숫자7, 앞 6자리가 월·일 모양), When 읽으면, Then 파일 전체가 `E-PARSE-RRN`. 읽지 않는 칸에만 있으면 보지 않는다
- AC-004.5: Given 처방코드 칸이 아닌 허용 칸에 붙여 쓴 13자리 숫자(앞 6자리가 월·일 모양, 7번째 자리가 1~8), When 읽으면, Then 파일 전체가 `E-PARSE-RRN`
- AC-004.6: Given 처방코드 칸의 13자리 의약품 표준코드(880으로 시작), 월·일·성별 자리가 맞지 않는 13자리 숫자, 14자리 이상 숫자 속의 13자리, When 읽으면, Then 주민번호로 보지 않는다

### REQ-005: 가짜 비트 파일 (파일럿 이식)
- AC-005.1: Given 같은 seed, When 가짜 표를 만들면, Then 같은 표가 나오고, 칸 순서는 실제 비트 23칸 그대로이며, 주민번호 칸은 `XXXXXX-XXXXXXX` 자리표시만 있다
- AC-005.2: Given 생성기, When 가짜 파일을 모두 만들면, Then 기본 6개(UTF-8 BOM·UTF-8·CP949·xlsx·BIFF .xls·HTML .xls)는 같은 표이고, 시험용 파일(잘못된 줄·빈 파일·기간 줄 없음·칸 순서 바뀜 등)은 정해진 모양이다

### REQ-006: 칸(일·주·월)마다 세기 (파일럿 이식 + 새 숫자)
- AC-006.1: Given 환자 줄, When 세면, Then 파일럿 규칙 그대로다: 일·주·월을 각각 따로 센 서로 다른 환자 수, 같은 환자·날·처방 여러 줄 = 1건, 칸 안에 신환 줄이 있으면 신환, 입원 줄 제외, F/U 1회·2회·3~5회·6회+, 처방 이름·유형은 가장 많이 나온 것, 지역별 환자 수, 처방코드 순
- AC-006.2: Given 처방 하나, When 세면, Then 그 처방을 받은 환자 중 칸에서 재진인 환자 수(`returning`)가 있고, 신환 + 재진 + 알 수 없음 = 그 처방 환자 수
- AC-006.3: Given 처방코드 그룹(id + 코드 목록), When 세면, Then 그룹마다 그 코드 중 하나라도 받은 서로 다른 환자 수·신환·재진·F/U(그룹 코드 중 하나라도 받은 서로 다른 날 수)가 나온다. 한 코드가 여러 그룹에 있으면 각 그룹에 센다. 그 칸에 환자가 없는 그룹은 빠진다. id 순이다
- AC-006.4: Given 신환, When 재방문을 세면, Then 집단은 '첫 신환일'(묶음 전체에서 그 환자의 가장 이른 신환 날)이 그 칸에 있는 환자다. 7일 재방문 = 첫 신환일 다음 날부터 7일째까지(양 끝 포함) 외래 줄(어떤 처방이든)이 있는 환자 수. 14일도 같다
- AC-006.5: Given 첫 신환일과 같은 날의 다른 처방, 입원 줄, 8일째 방문, When 7일 재방문을 세면, Then 재방문이 아니다. 같은 환자가 다른 날 다시 신환으로 찍히면 그 날은 재방문으로 세고, 그 날의 칸 집단에는 넣지 않는다

### REQ-007: 요약·증감 (파일럿 이식 + 새 숫자)
- AC-007.1: Given 센 숫자와 덮은 기간, When 요약하면, Then 파일럿 규칙 그대로다: 덮은 구간의 합집합, 칸 상태(완전·집계 중·부분), 맨 위 날·직전 진료일·지난주 같은 요일, 완전한 칸끼리만 증감, 이전 0이면 신규, 급증감은 이전 5명 이상 처방만
- AC-007.2: Given 칸 하나, When 요약하면, Then 신환율 = 신환 ÷ 전체, 재진율 = 재진 ÷ 전체(0~1)이고 전체가 0명이면 null. 처방 비교에도 재진율이 있다
- AC-007.3: Given 칸의 재방문 숫자, When 요약하면, Then '칸 첫날 ~ 칸 끝날 + N일'이 모두 덮였고 끝났을 때만 N일 재방문 수·비율이 숫자이고, 아니면 null('집계 중')이다. 집단이 0명이면 비율은 null
- AC-007.4: Given 그룹 숫자, When 요약하면, Then 일·주·월마다 그룹 비교가 처방 비교와 같은 규칙(같은 칸 짝, 증감, 신환율·재진율·F/U율)으로 나오고 id 순이다

### REQ-008: 서버에 저장할 모양 v2
- AC-008.1: Given 집계 품질이 정상인 결과, When 달 숫자로 바꾸면, Then 줄이 있는 달마다 `schemaVersion: 2` 하나가 달 순으로 나오고, 합계·처방(재진 포함)·그룹·재방문(집계 중은 null)·5명 이상인 동네만 담긴다. 그 달이 완전하지 않으면 `partial: true`
- AC-008.2: Given 같은 결과, When 일 숫자로 바꾸면, Then 줄이 있는 날마다 하나가 날짜 순으로 나오고, 합계·처방(코드·이름·유형·환자·신환·재진)·그룹(환자·신환·재진)·재방문이 담긴다. 동네와 F/U는 없다
- AC-008.3: Given 집계 품질이 incomplete인 결과, When 달·일 숫자로 바꾸면, Then null이다(멀쩡한 칸만 골라 내지도 않는다)
- AC-008.4: Given 저장 전·읽은 뒤의 값, When 검사하면, Then 정해진 열쇠만 있고 합이 맞을 때만(처방·그룹: 신환 + 재진 ≤ 환자, F/U 합 = 환자 / 재방문: 7일 ≤ 14일 ≤ 집단 ≤ 그 칸 신환, 7일이 null이면 14일도 null) 새 객체를 돌려주고, 아니면 null이다
- AC-008.5: Given 처방명·유형·동네 이름에 전화·붙임표 주민번호·붙여 쓴 주민번호·메일 모양, 처방코드에 전화·붙임표 주민번호·메일 모양, 영문·숫자·붙임표 1~64자가 아닌 그룹 id, When 검사하면, Then null이다. 처방코드의 13자리 의약품 표준코드는 통과한다

### REQ-009: 저장된 달로 보는 지난달·작년 대비 (파일럿 이식)
- AC-009.1: Given 저장된 달 숫자(v2), When 기록을 보면, Then 파일럿 규칙 그대로 기준 달(완전한 가장 최근 달)·지난달·작년 같은 달 대비와 최근 12달 추세가 나온다

### REQ-010: Web Worker 분석 (파일럿 이식 + 그룹 전달)
- AC-010.1: Given 화면이 넣은 파일들, When 분석을 시작하면, Then Worker에는 바이트와 오늘 날짜(와 그룹 정의)만 가고 파일 이름은 가지 않는다. 바이트를 꺼내지 못한 파일은 그 자리에 오류 번호가 간다. 30초가 넘으면 `E-ANALYZE-TIMEOUT`, Worker 오류는 `E-ANALYZE-FAILED`이고 예외 내용은 옮기지 않는다. 끝나면 Worker를 끝낸다
- AC-010.2: Given Worker 안의 파일 묶음, When 분석하면, Then 번호는 묶음 전체에서 한 번 매기고, 결과는 넣은 순서와 짝이며, 실패한 파일이나 뺀 줄이 있으면 묶음 전체가 incomplete, 파일 마지막 날이 오늘보다 3일 넘게 이전이면 그 날 수를 알린다
- AC-010.3: Given 그룹 정의, When 분석하면, Then 결과의 그룹 숫자는 그 정의로 센 것이다. 그룹 정의가 없으면 그룹은 빈 목록이다
