# 요구사항: 휴진 안내문 아래 병원 로고 (forms-logo)

## 배경
- 2026-11-10 사용자: 서식 탭 휴진 안내문에 "이 로고도 밑에 넣어줘" + 양지바른정형외과 로고 그림과 로고 모음(세로형·가로형, 테두리 있음·없음) **(사용자)**
- `specs/forms` 범위 밖이던 "병원 이름·전화·로고 넣기" 중 **로고 그림만** 이 명세가 연다. 글자로 된 병원 이름·전화·주소는 계속 넣지 않는다
- 시안: `docs/mockups/forms/logo.html`(테마 23개에 로고), 로고 파일 `docs/mockups/forms/logo.png`

## 결정
1. 로고는 앱 파일 하나(`public/poster/logo.png`)로 두고 **모든 안내문에 늘** 나온다 — 앱은 당분간 혼자 쓰는 MVP다(plan.md §1). 다른 병원을 받기 전에 병원별 로고로 바꾼다(범위 밖)
2. 모양은 사용자 로고 모음 왼쪽 아래의 **가로형·테두리 있는 것**. 처음 보낸 로고 그림(세로형, 글자가 커서 더 선명)의 조각을 가로형 비율로 다시 짜고 바탕을 투명하게 했다
3. 로고 뒤에 흰 받침·흰 테두리·흰 빛을 두지 않고 **그대로** 얹는다 — 세 가지 비교 그림에서 사용자가 ①을 골랐다 **(사용자)**. 장식이 많은 테마(11월 등)에서는 작은 영문이 덜 보일 수 있음을 알리고 고른 것이다
4. 자리: 맨 아래 가운데, 너비 340·높이 58(안내문 너비의 약 43%), 아래 끝에서 54 위. 카드 수와 상관없이 같은 자리

## 요구사항

### REQ-3601: 로고 그림 파일
- AC-3601.1: Given `public/poster/logo.png`, When 읽으면, Then PNG이고 1033×175이며 알파 칸이 있고 네 귀퉁이 점은 투명(알파 0)이며 파일은 200,000바이트 이하다
- AC-3601.2: Given 시안의 로고 `docs/mockups/forms/logo.png`, When 앱의 로고와 비교하면, Then 바이트가 같다(sha256)

### REQ-3602: 안내문 그림에 로고
- AC-3602.1: Given 안내문(카드 1~4장, 테마 23개 아무거나), When 그리면, Then 마지막 자식이 `<image href="/poster/logo.png" x="227" y="1011" width="340" height="58">` 하나이고, 안내문 안의 image는 테마 그림과 로고 둘뿐이며, 로고에는 filter가 없고 로고 뒤 받침 rect도 없다
- AC-3602.2: Given 로고 자리 상수, When 카드 배치(1~4장)와 비교하면, Then 가운데(x + 너비/2 = 397)에 있고, 어느 카드 아래 끝보다도 아래에서 시작하며(4장 아래 줄 끝 934 < 1011), 종이 안에서 끝난다(1069 ≤ 1123)
- AC-3602.3: Given 로고가 든 안내문, When 글자와 읽는 이름(aria-label)을 보면, Then 병원 이름·전화·주소 글자는 여전히 없다(AC-3505.1 시험이 그대로 통과)

### REQ-3603: 그림 파일(PNG)과 인쇄에도 로고
- AC-3603.1: Given 안내문 SVG 글, When 그림용으로 바꾸면(svgForImage), Then 로고 주소 `/poster/logo.png`는 `data:image/png;base64,`(로고 바이트 그대로)가 되고 바깥 주소는 남지 않는다
- AC-3603.2: Given [그림 파일], When 내려받기를 하면(downloadPosterPng), Then 테마 그림·글꼴 둘과 함께 로고 파일도 읽어 넣고, 로고를 못 읽으면 false(화면은 E-FORMS-IMAGE-FAILED)
- AC-3603.3: Given 서식 화면, When 인쇄 면(인쇄 사본)을 보면, Then 미리보기와 같은 로고 image가 있다

## 범위 밖
- 병원마다 로고 올리기(설정 화면·Storage), 로고 켜고 끄기, 로고 자리·크기 고르기
- 로고 뒤 흰 받침·흰 테두리·흰 빛(사용자가 ①을 고름)
- 병원 이름·전화·주소·진료시간 글자, 세로형 로고
