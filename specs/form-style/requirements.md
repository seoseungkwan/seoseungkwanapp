# 요구사항: 서식 글씨·로고 크기·색 조절

> 기능 ID: `form-style` · 형식: 요구사항은 `### REQ-NNNN: 제목`, 수용 기준은 `- AC-NNNN.n: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다. 시안: `docs/mockups/form-style/` (승인 줄은 notes.md).
> 기준 갈래: `feat-logo-fit`(logo-fit 다 합친 뒤)에서 `feat-form-style`. 화면 글자는 이 문서 글자 그대로 쓴다(시안과 다르면 이 문서가 이긴다).

## 배경 / 목표
- 2026-11-19 사용자: "글씨 크기 내가 조절할 수 있게 해 색깔이랑" — 진료일정(휴진) 안내와 환자 안내문 두 서식에서 글씨와 로고의 크기·색을 직접 바꾸고 싶다.
- 사용자 결정: 로고·글씨 둘 다, 두 서식 다, 크기는 밀어서 %로, 글씨 색은 제목·본문 따로, 로고 색은 원래·흰·검정·직접. 이어서 "색깔 로고색 따라 갈 수 있게 하고 색깔 다양성 많이 하게 해", "로고 열면 자동으로 로고 색" → 색은 로고에서 뽑은 색 + 기본 색 16가지 + 직접 고르기, [자동]은 로고가 있으면 로고 색.

## 낱말
- **글씨·로고 값(style)**: 제목 크기·본문 크기·로고 크기(%)와 제목 색·본문 색·로고 색. 크기 100과 색 없음(null)이 '처음대로'다.
- **로고 색 칩**: 병원 로고 그림에서 뽑은 색(최대 4개, REQ-6802).
- **기본 색 16가지**: 검정 `#111111`, 진회색 `#3a3a3a`, 회색 `#6b7280`, 흰색 `#ffffff`, 남색 `#1f2a44`, 파랑 `#2563eb`, 하늘 `#0ea5e9`, 청록 `#0d9488`, 초록 `#16a34a`, 연두 `#65a30d`, 노랑 `#eab308`, 주황 `#f97316`, 빨강 `#dc2626`, 분홍 `#db2777`, 보라 `#7c3aed`, 갈색 `#92400e` (이 차례).
- **로고 두 색(logoColors)**: 이미 있는 `logoPalette`(clinic-profile REQ-6604)가 로고에서 뽑는 바탕색 main과 띠 색 dark.

## 요구사항

### REQ-6801: '글씨·로고' 칸
- AC-6801.1: Given 진료일정 안내 만들기 화면, When 편집 칸을 보면, Then 맨 아래(배경 칸 다음)에 이름표 '글씨·로고' 묶음이 있고 그 안에 차례로 '제목 글씨'·'본문 글씨'·'강조 색'·'로고' 줄과 도움말, [처음대로] 단추가 있다. 환자 안내문 편집 칸은 맨 아래('색' 칸 다음)에 같은 묶음이 있되 '강조 색' 줄이 없다.
- AC-6801.2: Given '제목 글씨'·'본문 글씨' 줄, When 보면, Then '크기' 밀대(이름 '제목 글씨 크기'·'본문 글씨 크기', 80~130, 5씩)와 지금 값 `N%`가 있고, 밀면 그 값이 서식 값과 미리보기에 바로 들어간다. '로고' 줄의 밀대(이름 '로고 크기')는 60~150, 5씩이다.
- AC-6801.3: Given 색 고르기(제목 글씨 색·본문 글씨 색·강조 색·로고 색), When 보면, Then 차례로 ① 첫 단추(글씨·강조는 '자동', 로고는 '원래 색') ② 로고 색 칩이 하나 이상이면 작은 글 '로고 색'과 칩들 ③ 작은 글 '기본 색'과 16가지 칩 ④ '직접 고르기' 색 칸이 있다. 칩 이름은 `<고르기 이름> <색 이름>`(예: '제목 글씨 색 빨강', '로고 색 로고 색 1'), 색 칸 이름은 `<고르기 이름> 직접 고르기`다. 고르기 하나는 묶음(role group, 이름 = 고르기 이름)이다. 지금 값과 같은 단추·칩만 눌린 상태(aria-pressed true)이고, 값이 null이 아니고 어느 칩과도 다르면 색 칸이 눌린 표시(테두리, `data-own="true"`)를 가진다. 값이 null일 때 색 칸의 처음 값은 그 고르기의 시작 색이다 — 제목은 자동 제목 색, 본문은 진료일정 안내 `#3a3a3a`·환자 안내문 흰색, 강조는 자동 강조 색, 로고는 로고 색 칩 첫째(없으면 검정).
- AC-6801.4: Given 색 고르기, When 칩을 누르면 그 색, 색 칸에서 고르면 그 색(소문자 `#rrggbb`), 첫 단추를 누르면 색 없음(null)이 그 서식 값에 들어간다.
- AC-6801.5: Given 진료일정 안내, When 편집 칸을 보면, Then 배경 칸 아래에 있던 '글자 색' 칸은 없고, 그 값(accent)은 '글씨·로고' 묶음의 '강조 색' 줄이 고른다. '강조 색' 줄 아래 도움말은 `'<달>월'·날짜 띠·카드 아래 글이 이 색이에요. 자동은 로고가 있으면 로고 색, 없으면 테마·배경에 맞춰 골라요`이고, 직접 고른 색이 옅으면(이미 있는 isLightAccent) '옅은 색이라 흰 글자·흰 카드 위 글이 잘 안 보일 수 있어요'를 보인다. 강조 색의 지금 색 글자는 고른 색이면 그 값, 자동이면 `자동 <자동 색>`이다(forms-accent AC-4701의 '글자 색' 이름·자리를 이것으로 바꾼다).
- AC-6801.6: Given '글씨·로고' 묶음, When 보면, Then 도움말 글은 진료일정 안내에서 `제목은 '진료일정안내', 본문은 위 안내 두 줄과 카드 속 글씨예요. 본문 색은 안내 두 줄과 카드 이름에 들고, 'N월'·날짜 띠·상태 글씨는 '강조 색'을 따라요. [자동]은 로고가 있으면 로고 색이에요. 자리보다 크게는 커지지 않아요.`, 환자 안내문에서 `제목은 큰 문구 두 줄, 본문은 진회색 띠 안의 줄 글이에요. [자동]이면 제목은 띠 색, 본문은 흰색이에요. 자리보다 크게는 커지지 않아요.`다.
- AC-6801.7: Given 바꾼 글씨·로고 값, When [처음대로]를 누르면, Then 그 서식의 크기 셋이 100, 색 셋이 null이 되고, 진료일정 안내는 강조 색(accent)도 null(자동)이 된다.
- AC-6801.8: Given 색을 칠할 수 없는 로고(AC-6805.3), When '로고' 줄을 보면, Then 로고 색 고르기의 단추·칩·색 칸이 막히고(disabled) 그 아래에 '배경이 있는 로고라 색을 바꿀 수 없어요. 원래 색으로 그려요'가 보인다. 저장된 로고 색 값은 지우지 않는다. 크기 밀대는 그대로 쓸 수 있다.

### REQ-6802: 로고 색 칩 뽑기
- AC-6802.1: Given 로고 그림 점(RGBA), When 로고 색 칩을 뽑으면, Then 불투명도 128 미만인 점과 R·G·B 가장 작은 값이 200 이상인 점(글자로 쓰기엔 옅은 점)을 빼고, 남은 점을 R·G·B 각 위 4비트로 묶어 점이 많은 묶음부터(같으면 묶음 번호 `r>>4<<8 | g>>4<<4 | b>>4`가 작은 차례) 그 묶음 평균색(반올림)을 보며, 이미 고른 색 모두와 R·G·B 거리(유클리드)가 60 이상인 색만 골라 최대 4개를 소문자 `#rrggbb`로 낸다. 같은 점이면 늘 같은 결과다.
- AC-6802.2: Given 로고가 없거나 표본을 못 읽었거나 남는 점이 없는 경우, When 칩을 뽑으면, Then 빈 목록이고 색 고르기에 '로고 색' 글과 칩이 없다.
- AC-6802.3: Given 서식 화면, When 로고 두 색(logoPalette)을 뽑으면, Then 로고 색 칩도 logoPalette에 쓰는 것과 같은 표본(logo-fit 1절: 준비에 성공하면 준비한 그림의 표본, 아니면 원래 표본)에서 뽑아 두 서식의 색 고르기에 넘기고, `readLogoPixels`를 더 부르지 않는다.

### REQ-6803: [자동] 색은 로고 색
- AC-6803.1: Given 진료일정 안내 제목 색이 null, When 그리면, Then 로고 두 색이 있으면 '진료일정안내'를 dark 색으로, 없으면 지금 색 `#262626`으로 그린다.
- AC-6803.2: Given 진료일정 안내 강조 색(accent)이 null, When 그리면, Then 로고 두 색이 있으면 `onWhite(main)` 색, 없으면 지금처럼 배경 그림 강조색 → 테마 강조색 차례로 쓴다. 직접 고른 강조 색은 늘 그 색이다. '강조 색' 줄의 '자동 <색>' 글자와 직접 고르기 시작 색도 같은 자동 색이다.
- AC-6803.3: Given 색 하나, When `onWhite`를 부르면, Then 흰색과의 대비(WCAG 상대 밝기 식)가 3 이상이면 그대로, 아니면 색상·채도는 두고 HSL 밝기를 0.02씩 낮춰 3 이상이 되는 첫 색(밝기 0까지)을 소문자 `#rrggbb`로 낸다.
- AC-6803.4: Given 본문 색이 null, When 그리면, Then 지금과 같다 — 진료일정 안내 안내 두 줄 `#3a3a3a`·카드 이름 `#262626`, 환자 안내문 줄 글 흰색. 환자 안내문 제목 색이 null이면 지금처럼 띠 색(palette dark, '색' 칸 [자동]이면 이미 로고 색)이다.

### REQ-6804: 크기 조절대로 그리기
- AC-6804.1: Given 진료일정 안내 제목 크기 t%, When 그리면, Then '진료일정안내' 글자 크기는 `fitSize('진료일정안내', round(120 × t / 100), 746)`이다(100%면 120 그대로). 'N월'은 크기를 바꾸지 않는다.
- AC-6804.2: Given 진료일정 안내 본문 크기 b%, When 그리면, Then 안내 두 줄은 각각 `fitSize(줄, round(27 × b / 100), 746)`, 카드 날짜는 `fitSize(날짜, min(round(f날짜 × b / 100), floor(띠 높이 × 0.6)), 안쪽 폭)`, 이름·아래 글은 `fitSize(글, min(round(f × b / 100), floor(몸통 높이 × 0.37)), 안쪽 폭)`이다(f는 카드 수별 처음 크기). 100%면 지금 크기와 같다.
- AC-6804.3: Given 환자 안내문 제목 크기 t%, When 그리면, Then 큰 문구의 처음 크기는 보통 `min(round(109 × t / 100), 120)`(두 줄 같은 크기 규칙 그대로), '윗줄 작게'면 윗줄 `min(round(80 × t / 100), 88)`·아랫줄 `min(round(150 × t / 100), 165)`이고 가장 작은 크기(72·56·72)와 '한 줄에 들어가지 않아요' 까닭 규칙은 그대로다. 100%면 지금과 같다.
- AC-6804.4: Given 환자 안내문 본문 크기 b%, When 그리면, Then 줄 글 처음 크기는 체크 표시면 `min(round(34 × b / 100), floor(줄 높이 / 1.35))`, 번호 표시면 b ≤ 100일 때 `round(35 × b / 100)`, b > 100일 때 `min(round(35 × b / 100), max(35, floor(줄 높이 / 1.35)))`이고 폭 맞추기(가장 작게 26)는 그대로다. 체크 표시 크기(글자 + 2)도 이 크기를 따른다. 100%면 지금과 같다.
- AC-6804.5: Given 로고 크기 L%, When 크기를 아는 로고 그림을 그리면, Then `logoRect`(logo-fit) 네모를 가운데를 지킨 채 `s = min(L / 100, 최대 폭 ÷ 네모 폭, 최대 높이 ÷ 네모 높이)`배 하고 네 값을 소수 첫째 자리까지 낸다. 최대는 진료일정 안내 600×130, 환자 안내문 692×140이다. 크기를 모르는 그림은 원래 상자(logo-fit AC-6703.3)를 같은 식으로 키우고 줄인다. 이름 글자 로고는 맞출 폭 `W = min(최대 폭, 상자 폭 × L / 100)`, 글자 크기 `fitSize(이름, min(floor(상자 높이 × 0.8 × L / 100), floor(최대 높이 × 0.8)), W)`이고, 가장 작은 크기로도 W를 넘치면 지금처럼 W로 눌러 그린다(textLength). 100%면 상자 폭·높이 그대로라 지금과 같다.
- AC-6804.6: Given 글씨·로고 값이 없거나 처음대로이고 로고 두 색이 없는(logoColors를 넘기지 않거나 null) 서식, When 그리면, Then 그림은 이 기능 전과 한 점도 다르지 않다(지금 시험이 그대로 통과한다). 로고 두 색이 있으면 진료일정 안내의 자동 제목·강조 색만 AC-6803.1·.2대로 바뀐다.
- AC-6804.7: Given 본문 크기를 바꾼 환자 안내문, When '한 줄에 들어가지 않아요' 까닭을 보거나(편집 칸) 저장 검사(checkGuideValue)를 하면, Then 둘 다 그림과 같은 style을 넣은 배치로 본다(예: 본문 130%·체크 표시에서 가장 작은 크기로도 넘치는 줄은 까닭이 붙고 저장되지 않는다).

### REQ-6805: 고른 색대로 그리기
- AC-6805.1: Given 진료일정 안내 제목 색 c, When 그리면, Then '진료일정안내'만 c로 그린다. 본문 색 c면 안내 두 줄과 카드 이름을 c로 그리고, 날짜(흰 글자)·아래 글·'N월'·띠는 강조 색 그대로다.
- AC-6805.2: Given 환자 안내문 제목 색 c, When 그리면, Then 큰 문구 두 줄을 c로 그린다. 본문 색 c면 띠 안 줄 글을 c로 그리되 강조 낱말(em)·체크·번호 표시는 지금 색 그대로다.
- AC-6805.3: Given 로고 색 c와 색을 칠할 수 있는 로고, When 그리면, Then 그림의 모양(불투명도)은 그대로 두고 색만 c로 칠한다(SVG 필터 feFlood c + feComposite in SourceAlpha, 필터 이름은 그림마다 다르다). 이름 글자 로고는 글자를 c로 그린다. '칠할 수 있는 로고'는 이름 글자 로고이거나, 준비에 성공한 그림(크기를 앎) 중 불투명도 16 미만 점이 전체 점의 10% 이상인 것(`tintable: true`)이다. 그 밖(배경이 남은 그림, 준비 실패로 원래 그림을 쓴 경우)이나 로고 색 null이면 필터 없이 지금 그대로 그린다 — 네모 전체가 한 색이 되지 않게.
- AC-6805.4: Given 고른 크기·색, When 미리보기·그림 파일 저장·인쇄를 하면, Then 셋 다 같은 서식 값으로 같은 그림을 그린다.

### REQ-6806: 저장
