# 요구사항: 청구 메모 목록 닫힌 줄에 시술 코드×총투여량과 증상 차트

> 기능 ID: `memo-closed-chart` · 형식: 요구사항은 `### REQ-2604: 제목`, 수용 기준은 `- AC-2604.1: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다.
> 번호는 바로 앞 기능 `memo-chart-lines`(REQ-2601~2603) 다음이다. 이름·글은 모두 지어낸 값이다.

## 배경 / 목표
- 2026-11-07 사용자(배포된 메모 목록 사진과 함께): "이름 밑에 처방 코드가 쭉 나와 있잖아. 그 처방 코드에 시술 코드 있잖아. LA 코드랑 그런 거 있잖아. 그런 거 총투여량 나와 있으면 좋겠고, 그리고 증상도 우리가 지금은 한번 눌러서 증상을 차트를 보잖아. 차트로 좀 볼 수 있었으면 좋겠어." 세 모양 가운데 '차트 모양'(닫힌 줄에도 증상 칸을 열린 줄과 같은 모양으로)을 골랐다
- `memo-chart-lines`가 범위 밖으로 둔 '닫힌 줄에 증상·처방을 늘 보이기'를 이번에 한다. 그래서 그 명세의 AC-2602.3 가운데 '닫힌 줄의 머리는 지금 그대로'와 AC-2602.4('닫힌 줄은 증상·처방내역 칸이 없다')는 이 명세의 AC가 대신한다
- 자료는 이미 목록 줄(`TargetRow`)에 있다: `chartLines`·`rxRows`·`rxNames`. Worker·도우미·확장·명령은 바꾸지 않는다. 새 도우미 배포가 없다

## 요구사항

### REQ-2604: 닫힌 줄 머리에 시술 코드 ×총투여량
- AC-2604.1: Given 시술(`rxRows`의 `kind`가 `proc`)이 있는 닫힌 줄, When 그리면, Then 줄 머리 이름 아래가 `차트 N` · `시술 …` · `처방 …` 세 줄이다. 시술 줄은 시술마다 `코드 짧은이름 ×총투여량`(짧은 이름이 없으면 처방 이름)을 `rxRows` 차례대로, 같은 코드 두 줄도 합치지 않고 보인다. 총투여량을 모르면(`qty: null`) `×?`다. 시술 하나하나는 주황 바탕(`bg-negative-soft`)이다
- AC-2604.2: Given 같은 닫힌 줄, When 그리면, Then `처방` 줄은 `rxNames`(비트 표 차례, 같은 이름 하나)에서 시술 줄의 처방 이름을 뺀 것을 쉼표로 잇는다. 남는 이름이 없으면 처방 줄이 없다
- AC-2604.3: Given 시술이 없는 닫힌 줄(`rxRows`가 비어 있는 줄 포함), When 그리면, Then 시술 줄이 없고 처방 줄은 `rxNames` 모두다. `rxNames`도 비면 머리 이름 아래는 `차트 N`뿐이다
- AC-2604.4: Given 열린 줄, When 그리면, Then 머리 이름 아래는 `차트 N`뿐이다(시술·처방 줄은 아래 처방내역에 있다. AC-2602.3의 열린 줄 부분 그대로)

### REQ-2605: 닫힌 줄에도 증상 · 차트 원문
- AC-2605.1: Given 증상 줄이 있는 닫힌 줄(입력할 사람과 빠지는 사람의 모든 묶음: 이미 입력됨·메모 없음·확인 필요·직접 입력·다른 메모 있음·비트 메모를 읽지 못함·지난번 건너뜀), When 그리면, Then 지금 보이던 칸(나란히 메모·확인 필요의 우리 메모) 아래에 '증상 · 차트 원문 N줄' 칸이 열린 줄과 같은 모양(한 줄에 하나, 이름표, 종류별 바탕색, AC-2602.1)으로 있다. 지금 보이던 칸은 그대로다
- AC-2605.2: Given 닫힌 줄, When 그리면, Then 처방내역 칸('처방내역' 구역)과 '×숫자는 총투여량이에요.'는 없다(약제·기타 ×총투여량은 줄을 열면 보인다)
- AC-2605.3: Given 증상 줄이 없는 닫힌 줄(`chartLines` 빈 배열), When 그리면, Then 증상 칸이 없다
- AC-2605.4: Given 열린 줄, When 그리면, Then 증상 칸은 열린 자리에 하나뿐이다(닫힌 줄 칸과 겹쳐 두 번 나오지 않는다)
- AC-2605.5: Given `components/claim/rows/MemoRows.tsx`, When 고친 코드를 보면, Then 새 import가 없고 증상·처방은 props로만 받는다. `src/guardrails.test.ts`와 `npm run lint`가 그대로 통과한다. 메모 목록 시험(`MemoRows.test.tsx`)에서 기대값을 바꾸는 것은 AC-2602.3의 닫힌 줄 확인과 AC-2602.4 두 시험뿐이고, 나머지 시험은 그대로 통과한다

## 범위 밖
- 닫힌 줄에 처방내역 칸 전체(약제·기타의 ×총투여량, 급여/비급여). 줄을 열면 지금처럼 보인다
- 아래 메모 표(`MemoTable`)·쓰다 멈춘 사람 줄(`StuckBand`)·점검 결과 자세히(`VisitDetail`)·입력 결과 줄
- 상병 칸, 사전점검 경고 칸, 증상 칸 접기/펴기 단추
- Worker·도우미·확장·명령 표 바꾸기, 새 도우미 배포
