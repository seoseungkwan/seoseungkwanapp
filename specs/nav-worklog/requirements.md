# 요구사항: 업무일지 탭을 주요 탭 줄 수납일지 왼쪽으로

사용자 요청(2026-11-17): "더보기에 있는 업무일지 수납일지 옆으로 옮겨 / 왼쪽에". 시안 `docs/mockups/nav-worklog/`.

## 범위
- 탭 줄(주요 메뉴)과 [더보기] 판의 항목 차례만 바꾼다. 업무일지 화면·주소(/worklog)·다른 탭은 그대로다.
- 탭 차례를 따르기로 한 두 곳도 같이 옮긴다(기존 AC-307.1 대시보드 기능 목록, AC-421.2 랜딩 미리보기 탭 줄).
- 범위 밖: 새 '예약' 탭(clinic-calendar에서 따로).

### REQ-5801: 업무일지는 주요 탭이고 수납일지 바로 왼쪽이다
- AC-5801.1: Given 탭 목록(MENU), When 차례를 보면, Then 대시보드 · 통계 · 청구 · 고시·공지 · 환자 · 업무일지 · 수납일지 · AI 리포트 · 서식 · 직원 · 재고 · 주소록 · 설정 13개이고 업무일지는 `primary: true`다(주소 /worklog, ready true 그대로).
- AC-5801.2: Given 탭 줄(PRIMARY_MENU), When 그리면, Then 대시보드 · 통계 · 청구 · 환자 · 업무일지 · 수납일지 여섯이 이 차례로 보이고, [더보기] 판(MORE_MENU)은 고시·공지 · AI 리포트 · 서식 · 직원 · 재고 · 주소록 · 설정 일곱이며 업무일지가 없다.
- AC-5801.3: Given /worklog 화면, When 탭 줄을 보면, Then 탭 줄의 업무일지가 지금 탭 모양(aria-current="page")이고 [더보기] 단추 글자는 "더보기"다(판 안 탭일 때만 "더보기 · {이름}").
- AC-5801.4: Given 대시보드 기능 목록(DASHBOARD_FEATURES)과 랜딩 미리보기 탭 줄(PREVIEW_TABS), When 차례를 보면, Then 둘 다 MENU 차례를 따라 업무일지가 수납일지 바로 앞이다(AC-307.1·AC-421.2 그대로).
