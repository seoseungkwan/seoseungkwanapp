# 요구사항: 점검 규칙 표 등급 칸 '기본:' 글자 겹침 고치기

> 기능 ID: `rule-grade-help` · 형식: 요구사항은 `### REQ-001: 제목`, 수용 기준은 `- AC-001.1: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다.

## 배경 / 목표
- 2026-11-08 사용자 제보(폰·PC 사진): 설정 → 점검 규칙 표의 '등급' 칸에서 고르는 상자 옆 '기본: 확인 필요' 글자가 옆 '고시 근거' 칸 글자와 겹쳐 깨져 보인다.
- 까닭: 표 칸 공통 모양(`dsCell`)이 줄바꿈 안 함(`whitespace-nowrap`)이고, 고르는 상자는 칸 너비 100%, 그 뒤 '기본:' 글은 줄 안 글자(`span`)라 같은 줄에 남아 칸 밖 오른쪽으로 넘친다. 2026-11-01 규칙 설정 화면(80cf58d) 때부터 있던 것이고 오늘 배포와는 상관없다.
- 목표: '기본: …'을 고르는 상자 바로 아래 한 줄로 내려 어느 칸과도 겹치지 않게 한다.

## 요구사항

### REQ-3201: 등급 칸 '기본:' 글은 상자 아래 한 줄
- AC-3201.1: Given 점검 규칙 표의 규칙 줄, When 그리면, Then 등급 칸의 '기본: {등급}' 글은 고르는 상자 아래 자기 줄(블록)에 있고 상자와 사이가 조금 있다(`mt-1`). 글·등급 고르기·저장 동작은 그대로다
- AC-3201.2: Given 1440px 화면, When 규칙 표를 보면, Then '기본: …' 글이 '고시 근거' 칸 글과 겹치지 않는다(실제 브라우저 사진으로 확인)

## 범위 밖
- 표 칸 공통 모양(`dsCell`)·다른 표, 규칙 내용·등급 값, 폰 전용 모양 바꾸기
