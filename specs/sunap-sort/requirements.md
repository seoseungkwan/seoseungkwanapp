> 기능 ID: `sunap-sort` · 형식: 요구사항은 `### REQ-001: 제목`, 수용 기준은 `- AC-001.1: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다.

## 배경 / 목표
- 2026-11-17 사용자: "수납일지에서 이름·구분·예약·금액 오름차순·내림차순으로 볼 수 있게 해". '다음 예약'은 "세우는 기준 고르기"를 골랐다. 이어서 "Block 물리치료도 오름 내림차순".

## 요구사항

### REQ-5301: 줄 세우기 규칙
- AC-5301.1: Given 장부 줄들과 기준 `{ key: 'name'|'kind'|'cash'|'card'|'transfer'|'unpaid'|'block'|'pt', dir: 'asc'|'desc' }`, When `sortLedger`로 세우면, Then 이름은 가나다(한국어 비교), 구분은 초진 → 90일초진 → 재진, 금액은 그 칸 숫자(FREE 줄은 0원), Block·물리치료는 체크 안 한 줄 → 체크한 줄 순서이고 `desc`면 거꾸로다. 값이 같은 줄은 원래(접수) 차례를 지킨다
- AC-5301.2: Given 기준 `{ key: 'rsv', by: 'kind', dir }`, When 세우면, Then 종류 순 주사치료 → 진료(경과) → 기타 → 종류 모름(`desc`면 거꾸로)이고 같은 종류 안은 예약 날짜 순(`asc` 가까운 날 먼저, `desc` 먼 날 먼저, 날짜 없는 줄은 그 종류 맨 뒤)이다. '예약 안 하고 가심'은 `asc`·`desc` 모두 맨 뒤다
- AC-5301.3: Given 기준 `{ key: 'rsv', by: 'date', dir }`, When 세우면, Then 예약 날짜 순(`asc` 가까운 날 먼저, `desc` 먼 날 먼저)이고, 날짜 없는 예약 줄은 날짜 있는 줄 뒤, '예약 안 하고 가심'은 맨 뒤다. 같으면 접수 차례다
- AC-5301.4: Given 기준 `null`, When 세우면, Then 받은 차례(접수 순) 그대로다. 어떤 기준이든 받은 배열을 바꾸지 않고 새 배열을 돌려준다

### REQ-5302: 장부 화면에서 세우기
- AC-5302.1: Given 환자 장부 표, When 제목 [이름]·[구분]·[현금]·[카드]·[계좌]·[미수]·[Block]·[물리치료]를 누르면, Then 누를 때마다 오름차순(▲) → 내림차순(▼) → 접수 순(↕)으로 바뀌고, 다른 제목을 누르면 그 칸 오름차순부터다. 세운 칸의 `th`는 `aria-sort`가 `ascending`/`descending`, 나머지는 `none`이다
- AC-5302.2: Given 제목 [다음 예약], When 누르면, Then 목록(role="menu")이 펼쳐지고 항목은 차례대로 '종류 순 ▲'(주사치료 → 진료(경과) → 기타) · '종류 순 ▼'(거꾸로) · '날짜 순 ▲'(가까운 예약부터) · '날짜 순 ▼'(먼 예약부터) · '접수 순'(처음 순서로)이다. 고르면 목록이 닫히고 그 기준으로 세우며, 제목은 '다음 예약 · 종류' 또는 '다음 예약 · 날짜'와 ▲/▼로 바뀐다. Esc나 목록 바깥을 누르면 닫힌다
- AC-5302.3: Given 표 위 한 줄, When 그리면, Then 세우지 않았을 때 '제목(이름·구분·금액·Block·물리치료·다음 예약)을 누르면 줄을 세워요', 칸으로 세웠을 때 '<칸 이름> 오름차순 · 한 번 더 누르면 내림차순' 또는 '<칸 이름> 내림차순 · 한 번 더 누르면 접수 순', 다음 예약으로 세웠을 때 '다음 예약 <종류|날짜> 순 <▲|▼> · '예약 안 하고 가심'은 늘 맨 뒤 · 제목을 눌러 다른 기준·접수 순'이다
- AC-5302.4: Given 세운 표, When 그리면, Then NO는 접수 번호 그대로이고, 위 칩 거르기·이름 찾기와 함께 쓰이며, 합계 줄은 그대로다. 마감한 날(고칠 수 없는 날)에도 세울 수 있다. 세운 상태는 저장하지 않는다(다시 열면 접수 순)
