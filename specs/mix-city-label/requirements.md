# 요구사항: 환자 구성 동네 이름 겹침 구별

> 기능 ID: `mix-city-label` · 형식: 요구사항은 `### REQ-001: 제목`, 수용 기준은 `- AC-001.1: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다.

## 배경 / 목표
- 2026-11-13 비트 DB와 통계를 견주다가 찾았다. 최근 7일 환자 구성 동네 [구·시]에 `수정구` 줄이 둘 나온다.
  - 하나는 `성남시 수정구`(97명)다. 1위 시 안의 구라서 화면에 구 이름만 보인다(stats-bit-sections AC-2703.5).
  - 다른 하나는 주소를 시 없이 `수정구 …`부터 적은 환자 2명이다. 구 없는 시·군처럼 그 이름 그대로 보인다.
- 숫자는 비트와 맞지만, 이름이 같아서 어느 줄이 무엇인지 알 수 없다.
- 사용자 결정(2026-11-13): 제안 "시 없이 적은 주소는 '수정구(시 없음)'처럼"에 "2는 고쳐"라고 답했다. 숫자는 합치지 않고 이름만 구별한다.

## 요구사항

### REQ-3901: 겹치는 [구·시]·[동] 이름 구별
- AC-3901.1: Given [구·시] 묶음에 1위 시 안의 구(예: `성남시 수정구`, 화면 `수정구`)와 시 없이 같은 이름으로 적은 주소의 묶음(`수정구`)이 함께 있음, When 화면 이름을 만들면, Then 시 없는 쪽은 `수정구(시 없음)`, 1위 시 쪽은 `수정구` 그대로다. 두 줄의 명·건·지난 기간 명은 합치지 않고 지금 그대로다
- AC-3901.2: Given 시 없이 적은 구가 1위 시 안의 구 이름과 겹치지 않음(예: `서울 강남구` → `강남구`, 1위 시에 없는 `서구`), When 이름을 만들면, Then 지금처럼 그 이름 그대로다(AC-2703.5 그대로). 다른 시의 구(`용인시 기흥구`)와 구 없는 시·군(`화성시`)도 그대로다
- AC-3901.3: Given [동] 묶음에 같은 동 이름이 AC-3901.1의 두 [구·시] 묶음에 다 있음(`성남시 수정구 신흥동`, `수정구 신흥동`), When 화면 이름을 만들면, Then `신흥동 (수정구)`와 `신흥동 (수정구(시 없음))`이다(AC-2703.6의 괄호 규칙이 AC-3901.1의 [구·시] 이름을 쓴다)
- AC-3901.4: Given AC-3901.1·AC-3901.3의 기간, When [구·시] 줄 이름과 [동] 줄 이름을 각각 모두 보면, Then 같은 이름이 둘인 줄이 없다

## 범위 밖
- 시 없이 적은 주소를 1위 시로 짐작해 합치기(`중구`·`서구`처럼 여러 시에 있는 이름은 틀릴 수 있어 하지 않는다)
- 시·도만 다른 같은 이름(예: 다른 도의 같은 시 이름)
- 동네 묶기 규칙(toRegion·AC-2703.5~7의 묶음 열쇠)과 줄 고르기·차례(위 10줄, 그 밖)
- stats-bit-sections 명세 글 고치기(이 명세가 AC-2703.5·2703.6에 더하는 규칙이다)
