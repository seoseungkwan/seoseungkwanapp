# 요구사항: 수납일지 다음 예약 종류 직접 만들기

> 기능 ID: `sunap-kinds` · 형식: 요구사항은 `### REQ-001: 제목`, 수용 기준은 `- AC-001.1: Given/When/Then`.
> 각 AC 는 테스트 하나 이상으로 검증되어야 하며, 테스트 이름에 AC ID 를 넣는다.

## 배경 / 목표
- 2026-11-17 검토 뒤 고침: 말 길이 재는 법(AC-5501.2), 서버 숫자 화면 글(AC-5503.7).
- 2026-11-17 사용자(다음 예약 고르기 창 사진): "이 목록 추가 수정할 수 있게 해", "예약률도 선택하고".
- 시안 `docs/mockups/sunap-kinds/`(notes.md 승인 줄): 사용자 "이대로 만들기". 정함: 종류를 지우면 직접 고른 줄은 비트 따라가기, 비트 메모로 그 종류였던 마감한 날 줄은 종류 모름. 새 종류 예약률 처음 값 ✕ 뺌.
- 지금은 종류가 주사치료·진료(경과)·기타 셋으로 고정이고 예약률은 주사치료·진료(경과)만 센다.
- Supabase SQL 바뀜 없음: 설정은 지금 `sunap_settings.rsv_words`(jsonb, 4,000바이트 미만) 안에 목록으로 둔다. 서버 마감 숫자 24칸 모양 그대로. 도우미 바뀜 없음.

## 요구사항

### REQ-5501: 종류 목록 설정
- AC-5501.1: Given 설정, When 읽으면, Then 종류는 목록 `{id, label, counts, words}[]`이고 차례가 메모 맞춰 보는 차례다. 기본값은 주사치료(`inj`, ○, 주사·블록) → 진료(경과)(`visit`, ○, 경과·진료) → 기타(`etc`, ✕, 기타). 서버 줄 `rsv_words`에 맞는 `kinds`가 있으면 그것을, 없고 옛 모양 `{inj, visit, etc}` 말 목록이 있으면 기본 이름·예약률에 그 말을, 둘 다 아니면 기본값을 쓴다. 저장은 `rsv_words = {kinds: [...]}`로 한다
- AC-5501.2: Given 종류 목록, When 저장하거나 Worker가 받으면, Then 다음을 모두 지킬 때만 맞다(틀리면 저장은 보내지 않고 failed, Worker는 load를 거절): 종류 3~10개 · `inj`·`visit`·`etc`가 꼭 한 번씩 · 새 종류 id는 `k` + 영문 소문자·숫자 6자이고 겹치지 않음 · 이름은 앞뒤 빈칸 뺀 1~10자, 서로 겹치지 않고 '예약 안 하고 가심'·'종류 모름'이 아님 · counts는 참/거짓 · 말은 앞뒤 빈칸 뺀 1~20자이고 한 종류의 말을 ','로 이은 글이 40자 이하(말 칸 40자 안에서 적은 글은 AC-5501.3대로 다듬은 뒤에도 늘 맞는다 — 2026-11-17 검토: ', '로 재면 띄어쓰기 없이 적은 글이 저장 실패)
- AC-5501.3: Given 설정 판에서 말 칸에 쉼표(`,` 또는 `，`)로 나눈 글, When 저장하면, Then 앞뒤 빈칸을 빼고 빈 말은 버리고 겹친 말(영문 대소문자 무시)은 처음 하나만 남긴다

### REQ-5502: 종류 정하기와 숫자 [환자 자료 구역]
- AC-5502.1: Given 비트 예약 메모와 종류 목록, When 종류를 정하면, Then 목록 차례로 처음 말이 메모에 든 종류의 id이고(앞뒤 빈칸 빼고 영문 대소문자 무시, 빈 말 무시) 없으면 `unknown`이다
- AC-5502.2: Given 장부 줄, When 예약 종류를 정하면, Then 직접 고른 값이 '예약 안 하고 가심'이거나 목록에 있는 id면 그 값(직접)이고, 목록에 없는 id(지운 종류)면 직접 고르지 않은 것처럼 비트를 따른다. 마감 때 적어 둔 값(fixed)이 목록에 없는 id면 `unknown`, 'none'·'unknown'은 그대로다
- AC-5502.3: Given 장부, When 마감 숫자를 세면, Then 초진·90일 예약 수는 그 줄 종류가 목록에서 counts가 참인 줄만 센다(기본 목록이면 지금처럼 주사치료·진료(경과))
- AC-5502.4: Given PC 저장(edits.rsv·fixed)과 화면이 보낸 고르기, When Worker가 읽으면, Then edits.rsv와 고르기는 'none' 또는 종류 id 모양(`inj`·`visit`·`etc`·`k`+6자), fixed는 거기에 'unknown'까지 받고, 그 밖은 지금처럼 E-STORE-BROKEN·거절이다. load 메시지는 words 대신 kinds를 싣는다
- AC-5502.5: Given 장부 줄 세우기 '종류 순', When 세우면, Then 종류 목록 차례 → 종류 모름 → 예약 안 하고 가심(늘 맨 뒤)이고 ▼는 앞 둘의 차례만 거꾸로다(날짜 순·다른 칸은 그대로)

### REQ-5503: 화면
- AC-5503.1: Given 수납일지 설정 판, When 열면, Then '예약 메모 말' 세 줄과 노란 점선 안내 대신 제목 `다음 예약 종류`, 설명 `비트 예약 메모에 이 말이 있으면 그 종류로 정해요. 위에 있을수록 먼저 맞춰 봐요(메모에 말이 둘 다 있으면 위 종류). 말은 쉼표(,)로 나눠 적어요.`와 `예약률 ○ 넣음인 종류만 초진·90일 예약률에 세요. 주사치료·진료(경과)·기타는 기본 종류라 이름은 바꿀 수 있지만 지울 수는 없어요.`, 종류마다 한 칸(차례 번호 · 이름 칸(빈 글 `이름 (예: 도수치료)`, 10자, 읽는 이름 `N번째 종류 이름`) · 예약률 단추 `○ 넣음`/`✕ 뺌`(눌린 쪽 aria-pressed) · `▲`/`▼`(읽는 이름 `N번째 종류 위로`/`N번째 종류 아래로`, 맨 위 ▲·맨 아래 ▼는 못 누름) · 새 종류는 `지우기`, 기본 종류는 `기본`(title `기본 종류라 지울 수 없어요`) · `메모에 이 말이 있으면` 칸(빈 글 `예: 도수, 수기 (비우면 직접 고를 때만 써요)`, 40자))이 있고, PC 너비에서 목록 위에 `이름` · `예약률` · `순서` 칸 제목이 있다
- AC-5503.2: Given 설정 판, When `+ 종류 더하기`를 누르면, Then 목록 맨 아래에 이름·말 빈칸, 예약률 ✕ 뺌인 새 종류가 생기고 그 이름 칸에 글자를 넣을 수 있다(포커스). 단추 옆 글은 `종류는 10개까지 만들 수 있어요 · 지금 N개`, 10개면 단추를 못 누르고 글은 `10개를 다 만들었어요. 더 만들려면 안 쓰는 종류를 지워 주세요.`다. 목록 아래 흐린 칸 `늘 있는 줄 · 바꿀 수 없어요`에 `예약 안 하고 가심`(`비트에 다음 예약이 없을 때`, `예약률 ✕`)과 `종류 모름`(`비트 예약은 있는데 메모에 맞는 말이 없을 때`, `예약률 ✕`), 그 아래 `예약률 ○·✕를 바꾸면 아직 마감 안 한 날부터 새로 세요. 마감한 날 숫자는 그대로예요(마감을 풀고 다시 마감하면 새 설정으로 세요).`가 있다
- AC-5503.3: Given 설정 판, When `저장`을 누를 때 이름이 비었거나·같은 이름(늘 있는 줄 이름 포함)이 있거나·말 하나가 20자를 넘으면, Then 저장하지 않고 그 칸 아래에 `이름을 적어 주세요`·`같은 이름이 이미 있어요`·`말 하나는 20자까지 적을 수 있어요`, 저장 단추 위에 `빨간 칸을 고쳐 주세요`를 보인다. 맞으면 AC-5501.3대로 다듬어 저장한다(저장 뒤는 지금처럼 판이 닫힌다)
- AC-5503.4: Given 다음 예약 고르기 판, When 열면, Then 선택지는 `비트 따라가기` · `예약 안 하고 가심`(`예약률 ✕`) · 가는 선 · 설정 목록 차례대로 모든 종류(counts면 `예약률 ○`, 아니면 `예약률 ✕`)이고, 지금 팁 아래에 `종류를 더하거나 예약률 ○·✕를 바꾸려면 [설정] → 다음 예약 종류에서 해요.`가 있다. 비트 따라가기 아래 글의 종류 이름도 설정 이름이다
- AC-5503.5: Given 장부, When 그리면, Then 다음 예약 칩 글은 설정 이름이고(종류 모름·예약 안 하고 가심은 지금 글) 색은 주사치료 파랑·진료(경과) 청록·종류 모름 노랑·기타와 새 종류 회색이다. 장부 아래 설명 줄에 회색 칩(목록에서 `inj`·`visit` 아닌 첫 종류 이름)과 `설정에서 더한 종류·기타는 회색`을 더한다. 줄 세우기 메뉴의 `종류 순 ▲` 아래 글은 `설정에 둔 종류 순서대로`다
- AC-5503.6: Given 종류 모름 줄이 있는 마감 전 날, When 알림 띠를 그리면, Then `예약 종류 모름 N줄 — 비트 예약은 있는데 메모에 설정한 말이 하나도 없어요. 다음 예약 칸을 눌러 직접 고르거나, [설정] → 다음 예약 종류에서 종류나 말을 더해 주세요.`다
- AC-5503.7: Given 예약·Block 전환 카드, When 초진 예약률 아래 글을 그리면, Then `초진 N명 중 M명 · ` 뒤에 counts인 종류 이름을 목록 차례로 `·`로 이어 `예약만`(예: `주사치료·진료(경과)·도수치료 예약만`), 하나도 없으면 `예약률에 넣는 종류가 없어요`다. 서버 숫자만 보이는 화면(다른 기기·옛 도우미·62일 넘은 날)은 설정을 읽지 않으므로 뒤 글이 `예약률 ○ 종류 예약만`이다(2026-11-17 사용자 고름: 그 숫자는 마감할 때 설정으로 센 것)
- AC-5503.8: Given 통계 탭 수납일지 칸, When 그리면, Then `주사치료·진료(경과) 예약` 글은 `예약률 ○ 종류 예약`, [어떻게 세나요?] 첫 줄은 `예약률 = 수납일지 마감한 날의 합 · 마감할 때 예약률 ○였던 종류만(예약 안 하고 가심·종류 모름은 빼요)`이다(달 중간에 설정을 바꾸면 날마다 기준이 달라서 이름을 늘어놓지 않는다)
