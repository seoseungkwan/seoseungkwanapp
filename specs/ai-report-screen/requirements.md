# 요구사항: AI 리포트 탭 화면

> 기능 ID: `ai-report-screen` · 형식: 요구사항은 `### REQ-701: 제목`, 수용 기준은 `- AC-701.1: Given/When/Then`.
> 각 AC는 시험 하나 이상으로 검증하고, 시험 이름에 AC ID를 넣는다.
> 번호는 701부터다. 다른 명세(… ui-90 401~423, ai-report 501~515, bit-dashboard 601~)와 시험 이름이 겹치지 않게 한다.

## 배경 / 목표
- 승인한 시안 `docs/mockups/ai-report/index.html`(사용자 '승인해', 2026-11-02, 커밋 6835691)의 9상태를 진짜 화면으로 만든다. 글자·모양·동작은 시안이 기준이고, 시안에 없는 경우만 이 문서가 정한다('시안에 없어 정한 것').
- 뒷단(`specs/ai-report`, PR #16)은 이미 main에 있다. 이 명세는 화면과, 화면이 저장된 값을 읽는 길을 더한다.
- **탭 범위는 월간 AI 분석 하나다.** '준비 중' 안내가 약속했던 월간보고 발표 자료·주간 요약·분기와 연간 보고는 이 명세에 없다. 탭을 켜면서 그 안내 글도 사라지고, 대시보드 기능 목록의 설명은 지금 되는 일로 바꾼다.
- **지금 앱에서 실제로 볼 수 있는 상태는 '아직 안 만든 달'과 '통계가 없는 달'뿐이다.** 분석할 숫자를 저장하는 곳(`months`)이 통계 명세에 있어, [AI 분석]을 누르면 늘 `E-AI-NO-DATA`가 된다. 나머지 상태는 시험에서 가짜 답으로 증명하고, 통계 명세가 들어오면 바뀌는 코드 없이 살아난다.
- 열쇠(`ANTHROPIC_API_KEY`) 넣기와 `npm run ai:try`는 맨 마지막이다(사용자, 2026-11-02). 화면은 열쇠 없이 만들고 시험한다. 숫자가 없으면 Claude를 부르기 전에 끝나므로 지금은 열쇠 없이도 화면이 같다.

## 시안에 없어 정한 것 (승인 때 함께 본다)
1. **읽는 중**: 탭을 열거나 달을 옮긴 직후 저장된 리포트를 읽는 동안. 글자만 있고 움직임은 없다. 이때는 [AI 분석]·[다시 분석]이 없어, 있는 리포트를 모르고 덮어쓰지 못한다.
2. **읽지 못했을 때**: 새 오류 번호 `E-AI-READ`, 시안의 오류 상자와 같은 모양, 단추 [다시 읽기].
3. **달이 끝나기 전에 만든 리포트를 달이 끝난 뒤 볼 때**: 시안 글 "11월은 아직 끝나지 않은 달이에요"는 12월에는 틀린 말이 되므로 다른 글을 쓴다.
4. **리포트가 있는 달에서 [다시 분석]이 `E-AI-NO-DATA`일 때**: 옛 리포트를 그대로 두고 그 위에 오류 상자를 보인다.
5. **'숫자가 바뀐' 안내 글자 한 곳**: 시안의 "이 리포트를 만든 뒤 10월 숫자가 바뀌었어요"에서 달 이름을 뺀다. 지문은 비교하는 지난달·작년 같은 달의 숫자까지 보므로, 9월 숫자만 바뀌어도 이 안내가 뜬다. 그때 "10월 숫자"라고 하면 틀린 말이 된다.

## 요구사항

### REQ-701: 읽기 오류 번호
- AC-701.1: Given `errorInfo`, When `E-AI-READ`를 찾으면, Then what은 "저장한 AI 리포트를 읽지 못했어요", fix는 "[다시 읽기]를 눌러 주세요. 계속되면 오류 번호와 함께 문의해 주세요."이고, 문구에 "병원"이 없고 "니다."로 끝나는 문장이 없다.

### REQ-702: 저장된 리포트 검사
- AC-702.1: Given 맞는 모양의 저장 줄(달·`{ partial, summary, cards }`·지문·모델·만든 시각), When `parseSavedReport`를 부르면, Then 정해 둔 칸만 담은 `SavedReport`를 새 객체로 돌려준다.
- AC-702.2: Given 칸이 빠졌거나, 글자 칸이 글자가 아니거나, 꼬리표가 넷(`up`·`down`·`watch`·`guess`) 밖이거나, `cards`가 배열이 아닌 저장 줄, When 검사하면, Then null이다.
- AC-702.3: Given 저장 줄의 `report`에 정해 둔 칸 밖의 칸이 더 있음, When 검사하면, Then 돌려준 값에 그 칸이 없다.

### REQ-703: 화면 글자를 만드는 순수 함수
- AC-703.1: Given 오늘 2026-11-18, When 첫 달을 물으면, Then 지난달 2026-10이다. Given 고를 수 있는 처음 달 2026-01보다 앞이 되면, Then 2026-01이다.
- AC-703.2: Given 이번 달 2026-11과 처음 달 2026-01, When 옮길 수 있는지 물으면, Then 2026-11에서는 다음 달로 못 가고 2026-01에서는 이전 달로 못 간다. 그 사이에서는 둘 다 간다.
- AC-703.3: Given 달 2026-10, When 견주는 글을 만들면, Then "2026년 10월을 9월, 작년 10월과 견줘요"다. Given 2026-01, Then 지난달 자리가 "작년 12월"이다.
- AC-703.4: Given 저장 시각과 지금의 차이가 60초 미만, When 만든 때 글을 만들면, Then "방금 만들었어요"다. 60초 이상이면 한국 시각으로 "11월 2일 오전 9:12에 만들었어요"이고, 낮 12시는 "오후 12:00", 밤 0시는 "오전 12:00"이다.
- AC-703.5: Given 모델 `claude-opus-5-5`, When 이름을 물으면, Then "Claude Opus 5.5"다. Given 그 밖의 모델 이름(예: 대신 답한 모델), Then 받은 글자 그대로다.
- AC-703.6: Given 사용량 입력 10,000·출력 4,060 토큰·3회·비용 120,000(백만분의 1달러), When 표시 글을 만들면, Then "3회"·"14,060개"·"$0.12"다. 비용은 센트 아래를 버린다(1,999,999는 "$1.99"). 사용량이 없는 달은 "0회"·"0개"·"$0.00"이다.
- AC-703.7: Given 리포트, When 복사할 글을 만들면, Then "2026년 10월 보고", 빈 줄, 요약, 빈 줄, 카드마다 "[늘었어요] 문장" 다음 줄에 근거 줄이고 카드 사이는 빈 줄이다.
- AC-703.8: Given 리포트의 `partial`이 true이고 고른 달이 이번 달, When 안내를 고르면, Then 칩은 "진행 중", 안내는 "11월은 아직 끝나지 않은 달이에요"와 "숫자가 적게 보일 수 있어요. 달이 끝난 뒤 다시 분석하면 다 찬 숫자로 써요."다. Given `partial`이 true이고 그 달이 이미 지남, Then 칩은 "달 끝나기 전", 안내는 "이 리포트는 11월이 끝나기 전에 만들었어요"와 "숫자가 적게 잡혀 있을 수 있어요. [다시 분석]을 누르면 다 찬 숫자로 써요."다. Given `partial`이 false, Then 칩·안내가 없다.

### REQ-704: 저장된 값 읽기
- AC-704.1: Given 사용자 세션 클라이언트와 달, When `readSavedReport`를 부르면, Then `ai_reports`에서 그 달 줄을 읽어 검사한 `SavedReport`를 돌려주고, 줄이 없으면 null을 돌려준다. 병원을 고르는 조건은 넣지 않는다(RLS가 내 병원 줄만 보여 준다).
- AC-704.2: Given 읽기 오류이거나 검사를 못 넘는 줄, When 부르면, Then "읽지 못함"을 돌려주고 오류 내용은 밖에 내지 않는다.
- AC-704.3: Given 한국 날짜 기준 이번 달, When `readUsage`를 부르면, Then `ai_usage`의 이번 달 줄에서 횟수·토큰 합(입력+출력)·비용을 돌려준다. 줄이 없으면 모두 0이고, 오류면 "읽지 못함"이다.

### REQ-705: 숫자가 바뀌었는지 보기
- AC-705.1: Given 어떤 세 달 자료로 `generateReport`가 저장한 지문, When 같은 세 달 자료로 `isReportStale`을 부르면, Then false다(만들 때와 같은 방법으로 입력을 만든다).
- AC-705.2: Given 같은 저장 지문, When 고른 달이나 지난달이나 작년 같은 달의 숫자 하나가 바뀐 자료로 부르면, Then true다.
- AC-705.3: Given 고른 달 숫자가 없거나 검사를 못 넘거나 그 달이 아닌 자료, 또는 숫자 읽기가 실패, When 부르면, Then false다(모르면 "바뀌었어요"라고 하지 않고, 리포트 보기를 막지 않는다). 비교 달이 검사를 못 넘거나 그 달이 아니면 만들 때처럼 없는 달로 본다.

### REQ-706: 서버 경로 `GET /api/ai/report`
- AC-706.1: Given 로그인 안 함, When `GET`을 부르면, Then 401이고 몸통이 없다. 승인 안 된 병원·병원 없음이면 403이다.
- AC-706.2: Given `?month=` 값이 없거나, `YYYY-MM`이 아니거나, 이번 달(한국 날짜)보다 뒤, When 승인된 사용자가 부르면, Then 400이고 DB를 읽지 않는다.
- AC-706.3: Given 승인된 사용자와 저장된 리포트가 있는 달, When 부르면, Then 200 `{ report, stale, usage }`이고 `report`에 지문(`inputHash`)이 없다. 응답 머리에 `Cache-Control: no-store`가 있다.
- AC-706.4: Given 저장된 리포트가 없는 달, When 부르면, Then 200 `{ report: null, stale: false, usage }`이고 숫자 읽기(`loadReportMonths`)를 부르지 않는다.
- AC-706.5: Given 리포트나 사용량을 읽지 못함, When 부르면, Then 502 `{ code: 'E-AI-READ' }`이고 `console.error` 한 줄에 경로와 오류 번호만 있으며 달·숫자·글자는 없다.
- AC-706.6: Given 경로 파일, When `POST`를 부르면, Then 뒷단 명세(REQ-512)의 동작이 그대로이고 `runtime`·`maxDuration`도 그대로다.

### REQ-707: 브라우저 쪽 부르기
- AC-707.1: Given 달, When `analyzeMonth`를 부르면, Then 같은 origin의 `POST /api/ai/report`에 몸통 `{"month":"YYYY-MM"}` 하나만 보내고, 숫자는 보내지 않으며, 다른 곳으로 돌려보내는 응답을 따라가지 않는다.
- AC-707.2: Given `analyzeMonth`의 응답, When 200 `{ report }`면 그 리포트, `{ code }`에 AI 오류 번호가 있으면 그 번호다. 응답을 못 받았거나(연결 끊김) 몸통 없는 5xx·JSON이 아닌 5xx면 `E-AI-BUSY`, 그 밖은 `E-AI-FAILED`다.
- AC-707.3: Given `loadMonth`의 응답, When 200이고 모양이 맞으면 `{ report, stale, usage }`이고, 몸통 모양이 틀리거나 응답을 못 받았거나 그 밖의 상태면 `E-AI-READ`다.
- AC-707.4: Given 두 함수의 응답이 401·403이거나 다른 곳으로 돌려보내는 응답(로그인이 끊겨 middleware가 `/login`으로 보냄), When 받으면, Then "로그인 확인 필요"를 돌려준다. 화면은 이때 페이지를 다시 읽어 문지기가 갈 곳을 정하게 한다.

### REQ-708: 화면 — 달과 머리
- AC-708.1: Given 탭을 엶, When 그리면, Then 제목 "AI 리포트", 견주는 글, 달 고르기(이전·다음 단추, 달 글자 `aria-live="polite"`)가 있고 첫 달은 지난달이다.
- AC-708.2: Given 달을 옮김, When 그리면, Then 그 달을 새로 읽고, 앞 달의 오류·복사 표시는 사라진다.
- AC-708.3: Given 달을 빠르게 두 번 옮겨 앞 달의 답이 뒤에 도착, When 그리면, Then 마지막에 고른 달의 내용만 보인다.
- AC-708.4: Given 읽는 중, When 그리면, Then "<달> 리포트를 읽고 있어요"가 `role="status"`로 있고, [AI 분석]·[다시 분석]이 없으며, 사용량 값은 "—"다. 움직이는 효과가 없다.
- AC-708.5: Given 읽기가 `E-AI-READ`, When 그리면, Then 오류 상자(`role="alert"`, 무엇·어떻게·오류 번호)와 [다시 읽기]가 있고 [AI 분석]·[다시 분석]이 없다. 사용량 값은 "—"다. [다시 읽기]를 누르면 그 달을 다시 읽는다.

### REQ-709: 화면 — 리포트 있는 달
- AC-709.1: Given 리포트가 있는 달, When 그리면, Then "<YYYY년 M월> 보고", 만든 때와 모델 이름, 요약(제목 2단계), 카드 목록(`<ol>`)이 있고 카드마다 꼬리표 칩·문장·근거 줄이 저장된 순서대로 있다. [다시 분석]은 보조 단추다.
- AC-709.2: Given 꼬리표 넷, When 칩을 그리면, Then `up`은 "늘었어요"(positive, 위 화살표), `down`은 "줄었어요"(negative, 아래 화살표), `watch`는 "살펴볼 것"(warning, 아이콘 없음), `guess`는 "추정"(neutral, 아이콘 없음)이다.
- AC-709.3: Given 문장·요약·근거 줄에 `<b>`나 `<script>` 글자가 있음, When 그리면, Then 글자 그대로 보이고 HTML로 그리지 않는다(`dangerouslySetInnerHTML` 없음).
- AC-709.4: Given `partial`이 true인 리포트, When 그리면, Then REQ-703의 칩과 안내 상자가 있다.
- AC-709.5: Given 서버가 `stale: true`로 답함, When 그리면, Then 안내 상자 "이 리포트를 만든 뒤 숫자가 바뀌었어요"와 "[다시 분석]을 누르면 새 숫자로 다시 써요."가 있고 [다시 분석]이 주 단추로 바뀐다. `stale: false`면 안내가 없고 보조 단추다.
- AC-709.6: Given [복사]를 누름, When 복사가 되면, Then 복사할 글이 클립보드에 들어가고 단추가 2초 동안 "복사했어요"다. Given 복사가 실패, Then `role="status"`에 "복사하지 못했어요. 문장을 길게 눌러 직접 복사해 주세요."가 2.2초 동안 보인다.

### REQ-710: 화면 — 리포트 없는 달과 분석
- AC-710.1: Given 리포트가 없는 달, When 그리면, Then "<M월> 리포트를 아직 만들지 않았어요", 견주는 달이 든 설명, 주 단추(큰) [AI 분석]이 있고 머리에는 [다시 분석]이 없다.
- AC-710.2: Given 리포트 없는 달에서 [AI 분석]을 누름, When 기다리는 동안, Then "<M월> 숫자를 읽고 있어요", `role="status"`의 "1분쯤 걸려요. 이 화면을 그대로 두고 기다려 주세요.", `aria-busy="true"` 단추 "분석 중", "지금까지 N초"(1초마다 늘어남)가 있다. 이전·다음 달 단추는 막힌다.
- AC-710.3: Given 기다리는 중, When "분석 중" 단추를 다시 누르면, Then 요청을 또 보내지 않는다.
- AC-710.4: Given 분석 성공, When 끝나면, Then 받은 리포트와 "방금 만들었어요"가 보이고 그 달을 다시 읽어 사용량과 숫자 바뀜 여부를 새로 한다. 다시 읽기가 실패해도 받은 리포트는 그대로 보이고 오류 상자를 띄우지 않는다.
- AC-710.5: Given 리포트 없는 달에서 답이 `E-AI-NO-DATA`, When 그리면, Then "이 달 통계가 아직 없어요", "통계 탭에서 그 달 비트 자료를 먼저 넣어 주세요.", `/stats`로 가는 보조 단추 "통계 탭으로"(화살표), "오류 번호 E-AI-NO-DATA"가 있고 [AI 분석]은 없다. 다른 달로 옮겼다 돌아오면 다시 '아직 만들지 않았어요'다.
- AC-710.6: Given 답이 `E-AI-BUSY`·`E-AI-LIMIT`·`E-AI-FAILED`, When 그리면, Then 오류 상자(`role="alert"`)에 `errorInfo`의 무엇·어떻게·"오류 번호 <번호>"가 있고, 리포트가 있으면 리포트가, 없으면 [AI 분석]이 있는 빈 화면이 그대로 있다. 끝난 뒤에는 사용량을 다시 읽는다.

### REQ-711: 화면 — 다시 분석
- AC-711.1: Given [다시 분석]을 누름, When 그리면, Then 확인 창(`role="dialog"`, `aria-modal`, 제목 "<M월> 리포트를 다시 만들까요?", "지금 리포트를 덮어써요. 옛 리포트는 남지 않고, AI 비용이 한 번 더 들어요.", [취소]·[다시 분석])이 뜨고 초점이 창의 [다시 분석]에 있다. 이때 요청은 아직 보내지 않는다.
- AC-711.2: Given 확인 창, When [취소]·Esc·뒤 가림막을 누르면, Then 창이 닫히고 초점이 머리의 [다시 분석]으로 돌아오며 요청을 보내지 않는다.
- AC-711.3: Given 창의 [다시 분석]을 누름, When 기다리는 동안, Then 옛 리포트가 그대로 있고 안내 상자 "새 리포트를 만들고 있어요" · "1분쯤 걸려요. 다 되면 아래 리포트가 바뀌어요." · "지금까지 N초", `aria-busy="true"` 보조 단추 "분석 중"이 있다.
- AC-711.4: Given 리포트 있는 달의 다시 분석이 오류(`E-AI-NO-DATA` 포함), When 그리면, Then 옛 리포트가 그대로 있고 그 위에 그 번호의 오류 상자가 있다. '통계 탭으로' 빈 화면으로 바꾸지 않는다.

### REQ-712: 화면 — 옆 칸
- AC-712.1: Given 읽기 성공, When 그리면, Then 옆 칸(`<aside>`)에 "이번 달 AI 사용량"의 분석 횟수·토큰·비용과 "정확한 청구 금액은 Anthropic 콘솔에서 봐요."가 있다. 고른 달과 상관없이 늘 이번 달 값이다.
- AC-712.2: Given 어느 상태든, When 그리면, Then "AI에게 보내는 것"과 "집계 숫자와 처방·동네 이름만 보내요. 환자 이름과 차트번호는 보내지 않아요."가 있다.

### REQ-713: 로그인이 끊겼을 때

### REQ-714: 탭 켜기

- AC-714.2: Given `NOT_READY_FEATURES`, When 읽으면, Then `/ai-report`가 없다.
- AC-714.3: Given `/ai-report` 페이지, When 읽으면, Then `NotReadyScreen`을 쓰지 않고, 브라우저 탭 이름은 "AI 리포트"이며, 요청 때의 한국 날짜를 화면에 넘긴다(`dynamic = 'force-dynamic'`).
- AC-714.4: Given 대시보드 기능 목록, When 읽으면, Then 'AI 리포트'는 `status: 'ready'`이고 설명은 "지난달·작년 같은 달과 견준 월간 AI 보고"이며 "사용 가능" 표시가 붙는다. "준비 중" 표시 수와 기능 목차 옆 글의 숫자는 `DASHBOARD_FEATURES`에서 센 수다(worklog AC-012.5, 시험은 손으로 적지 않는다. 2026-11-02 합친 뒤 값은 "준비 중" 8개, 옆 글 "12개 가운데 3개는 지금, 1개는 연결하면 쓸 수 있어요").
