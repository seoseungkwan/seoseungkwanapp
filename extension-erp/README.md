# ERP 마감일지 채우기 (크롬 확장) 설치·사용 안내

이 확장은 ERP 마감일지 화면(`https://erp.minesolution.com/h/closing`) 오른쪽 아래에 **[기간 채우기]**와 **[비트 값 채우기]** 단추를 붙입니다.

- **[비트 값 채우기]**: 이 PC의 **ERP 도우미**가 화면의 '마감 일자' 하루치 숫자를 비트에서 세어, 비트로 셀 수 있는 마감일지 칸에 넣습니다.
  **저장은 하지 않습니다.** 숫자를 확인한 뒤 직접 저장해 주세요('5. 매일 쓰는 법').
- **[기간 채우기]**: 고른 기간의 날마다 같은 비트 숫자를 넣고, ERP의 **'전체 저장'**·**'일일 상세 저장'**까지 눌러 줍니다(아래 '기간 채우기').

- 비트가 깔린 PC의 크롬에 설치합니다. **관리자 권한은 필요 없습니다.**
- 확장 **'청구 사전점검 연결'**이나 **'청구 사전점검 도우미'**를 쓰고 있다면, 그것과 청구 화면은 그대로입니다. 같이 깔아 두어도 됩니다.
- **확장과 ERP 도우미는 정해 둔 짝끼리 씁니다**(지금 확장 0.3.0 ↔ ERP 도우미 0.3.0). ERP 도우미가 새 판으로 나오면 꼭 같이 바꿉니다('7. 새 판으로 바꾸기').
- 설정의 처음 값은 **이 확장을 만든 의원 기준**입니다. 다른 의원에서는 처음 한 번 '4. 다른 의원 첫 설정'을 꼭 합니다.

## 1. 먼저 ERP 도우미 설치

이 확장은 **ERP 도우미**가 있어야 움직입니다. 청구 사전점검 도우미와는 다른 프로그램입니다.

- 순서는 [ERP 도우미 설치 안내](../helper-erp/install/README.md)에 있습니다.
  짧게: `seoseungkwan-erp-helper-<판>.zip`을 **모두 압축 풀기** → 푼 폴더의 `install.cmd`를 두 번 누르기 →
  끝에 뜨는 **비트 로그인 창**에서 로그인 → **PC 확인 창**에서 **[확인]** → 검은 창에 **'이 PC를 등록했어요.'**
- 확장과 **짝인 판**의 ERP 도우미를 깝니다(확장 0.3.0 ↔ ERP 도우미 0.3.0).

## 2. 크롬에 확장 붙이기

1. 받은 확장 zip을 오른쪽 클릭 → **모두 압축 풀기**를 누릅니다.
   푼 폴더는 지우거나 옮기지 마세요. 크롬이 그 폴더를 계속 씁니다.
2. 크롬 주소창에 `chrome://extensions`를 넣고 엔터를 누릅니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**(크롬 판에 따라 '압축해제된 확장 프로그램 로드')를 누르고, 1에서 푼 폴더를 고릅니다.
   (고르는 폴더 안에 `manifest.json` 파일이 바로 보여야 합니다.)
5. 목록에 **ERP 마감일지 채우기**가 보이면 끝입니다.

## 3. 처음 한 번: 설정 저장

1. ERP에서 마감일지 화면을 엽니다. 이미 열려 있었으면 새로고침(F5)합니다.
2. 오른쪽 아래 **[비트 값 채우기]**를 누릅니다.
   처음에는 칸을 채우지 않고 **'처음 한 번 설정 화면에서 코드를 확인하고 [저장]을 눌러 주세요.'**가 뜨며 설정 화면이 새 탭으로 열립니다.
3. 설정 화면 위에 **'코드 목록을 받는 중이에요(30초쯤).'**가 보이면 기다립니다. 비트에서 최근 1년 동안 쓴 코드 목록을 받는 중입니다.
4. 항목마다 셀 비트 처방 코드를 확인합니다.
   - 처음 값이 들어 있습니다(아래 표, **만든 의원 기준**). 다른 의원이면 '4. 다른 의원 첫 설정'대로 바꿉니다.
   - 찾기 칸에 코드나 이름 일부를 넣으면 최근 1년 동안 쓴 코드가 나옵니다. 누르면 더해지고, 코드 옆 **[×]**로 뺍니다.
   - 아래 **예약** 6줄(주사·경과·도수·충격파·진료예약·기타)은 처음엔 비어 있습니다. 줄마다 비트 예약 메모 번호를 고릅니다('4-3').
5. **[저장]**을 누릅니다. **'저장했어요.'**가 보이면 됩니다. 묻는 글이나 막는 글이 나오면 '4-5. 저장할 때 나오는 글'을 봅니다.
6. ERP 화면으로 돌아와 **[비트 값 채우기]**를 다시 누릅니다.

### 처음 값 (만든 의원 기준)

| 항목 | 처음 값 |
|---|---|
| 씨암 | `CARM1` · 매출로 셀 코드: 셀 코드 없음 |
| SONO | `SONO1` · 매출로 셀 코드: 셀 코드 없음 |
| 관절조영 | `HA280` |
| 도수 | `도수` |
| 충격파 | `ESWT7`·`ESWT10`·`ESWT12`·`ESWT17` |
| 물리치료 | `MM010`·`MM015`·`MM011`·`MM085`·`MM080`·`MM020` |
| 기타1 (ERP 줄 이름 '크라이오') | `CRYO`·`CRYO3` |
| 물리치료내원 | `AA222` |
| 그 밖의 항목 · 기타2~4 · 예약 6줄 | 비어 있음 |

### 설정 화면 다른 단추

- **[처음 값으로]**: 먼저 **'고른 코드와 씨암·SONO 매출 규칙을 처음 값으로 바꿀까요?'** · '예약 메모 번호와 기타 줄 이름은 그대로 둬요. 바꾼 뒤 [저장]을 눌러야 저장돼요.'로 묻습니다. **[바꾸기]**를 누르면 화면만 바뀌고(읽지 않을 처방 규칙도 비웁니다, '4-6'), **[그만두기]**면 그대로입니다.
- 바꾼 것을 저장하지 않고(**'바꾼 것을 아직 저장하지 않았어요.'**) 탭을 닫거나 새로고침하면 크롬이 나갈지 묻는 창을 띄웁니다. 저장하려면 그 창에서 나가지 말고 **[저장]**을 누릅니다.
- 설정 화면은 나중에 결과 안내의 **[설정 열기]**, 또는 `chrome://extensions` → 이 확장의 **세부정보** → **확장 프로그램 옵션**으로도 엽니다.

## 4. 다른 의원 첫 설정

처음 값은 이 확장을 만든 의원의 비트 코드입니다. 의원마다 처방 코드·예약 메모 번호·ERP 줄 이름이 다를 수 있습니다.
다른 의원에서는 처음 한 번 아래를 차례로 맞추고 **[저장]**합니다.

### 4-1. 처방 코드를 우리 의원 코드로

1. 항목 줄마다 고른 코드를 봅니다. 코드 옆에 **'(최근 1년 처방 없음)'**이 붙어 있으면 우리 의원 비트에서 1년 동안 쓰지 않은 코드입니다. 대개 만든 의원 코드이니 **[×]**로 뺍니다.
2. 찾기 칸에 우리 의원 코드나 이름 일부를 넣고, 나온 코드를 눌러 더합니다(항목마다 20개까지).
3. 어떻게 세는지: '그날 고른 코드 가운데 하나라도 받은 환자 수를 건수로, 그날 고른 코드 처방 줄의 금액 합을 매출로 채워요. 씨암 · SONO 매출은 그 줄의 '매출로 셀 코드'로 세요.'
4. **물리치료내원**은 고른 코드를 받은 환자(신환·90일초진 아님)를 물리치료내원으로 세고, 재진·진찰료 산정안함에서 뺍니다. 우리 의원에서 물리치료내원으로 셀 때 쓰는 코드를 고릅니다.

### 4-2. 씨암·SONO 표시 코드와 '매출로 셀 코드'

- 씨암·SONO 줄에 고른 코드는 그 진료가 씨암·SONO인지 알아보는 **표시 코드**입니다. 의원마다 다릅니다(만든 의원은 `CARM1`·`SONO1`). 건수는 이 코드로 셉니다.
- 매출은 그 줄 아래 **'매출로 셀 코드'**로 셉니다. 화면 글: '{이름} 코드가 있는 진료에서 아래 코드의 금액만 치료별 매출 {이름}에 넣어요.'
  - **'셀 코드'**: 매출로 셀 시술 코드를 찾기 칸에 코드나 이름 일부를 넣어 찾고, 나온 코드를 눌러 하나씩 더합니다(20개까지). 안 맞는 코드는 **[×]**로 뺍니다. 처음 값은 셀 코드 없음입니다.
  - 찾기 칸에 두 글자 이상 넣고 잠시 멈추면 비트에 등록된 코드 전부에서 찾습니다(1년 동안 쓰지 않은 코드도 나옵니다). 찾는 동안 '찾는 중…', 없으면 '등록된 코드에 없어요.'가 보이고, 이미 더한 코드는 '더함'으로 보여 눌리지 않습니다.
  - ERP 도우미가 예전 판이면 최근 1년 동안 쓴 코드에서만 찾고, 찾기 칸 아래에 'ERP 도우미를 새 판으로 바꾸면 비트에 등록된 코드 전부에서 찾을 수 있어요.'가 보입니다. 다른 문제가 있으면 그 오류 글('6-1. 오류 표')이 보이고 1년 동안 쓴 코드에서 찾습니다.
  - 셀 코드가 비면 **'비어 있으면 위 코드 줄 금액만 넣어요.'**대로 표시 코드 줄 금액만 넣습니다.
  - 확장을 새 판으로 바꾼 뒤에는 씨암·SONO 셀 코드를 꼭 확인합니다('7. 새 판으로 바꾸기').
- 한 진료에 씨암·SONO 표시 코드가 함께 있으면, 채울 때 어디에 넣을지 묻습니다('5. 매일 쓰는 법').

### 4-3. 예약 메모 번호

- 업무일지 2 예약 6줄(주사·경과·도수·충격파·진료예약·기타(수액,드레싱등))마다 비트 예약 메모 번호를 고릅니다. 고른 번호들의 예약을 더해 총갯수·내원·변경·취소를 채웁니다. 실예약환자수는 늘 채웁니다.
- 번호는 의원마다 다릅니다. 우리 의원 비트에서 어떤 번호를 어느 예약에 쓰는지 보고 고릅니다.
- **한 번호는 한 줄에만** 둡니다. 두 줄에 같은 번호가 있으면 저장되지 않습니다('4-5').

### 4-4. 기타 줄 이름

- 기타1~4는 ERP 업무일지 2 치료별 건수·치료별 매출 표에서 의원이 따로 만든 줄입니다. **'ERP 줄 이름'** 칸에 ERP 업무일지 2 그 줄 이름을 **글자 그대로** 넣습니다(20자까지). 만든 의원은 기타1 = '크라이오'입니다.
- 이름이 ERP 줄 이름과 다르면 그 줄을 찾지 못합니다('화면에서 찾지 못한 칸'으로 나옵니다).
- 코드를 골랐는데 이름이 비어 있으면, 채운 뒤 **'ERP 줄 이름이 빈 기타 줄'**로 알려 줍니다.
- 이런 이름은 저장되지 않습니다(영문 대소문자와 빈칸 수는 따지지 않고 견줍니다).
  - 업무일지 2에 이미 있는 줄 이름: 씨암(주사)·SONO(주사)·관절조영·도수·충격파·씨암·SONO·물리치료
  - 다른 기타 줄과 같은 이름

### 4-5. 저장할 때 나오는 글

[저장]을 누르면 아래 차례로 봅니다.

1. **막는 글**(겹친 것마다 한 줄, 끝에 '저장하지 않았어요.'). 고친 뒤 [저장]을 다시 누릅니다.
   - '기타{n} 줄 이름 ‘{이름}’은 업무일지 2에 이미 있는 줄 이름이에요. 다른 이름을 넣어 주세요.'
   - '기타{n}·기타{m} 줄 이름이 ‘{이름}’으로 같아요. 서로 다르게 넣어 주세요.'
   - '예약 메모 {번호}번이 {줄 이름}·{줄 이름} 줄에 함께 있어요. 한 줄에만 두세요.'
2. **묻는 글**: **'최근 1년에 처방이 없는 코드 {N}개 — 맞나요?'** · '{항목 이름} {코드}' · '다른 의원 코드거나 잘못 고른 코드면 그 칸은 매일 0이 돼요.'
   - 이번에 새로 고른 코드만 셉니다(처음 저장이면 고른 코드 모두).
   - 맞으면 **[그대로 저장]**, 아니면 **[돌아가기]**를 누르고 코드를 고친 뒤 [저장]합니다.
3. **'저장했어요.'** — 끝입니다.

저장이 안 되면 **'저장하지 못했어요. 이 화면을 닫지 말고 [저장]을 다시 눌러 주세요.'**가 나옵니다. 화면을 닫지 말고 [저장]을 다시 누릅니다.

### 4-6. 읽지 않을 처방

- 건수를 세는 줄마다 코드 줄 아래에 **'읽지 않을 처방'** 줄이 있습니다(씨암·SONO는 '매출로 셀 코드' 줄 아래).
  - 치료별 건수 · 매출: 씨암·SONO·관절조영·도수·충격파·물리치료·기타1~4
  - 진료 · 치료현황만: 도수상담·리푸스·손발톱케어·CT·수술
  - 운영 지표: ESWT Standard·ESWT Radial
  - 주사1회환자·물리치료내원 줄에는 없습니다.
- 화면 글: '고른 처방은 같이 있을 처방이 한 진료에 있으면 {이름}에 세지 않아요. 그 처방만 없는 것으로 보고, 같은 진료의 다른 {이름} 처방은 그대로 세요. 그 처방 때문에만 {이름}에 들던 진료는 건수에서도 빠져요.'
- 규칙 만들기(새 규칙 칸):
  1. **'이 처방'**에서 그 줄 코드를 고릅니다(씨암·SONO는 셀 코드도 고를 수 있습니다).
  2. **'같이 있을 처방'** 찾기 칸에서 코드를 찾아 눌러 담습니다(5개까지, 조각 옆 **[×]**로 뺍니다). 찾기는 '셀 코드' 찾기와 같습니다('4-2'). 목록에서 '이 처방'과 같은 코드는 '이 처방', 이미 담은 코드는 '담음'으로 보여 눌리지 않습니다.
  3. **'빼는 때'**를 고릅니다: **'하나라도 있으면'**(처음 선택) 또는 **'모두 있을 때만'**.
  4. **[규칙 더하기]**를 누르면 규칙이 목록 끝에 더해지고 새 규칙 칸이 빕니다. 칸 아래 글: "'이 처방'을 고르고 같이 있을 처방을 찾아 담은 뒤 [규칙 더하기]를 누르세요. 규칙은 20개, 같이 있을 처방은 5개까지예요."
- 규칙은 '{코드} — {같이 있을 처방} 같이 있으면 안 셈'처럼 보입니다. 같이 있을 처방이 둘 이상이면 '같이 있으면' 자리에 '하나라도 있으면' 또는 '모두 있으면'이 옵니다. 규칙 옆 **[×]**로 지웁니다. 규칙이 없으면 '규칙이 없으면 지금처럼 모두 세요.'입니다.
- 예: 씨암 셀 코드 `LA357`이 `LA248`과 같이 있는 진료는 SONO이니 씨암에서 세지 않으려면 씨암 줄에서 '이 처방' `LA357`, 같이 있을 처방 `LA248`로 규칙을 더합니다. 진료를 그 줄에서 통째로 빼려면 그 줄 코드(예: `CARM1`)를 '이 처방'으로 고릅니다. 같은 '이 처방'에 조건이 다른 규칙을 여러 개 둘 수 있습니다.
- 규칙을 더하지 못하면 칸 아래 글 자리에 까닭이 나옵니다: '이 처방을 골라 주세요.' · '같이 있을 처방을 하나 이상 담아 주세요.' · '이미 있는 규칙이에요.' · '규칙은 20개까지예요.' '이 처방'도 같이 있을 처방도 비었으면 [규칙 더하기]는 눌리지 않습니다.
- 새 규칙 칸에 담는 중인 것은 저장되지 않습니다. [규칙 더하기]로 목록에 넣은 뒤 **[저장]**을 눌러야 저장됩니다.
- 줄에서 코드(씨암·SONO는 셀 코드 포함)를 빼면 그 코드가 '이 처방'인 규칙도 빠집니다. **[처음 값으로]**는 규칙도 비웁니다.

## 5. 매일 쓰는 법

1. ERP 왼쪽 메뉴 **'마감 · 입력'** → 달력에서 날짜 칸(또는 **'오늘 업무일지 입력'**)을 눌러 **마감일지** 화면을 엽니다.
2. 화면의 **마감 일자**가 채울 날인지 봅니다. 오늘이나 지난 날만 채웁니다(오늘은 진료 중 중간 확인도 됩니다).
3. 오른쪽 아래 **[비트 값 채우기]**를 누릅니다. **'비트에서 읽는 중…'**이 보이는 동안 기다립니다.
4. 채우기 전에 멈추거나 묻는 글이 나올 수 있습니다(아래 '채우기 전에 나오는 글').
5. 채운 뒤 안내를 위에서부터 읽습니다(아래 '채운 뒤 안내').
6. 아래 '직접 넣는 칸'을 채웁니다.
7. 업무일지 1 **[전체 저장]**과 업무일지 2 **[일일 상세 저장]**을 **직접** 누릅니다. [비트 값 채우기]는 저장 단추를 누르지 않습니다.

`{ }` 자리에는 그날 날짜·숫자가 들어갑니다.

### 채우기 전에 나오는 글 (해당할 때만)

| 화면 글 | 뜻과 할 일 |
|---|---|
| **'마감 일자({날짜})가 오늘보다 뒤예요.'** · '날짜를 확인해 주세요.' · '아무 칸도 바꾸지 않았어요.' | 내일 이후 날짜는 채우지 않습니다. 마감 일자를 오늘이나 지난 날로 고친 뒤 다시 누릅니다. |
| **'{날짜}에는 비트 진료가 한 건도 없어요.'** · '마감 일자가 맞는지 확인해 주세요. 맞으면 [그래도 채우기]로 채울 수 있어요(쉬는 날 예약 칸 등).' · '아직 아무 칸도 바꾸지 않았어요.' | 날짜가 틀렸으면 **[안내 닫기]**(엔터만 누르면 이것)를 누르고 날짜를 고칩니다. 쉬는 날이라 맞으면 **[그래도 채우기]**를 누릅니다. |
| **'씨암·SONO 코드가 함께 있는 진료가 {N}건 있어요(씨암 쪽 {A}원 · SONO 쪽 {B}원). 어디에 넣을까요?'** | **[씨암에 넣기]** · **[SONO에 넣기]** · **[둘 다 넣기]** 가운데 하나를 누릅니다. 지난번에 고른 단추에는 ' (지난번)'이 붙습니다. [안내 닫기]면 아무 칸도 바꾸지 않습니다. |
| **'이미 적힌 칸 {N}개가 비트 값으로 바뀌어요.'** · '바뀌는 칸: …' · '[빈 칸만]을 누르면 적힌 칸은 그대로 두고 빈 칸만 채워요.' | 손으로 적어 둔 값을 지키려면 **[빈 칸만]**(엔터만 누르면 이것), 모두 비트 값으로 바꾸려면 **[바꾸기]**, 그만두려면 **[안내 닫기]**를 누릅니다. |
| **'이 화면은 읽기 전용이라 채울 수 없어요(본사 열람 등).'** · '아무 칸도 바꾸지 않았어요.' | 잠긴 화면입니다. 입력할 수 있는 화면에서 다시 누릅니다. |

- **이미 적힌 칸**: 지금 숫자가 적혀 있고 넣을 값과 다른 칸입니다. 비었거나 '-'이거나 **0인 칸은 빈 칸으로 봅니다.** 그래서 0을 적어 둔 칸은 묻지 않고 비트 값으로 바뀝니다([되돌리기]로 돌릴 수 있습니다).
- **바뀌는 칸** 이름은 짧게 보입니다. 예: '예약 경과' · '치료별 매출 기타2' · '외래 수입 감액' · 'ESWT Standard'. 10줄이 넘으면 ' 외 {K}줄'이 붙습니다.

### 채운 뒤 안내 (위에서 아래로)

1. **'비트와 맞춰 볼 숫자'** · '외래 총매출 {N}원' · '진료수납액 {N}원' · '환자 합계 {N}명' · '비트 화면의 같은 숫자와 먼저 견주어 보세요.'
   비트에서 보는 그날 숫자와 같은지 **먼저** 봅니다. 다르면 **[되돌리기]**를 누르고 알려 주세요. (값을 모르면 '—'로 보입니다.)
2. **'{날짜} 비트 값으로 {N}칸을 채웠어요. 저장은 하지 않았어요.'**
3. ([빈 칸만]을 눌렀을 때) '이미 적힌 {K}칸은 그대로 두었어요.'
4. (씨암·SONO 함께 있는 진료가 있을 때) '함께 있는 진료 {N}건은 씨암에 넣었어요.'처럼 넣은 곳이 나옵니다.
5. **넣지 않은 칸**: 까닭마다 '{까닭} {N}칸', 짧은 줄 이름, 할 일이 나옵니다(아래 표).
6. 경고 줄(있을 때만, '6-3. 경고 줄')과 끝 줄 '확인한 뒤 업무일지 1 [전체 저장]과 업무일지 2 [일일 상세 저장]을 눌러 주세요.'
7. **[되돌리기]** · **[설정 열기]**

| 넣지 않은 칸 | 화면 글 (할 일) |
|---|---|
| 화면에서 찾지 못한 칸 | 'ERP 화면에서 찾지 못해 그대로 둔 칸이에요. 직접 넣어 주세요.' |
| 치료사별 입력 줄 | '치료사별로 넣는 줄이라 그대로 두었어요. 치료사별 칸에 직접 넣어 주세요.' |
| 읽기 전용 칸 | '잠긴 칸이라 그대로 두었어요.' |
| ERP 줄 이름이 빈 기타 줄 | '설정 화면에서 그 기타 줄의 ERP 줄 이름을 업무일지 2 줄 이름과 똑같이 넣어 주세요.'('4-4') |
| 고르지 않아 건너뛴 칸 | '설정에서 코드를 고르지 않은 항목이라 그대로 두었어요.' |

### [되돌리기]

- 누르면 이번에 채운 칸을 **채우기 전 값**으로 돌립니다: **'되돌렸어요. {N}칸을 채우기 전 값으로 돌렸어요. 저장은 하지 않았어요.'**
- 채운 뒤 **손으로 고친 칸은 되돌리지 않고 그대로 둡니다**(직원이 고친 값을 지우지 않으려고): '채운 뒤 손으로 고친 {K}칸은 그대로 두었어요.'가 붙습니다. 그 칸도 채우기 전 값으로 돌리려면 직접 고칩니다.
- 그 사이 화면이 바뀐 칸이 있으면 '화면이 바뀌어 {K}칸은 되돌리지 못했어요.'가 붙습니다. 그 칸은 직접 고칩니다.
- 마감 일자를 바꾼 뒤에는 되돌리지 않습니다: '마감 일자가 바뀌어 되돌리지 않았어요.' · '아무 칸도 바꾸지 않았어요.'
- **마지막 채우기 한 번만** 되돌립니다. 새로고침하거나, 화면을 떠나거나, 다시 채우면 되돌릴 수 없습니다. 되돌릴 값은 그 화면에만 잠깐 기억하고 저장하지 않습니다.

### [지난 결과]

- 안내를 닫으면 **[비트 값 채우기]** 옆에 **[지난 결과]**가 생깁니다. 누르면 칸을 다시 채우지 않고 마지막 채운 안내를 다시 엽니다([되돌리기]가 아직 되면 함께).
- 화면을 떠나면 없어집니다. 열린 안내는 **Esc** 키로 닫힙니다.

### 확장이 건드리지 않는 것

**[비트 값 채우기]는 저장 단추를 누르지 않습니다. [기간 채우기]는 '전체 저장'·'일일 상세 저장'만 누릅니다**(아래 '기간 채우기'의 '확장이 누르는 단추').
두 단추 모두 상태 선택, 중간저장·초기화·삭제 단추, 기본단가, 그리고 아래 '직접 넣는 칸'은 건드리지 않습니다.
입원수입 4칸은 입원 접수가 없는 날 0으로 넣습니다.

### 직접 넣는 칸 (비트로 셀 수 없어 비워 둡니다)

담당자·휴무자, 신환경로, 상담-전환률, 치료사별, 지출, 이벤트, 특이사항, MOU 감액, 상태

## 기간 채우기 (여러 날을 한 번에 채우고 저장)

**[기간 채우기]**는 고른 기간의 날마다 [비트 값 채우기]와 같은 비트 숫자를 넣고, ERP 저장 단추까지 눌러 줍니다. 지난 한 달치 업무일지를 한 번에 넣을 때 씁니다.

- 이미 적어 둔 날도 비트 값으로 **덮어쓰고 저장합니다**(확정한 날도). 그래서 시작하기 전에 날 수를 보여 주고 **한 번 묻습니다.**
- 상태(작성중·확정)는 바꾸지 않습니다. 비트 진료가 0건인 날은 건너뜁니다. 오늘 뒤 날짜는 고를 수 없고, 기간 길이는 제한이 없습니다.
- 세는 법과 넣는 칸은 [비트 값 채우기]와 같습니다. '직접 넣는 칸'은 날마다 직접 넣습니다.
- 처음 한 번 설정을 저장해 두어야 씁니다('3. 처음 한 번: 설정 저장'). 안 했으면 [비트 값 채우기]처럼 설정 화면이 열립니다.

`{ }` 자리에는 그때 날짜·숫자가 들어갑니다. `{기간}`은 '10월 1일~31일'처럼, `{날짜}`는 '10/2 · 10/6 확정 · 10/7'처럼 보입니다.
날짜 목록에서 확정한 날은 뒤에 '확정'이 붙고, 10개가 넘으면 앞 10개 뒤에 '외 {k}일'이 붙습니다.

### 쓰는 법

**① 단추** — 마감일지 화면 오른쪽 아래, **[비트 값 채우기]** 왼쪽의 흰 단추 **[기간 채우기]**를 누릅니다.

**② 기간 고르기** — **'채울 기간을 골라 주세요.'** 아래 **시작일**·**끝일** 칸에서 날짜를 고르고 **[살펴보기]**를 누릅니다. 그만두려면 **[닫기]**를 누릅니다.

- 처음에는 화면 마감 일자 달의 1일부터 마감 일자까지가 들어 있습니다.
- 칸 아래 글: '오늘 뒤 날짜는 고를 수 없어요. [살펴보기]를 누르면 기간 안 날마다 이미 적어 둔 것이 있는지 먼저 봐요. 아직 아무 칸도 바꾸지 않아요.'
- [살펴보기]가 눌리지 않으면 칸 아래 까닭을 보고 고칩니다: '시작일과 끝일을 골라 주세요.' · '시작일이 끝일보다 뒤예요.' · '오늘 뒤 날짜는 고를 수 없어요.'
  기간은 시작일과 끝일을 넣어 셉니다(10월 1일~31일은 31일). 기간 길이는 제한이 없지만 날마다 시간이 걸려(하루 약 15~20초, 1년이면 살펴보기 약 20분 + 채우기 1시간 30분~2시간) 긴 기간은 오래 걸립니다. 도는 중에 **[멈추기]**로 멈추고 **[이어서 하기]**로 남은 날부터 이어 갈 수 있습니다(④).
- 살펴보는 동안 **'기간 안 날을 살펴보는 중이에요.'** · '{N}일 중 {k}일' · '아직 아무 칸도 바꾸지 않아요.'가 보입니다.
  확장이 화면의 마감 일자를 하루씩 바꿔 가며, 그날 마감일지가 있는지와 비트 진료 수를 봅니다. **칸은 바꾸지 않습니다.** 그만두려면 **[그만두기]**를 누릅니다.

**③ 시작 전에 한 번 승인** — 살펴보기가 끝나면 **'{기간} 중 {S}일을 비트 값으로 덮어쓰고 저장해요.'**가 뜹니다. 아래 날 수를 봅니다(0일인 줄은 보이지 않습니다).

- '새로 채울 날 {n}일' — 아직 마감일지가 없는 날
- '이미 적어 둔 날 {m}일 — 작성중 {a}일 · 확정 {b}일 ({날짜})' — 이미 마감일지가 있는 날입니다. 이 날도 비트 값으로 바뀝니다.
- '확인하지 못한 날 {u}일 — 채울 때 다시 불러와요 ({날짜})' — 살펴볼 때 ERP가 그날을 불러오지 못한 날입니다.
- '진료 0건이라 건너뛸 날 {z}일 ({날짜})' — 비트 진료가 없는 날입니다. 채우지도 저장하지도 않습니다.

노란 경고 줄:

- '이미 적어 둔 {m}일도 비트 값으로 바뀌어요.' (확정한 날이 있으면 뒤에 '확정한 날도 바뀌어요.'가 붙습니다)
- "날마다 ERP의 '전체 저장'과 '일일 상세 저장'을 확장이 눌러요. 상태(작성중·확정)는 그대로 둬요."
- 씨암·SONO 코드가 함께 있는 진료가 있는 기간이면, 설정에 지난번 고른 것이 있을 때 '씨암·SONO를 같이 받은 진료는 지난번 고른 대로 씨암에 넣어요.'처럼 넣을 곳(씨암에 · SONO에 · 씨암·SONO 둘 다에)이 나옵니다.
  고른 적이 없으면 '씨암·SONO를 같이 받은 진료가 {K}건 있어요. 어디에 넣을까요?'와 **[씨암에 넣기]** · **[SONO에 넣기]** · **[둘 다 넣기]**가 나옵니다. 하나를 눌러야 시작할 수 있고, 고른 것은 다음에도 씁니다.

끝에 작은 줄 '도는 동안 이 크롬 창을 닫거나 다른 화면으로 옮기지 마세요.'가 있습니다.
맞으면 **[덮어쓰고 저장 시작]**, 아니면 **[닫기]**를 누릅니다([닫기]면 아무 칸도 바꾸지 않습니다).
채울 날이 하나도 없으면 '{기간}에는 채울 날이 없어요.'와 [닫기]만 보입니다.

**④ 도는 중** — **'{S}일 중 {k}일 저장했어요.'** · 진행 막대 · '지금: {M월 D일} 채우는 중' · '[멈추기]를 누르면 지금 날까지 저장하고 멈춰요. 멈춘 뒤 다시 시작하면 남은 날부터 이어 가요.'가 보입니다.

- 확장이 날마다 차례로 합니다: 마감 일자를 그날로 바꿈 → 다 불러오기를 기다림 → 비트 숫자를 다시 받음 → 칸을 모두 비트 값으로 덮어씀 → 업무일지 1 '전체 저장' → 업무일지 2 '일일 상세 저장' → 다음 날. {k}는 두 저장이 다 된 날 수입니다.
- 이 안내는 ×가 없고 Esc로도 닫히지 않습니다. 멈추려면 **[멈추기]**를 누릅니다. 단추가 '멈추는 중…'으로 바뀌고, 지금 날의 저장까지 끝낸 뒤 멈춥니다.
- 멈추면 **'멈췄어요. {k}일 저장했어요.'** · '남은 날 {r}일 ({날짜})'와 그때까지의 건너뛴 날·저장 못 한 날(끝 안내와 같은 결과 줄)이 보입니다.
  **[이어서 하기]**를 누르면 다시 묻지 않고 남은 날부터 이어 갑니다. [닫기]면 거기서 끝납니다.
- 남은 날은 그 화면에만 기억합니다. 새로고침하거나 화면을 떠나면 사라지니, 다시 할 때는 [기간 채우기] → [살펴보기]부터 합니다.
  이미 저장한 날은 '이미 적어 둔 날'로 보입니다. 남은 날만 기간으로 고르면 저장한 날을 다시 저장하지 않습니다.

**⑤ 끝** — **'{n}일을 비트 값으로 저장했어요.'**(한 날도 저장하지 못했으면 '저장한 날이 없어요.') 아래 결과 줄과 '직접 넣는 칸(담당자·지출·특이사항 등)은 건드리지 않았어요.' · **[닫기]**가 보입니다. 결과 줄은 0일이면 보이지 않습니다.

- '건너뛴 날 {z}일 — 진료 0건 ({날짜})' — 비트 진료가 없어 채우지 않은 날입니다(③의 건너뛸 날 포함).
- '건너뛴 날 {d}일 — 저장하지 않은 입력이 남은 날 ({날짜})' — ERP가 그날 **'저장하지 않은 입력을 되살렸습니다'** 띠를 보인 날입니다. 누가 넣다 만 입력을 지우지 않으려고 건드리지 않았습니다. 그날을 열어 남은 입력을 확인합니다.
- '저장 못 한 날 {f}일' 아래 날마다 '{M/D}: {까닭} 그날을 열어 [비트 값 채우기]로 다시 해 주세요.'가 나옵니다. {까닭}은 아래 다섯 가지입니다.
  [비트 값 채우기]는 저장하지 않으니, 그날을 열어 채운 뒤 업무일지 1 [전체 저장]과 업무일지 2 [일일 상세 저장]을 직접 누릅니다.

| 까닭 (화면 글) | 뜻 |
|---|---|
| 'ERP가 그날을 불러오지 못했어요.' | 30초 안에 그날 마감일지가 다 열리지 않았거나, ERP가 불러오기 오류를 보였습니다. 그날은 칸을 바꾸지 않았습니다. |
| 'ERP가 업무일지 1 저장 오류를 알렸어요.' | [전체 저장]이 되지 않았습니다(ERP 오류 쪽지, 또는 단추가 없거나 막혀 있음). 그날 업무일지 2는 누르지 않았습니다. |
| 'ERP가 업무일지 1을 저장했다는 답을 주지 않았어요.' | [전체 저장]을 누른 뒤 30초 안에 '저장되었습니다.' 쪽지가 없었습니다. 그날 업무일지 2는 누르지 않았습니다. |
| 'ERP가 업무일지 2 저장 오류를 알렸어요(업무일지 1은 저장됨).' | 업무일지 1은 저장됐고, [일일 상세 저장]이 되지 않았습니다. |
| 'ERP가 업무일지 2를 저장했다는 답을 주지 않았어요(업무일지 1은 저장됨).' | 업무일지 1은 저장됐고, [일일 상세 저장]을 누른 뒤 30초 안에 답이 없었습니다. |

### 확장이 누르는 단추

- [기간 채우기]가 누르는 ERP 저장 단추는 업무일지 1 **'전체 저장'**과 업무일지 2 **'일일 상세 저장'** 두 가지뿐입니다. 그 밖에는 업무일지 1·2 탭만 누릅니다.
- 한 번에 하나씩 누릅니다. 업무일지 1의 '저장되었습니다.' 쪽지를 본 뒤 업무일지 2를 누르고, 업무일지 1이 안 되면 그날 업무일지 2는 누르지 않습니다.
- 상태 선택·특이사항·기본단가 칸은 바꾸지 않고, 중간저장·이 항목만 저장·초기화·마감일지 삭제·월 선택·재계산·기본단가 저장·이벤트 추가 단추는 누르지 않습니다.
- 확장이 ERP에 직접 요청을 보내지 않습니다. 사람이 하듯 화면의 날짜와 단추만 다룹니다.

### 멈추는 경우

아래 열 가지가 생기면 **다음 날로 가지 않고 멈춥니다.** 살펴보는 중이면 승인 안내로 가지 않고, 채우는 중이면 그때까지 저장한 날은 저장된 채로 남습니다.
안내에는 까닭 두 줄과 '{k}일 저장했어요. 남은 {r}일은 하지 않았어요.', 그때까지의 결과 줄, [닫기]가 나옵니다.

| 멈춘 까닭 | 화면 글 | 할 일 |
|---|---|---|
| 1. ERP 안내 창(새 판 안내 등)이 뜸 | **'ERP 화면에 안내 창이 떠서 멈췄어요.'** · 'ERP 창을 보고 닫은 뒤 [이어서 하기]를 눌러 주세요.' | ERP 창을 읽고 닫은 뒤 누릅니다. |
| 2. 날짜 칸이 없음(원무 계정) | **'이 계정은 오늘 마감일지만 열 수 있어 기간 채우기를 쓸 수 없어요.'** · '날짜를 고를 수 있는 계정으로 열어 주세요. 아무 칸도 바꾸지 않았어요.' | 날짜를 고를 수 있는 계정으로 다시 로그인해 [살펴보기]부터 합니다. |
| 3. 업무일지 2 저장 줄이 없음 | **'업무일지 2 저장 줄이 없어 멈췄어요.'** · 'ERP에 진료실이 하나 이상 있어야 업무일지 2를 저장할 수 있어요. 확인한 뒤 [이어서 하기]를 눌러 주세요.' | ERP에 진료실이 있는지 본 뒤 누릅니다. |
| 4. 읽기 전용 화면(본사 열람 등) | **'이 화면은 읽기 전용이라 저장할 수 없어요(본사 열람 등).'** · '저장할 수 있는 계정으로 열어 주세요.' | 저장할 수 있는 계정으로 다시 로그인해 [살펴보기]부터 합니다. |
| 5. ERP 도우미 오류 | 굵은 줄은 '6-1. 오류 표'의 무엇이, 다음 줄은 어떻게 글 그대로이고 끝에 '(번호 {번호})'가 붙습니다. | '6-1. 오류 표'에서 번호를 찾아 할 일을 한 뒤 **[이어서 하기]**를 누릅니다. |
| 6. 채우는 동안 마감 일자가 그날이 아니게 됨 | **'채우는 동안 ERP 마감 일자가 바뀌어 멈췄어요.'** · '그날은 저장하지 않았어요. 도는 동안에는 마감 일자를 바꾸지 말고 [이어서 하기]를 눌러 주세요.' | 마감 일자 칸을 만지지 말고 누릅니다. 그날부터 다시 합니다. |
| 7. ERP 화면에서 찾지 못한 칸이 있음 | **'ERP 화면에서 찾지 못한 칸이 {n}개 있어 멈췄어요.'** · 'ERP 화면이 바뀌었을 수 있어요. 그날은 아무 칸도 바꾸지 않았어요. [비트 값 채우기]를 누르면 어느 칸인지 보여요.' | 그날을 열어 [비트 값 채우기]로 어느 칸인지 보고, 만드는 사람에게 알립니다. |
| 8. 저장 단추가 하나씩이 아님 | **'ERP 저장 단추를 찾지 못해 멈췄어요.'** · "'전체 저장'과 '일일 상세 저장'이 하나씩 있어야 해요. ERP 화면이 바뀌었을 수 있어요. 그날은 아무 칸도 바꾸지 않았어요." | 만드는 사람에게 알립니다. 그동안은 [비트 값 채우기]로 하루씩 채우고 직접 저장합니다. |
| 9. 씨암·SONO 함께 있는 진료를 넣을 곳을 안 고름 | **'씨암·SONO를 같이 받은 진료를 어디에 넣을지 정하지 않아 멈췄어요.'** · '그날은 아무 칸도 바꾸지 않았어요. [닫기] 뒤 [기간 채우기]를 다시 하면 살펴본 뒤 어디에 넣을지 물어요.' | [닫기] 뒤 [기간 채우기] → [살펴보기]부터 다시 하고, 승인 안내에서 넣을 곳을 고릅니다. |
| 10. 확장 안 뜻밖의 문제 | **'확장에 뜻밖의 문제가 생겨 멈췄어요.'** · "이 화면을 새로고침(F5)한 뒤 [기간 채우기]를 다시 해 주세요. 저장한 날은 '이미 적어 둔 날'로 보여요." | 새로고침(F5) 뒤 [기간 채우기] → [살펴보기]부터 합니다. 계속되면 만드는 사람에게 알립니다. |

- [이어서 하기]는 1·3·5·6에만 있습니다. 누르면 화면을 다시 확인하고 남은 날부터 이어 갑니다(6은 멈춘 그날부터). 나머지는 [닫기]만 있습니다.
- 7·8·9는 그날 칸을 하나도 바꾸기 전에 멈춥니다.
- 마감일지 화면을 떠나면(주소 끝이 `/h/closing`이 아니게 되면) 안내가 사라지고 거기서 끝납니다.

### 원무(오늘만) 계정은 쓸 수 없어요

마감 일자가 날짜 칸 없이 'YYYY-MM-DD (오늘)' 글자로만 보이는 계정(원무 권한)은 오늘 마감일지만 열 수 있어 기간 채우기를 쓸 수 없습니다.
[기간 채우기]를 누르면 **'이 계정은 오늘 마감일지만 열 수 있어 기간 채우기를 쓸 수 없어요.'** · '날짜를 고를 수 있는 계정으로 열어 주세요. 아무 칸도 바꾸지 않았어요.'만 나오고 아무것도 하지 않습니다.
이 계정에서는 [비트 값 채우기]로 오늘 하루만 채웁니다.

### 도는 동안 지킬 것

- '도는 동안 이 크롬 창을 닫거나 다른 화면으로 옮기지 마세요.' 크롬 창을 닫거나, ERP 다른 메뉴로 옮기거나, 새로고침하면 그 자리에서 멈추고 남은 날 기억도 사라집니다. 이미 저장한 날은 저장된 채로 남습니다.
- 확장이 화면의 마감 일자와 업무일지 1·2 탭을 바꿔 가며 일합니다. 끝날 때까지 ERP 화면의 칸·단추를 만지지 말고 기다립니다.
- 살펴보는 동안과 채우는 동안에는 [기간 채우기]·[비트 값 채우기]·[지난 결과]가 눌리지 않습니다.
- ERP 로그인이 풀리면 멈춥니다. 다시 로그인한 뒤 [기간 채우기] → [살펴보기]부터 합니다.

## 6. 안내 글과 할 일

### 6-1. 오류 표

오류가 나면 안내에 굵은 줄(무엇이) · 다음 줄(어떻게) · 작은 줄 **'아무 칸도 바꾸지 않았어요. (번호 {번호})'**가 나옵니다. **어느 칸도 바꾸지 않습니다.**
설정 화면에서는 **'도우미에서 코드 목록을 받지 못했어요 ({번호})'** 아래에 같은 무엇이·어떻게가 나옵니다('6-2').
알려 줄 때는 괄호 안 번호(`E-`로 시작)를 같이 알려 주세요.

| 번호 | 무엇이 (굵은 줄) | 어떻게 (다음 줄) | 할 일 |
|---|---|---|---|
| `E-HELPER-MISSING` | ERP 도우미가 이 PC에 없어요. | ERP 도우미를 설치해 주세요. 받은 zip을 풀고 install.cmd를 두 번 누르면 돼요. | '1. 먼저 ERP 도우미 설치'를 한 뒤 단추를 다시 누릅니다. 깔았는데도 뜨면 확장과 짝인 판인지 보고 `install.cmd`를 다시 누릅니다. |
| `E-HELPER-STOPPED` | ERP 도우미가 읽는 도중 멈췄어요. | 잠시 뒤 다시 해 주세요. 계속되면 ERP 도우미 설치 파일(install.cmd)을 다시 실행해 주세요. | 잠시 뒤 단추를 다시 누릅니다. 또 뜨면 ERP 도우미 zip을 푼 폴더의 `install.cmd`를 다시 누르고 등록까지 합니다. |
| `E-HELPER-TIMEOUT` | 도우미가 답하지 않아요(120초). | 잠시 뒤 다시 해 주세요. | 잠시 기다린 뒤 단추를 다시 누릅니다. |
| `E-HELPER-BAD-MESSAGE` · `E-HELPER-UNKNOWN-COMMAND` | ERP 도우미가 예전 판이에요. | 새 판을 설치해 주세요. 확장과 ERP 도우미는 꼭 같이 바꿔요. | 확장과 짝인 판의 ERP 도우미를 설치합니다('7. 새 판으로 바꾸기'). |
| `E-BIT-NOT-REGISTERED` | 이 PC가 아직 등록되지 않았어요. | ERP 도우미 설치 파일을 다시 실행해 주세요(비트 로그인 → PC 확인 창 [확인]). | ERP 도우미 zip을 푼 폴더의 `install.cmd`를 다시 누르고, 비트 로그인 창 → PC 확인 창 **[확인]**까지 합니다. |
| `E-BIT-HOSPITAL-MISMATCH` | 이 PC의 비트가 등록할 때와 달라요(병원·설치 위치·서버). | 우리 병원 비트가 맞으면 ERP 도우미 설치 파일을 다시 실행해 다시 등록해 주세요. | 비트를 새로 깔았거나 옮겼거나 서버가 바뀌면 뜹니다. 우리 병원 비트가 맞는지 보고 `install.cmd`를 다시 눌러 다시 등록합니다. |
| `E-BIT-NOT-FOUND` | 이 PC에서 비트를 찾지 못했어요. | 비트가 깔린 PC에서 써 주세요. 비트를 옮겼으면 ERP 도우미 설치 파일을 다시 실행해 주세요. | 비트가 깔린 PC인지 봅니다. 비트를 옮겼으면 `install.cmd`를 다시 누릅니다. |

## 7. 새 판으로 바꾸기

**확장과 ERP 도우미는 정해 둔 짝끼리 씁니다**(지금 확장 0.3.0 ↔ ERP 도우미 0.3.0). ERP 도우미가 새 판으로 나오면 확장과 꼭 같이 바꿉니다.
ERP 도우미도 바뀐 판인데 확장만 바꾸면 ERP 화면에 **'ERP 도우미가 예전 판이에요.'** · '새 판을 설치해 주세요. 확장과 ERP 도우미는 꼭 같이 바꿔요.'가 뜨고 칸을 채우지 않습니다.

**이 확장을 판 0.2.0에서 0.3.0으로 바꿀 때**: [기간 채우기]가 더해진 판이고, ERP 도우미도 0.3.0으로 바뀌었습니다. 아래 1·2·3을 모두 합니다.
ERP 도우미를 다시 설치해야 설정 화면 '셀 코드' 찾기가 **비트에 등록된 코드 전부**에서 찾고, **'읽지 않을 처방'** 규칙이 셈에 들어갑니다.
ERP 도우미 0.2.0이어도 나머지는 그대로 됩니다. 다만 '셀 코드' 찾기는 1년 동안 쓴 코드에서만 하고, '읽지 않을 처방' 규칙을 저장해 두면 위 **'ERP 도우미가 예전 판이에요.'**가 뜨고 칸을 채우지 않습니다.

1. (ERP 도우미도 바뀐 판일 때만) ERP 도우미 새 zip으로 설치합니다([ERP 도우미 설치 안내](../helper-erp/install/README.md)의 '새 판으로 바꾸기').
2. 새 확장 폴더로 옛 폴더를 바꾼 뒤, `chrome://extensions`에서 이 확장 칸의 **새로고침(동그란 화살표)**을 누릅니다. 이 확장 칸에 보이는 판 번호와 ERP 도우미 판 번호가 위 짝과 맞는지 봅니다.
3. 열어 둔 ERP 마감일지 화면을 새로고침(F5)합니다. 안 하면 `E-BRIDGE-DISCONNECTED`가 뜹니다.

확장을 지우지 않고 새로고침만 하면 고른 설정은 그대로 남습니다.

0.3.0으로 바꾼 뒤 설정 화면에서 씨암·SONO **'셀 코드'**를 꼭 확인합니다. 새 판은 앞글자(전 판 처음 값 `LA`)를 읽지 않고, 직접 더한 셀 코드만 셉니다.
전 판에서 `LA` 뒤가 숫자인 코드로 세던 매출(SONO 등)은 그 코드를 '셀 코드'에 더하고 **[저장]**하기 전까지 줄어듭니다('4-2').
새 판에서 처음 값에 코드가 더해졌으면, 설정 화면 맨 위에 **'새 처음 코드가 있어요: {항목 이름} {코드·코드} · …'** · '[더하기]를 누르면 화면에 더해요. [저장]을 눌러야 저장돼요.'가 나옵니다.
우리 의원에서도 쓰는 코드면 **[더하기]** → **[저장]**, 아니면 더하지 말고 **[저장]**만 누릅니다. 한 번 저장하면 다시 나오지 않습니다.

## 8. 지우기

- 확장: `chrome://extensions`에서 **ERP 마감일지 채우기**의 **삭제**를 누릅니다. 고른 설정도 함께 지워집니다.
- ERP 도우미: 따로 지웁니다. ERP 도우미 zip을 푼 폴더의 `uninstall.ps1`을 오른쪽 클릭 → **PowerShell에서 실행**([ERP 도우미 설치 안내](../helper-erp/install/README.md)의 '지우기').
- 청구 사전점검 확장·도우미를 쓰고 있다면, 둘 다 지워도 그것과 청구 화면은 그대로 남습니다.

## 이 확장이 하는 일 (참고)

- 권한은 도우미와 이야기하기와 설정 저장, 두 가지뿐입니다. `https://erp.minesolution.com` 화면에서만 움직입니다.
- 확장이 직접 인터넷으로 보내는 것은 없습니다. 도우미가 준 숫자는 확장에 저장하지 않고 화면 칸에 넣기만 합니다([기간 채우기]는 그 뒤 ERP의 저장 단추를 눌러 ERP에 저장합니다). 확장이 저장하는 것은 고른 코드 설정(씨암·SONO 함께 있는 진료를 넣을 곳 포함)뿐입니다.
- 되돌릴 값과 지난 결과, 기간 채우기의 날마다 결과와 남은 날은 그 화면에만 잠깐 기억하고 저장하지 않습니다. 새로고침하거나 화면을 떠나면 사라집니다.
- 환자 이름·차트번호는 이 PC의 ERP 도우미 밖으로 나가지 않습니다. ERP 화면에는 숫자만 들어갑니다.

## 만드는 사람에게 (참고)

- 확장 폴더 만들기: 저장소 맨 위 폴더에서 `npm run ext-erp:build` → `extension-erp/dist/`가 생깁니다(`tsc`로 `src/*.ts`를 `.js`로 바꾸고 `manifest.json`·`options.html`을 복사). 이 `dist` 폴더가 확장이고, 다른 PC에는 이 폴더를 zip으로 묶어 옮깁니다.
- 확장 판 번호는 `manifest.json`의 `version`(지금 0.3.0)입니다. ERP 도우미가 바뀌는 판이면 ERP 도우미 판(`helper-erp/Directory.Build.props`)과 같이 올립니다. 0.3.0은 ERP 도우미도 바뀐 판이라(`closing.findCodes`·'읽지 않을 처방' 규칙) ERP 도우미도 0.3.0입니다.
- 확장 이름표(ID)는 `manifest.json`의 공개 열쇠(`key`)로 정해지고(`lkancaiekmoieooheifdimahhkejfmjc`), ERP 도우미는 이 확장 하나만 받습니다. 개인 열쇠는 두지 않습니다.
- 확장이 부르는 도우미 이름은 `com.seoseungkwan.erp_helper`, 명령은 `closing.codes`·`closing.day`·`closing.findCodes` 셋입니다(`helper-erp/commands.json`. `closing.findCodes`는 ERP 도우미 0.3.0부터).
- 화면 글은 `src/panel.ts`(ERP 화면 안내)·`src/rangeView.ts`(기간 채우기 안내)·`src/errors.ts`(오류 표)·`src/options.ts`(설정 화면)에 있습니다. 이 안내서의 화면 글을 그 글과 같게 둡니다.
