# ERP 마감일지 채우기 (크롬 확장) 설치·사용 안내

이 확장은 ERP 마감일지 화면(`https://erp.minesolution.com/h/closing`) 오른쪽 아래에 **[비트 값 채우기]** 단추를 붙입니다.
누르면 이 PC의 **ERP 도우미**가 화면의 '마감 일자' 하루치 숫자를 비트에서 세어, 비트로 셀 수 있는 마감일지 칸에 넣습니다.
**저장은 하지 않습니다.** 숫자를 확인한 뒤 직접 저장해 주세요.

- 비트가 깔린 PC의 크롬에 설치합니다. **관리자 권한은 필요 없습니다.**
- 이미 쓰고 있는 확장 **'청구 사전점검 연결'**과 **'청구 사전점검 도우미'**, 청구 화면은 그대로입니다. 둘 다 깔아 두어도 됩니다.

## 1. 먼저 ERP 도우미 설치

이 확장은 **ERP 도우미**가 있어야 움직입니다. 청구 사전점검 도우미와는 다른 프로그램입니다.

- 순서는 [ERP 도우미 설치 안내](../helper-erp/install/README.md)에 있습니다.
  짧게: `seoseungkwan-erp-helper-<판>.zip`을 **모두 압축 풀기** → 푼 폴더의 `install.cmd`를 두 번 누르기 →
  끝에 뜨는 **비트 로그인 창**에서 로그인 → **PC 확인 창**에서 **[확인]** → 검은 창에 **'이 PC를 등록했어요.'**

## 2. 크롬에 확장 붙이기

1. 받은 확장 zip을 오른쪽 클릭 → **모두 압축 풀기**를 누릅니다.
   푼 폴더는 지우거나 옮기지 마세요. 크롬이 그 폴더를 계속 씁니다.
2. 크롬 주소창에 `chrome://extensions`를 넣고 엔터를 누릅니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다**(크롬 판에 따라 '압축해제된 확장 프로그램 로드')를 누르고, 1에서 푼 폴더를 고릅니다.
   (고르는 폴더 안에 `manifest.json` 파일이 바로 보여야 합니다.)
5. 목록에 **ERP 마감일지 채우기**가 보이면 끝입니다.

## 3. 처음 한 번: 설정 저장

1. ERP에서 마감일지 화면을 엽니다. 이미 열려 있었으면 새로고침(F5)합니다.
2. 오른쪽 아래 **[비트 값 채우기]**를 누릅니다.
   처음에는 칸을 채우지 않고 **'처음 한 번 설정 화면에서 코드를 확인하고 [저장]을 눌러 주세요.'**가 뜨며 설정 화면이 새 탭으로 열립니다.
3. 설정 화면에서 항목마다 셀 비트 처방 코드를 확인합니다.
   - 처음 값이 들어 있습니다(씨암 `CARM1` · SONO `SONO1` · 관절조영 `HA280` · 도수 `도수` · 충격파 `ESWT7`·`ESWT10`·`ESWT12`·`ESWT17` · 물리치료 `MM010`·`MM015`·`MM011` · 기타1 '크라이오' `CRYO` · 물리치료내원 `AA222`).
   - 찾기 칸에 코드나 이름 일부를 넣으면 최근 1년 동안 쓴 코드가 나옵니다. 누르면 더해지고, 코드 옆 **[×]**로 뺍니다.
   - 아래 **예약** 6줄(주사·경과·도수·충격파·진료예약·기타)은 처음엔 비어 있습니다. 줄마다 비트 예약 메모 번호를 고릅니다(예: 충격파 1번, 도수 14·20·22번 — 의원에서 쓰는 번호에 맞추세요).
   - **[처음 값으로]**는 화면만 처음 값으로 되돌립니다(누르기 전 저장한 것은 [저장]을 누를 때까지 그대로).
4. **[저장]**을 누릅니다. '저장했어요.'가 보이면 됩니다.
5. ERP 화면으로 돌아와 **[비트 값 채우기]**를 다시 누릅니다.

설정 화면은 나중에 결과 안내의 **[설정 열기]**, 또는 `chrome://extensions` → 이 확장의 **세부정보** → **확장 프로그램 옵션**으로도 엽니다.

## 4. 매일 쓰는 법

1. ERP 왼쪽 메뉴 **'마감 · 입력'** → 달력에서 날짜 칸(또는 **'오늘 업무일지 입력'**)을 눌러 **마감일지** 화면을 엽니다.
2. 화면의 **마감 일자**가 채울 날인지 봅니다.
3. 오른쪽 아래 **[비트 값 채우기]**를 누릅니다. **'비트에서 읽는 중…'**이 보이는 동안 기다립니다.
4. 결과 안내에 **'{날짜} 비트 값으로 N칸을 채웠어요. 저장은 하지 않았어요.'**가 나옵니다. 아래 줄도 봅니다.
   - **못 찾은 칸**: ERP 화면에서 찾지 못해 그대로 둔 칸입니다. 직접 넣어 주세요.
   - **고르지 않아 건너뛴 칸**: 설정에서 코드를 고르지 않은 항목이라 그대로 둔 칸입니다.
   - **경고 줄**(있을 때만): 아래 '5. 안내 글과 할 일'을 봅니다.
5. 채워진 숫자를 확인합니다. **이미 적어 둔 칸도 비트 값으로 바뀝니다.**
6. 아래 '직접 넣는 칸'을 채웁니다.
7. 업무일지 1 **[전체 저장]**과 업무일지 2 **[일일 상세 저장]**을 **직접** 누릅니다. 확장은 저장 단추를 누르지 않습니다.

확장이 건드리지 않는 것: 상태 선택, 저장·중간저장·초기화·삭제 단추, 기본단가, 그리고 아래 '직접 넣는 칸'.
입원수입 4칸은 입원 접수가 없는 날 0으로 넣습니다.

### 직접 넣는 칸 (비트로 셀 수 없어 비워 둡니다)

담당자·휴무자, 신환경로, 상담-전환률, 치료사별, 지출, 이벤트, 특이사항, MOU 감액, 상태

## 5. 안내 글과 할 일

| 안내 글 | 할 일 |
|---|---|
| ERP 도우미를 설치해 주세요. | ERP 도우미가 없습니다. '1. 먼저 ERP 도우미 설치'를 한 뒤 단추를 다시 누릅니다. |
| 이 PC가 아직 등록되지 않았어요. ERP 도우미 설치 파일을 다시 실행해 주세요. | ERP 도우미 zip을 푼 폴더의 `install.cmd`를 다시 누르고, 비트 로그인 창 → PC 확인 창 **[확인]**까지 합니다. |
| 비트에서 읽지 못했어요 (번호) | 괄호 안 번호를 적어 알려 주세요. 번호가 `E-BIT-HOSPITAL-MISMATCH`이면 비트의 병원·설치 위치·서버·DB가 바뀐 것이라, `install.cmd`를 다시 눌러 다시 등록합니다. |
| 도우미가 답하지 않아요. 잠시 뒤 다시 눌러 주세요. | 잠시 기다린 뒤 단추를 다시 누릅니다. |
| 마감 일자를 먼저 골라 주세요. | 화면에서 마감 일자를 고른 뒤 다시 누릅니다. |
| 읽는 동안 마감 일자가 바뀌어 채우지 않았어요. 다시 눌러 주세요. | 날짜를 바꾸지 말고 다시 누릅니다. |
| 처음 한 번 설정 화면에서 코드를 확인하고 [저장]을 눌러 주세요. | '3. 처음 한 번: 설정 저장'을 합니다. |
| (설정 화면) 도우미에서 코드 목록을 받지 못했어요 (번호) | 고른 코드는 그대로 두고 저장할 수 있습니다. 코드를 새로 찾으려면 ERP 도우미 설치·등록을 확인한 뒤 설정 화면을 다시 엽니다. |

위 오류 안내가 뜰 때는 **어느 칸도 바꾸지 않습니다.**

채운 뒤 나오는 경고 줄은 그 칸을 다시 보라는 뜻입니다.

- 환불·변경수납 등이 있는 날 / 청구액·비급여가 딱 나눠지지 않는 날: 외래 수입 금액을 비트 수납 화면과 견주어 확인합니다.
- 수납이 끝나지 않은 진료가 있을 때: 치료별 매출이 적게 나왔을 수 있습니다.
- 환불이 있을 때: 현불/환불 금액을 확인합니다.
- 생년월일이 없는 환자가 있을 때: 그 환자는 연령별 표에 들어가지 않았습니다.
- 예전 자료가 따로 있을 때: 주사1회환자 칸은 채우지 않았습니다.
- 입원 접수가 있을 때: 입원수입 칸은 채우지 않았습니다.

### 단추가 안 보일 때

- 마감일지 화면(주소 끝이 `/h/closing`)인지 봅니다. 업무일지 2만 따로 여는 화면(`/h/closing-daily`)에는 단추가 없습니다.
- `chrome://extensions`에서 **ERP 마감일지 채우기**가 켜져 있는지 봅니다.
- 확장을 붙이기 전에 열어 둔 화면이면 새로고침(F5)합니다.

## 6. 새 판으로 바꾸기

새 확장 폴더로 옛 폴더를 바꾼 뒤, `chrome://extensions`에서 이 확장 칸의 **새로고침(동그란 화살표)**을 누릅니다.
확장을 지우지 않고 새로고침만 하면 고른 설정은 그대로 남습니다.

## 7. 지우기

- 확장: `chrome://extensions`에서 **ERP 마감일지 채우기**의 **삭제**를 누릅니다. 고른 설정도 함께 지워집니다.
- ERP 도우미: 따로 지웁니다. ERP 도우미 zip을 푼 폴더의 `uninstall.ps1`을 오른쪽 클릭 → **PowerShell에서 실행**([ERP 도우미 설치 안내](../helper-erp/install/README.md)의 '지우기').
- 둘 다 지워도 청구 사전점검 확장·도우미와 청구 화면은 그대로 남습니다.

## 이 확장이 하는 일 (참고)

- 권한은 도우미와 이야기하기와 설정 저장, 두 가지뿐입니다. `https://erp.minesolution.com` 화면에서만 움직입니다.
- 확장이 직접 인터넷으로 보내는 것은 없습니다. 도우미가 준 숫자는 저장하지 않고 화면 칸에 넣기만 합니다. 저장하는 것은 고른 코드 설정뿐입니다.
- 환자 이름·차트번호는 이 PC의 ERP 도우미 밖으로 나가지 않습니다. ERP 화면에는 숫자만 들어갑니다.

## 만드는 사람에게 (참고)

- 확장 폴더 만들기: 저장소 맨 위 폴더에서 `npm run ext-erp:build` → `extension-erp/dist/`가 생깁니다(`tsc`로 `src/*.ts`를 `.js`로 바꾸고 `manifest.json`·`options.html`을 복사). 이 `dist` 폴더가 확장이고, 다른 PC에는 이 폴더를 zip으로 묶어 옮깁니다.
- 확장 이름표(ID)는 `manifest.json`의 공개 열쇠(`key`)로 정해지고(`lkancaiekmoieooheifdimahhkejfmjc`), ERP 도우미는 이 확장 하나만 받습니다. 개인 열쇠는 두지 않습니다.
- 확장이 부르는 도우미 이름은 `com.seoseungkwan.erp_helper`, 명령은 `closing.codes`·`closing.day` 둘입니다(`helper-erp/commands.json`).
