# EMR 고르기 시안 메모 (emr-choice)

2026-11-19 사용자: "나중에 의사랑, 이지스도 연결할 건데 미리 준비만 해 놓을 수 있어?" → 고른 범위 "문서 + EMR 고르기 칸".

## 정한 것 (시안 기본값)
- 설정 → 병원 정보에 '쓰는 EMR' 칸: 비트 · 의사랑 · 이지스 · 그 밖의 EMR. 처음 값 비트(지금 병원은 모두 비트 그대로). 원장만 바꾼다(데스크는 설정을 못 연다).
- 비트가 아닌 병원:
  - 대시보드 연결 전 큰 글 → '○○ 연결은 준비하고 있어요' + [쓰는 EMR 바꾸기](/settings). 그 밖의 EMR은 '우리 병원 EMR은 아직 연결할 수 없어요'.
  - 비트 PC 연결 화면(/claim/setup) → 단계·내려받기 대신 준비 중 안내 + [쓰는 EMR 바꾸기]. 데스크는 단추 대신 '원장님 계정에서 바꿀 수 있어요.'
- 그대로: 다른 탭의 [비트 PC 연결] 단추·글(누르면 연결 화면에서 준비 중을 봄), 비트 병원 화면, 도우미·확장.
- 함께: docs/emr/README.md(탭별 EMR 자료 목록 + 의사랑·이지스 PC 체크리스트).

승인: 2026-11-19, 사용자 "굿 아마 의사랑도 컴퓨터네 폴더에서 자료 가져올 수 있을 거야 그 점까지 생각해서 만들어놔줘" — 화면은 시안 그대로(다른 탭 단추는 그대로), 폴더에서 읽는 길은 docs/emr/README.md에 계획으로 적는다.
