# 시안 메모: 휴진 안내 글자 색 (forms-accent)

- 시안: `screen.html` — forms-themes 승인 시안(`../forms-themes/screen.html`)에 '배경' 칸 맨 아래 '글자 색' 칸만 더함. 새 상태 `?s=color`(추석 내 배경 위 빨강 직접 고름), `?s=light`(옅은 노랑 → 경고). 나머지 상태는 forms-themes 그대로
- 칸: 제목 '글자 색' · 묶음 [자동]·[직접 고르기] · 색상판(`<input type="color">`) + 지금 색 글(직접 `#c62f2f` / 자동 `자동 #…`) · 도움말 · 옅은 색 경고
- 고른 색은 'N월'·날짜 띠·카드 아래 글 모두에 들어가고 안내문마다 저장. 옅으면 경고만(막지 않음)
- 사용자 결정(2026-11-15): 크리스마스 AI 배경에서 '휴진'이 금색 → "빨간 글씨면 좋겠다" → "글자 색 내가 정하게 못해?" → 범위 '강조색 전체', 고르는 법 '아무 색이나(색상판)'. "'휴진'만 늘 빨강"은 빼기로 함
- 사진: 1440 `color`·`light` 부분, 390 `color`
