# multi-admin 시안 메모 — 가입 승인 화면에서 관리자 정하기·빼기

- 시안: `index.html`(가입 승인)과 `settings.html`(설정 새 칸, 추가 요청), 상태는 `?s=`로 고른다. 맨 위 회색 띠는 검토용 상태 고르기(앱 밖)다.
- 기준: `~/.claude/state/handoff/multi-admin-brief.md`(2026-11-22). 모양은 지금 화면 `src/components/admin/AdminApplications.tsx`·`ds`(`components/ui/classes.ts`)·`globals.css :root` 토큰을 그대로 옮겼다. **새 색 없음.**
- PC 화면만. 폰 전용 모양·폰 규칙(max-md)을 새로 두지 않았다. 사진도 1440·1024만.
- 자료는 모두 지어낸 값이다(의원 이름·사람 이름·`@example.com` 메일·번호). 주 관리자(원장님 계정) = 한결정형외과의원. 기본은 주 관리자가 보는 화면이다.

## 상태 (index.html — 가입 승인)

| `?s=` | 보이는 것 |
|---|---|
| `list`(기본, 주 관리자가 볼 때) | '승인' 탭 5줄. 내 줄(한결) = `주 관리자` 칩 + 흐린 `내 계정` · 다른 관리자 줄(새봄) = `관리자` 칩 + [관리자 빼기] · 나머지 셋 = [관리자로 정하기] |
| `other`(추가 요청) | 같은 목록을 **다른 관리자(새봄)** 가 볼 때. 위쪽 띠도 새봄 이름·메일. 주 관리자 줄(한결) = `주 관리자` 칩 + **동작 칸 비움** · 새봄 자기 줄 = `관리자` 칩 + `내 계정` · 나머지 셋 = [관리자로 정하기](눌러 정하기·빼기도 된다, 그동안 주소는 `s=other` 그대로) |
| `add` | 목록 위 정하기 확인 창(바른정형외과의원) |
| `remove` | 목록 위 빼기 확인 창(새봄재활의학과의원) |
| `done` | 정한 뒤: 탭 줄과 표 사이 완료 줄 "바른정형외과의원 계정을 관리자로 정했어요." + 그 줄에 `관리자` 칩·[관리자 빼기] |
| `removed` | 뺀 뒤: 완료 줄 "새봄재활의학과의원 계정을 관리자에서 뺐어요." + 그 줄은 [관리자로 정하기]로 (브리프 끝 알림 둘째 글을 보이려고 더한 상태) |
| `error` | 실패: 완료 줄 자리에 오류 카드(지금 상태 바꾸기 실패와 같은 자리·모양). 줄은 바뀌지 않음 |

누르면 움직인다: [관리자로 정하기]·[관리자 빼기] → 확인 창 → [취소]·Esc는 닫고 누른 단추로 초점, 확인은 완료 줄(초점은 '승인' 탭). 띠의 "확인 단추를 실패로"를 켜면 확인이 실패 카드로 간다(초점은 누른 단추). 탭(대기·승인·거절)을 바꾸면 완료 줄·오류 카드가 지워진다(지금 화면과 같다). 대기·거절 탭의 단추는 그림만이다.

## 쓴 화면 글자 (브리프 그대로)

- 안내: `승인하면 그 계정은 바로 대시보드를 쓸 수 있어요. 거절한 신청은 거절 탭에서 되돌릴 수 있어요. 승인 탭에서 관리자를 정하거나 뺄 수 있어요.`
- 칩: `관리자` · 주 관리자 줄 칩: `주 관리자`(추가 요청) · 단추: `관리자로 정하기` / `관리자 빼기` · 내 줄: `내 계정`
- 정하기 창: 제목 `이 계정을 관리자로 정할까요?` · 신청 내용 칸(의원 이름 / 신청자 · 이메일) · 본문 `관리자는 가입 승인·거절, 설치 파일 올리기, 관리자 정하기·빼기를 할 수 있어요.` · [`취소`] [`관리자로 정하기`]
- 빼기 창: 제목 `관리자에서 뺄까요?` · 신청 내용 칸 · 본문 `빼도 이 계정은 지금처럼 대시보드를 써요. 가입 승인 화면만 열 수 없어요.` · [`취소`] [`빼기`]
- 끝 알림: `{의원 이름} 계정을 관리자로 정했어요.` / `{의원 이름} 계정을 관리자에서 뺐어요.`
- 실패 번호: `E-ADMIN-ROLE`

## 브리프와 다른 곳 · 브리프에 없어 정한 것

1. **'승인됨' 칩이 없어진다.** 지금 '승인' 탭 동작 칸에는 `승인됨`(positive 칩)이 있다. 브리프는 동작 칸에 단추·`내 계정`만 적었고, 150px 칸에 칩과 단추를 함께 두면 넘친다 → 칩 자리를 새 단추·`내 계정`이 차지한다(탭이 이미 '승인'이라 뜻은 잃지 않는다). `docs/UI_GUIDE.md` '관리자'의 "승인 '승인됨'(positive 칩)"·'칩' 줄을 명세가 고쳐야 한다.
2. **E-ADMIN-ROLE 글은 이 시안이 정했다**(브리프에 번호만 있음). 무엇이 `관리자를 정하거나 빼지 못했어요` · 어떻게 고치나 `인터넷 연결을 확인하고 다시 눌러 주세요. 계속되면 오류 번호와 함께 문의해 주세요.`(뒤 문장은 E-ADMIN-FAILED와 같다). E-ADMIN-FAILED("신청 상태를 바꾸지 못했어요")는 뜻이 달라 쓰지 않았다.
3. `s=removed`(뺀 뒤)를 더했다. 브리프 끝 알림 둘째 글을 보이려고만.
4. '설치 파일' 칸은 바뀌지 않아 줄여 그렸다(아래 안내 문단을 뺌).
5. 확인 창이 떠 있는 동안 앞 완료 줄은 그대로 둔다(지금 거절 창과 같다).

## 모양 결정

- `관리자` 칩: `ds.chip.accent`(accent-soft 바탕 · accent-strong 글자 · 20px · caption 500). 의원 이름 글자 바로 뒤 6px. 이름만 말줄임되고 칩은 늘 보인다. 전체 이름은 칸 `title`(지금과 같다).
- `주 관리자` 칩: `관리자` 칩과 같은 `ds.chip.accent`, 글자만 다르다(새 색 없음). 주 관리자는 아무도 뺄 수 없어 남이 볼 때 동작 칸이 비고, 자기가 볼 때는 `내 계정`.
- `내 계정`: 단추 없이 small(13px) `muted` 글자, 오른쪽 정렬(faint는 글자에 못 쓴다).
- [관리자로 정하기]·[관리자 빼기]: `ds.button.secondarySmall`(32px). 확인 창은 `RejectDialog` 틀 그대로(가림막 ink 36% · `ds.layer` · 폭 400 · 안쪽 24 · 처음 초점 [취소] · Esc · Tab은 두 단추 사이만), 확인 단추는 정하기 `ds.button.primary`, 빼기 `ds.button.danger`.
- 완료 줄·오류 카드: 지금 화면 자리(탭 줄과 표 사이, `role=status` small positive + 체크 16 / `ErrorCard`) 그대로.

## 칸 폭

- 칸은 지금 그대로(신청일·의원 이름·EMR·신청자·이메일·연락처·동작), **동작 칸 150px 그대로 둔다(넓히지 않음).**
- 잰 값(1440·1024 둘 다): 동작 칸 안쪽 118px, [관리자로 정하기] 107.8px(10px 남음), [관리자 빼기] 85.4px, 단추 높이 32px(줄바꿈 없음), 칸 밖으로 안 나감.
- 1024px에서는 의원 이름 칸이 162px이라 **관리자 줄의 이름이 말줄임된다**: `관리자` 칩 줄은 약 10~22px(예: "새봄재활의학…"), `주 관리자` 칩은 더 넓어 약 23px(예: "한결정형외…"). 지금도 긴 이름은 말줄임 + `title`이라 규칙은 같다. 1440px에서는 잘리지 않는다.
- 명세에 남길 것: 지금 코드는 768~1023px에서 동작 칸을 140px(`max-lg:w-35`, 안쪽 108px)로 줄인다 → [관리자로 정하기]가 0.2px 남기고 겨우 들어간다. 그 폭에서도 150px을 두는 쪽을 권한다(이 시안은 1024 이상만 찍음).

## 설정 새 칸 (settings.html — 추가 요청)

지금 설정 화면(`src/components/settings/SettingsPage.tsx`) 그대로: 앱 틀(탭 줄 [더보기 · 설정]이 지금 탭 모양) → h1 `설정` + 안쪽 메뉴 [설정 | 비트 PC 연결] → 칸들. 바뀌지 않는 칸(병원 정보 · 비트 PC 연결 · 설치 파일 · 점검 규칙 · 병원 문구 · 상병 연결표 · 현금 시재 · 데스크 계정)은 제목·안내만 남겨 줄였다. 새 칸은 **맨 아래(데스크 계정 다음)**.

| `?s=` | 보이는 것 |
|---|---|
| `owner`(기본) | 주 관리자가 볼 때. 새 칸 `관리자만 보는 탭`: 12개 탭 목록, 예시로 AI 리포트·직원·재고가 켜져 있음(저장된 값) + [저장] |
| `saved` | 서식을 더 켜고 [저장]한 뒤: [저장] 옆 `저장했어요.` |
| `error` | 같은 저장이 실패: [저장] 위에 오류 카드 `E-SETTINGS-FAILED`, 단추 글자 `다시 저장`, 켠 값은 그대로 |

누르면 움직인다: 체크를 바꾸면 `저장했어요.`가 사라지고, [저장]은 `저장했어요.`로, 띠의 "저장을 실패로"를 켜면 실패 카드로 간다.

- 쓴 글자(브리프 그대로): 제목 `관리자만 보는 탭` · 설명 `켜 둔 탭은 관리자 계정에만 보여요. 다른 원장 계정과 데스크 계정에서는 메뉴에서 사라지고, 주소로 들어와도 대시보드로 돌아가요. 새로 생긴 탭은 처음에 켜져 있어요.`
- 탭 목록(12개, `src/components/shell/menu.ts` `MENU` 차례 = 탭 띠 → [더보기]에서 대시보드·설정을 뺌): 통계 · 청구 · 고시·공지 · 환자 · 업무일지 · 수납일지 · 예약 · AI 리포트 · 서식 · 직원 · 재고 · 주소록. 가입 승인은 원래 관리자만이라 목록 밖.
- 켜고 끄기 모양: 설정 화면에 미끄럼 스위치는 없다. 지금 설정 화면의 켜고 끄기는 **체크 상자 `ds.checkbox`**(점검 규칙 '켜기' 칸, 병원 정보 '휴진'·'예약에 보이기')라 그것을 쓴다. 목록 틀은 병원 정보 '진료시간' 목록(1px line · 4px · 줄 사이 1px line · 줄 안쪽 8px 12px), 폭 360px, 줄 전체가 눌리는 label(탭 이름 body ink).
- 저장·알림·실패: 상병 연결표(`DxLinks`)와 같은 방식 — 칸 아래 [저장](`ds.button.primary`) + 옆 `role=status` small ink-2 `저장했어요.` / 실패는 단추 위 `ErrorCard` + 단추 글자 `다시 저장`. 체크를 바꾸면 `저장했어요.`가 사라진다.

### 설정 칸에서 브리프와 다르거나 정한 것

1. **실패 번호는 새로 만들지 않고 `E-SETTINGS-FAILED`를 썼다.** 다른 설정 칸이 모두 이 번호이고 글("설정을 불러오거나 저장하지 못했어요 …")이 그대로 맞는다. 브리프는 "필요하면 `E-TAB-ACCESS`"라 했는데, 이 칸만 따로 번호를 둘 까닭이 없어 보였다. 명세가 따로 두기로 하면 번호만 바꾸면 된다.
2. 칸 자리(맨 아래)와 목록 모양(한 줄에 하나, 폭 360px)은 브리프에 없어 이 시안이 정했다. 계정에 관한 칸(데스크 계정) 바로 아래라서 맨 아래.
3. 켜진 예시 셋(AI 리포트·직원·재고)은 보기용이다. 실제 첫 값은 브리프대로 지금 탭 모두 꺼짐('모두에게').
4. 주 관리자가 아닌 계정(다른 관리자·원장·데스크)의 설정 화면은 새 칸이 없을 뿐 지금과 같아 따로 그리지 않았다.
5. 저장 단추는 바뀐 것이 없어도 눌린다(상병 연결표와 같다).

## 확인한 것

- 가입 승인 찍은 너비: list·add·remove·done 1440·1024, error·removed·other 1440. 설정: owner·saved 1440·1024, error 1440. 모두 가로 넘침 0px, 콘솔 오류 0개. 한글은 모두 앱 글꼴(Pretendard 부분 글꼴)로 그려진다.
