# 재고 탭 시안 (inventory)

- 시안: `index.html` 한 파일. 상태는 `?s=`: `list` · `order` · `count` · `print` · `in-check` · `in-manual` · `in-list` · `in-photo` · `excel`(양식 파일) · `excel-own`(갖고 있던 엑셀) · `month` · `edit` · `cats` · `bit`(비트 코드에서 고르기) · `bit-empty` · `dash` · `empty`
- 기준: 인터뷰 결정(2026-11-21, 메모 `inventory-interview`) + 같은 날 사용자 추가 "주소록처럼 엑셀 양식 받기, 양식 아닌 엑셀은 AI 칸 맞춤 그대로" · "[주문함]은 주문하세요 줄에만" · "새 화면은 폰 전용 모양 없음" · "비트 코드에서 골라 물품 더하기"
- 값: `src/app/globals.css` 토큰, `ds` 모양(단추·칩·입력·표), 도구 단추 줄(ToolRow), 오른쪽 판 = 예약 탭 `AddPanel` 모양. 물품·숫자·사진은 지어낸 예시

## 짜임
- 탭 틀: 재고는 [더보기] 안 → 단추가 "더보기 · 재고"(지금 탭). h1 "재고" → 도구 단추 줄 **목록 · 세기 · 들어온 기록 · 달별**(`?tool=`처럼 주소에 남김)
- 목록: 맨 위 **챙길 것**(주문하세요 n · 기한 가까움 n 칩 + 줄마다 [주문함]) → 물품 목록 머리(오른쪽 [양식 받기] [엑셀 올리기] [분류 고치기] [순서 바꾸기] [비트 코드에서 고르기] [물품 더하기]=주 단추) → 분류별로 묶은 표(물품 이름 · 지금 수량+단위 · 최소 수량 · 가장 빠른 유통기한 · 거래처 · 단가 · 상태 칩 · [고치기]) → "안 쓰는 물품 n개는 숨겨 뒀어요 [보기]"
- [주문함] 누르면 그 줄이 "주문함 11/21"(neutral 칩) + [주문 취소]로 바뀌고 맨 아래로, 알림 개수에서 빠짐. 표 상태 칸도 같은 칩
- 세기: 센 날(기본 오늘) → 같은 차례 표(지난 수량 · 그 뒤 들어옴 · 센 수량 입력 · 가장 빠른 유통기한 입력) → 아래 붙는 줄 "n개 가운데 n개 적었어요 · 비운 n개는 그대로예요" + [저장]. 경고는 그 줄 바로 아래 warning 글 + [입고 적기]
- 세기 종이: 미리 보기 화면 + [인쇄](브라우저 인쇄). A4 세로, 칸 = 물품 이름 · 단위 · 지금 수량 · 센 수량(빈 네모) · 지금 유통기한 · 가장 빠른 유통기한(빈 네모), 위에 센 날·센 사람 빈칸
- 입고 확인: PC 왼쪽 사진(300px) + 오른쪽 날짜·거래처·줄 표(명세서에 적힌 이름 · 목록 물품 고르기 · 수량+단위 · 단가 · 금액 · 지우기). 칩: "기억한 이름"(neutral) · "확인해 주세요"(warning, AI가 자신 없음) · "새 물품"(accent → 분류·단위 칸이 그 줄 안에 열림). 1200px 아래(작은 PC 화면)는 사진이 표 위로 가서 표가 넓게. 덩어리는 최소 960px, 그보다 좁으면 제 상자 안에서 옆으로. 저장 줄은 그 아래 전체 폭
- 들어온 기록: 달로 묶은 표(날짜 · 거래처 · "첫 물품 외 n줄" 펼치기 · 금액 · [사진 보기] 또는 "사진 없음" · [고치기]). 지난달은 접힌 머리 한 줄. 사진 보기 = 가운데 확인 창(ds.layer, 640px)
- 엑셀: 양식 파일이면 "양식 그대로"(positive 칩) + 바로 미리 보기. 양식이 아니면 위에 **AI가 맞춘 칸**(재고 탭 칸 8개 → 엑셀 칸 고르기, 4칸 그리드)·**분류 맞추기**(엑셀 값 → 분류, '+ 새 분류' 고르기 있음) → 미리 보기. 미리 보기 = 엑셀 줄 · 상태(새 물품 accent / 고침 warning / 그대로 neutral / 건너뜀 neutral) · 양식 8칸 · 바뀐 것·살펴볼 것. 위에 거르기 단추(모두·새 물품·고침·건너뜀·그대로). 아래 붙는 줄 "새 물품 n · 고침 n · 건너뜀 n" + [넣기]
- 달별: ◀ 2026년 10월 ▶ → 그 달에 끝난 세기 날짜 → 숫자 3칸(구입비·들어온 기록·세기) → PC 두 칸: 분류별 구입비 표(합계 줄) | 물품별 쓴 양·구입비 표(분류 머리 줄에 분류 합계). 1280px 아래(작은 PC 화면)는 두 표가 위아래로
- 물품 고치기·분류 고치기: 오른쪽 판 460px(화면이 좁으면 화면 폭까지), 아래 [취소] [저장]. [물품 더하기]도 같은 판(제목 "물품 더하기", 지금 수량 입력 칸 — 시안은 고치기 판만 그림). 물품 고치기에 읽기 전용 칸 "비트 코드": XH0201 · 비트 이름 + [연결 끊기]
- 비트 코드에서 고르기: 가운데 창(사진 보기와 같은 640px 창). 위 찾기 칸("이름이나 코드") + 출처 한 줄 → 표(체크 · 이름 · 코드(muted) · 쓴 건수 "1,240건", 많이 쓴 차례) → 아래 왼쪽 "넣을 분류" 고르기, 오른쪽 [취소] [n개 더하기]. 이미 이어진 코드는 "이미 있음"(neutral 칩) + 체크 못 함. 코드가 없으면 창 가운데 "불러온 처방 코드가 없어요. 통계에서 비트 자료를 불러오면 고를 수 있어요." + [닫기]
- 대시보드: 챙길 것이 있을 때만, 연결 뒤 브리핑 오른쪽 칸(12칸 중 9~12) — 위 1px line-strong, h2 "재고" + [재고 탭에서 보기], 숫자 두 칸(주문하세요·기한 가까움), 물품 4줄 + "외 n개". 1024px 아래는 지금 대시보드 흐름 그대로(브리핑이 한 칸이 되면 그 아래)
- 빈 상태: "아직 물품이 없어요" → 3단계(1 양식 받기 [양식 받기] · 2 채우기 · 3 엑셀 올리기 [엑셀 올리기]=주) → "갖고 계신 엑셀도 올릴 수 있어요(AI가 칸을 맞춰요)." → [물품 더하기] 글자 단추 → "비트에서 쓰던 약·재료 코드에서 골라 넣을 수도 있어요." [비트 코드에서 고르기] 글자 단추 → 시작 분류 넷 + [분류 고치기]
- 폰 전용 모양 없음(사용자 규칙): 폰에서도 PC 화면 그대로. 표·챙길 것 목록(최소 800px)·입고 확인 덩어리(최소 960px)·빈 상태 3단계(최소 720px)는 제 상자 안에서 옆으로 밀리고, 페이지는 가로로 넘치지 않음. 위쪽 띠·탭 줄만 지금 앱 틀 그대로. 시안 사진은 1440·1024

## 내가 정한 것 (명세에서 확인할 것)
1. 시작 분류 이름: **약품 · 치료 소모품 · 보조기·깁스 · 사무·생활**(인터뷰 "/"를 "·"로)
2. 칸 이름은 양식과 같게 **물품 이름 · 가장 빠른 유통기한**(표·판·세기 종이 모두). 알림 이름은 '주문하세요'·'기한 가까움' 그대로
3. 챙길 것은 **목록 도구에만**(세기·들어온 기록·달별에는 없음). 없으면 "챙길 것이 없어요." 한 줄
4. '주문하세요' = 지금 수량 **<** 최소 수량(같으면 알림 없음). '기한 가까움' = 오늘부터 30일 안. 이미 지난 것도 이 알림(개수도 '기한 가까움'에 셈)이고 칩만 **"기한 지남"**, 글은 "기한 11월 18일 · 3일 지났어요"(오늘이면 "오늘까지"). **[주문함]은 '주문하세요' 줄에만 있다(사용자 결정)** — 기한 가까움·기한 지남 줄은 정보만, 단추 없음(대시보드 칸에도 단추 없음). 주문함은 '주문하세요' 칩만 바꾸고 기한 칩은 그대로 둠
5. 순서 바꾸기는 **[순서 바꾸기] 모드**에서만 끌기(줄 앞 손잡이) + ▲▼ 단추. 분류 안에서만, 분류 차례는 [분류 고치기]의 ▲▼
6. 세기 칸 비우면 placeholder "그대로". 표 안 입력은 36px(ds.input 44px 아님, 줄이 많아서)
7. 경고 글: "센 수량 18이 지난 수량 8 + 들어온 0 = 8보다 많아요. 입고 기록이 빠졌을 수 있어요." + [입고 적기](사진 없이 적기로). 저장은 막지 않음
8. 세기 종이에 **지금 수량·지금 유통기한을 찍어 줌**(크게 다르면 다시 세게). 안 쓰는 물품은 빠짐, 물품 많으면 다음 장
9. 물품 고치기의 지금 수량은 **읽기 전용**("수량은 [세기]에서 고쳐요") — 쓴 양 계산이 맞게
10. [안 씀]은 고치기 판 맨 아래 체크 상자. 숨긴 물품은 목록 아래 "안 쓰는 물품 n개는 숨겨 뒀어요. [보기]"로 흐리게 보임(칩 "안 씀", 줄 끝 **[다시 쓰기]** = 숨김 풀기, `?s=list&h=1`)
11. 분류 지우기는 물품 0개일 때만
12. 입고 저장 = 지금 수량에 더함 + 단가 적은 줄은 물품 단가도 그 값으로 바꿈(목록과 다르면 줄 아래 "목록 단가 3,000원 → 3,200원으로 바뀌어요") + 그 물품 '주문함' 풀림 + 고른 짝 기억
13. 기억한 짝은 물품 고치기 판 "명세서에서 맞춘 이름" 목록에서 [지우기]로 지움
14. 수량 단위 안내: "수량은 목록 단위로 적어요. 100개들이 2박스면 200이에요." (AI가 박스→낱개로 바꾸지 않음)
15. 엑셀: 같은 물품 이름이면 **고침**(바뀐 칸만, 굵게), 파일에 없는 물품은 그대로(지우지 않음), 지금 수량이 바뀐 줄은 **그날 센 것**으로 남음, 빈 줄은 세지 않음, 같은 파일 안 같은 이름 두 번째 줄·숫자 아닌 수량 = 건너뜀("수량은 0 이상 숫자로 적어요"), '27.08' 같은 달만 있는 기한 = 그 달 마지막 날
16. [양식 받기]: 물품이 있으면 지금 목록이 채워진 양식(숨긴 물품 빼고, 목록 차례), 없으면 빈 양식. 시트 '물품', 8칸
17. 달별 증감은 좋고 나쁨이 없어 **색 없이** ink-2 화살표 + 글자(+4 (+13.3%)). 9월 없음 = "새로 생김", 0 = "–"
18. 대시보드 작은 칸은 챙길 것 0이면 아예 안 보임
19. 새 아이콘 둘: 끌기 손잡이(grip, 점 6개) · 찾기 돋보기(search). 나머지는 지금 `Icon` 그대로(목록 doc · 세기 check · 들어온 기록 arrowDown · 달별 cal · 양식 받기 arrowDown · 올리기 upload)

20. 비트 코드 고르기: 고른 코드는 **넣을 분류 하나로 한꺼번에** 들어가고, 이름 = 비트 이름 그대로 · 단위 "개" · 지금 수량 0 · 그 코드와 이어짐(단위·최소 수량은 뒤에 [고치기]). 이미 이어진 코드는 다시 못 고름. 쓴 건수 = 통계에서 불러온 비트 자료 기간의 처방 줄 수(기간을 한 줄로 보여 줌). 코드·이름·건수만 쓰고 환자 정보는 없음. 시안 코드(XH0201 등)는 지어낸 것

## 단추·글자 (시안 글자 그대로)
- 입고: 들어온 기록 머리 [사진 없이 적기](보조) · [사진 올리기](주, upload 아이콘). 확인 화면 제목 "들어온 것 확인" / "사진 없이 적기", [사진 다시 올리기], [+ 줄 더하기], [취소] [저장]. 기록 줄 [사진 보기] 또는 "사진 없음", [고치기]
- 세기: [세기 종이 인쇄] → 미리 보기 [세기로 돌아가기] [인쇄], 입력 화면 [저장]
- 목록: [양식 받기] [엑셀 올리기] [분류 고치기] [순서 바꾸기] [비트 코드에서 고르기] [물품 더하기], 순서 모드 [다 됐어요], 알림 [주문함]/[주문 취소], 숨긴 줄 [다시 쓰기]
- 엑셀: [양식 받기] [다른 파일 올리기] [모두 보기] [취소] [넣기]
- 비트 코드: 창 제목 "비트 코드에서 고르기", 찾기 칸 "이름이나 코드", 칩 "이미 있음", "넣을 분류", [취소] [n개 더하기], 빈 때 [닫기]. 물품 고치기 "비트 코드 XH0201" [연결 끊기]
- 대시보드 칸: 제목 h2 **"재고"** + [재고 탭에서 보기 →], 숫자 칸 "주문하세요 n개" · "기한 가까움 n개", 물품 4줄 + "외 n개"

## 명세가 정할 것 (시안에서 안 정함)
- 명세서의 부가세·할인 줄: 시안은 줄 금액 = 수량 × 단가만 봄
- 사진 보관 크기·기간, 여러 장 사진(앞뒤 장)
- 엑셀 미리 보기 줄이 많을 때(시안은 일부 줄만 그림)
- 비트 코드: 약·재료 코드만 어떻게 골라 낼지(처치·검사 코드 빼기), 새 물품 단위를 비트에서 가져올 수 있는지, 이어진 코드로 나중에 쓴 양을 셀지
