# 수납일지 장부 줄 세우기 시안 (sunap-sort)

2026-11-17 사용자: "수납일지에서 이름·구분·예약·금액 오름차순·내림차순으로 볼 수 있게 해".

- 바탕: 승인된 `docs/mockups/sunap-ilji/index.html`을 복사. 실제 화면처럼 원장님 칸은 뺐다.
- 제목 버튼: 이름·구분·현금·카드·계좌·미수·다음 예약. 누를 때마다 오름차순(▲) → 내림차순(▼) → 접수 순(↕)으로 바뀐다.
- 세우는 기준:
  - 이름: 가나다 순.
  - 구분: 초진 → 90일초진 → 재진.
  - 금액: 그 칸 금액. FREE 줄은 0원으로 친다.
  - 다음 예약: 종류 순(주사치료 → 진료(경과) → 기타 → 종류 모름), 같은 종류 안에서는 날짜 순. '예약 안 하고 가심'은 어느 쪽으로 세워도 맨 뒤.
- 값이 같은 줄은 접수 순서대로 둔다. NO는 접수 번호 그대로라 다시 매기지 않는다.
- 위 칩 거르기·찾기와 함께 쓸 수 있다. 합계 줄은 그대로.
- 정렬 상태는 저장하지 않는다. 다시 열면 접수 순이다.
- 표 위 한 줄: 처음에는 '제목(이름·구분·금액·다음 예약)을 누르면 줄을 세워요'. 세우면 '<칸> 오름차순 · 한 번 더 누르면 내림차순'.
- 상태 고르기: `?k=name|kind|cash|card|acct|un|rsv&d=asc|desc`.
