# 점검 규칙 저절로 바꾸기 시안 (rule-auto)

- 시안: `docs/mockups/rule-auto/index.html` — 파일 하나. 상태는 `?s=`, 화면은 `?v=`로 고른다(위쪽 회색 띠의 단추로도 바꾼다).
- 정한 것의 기준: 사용자 결정(2026-11-22) "점검규칙 저절로 바뀌게해". 'AI 안 → [적용] 한 번 누르기'와 '완전히 저절로' 가운데 **완전히 저절로**를 골랐다 — AI가 고친 규칙이 바로 적용되고, 대시보드에 '규칙 n개가 바뀌었어요' 알림과 [되돌리기].
- 모양: 고시·공지 시안(`docs/mockups/notices`)과 앱 토큰(`src/app/globals.css :root`)·공통 모양(`classes.ts ds`)을 옮겼다. 글꼴은 `src/app/fonts` Pretendard.
- 자료: 고시 번호·규칙 번호·규칙 제목·횟수는 모두 지어낸 **예시**다. 환자 자료는 하나도 없다.
- **PC 화면만** 그렸다(폰 전용 모양 없음, 2026-11-21 사용자 지시). 폰에서도 PC 화면 그대로 보인다.

## 상태 (`?s=`) × 화면 (`?v=`)

| s | 뜻 |
|---|---|
| `changed` (기본) | 바뀜 있음: 고시 제2026-251호가 규칙 2개(ES-04 횟수 5→6회, MN-03 함께 못 하는 열치료 하나 더함)를 저절로 바꿈, 3개는 바꿀 것 없음. 다른 고시(제2026-255호)는 AI가 살펴보는 중 |
| `human` | 사람이 봐야 함: 같은 고시가 규칙 1개를 바꾸고, 2개는 저절로 고칠 수 없음(새 수가 코드 · 앱 안 계산 규칙) |
| `reverted` | 되돌림: ES-04를 우리 병원만 되돌림(전 규칙으로 점검), MN-03은 그대로. `&fail=1`이면 되돌리기 저장 실패 상자 |
| `none` | 바꿀 것 없음: 살펴본 3개 모두 그대로 → 대시보드 알림 없음, 글 화면에는 회색 상자 하나 |

| v | 보이는 것 |
|---|---|
| `dashboard` | 대시보드 맨 위 알림 띠(노랑 '확인 필요' 먼저, 파랑 '바뀌었어요' 다음) · '고시·공지' 칸 |
| `detail` | 글 화면 규칙 상자: 확인 필요(노랑) → 저절로 바뀜(파랑, 규칙마다 전·후·까닭·적용 날짜·[되돌리기]) → 바꿀 것 없음(회색, [보기]로 펼침) |
| `list` | 글 목록 칩: `점검 규칙 2개 바뀜` · `점검 규칙 살펴보는 중` · `점검 규칙 확인 필요` |
| `settings` | 설정 → 점검 규칙 표: 규칙 이름 옆 `고시로 바뀜 · 11월 20일부터`(오늘 이미 적용된 판은 제목·고시 근거도 새것), 되돌린 규칙은 `고시 변경 되돌림` |

눌러 볼 수 있는 것: [되돌리기]·[다시 적용] · [확인했어요] · 바꿀 것 없는 규칙 [보기]/[접기] · 상태·화면 단추.

## 보여 준 결정

사용자가 정한 것:
1. **완전히 저절로**(2026-11-22): AI가 새 고시를 읽고 고친 규칙이 사람 누름 없이 바로 점검에 쓰인다. 알림과 [되돌리기]로 사람이 뒤에서 본다.

시안에서 Claude가 정한 것(승인 때 같이 확인):
1. **규칙마다 넷 중 하나**: AI가 고시와 연결된 규칙을 하나씩 '상관없음 · 바뀔 것 없음 · 바꿈 · 사람이 봐야 함'으로 나눈다. **사람이 봐야 함만** 노란 '확인 필요'로 남는다(전에는 번호만 맞으면 모두 '확인 필요'였다 — 고시 하나에 규칙 27개가 걸리기도 했다).
2. **사람이 봐야 함이 되는 경우**: 지금 규칙 종류(18가지)로 나타낼 수 없는 새 내용, 규칙표에 없는 새 코드·새 묶음, 규칙이 보던 코드·묶음·약 분류를 빼야 하는 변경, 등급을 바꿔야 하는 변경, 앱 안 계산으로 도는 규칙(진찰료·상병마스터 등), 시행일을 모름, AI 답이 규칙 모양 검사를 못 지남, AI가 세 번 실패함. 경고를 빠뜨리는 쪽의 자동 변경은 막는다.
3. **진료일 기준 적용**: 바뀐 규칙은 고시 시행일(`{날짜} 진료부터 적용`)부터의 진료에만 쓰고, 그 전 진료는 전 규칙으로 점검한다. 지난달을 다시 점검해도 맞다.
4. **되돌리기는 병원마다**: 한 병원이 되돌려도 다른 병원은 그대로다. 되돌린 규칙은 [다시 적용]으로 돌아온다. 되돌린 시각을 상자에 남긴다.
5. **알림 자리**: 대시보드 맨 위 띠 둘(노랑 '점검 규칙 확인 필요' → 파랑 '점검 규칙이 바뀌었어요'). 파랑 띠는 그 글 화면을 열어 바뀐 내용을 보면 사라진다(병원마다). 노랑 띠는 지금처럼 [확인했어요]까지 남는다.
6. **글 화면 상자 차례**: 확인 필요 → 저절로 바뀜 → 살펴보는 중 → 바꿀 것 없음(처음엔 접힘). 바뀐 규칙은 카드마다 전(지운 줄)·후(굵게)·까닭·적용 날짜·[되돌리기]. 되돌리면 전이 굵게, 후가 지운 줄로 바뀐다.
7. **규칙표 날짜보다 앞선 글은 연결하지 않는다**: 지금 규칙표(판 2026-10-19)는 그때까지의 고시를 담고 있어, 그 날짜까지 올라온 글은 규칙과 잇지 않는다. 이미 이어 둔 것도 모으기가 다음 실행에 지운다(사용자가 SQL을 따로 돌리지 않아도 됨).
8. **설정 → 점검 규칙**: 바뀐 규칙 이름 옆에 `고시로 바뀜 · {날짜}부터` 칩. 오늘 이미 적용되는 판이면 제목·고시 근거도 새 판으로 보인다. 켜기·끄기·등급 고르기는 지금처럼 규칙마다 그대로 걸린다.
9. 글 목록 칩: `점검 규칙 {n}개 바뀜`(파랑) · `점검 규칙 확인 필요`(노랑) · `점검 규칙 확인함`(회색) · `점검 규칙 살펴보는 중`(회색). 바꿀 것 없는 글은 칩 없음.

## 화면 글자 (명세가 그대로 옮길 것)

`{…}`는 바뀌는 값. 시안 `index.html`의 `T`와 같다. `{번호}`는 `보건복지부 고시 제2026-251호` 꼴, `{날짜}`는 `12월 1일` 꼴, `{시각}`은 `11월 22일 (일) 09:12` 꼴.

대시보드 맨 위 — 저절로 바뀜(파랑 띠)
- 제목: `점검 규칙이 바뀌었어요`
- 글(글 하나, 고시 번호 있음): `새 고시({번호})로 점검 규칙 {n}개가 저절로 바뀌었어요. 틀려 보이면 글 화면에서 되돌릴 수 있어요.`
- 글(글 하나, 번호 없음): `새 글로 점검 규칙 {n}개가 저절로 바뀌었어요. 틀려 보이면 글 화면에서 되돌릴 수 있어요.`
- 글(글 둘 이상): `새 고시 {k}개로 점검 규칙 {n}개가 저절로 바뀌었어요. 틀려 보이면 글 화면에서 되돌릴 수 있어요.`
- 링크: `바뀐 내용 보기`

대시보드 맨 위 — 사람이 봐야 함(노랑 띠)
- 제목: `점검 규칙 확인 필요`
- 글(하나, 번호 있음): `새 고시({번호})가 점검 규칙 {n}개를 바꿨는데, 저절로 고칠 수 없는 내용이라 직접 확인해야 해요.`
- 글(하나, 번호 없음): `새 글이 점검 규칙 {n}개를 바꿨는데, 저절로 고칠 수 없는 내용이라 직접 확인해야 해요.`
- 글(둘 이상): `새 고시 {k}개가 점검 규칙 {n}개를 바꿨는데, 저절로 고칠 수 없는 내용이라 직접 확인해야 해요.`
- 링크: `글 보기`

글 화면 — 확인 필요 상자(노랑)
- 제목: `이 글이 점검 규칙 {n}개를 바꿔요 — 확인 필요`
- 글: `저절로 고칠 수 없는 내용이에요. 아래 규칙이 새 기준과 맞는지 설정 → 점검 규칙에서 확인해 주세요.`
- 규칙마다: 제목 · 규칙 번호 · 까닭 한 줄
- 단추: `점검 규칙 보기` · `확인했어요`
- 확인한 뒤: `점검 규칙 {n}개 확인함` · `{시각}에 확인했어요.`

글 화면 — 저절로 바뀜 상자(파랑)
- 제목: `이 글로 점검 규칙 {n}개가 저절로 바뀌었어요`
- 글: `AI가 새 고시를 읽고 규칙을 고쳤어요. 틀려 보이면 ‘되돌리기’를 누르세요. 우리 병원만 전 규칙으로 돌아가요.`
- 카드마다: 제목 · 규칙 번호 · `전` {전} · `후` {후} · `까닭` {까닭} · `{날짜} 진료부터 적용` · 단추 `되돌리기`(화면 읽기 `{규칙 번호} 되돌리기`)
- 되돌린 카드: 칩 `우리 병원은 되돌림` · `{시각}에 되돌렸어요. 우리 병원은 전 규칙으로 점검해요.` · 단추 `다시 적용`(화면 읽기 `{규칙 번호} 다시 적용`)
- 상자 끝: `AI가 고친 규칙이라 틀릴 수 있어요. 바뀐 내용은 고시 원문과 꼭 맞춰 보세요.`
- 저장 실패(카드 안): `점검 규칙을 바꾸지 못했어요` · `잠시 뒤 다시 눌러 주세요. 지금은 누르기 전 규칙 그대로 점검해요`

글 화면 — 살펴보는 중 · 바꿀 것 없음(회색)
- 살펴보는 중 제목: `AI가 점검 규칙 {n}개를 살펴보는 중이에요` · 글: `이 글이 근거를 바꾸는 규칙이에요. 바꿀지 AI가 살펴보고 있어요. 끝나면 여기와 대시보드에 알려요.` · 규칙 제목 목록
- 바꿀 것 없음 제목: `살펴봤는데 바꿀 것 없는 점검 규칙 {n}개` · 단추 `보기`/`접기` · 펼치면 규칙마다 제목 · 규칙 번호 · 까닭 한 줄

글 목록 · 대시보드 '고시·공지' 칸 칩
- `점검 규칙 {n}개 바뀜` · `점검 규칙 확인 필요` · `점검 규칙 확인함` · `점검 규칙 살펴보는 중` (대시보드 칸은 `점검 규칙 확인 필요`만)

설정 → 점검 규칙
- 칩: `고시로 바뀜 · {날짜}부터` · 되돌린 규칙 `고시 변경 되돌림`

까닭 줄 가운데 앱이 정하는 글(AI가 쓰지 않음, 명세 기본값):
- `이 규칙은 앱 안 계산으로 돌아 저절로 바꿀 수 없어요.`
- `AI가 고친 규칙이 점검 규칙 모양에 맞지 않아 직접 확인해야 해요.`
- `시행일을 글에서 찾지 못했거나 앞뒤가 맞지 않아 직접 확인해야 해요.`
- `AI가 이 규칙을 살펴보지 못했어요. 직접 확인해 주세요.`
