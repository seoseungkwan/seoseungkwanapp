# desk-setup 시안 메모

데스크 계정도 비트 PC에 확장·도우미를 깔고 연결할 수 있게(사용자 2026-11-19 "ㅇㅇ 그거해" — 데스크는 확장·도우미 받는 곳이 안 보임).

- ① 수납일지 다른 기기 안내 칸(device): 글 한 줄 '이 PC에 비트가 깔려 있으면 확장·도우미를 깔고 연결해서 장부를 볼 수 있어요.' + [이 PC 연결하기] → /claim/setup. 옛 도우미 칸(old-helper): [도우미 새 판 받기] → /claim/setup. 데스크·원장 같음. 62일 넘은 날(old-day) 칸은 그대로.
- ② 데스크 계정 메뉴: [비트 PC 연결] 링크(로그아웃 위). 원장 메뉴는 그대로.
- ③ /claim/setup을 데스크도 연다: 제목 '비트 PC 연결', 안쪽 메뉴([설정]·[비트 PC 연결]) 없음, 옆 의원 이름은 데스크 병원 이름. 나머지 단계·내려받기는 원장 화면 그대로. 원장 화면 바뀜 없음.
- 데스크 탭(업무일지·수납일지·예약)과 다른 화면 막힘은 그대로. 서버에 새로 가는 자료 없음. 설치 파일 보관함 읽기 권한에 데스크를 더하는 SQL 하나.

승인: 2026-11-19, 사용자 "이대로 만들기"
