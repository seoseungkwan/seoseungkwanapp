# clinic-calendar(예약 탭) 시안 메모

- 파일: `index.html` 한 파일(CSS·JS 안에 있음, 밖에서 불러오는 것 없음). 사진: `week-1440.png` · `day-1440.png` · `month-1440.png` · `new-1440.png` · `settings-1440.png` · `phone-week-390.png` · `phone-new-390.png`.
- 모양: 승인된 시안(`docs/mockups/sunap-kinds`·`worklog`)의 머리·탭 줄·단추와 앱 토큰(`src/app/globals.css :root`) 그대로. 밝은 화면, 파란 강조.
- 탭 줄: 대시보드 · 통계 · 청구 · 환자 · 업무일지 · 수납일지 · **예약**(지금) · 더보기 ▾ (업무일지를 수납일지 옆으로 옮긴 모습).
- 자료는 모두 지어낸 값: 이름 ○○, 차트번호 다섯 자리, 담당 표시 (가)(나)(다)(라)(원). 지금 시각은 **2026-11-17 (화) 10:40**으로 고정.
- 승인: (대기)

## 상태 (`?s=`)
| 값 | 보이는 것 |
|---|---|
| `week` (기본) | 비트 PC 주 보기. 11/16~21, 종일 줄(회의 메모·(나) 휴무·학회·(다) 휴무), 비트 예약 회색 칸, 도착 표시, 지금 선 |
| `day` | 11/17 일 보기. 칸마다 시간·길이·메모 |
| `month` | 11월. 날마다 예약 수·종류별 수·지난 날 안 옴 수, 종일 항목 |
| `new` | 예약 더하기. 이름에 '김' → 비트에 같은 이름 3명 고르기 목록 |
| `phone-new` | 폰(390px) 예약 더하기. 이름·차트번호 손으로, '비트 PC에서는 자동으로 채워져요' |
| `overlap-warn` | (가)에게 14:00–14:30 예약이 있는데 14:20에 넣는 중 → 경고, [그래도 저장] |
| `off-warn` | 11/18 휴무인 (나)를 고름 → 경고, [그래도 저장] |
| `detail` | 예약 자세히: 도착(자동·왔음·안 옴), [다음 주에도], 고치기·예약 취소·지우기 |
| `settings` | 종류·시행자·보이는 시간·알아 둘 글 |
| `phone-week` | 폰 주 보기(날짜별 목록, 오늘만 펼침) |
| `phone-day` | 폰 일 보기(비트 예약 칸 없음) |
| `empty` | 예약이 없는 주 |

폰 상태는 넓은 화면에서 열어도 390px 틀 안에 그린다. 누를 수 있는 곳: 일·주·월, 오늘·◀▶, 빈 칸(그 시간으로 더하기), 예약 칸(자세히), 비트 예약 칸(알림), 종일 줄(메모·휴무 더하기·지우기), 날짜 머리·월 칸(그날 일 보기), 설정 고치고 [저장](바로 반영), 더하기 판의 고르기·담당·종류·길이·저장.

## 사용자가 정한 것 (시안에 그대로 넣음)
- 의원 공용 구글 캘린더를 **대신**한다. 구글 캘린더와 잇지 않는다. 의원 구글 계정 하나로 접수·치료실·진료실 PC와 폰(총괄·원장님)에서 쓴다.
- 일·주·월 보기, **주 보기가 기본**. [오늘]·◀▶. 보이는 시간은 설정(기본 08:00–20:00). 10분 칸, 10분에 맞춤.
- 예약 칸 글: `차트번호 이름 종류 (시행자 한 글자)` + 길이. 예: `10231 김○○ 도수 (가) 30분`.
- 색: 주사·진료는 종류 색, 충격파·도수·자보도수는 시행자 색. 종류마다 '고정 색' 또는 '시행자 색 따름'을 설정에서 고른다.
- 종류는 설정에서 고친다. 기본: 도수 30분 · 자보도수 30분 · 충격파 15분 · 주사 10분 · 진료 10분. 길이는 예약마다 바꿀 수 있다.
- 더하기 칸: 날짜·시작·길이·이름·차트번호·담당(시행자)·종류·메모. 전화번호 없음.
- 비트 PC: 이름이나 차트번호를 적으면 비트에서 찾아 나머지를 채운다. 같은 이름이 여럿이면 고르는 목록. 담당·종류·메모는 늘 직접 고른다.
- 폰(비트 없음): 이름·차트번호를 손으로 적는다. '비트 PC에서는 자동으로 채워져요'.
- 경고(저장은 됨): 같은 시행자 시간 겹침 / 그날 휴무인 시행자.
- 종일 줄: 학회 같은 자유 메모 + 시행자 휴무(그날에 사람을 묶음).
- 도착: 비트 PC에서 같은 날 같은 차트번호의 비트 접수가 있으면 저절로 '왔음', 시간이 지나도 접수가 없으면 '안 옴', 취소·손으로 바꾸기 가능. 칸 위 작은 표시 + 안내.
- 비트 PC에서만 비트 자체 예약을 흐린 회색 칸(보기만, '비트 예약')으로. 폰에는 없음.
- 자세히 판: [다음 주에도](다음 주 같은 시간에 복사), 고치기, 취소, 지우기.
- 설정: 종류 목록(더하기·이름·길이·색 또는 시행자 색 따름·순서), 시행자 목록(이름·한 글자 표시·색), 보이는 시간, '지난 예약은 1년 뒤 자동으로 지워져요'.
- 저장: 환자 이름·차트번호는 서버에 저장되고 로그인한 의원 계정만 본다(설정에 한 줄). 다른 PC에는 몇 초 안에 보인다.

## 시안에서 내가 정한 기본값 (사용자 확인 필요)
1. **주 보기는 월~토 6일**. 설정 '주 보기 요일'에서 월~일로 바꿀 수 있다. 월 보기는 월~일 7칸.
2. **10분 = 20px 높이**(1시간 120px). 1시간마다 선, 30분마다 옅은 선. 오늘 칸은 아주 옅은 파랑, 지금 시각은 주황 빨강 선.
3. **넓은 화면**: 1024px 이상에서 예약 탭은 메모 칸처럼 앱의 넓은 화면(`data-wide-page`)을 써서 1280px 제한을 푼다(머리·탭 줄·본문이 같이). 1440px에서 하루 칸이 약 220px.
4. 같은 시간 예약은 구글 캘린더처럼 **옆으로 나란히**(자리가 비면 오른쪽으로 넓힘). 칸이 좁으면 글이 줄을 바꾸고, 다 안 들어가면 끝이 잘리며 마우스를 올리면 전체 글이 뜬다. 1024px 같은 좁은 PC의 바쁜 시간에는 차트번호·이름까지만 보일 수 있다 → 일 보기에서는 다 보인다.
5. 일 보기 칸은 둘째 줄에 `09:30–10:00 · 30분 · 메모`. 15분 이하 짧은 칸은 한 줄에 이어 쓴다.
6. **월 보기는 목록이 아니라 수**: `예약 N`, 종류별 수, 지난 날은 `안 옴 N`(주황), 종일 항목. 취소는 세지 않는다. 날을 누르면 그날 일 보기. 폰 월 보기는 수만 + 종일 항목 점.
7. **폰 주 보기는 날짜별 목록**(7칸 표는 글이 안 들어가서). 날짜 줄에 예약 수·왔음·안 옴, 오늘만 펼침, 눌러서 펼치고 접기. 폰 일 보기는 PC와 같은 시간 표.
8. 색판 10색(파랑·청록·보라·주황·분홍·연두·남색·하늘·갈색·회색). 기본 시행자: (가) 한○○ 파랑 · (나) 윤○○ 청록 · (다) 조○○ 보라 · (라) 강○○ 주황 · (원) 원장님 회색. 기본 종류 색: 주사 분홍, 진료 연두. 칸은 옅은 바탕 + 왼쪽 굵은 띠.
9. **원장님도 시행자 목록에 넣음**(주사·진료 담당 (원)).
10. 도착 표시: 초록 동그라미 ✓ = 왔음, 주황 동그라미 ! = 안 옴(칸에 옅은 빗금), 회색 '취소' + 흐린 칸·가운데 줄 = 취소, 표시 없음 = 아직. **'안 옴'은 예약 끝 시각이 지나도 비트 접수가 없을 때.** 폰은 비트 PC가 정한 표시를 그대로 본다.
11. 자세히 판 도착 바꾸기: `자동 (비트 따라)` · `왔음` · `안 옴`. 손으로 고른 값이 비트보다 먼저.
12. 취소는 칸을 흐리게 남긴다([취소 되돌리기] 가능). 지우기는 판 아래에서 한 번 더 묻고 지운다. 닫기와 헷갈리지 않게 단추 이름은 **'예약 취소'**.
13. 더하기 판 차례: 날짜·시작 / 이름·차트번호 / 담당 / 종류 / 길이 / 메모. **꼭 채울 칸: 이름·담당·종류. 차트번호는 비워도 됨(신환).** 시작은 10분 단위 고르기, **길이는 5분씩**(충격파 15분 때문), 5~240분. 종류를 고르면 길이가 그 종류 기본으로 바뀐다.
14. 비트 찾기: 이름이 한 명과 맞으면 차트번호를 채움, 여럿이면 고르기 목록(**성별·나이·마지막 내원**으로 구별), 없으면 '비트에 없어요. 신환이면 차트번호는 비워 두세요.' 차트번호를 적으면 이름을 채움. 채운 칸은 옅은 초록.
15. 경고가 있으면 저장 단추가 **'그래도 저장'**으로 바뀐다. 담당 단추에 그날 휴무면 '휴무' 꼬리표. 예약표의 새 예약 자리 표시가 주황 점선이 된다.
16. 빈 칸을 누르면 그 날짜·시각(10분 맞춤)으로 더하기 판이 열린다. 마우스를 올리면 `+ 14:20`이 보인다. [+ 예약 더하기]는 오늘이면 지금 다음 10분, 다른 날이면 09:00.
17. 종일 줄을 누르면 작은 판: `메모`(20자) 또는 `시행자 휴무` 고르기, 그날 있는 항목 지우기. 휴무 칩은 그 시행자 색.
18. 비트 예약 칸: 회색 빗금·점선, `비트 예약 차트번호 이름`. 누르면 '비트에 있는 예약이에요. 여기서는 보기만 하고, 고치려면 비트에서 해요.' 비트에 길이가 없으면 20분 칸으로 그린다(시안 생각). **같은 날 같은 차트번호 예약이 이미 있으면 비트 예약 칸은 숨긴다.**
19. [다음 주에도]: 담당·종류·길이·메모까지 같게 복사. 다음 주 그 시간에 겹침·휴무가 있어도 넣고 알림으로 알려 준다. 한 번 누르면 '넣었어요 ✓'로 바뀌고 흐려진다.
20. 설정 종류: 한 종류 = ▲▼ 순서 · 이름(10자) · 기본 길이(5~120분) · 색(시행자 색 따름 또는 10색) · 지우기. 종류는 하나 이상 남는다. 지운 종류·시행자의 지난 예약은 그 이름 그대로 남는다. 시행자 표시 한 글자는 겹칠 수 없다. 보이는 시간은 1시간 단위(시작 05:00~12:00, 끝 12:00~24:00).
21. 설정 아래 알아 둘 글 세 줄: '지난 예약은 1년 뒤 자동으로 지워져요.' / '환자 이름과 차트번호는 서버에 저장되고, 의원 계정으로 로그인해야만 보여요.' / '다른 PC에서 고친 것도 몇 초 안에 이 화면에 보여요.' 저장 알림에도 '다른 PC에도 몇 초 안에 보여요'.
22. 빈 화면 글: '이번 주 예약이 아직 없어요' / '빈 칸을 누르면 그 시간으로 예약을 넣어요. 구글 캘린더에 있던 예약은 옮겨 오지 않아요.'
23. 도구 줄 아래 안내 줄: `비트 연결됨`(폰은 `비트 없는 기기`) · 색 안내 · 도착 표시 안내. 폰에서는 '색·도착 표시 보기'로 접어 둔다.

## 사용자에게 물을 것
1. 구글 캘린더에 이미 있는 앞으로의 예약을 **한 번만 옮겨 올지**(잇지는 않고), 아니면 새로 적을지.
2. 예약 칸을 **끌어서 옮기기·길이 늘리기**(구글 캘린더처럼)가 필요한지. 시안에는 없고 [고치기]로만 바꾼다.
3. '안 옴'으로 바뀌는 때: 예약 **끝** 시각(시안) / 시작 + 몇 분.
4. 주 보기 월~토, 폰 주 보기를 목록으로 한 것이 괜찮은지.
5. 원장님을 시행자로 두는 것, 기본 색이 괜찮은지.
6. 같은 이름 고르기 목록에 성별·나이·마지막 내원을 보여 줘도 되는지.
