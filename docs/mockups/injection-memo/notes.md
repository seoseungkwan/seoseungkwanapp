# 주사 차수 → 접수메모(당일) — 시안 메모

시안: `index.html`(상태 `?s=button|filled|xray|notices|settings`, 없으면 전부). 환자·차트번호·증상 글은 지어낸 예시다. 비트 접수 화면은 실제 모양이 아니라 자리를 보여 주는 그림이다(칸 이름·자리는 `specs/injection-memo/notes/reception-fields.md`에서 확인).

## 사용자 결정 (2026-11-20 grill-me·30일 대조 뒤)
- 넣는 곳: 비트 **접수 화면** 왼쪽 아래 **'접수메모(당일)'** 칸. 직원이 환자를 불러온 뒤 누르면 화면에서 차트번호를 읽고 칸에 글자를 쳐 준다. 비트 DB 쓰기·저장 없음(저장은 직원).
- 단추는 메모 칸 바로 옆 + 단축키. 확인 창 없이 바로 넣고, 못 넣으면 짧은 알림.
- 모양: `<좌우>)<부위> N차`. '주사' 말·'+ FNB' 같은 뒤붙이 뺌. 약 이름만 있는 줄은 약 이름만.
- 번호: 그날 한 것 +1, 다음 계획('합니다' 포함) 그대로, 번호 둘이면 앞 번호, 'N차까지'면 지난 메모 번호 +1(끝을 넘으면 안 넣고 알림).
- 주사만(ESWT·도수 뺌). 주사 차수가 적힌 마지막 내원, **최근 30일 안**.
- 좌우·부위는 **증상 기록에서만**, 주사 말이 든 줄 먼저.
- 기록에 간격('1주뒤')이 있는데 **계획 날짜보다 3일 넘게 일찍** 오면 넣지 않고 '주사 날이 아닐 수 있어요' 알림. 간격이 없으면 넣는다.
- 칸에 글이 있으면 **뒤에 '/'로** 붙인다. 접수 PC 여러 대, 우리 의원만. PT 종이 프로그램([PT 먼저])에 같이 넣는다(서류 인쇄는 2026-11-20 사용자 '그거 하지 말고 접수메모만'으로 뺌).

## 제가 정한 부분 (시안과 함께 승인받을 것)
1. 단추 글 **주사 차수**, 연한 초록 바탕(#C9F0D6, 테두리 #4A9B66). '접수메모(당일)' 칸 오른쪽에 붙어 비트 창을 따라간다. 비트 접수 화면이 맨 앞일 때만 보이고 아니면 숨는다.
2. 단축키 기본 **F8**, 고를 수 있는 키 F4·F8·F10·F11(비트가 쓰는 F1·F2·F3·F5·F6·F7·F9·F12 빼고). 접수 화면이 맨 앞일 때만 잡는다(다른 프로그램의 F8은 그대로).
3. 넣을 때 칸 끝에 커서를 두고 글자만 넣는다. 이미 'N차'가 있으면 넣지 않는다.
4. 알림은 칸 아래 작은 상자, 2~3초 뒤 저절로 사라짐, 포커스를 뺏지 않음. 초록=넣음, 노랑=안 넣음(기록 쪽 이유), 빨강=환자 없음·읽기 실패.
5. 지금 PT 종이 설정 창 맨 아래에 **주사 차수 단추 자리**(◀ 왼쪽으로 / 오른쪽으로 ▶, 20px씩, -400~400px)와 **주사 차수 단축키**(F8 ▾)를 더한다. 저장은 `%LOCALAPPDATA%\PtSlip\memo-settings.json`.

## 화면 글자 (명세는 이 글 그대로)
- 단추: `주사 차수`
- 넣음: `넣었어요: <넣은 글>` (예 `넣었어요: 오)무릎 3차`)
- 기록 없음: `최근 30일 안에 주사 차수 기록이 없어요.`
- 끝남: `계획한 주사가 끝났어요(<N>차까지). 넣지 않았어요.`
- 일찍 옴: `주사 날이 아닐 수 있어요(계획 <M>월 <D>일). 넣지 않았어요.`
- 이미 있음: `메모에 주사 차수가 이미 있어요.`
- 환자 없음: `접수 화면에 환자를 먼저 불러와 주세요.`
- 읽기 실패: `비트에서 기록을 읽지 못했어요. 잠시 뒤 다시 눌러 주세요.`
- 넣지 못함(빨강): `메모 칸에 넣지 못했어요. 직접 적어 주세요: <넣을 글>` — 칸이 꽉 참(50자)·잠김·윈도우가 막음(2026-11-20 더함)
- 엑스레이 창(2026-11-20 오후 다시 바꿈, [엑스레이] 단추): 창 제목 `엑스레이`, 줄 `<부위>` `<YYYY-MM-DD>` `<N년 M달 전|M달 전|N일 전>`(경과면 노랑 `경과`) + `넣기` 단추(경과 줄만) → 넣으면 `넣음 ✓`. 아래 `찍은 적 없음 (설정에서 고른 부위)` + 작은 단추 `<부위> 넣기`(넣으면 `<부위> ✓`). 바닥 `무릎은 1년, 다른 부위는 2년이 지나면 경과예요. 좌우는 안 가려요.` + `닫기`. 비면 `찍은 엑스레이가 없어요.`. 넣는 글 `<부위> xr1년경과`(무릎)·`<부위> xr2년경과`(그 밖), 칸 끝 주사 부위와 같으면 `xrN년경과`만(칸 끝이 주사 차수면 띄어, 아니면 '/'). 넣지 못함은 `메모 칸에 넣지 못했어요. 직접 적어 주세요: <글>`(빨강). 환자 없음·읽기 실패는 주사 차수와 같은 글(창 없음). 설정 `찍은 적 없을 때 보여 줄 엑스레이` · `체크한 부위는 한 번도 안 찍었으면 [엑스레이] 창에 나와요` · 힌트 `칸 아래 작은 글은 '찍은 것'으로 치는 비트 영상 처방이에요. 찍은 부위는 체크와 상관없이 다 나와요. 처음엔 팔·허벅지·다리·종아리만 꺼져 있어요. 무릎은 1년, 나머지는 2년이 지나면 경과.`
- 설정: `주사 차수 단추 자리`, `◀ 왼쪽으로`, `오른쪽으로 ▶`, `비트 단추나 글을 가리면 옆으로 옮겨요. 한 번에 20px씩, 접수 화면에 바로 보여요.`, `주사 차수 단축키`, `비트가 쓰는 키(F1·F2·F3·F5·F6·F7·F9·F12)는 고를 수 없어요.`
