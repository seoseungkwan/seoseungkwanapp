## 사용자 결정 (2026-11-21)
- 명단·근무표·휴가·급여 네 가지를 **한 번에**. 모든 병원이 씀(병원마다 설정).
- **원장 계정만** 봄(데스크에는 탭 없음). 추가 잠금·가림 없음.
- **주민번호는 저장하지 않음, 계좌만 저장**(plan.md 2-6 '둘 다 저장 안 함'에서 바뀜 → plan.md 고침).
- 명단은 예약 시행자 목록과 **따로**. 칸: 이름·직종·근무 형태·주 근무시간·입사일·퇴사일·연락처·생일·주소·은행·계좌·서류 파일·예약 시행자 연결·메모.
- 처음 채우기: 엑셀 양식 올리기 + 하나씩. 양식에 '올해 이미 쓴 연차 일수'.
- 연차 기준 병원마다(입사일 / 1월 1일), 단위 하루·반차, 종류 연차·반차·경조사·병가·출산·육아휴직·무급(결근), 못 쓴 연차 병원마다(수당 정산 / 넘김), 5인 이상 규칙만.
- 직원 카드에서 예약 시행자를 고르면 휴가가 예약 달력 '휴무'로 자동 표시.
- 근무표: 요일 고정 + 바뀐 날만. 출퇴근 기록 없이 더 일한 시간만 연장·야간·휴일 세 가지로.
- 급여: 모두 실수령 보장 계약, 세금·4대보험·법정 명세서는 세무사·노무사. 원장은 항목 금액만(기본 목록 + 병원 추가, 지난달 가져오기). 시간은 자동, 연장수당 금액은 원장.
- 인센티브는 자동 계산(plan.md 2-6과 같음): 직원마다 항목, 방식 건당 정액·매출의 %·고정 수당, 금액·%는 원장이 고침, 달마다 건수·매출 입력. 조정(±) 칸. [급여 확정] 잠금 없음. 지금 쓰는 급여 양식 없음 → 세무사 엑셀 모양은 Claude가 정함.
- 급여 화면: 세무사 자료 [엑셀 받기] · 세무사 파일 달마다 보관 · 인건비(지급 합계 + 병원 부담분 한 줄) 추이와 매출 대비 % · 원장용 간단 명세서 인쇄·PDF·그림 파일.
- 알림: 생일·입사 기념일만. 퇴사자 3년 보관 뒤 '지울 때가 됐어요' + [지우기].
- 시안 먼저 보고 승인 → 만들기. Phase별·병렬·검토는 마지막 한 번.
