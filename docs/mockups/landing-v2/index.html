바뀌는 점

  1. 큰 그림과 사진 6장을 모두 뺐습니다. 그 자리에 실제 프로그램 화면을 줄여서 넣었습니다. 숫자는 모두 예시입니다.
  2. 색을 줄였습니다. 회색 글자와 흰 바탕에 파랑 한 가지만 씁니다. 섹션마다 달랐던 바탕색과 카드 색은 없앴습니다.
  3. 그림자, 그라데이션, 반짝이 아이콘, 떠다니는 점 같은 장식을 없앴습니다. 움직이는 것은 첫 화면의 예시 숫자뿐입니다.
  4. 첫 화면의 숫자 카드들이 이제 프로그램 화면 안에 들어가 있어서 서로 겹치지 않습니다.
  5. 글자 크기, 간격, 카드 모양을 한 가지 규칙으로 맞췄습니다. 카드 모서리는 프로그램 화면과 같은 6px입니다.
  6. 휴대폰은 1줄, 태블릿은 2줄, PC는 넓은 칸으로 나눕니다. 휴대폰에서도 메뉴가 보입니다(옆으로 밀어서 보기).
  7. 휴대폰에서 스크롤 길이가 약 40% 줄었습니다. 급여표도 휴대폰 화면 안에 다 들어옵니다.
  8. 문구는 그대로입니다. 영어 소제목(AI ANALYSIS, FEATURES 같은 것)만 뺐습니다.

  • 필요한 칸만 읽습니다

    계산에 쓰는 칸을 정해 두고 그 칸만 읽습니다. 차트번호는 계산하는 동안 메모리 안에서만 씁니다.

    '-' 없이 붙여 쓴 13자리까지 잡아서, 섞여 있으면 계산하지 않고 알려 줍니다.

  • AI에는 합계 숫자만

    통계·매출 합계와 인건비 총액만 보냅니다. 직원 이름·개인별 급여도 보내지 않습니다.

  • 승인한 사람만, 공용 PC도 안심

    구글 로그인 뒤 관리자가 승인한 계정만 들어옵니다. 30분 동안 움직임이 없으면 자동으로 로그아웃합니다.
