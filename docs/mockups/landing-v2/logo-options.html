십자 로고 시안 12개

모양 4가지(A~D)에 색 3가지(①~③)를 입혔습니다. 모두 실제 크기로 첫 화면 메뉴, 프로그램 위쪽, 브라우저 탭에 넣어 보았습니다. 마음에 드는 번호 하나만 알려 주세요. 예: C②

지금 로고 막대 세 개 모양
  • 빨간 십자는 넣지 않았습니다. 흰 바탕의 빨간 십자(적십자 표장)는 법으로 사용이 제한됩니다.
  • ③은 예전 로고 색입니다. 새 화면은 검정·회색·파랑만 쓰기 때문에 ③을 고르면 로고만 다른 색이 됩니다.
