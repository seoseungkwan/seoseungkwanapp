## 사용자 결정 (2026-11-16)
- 가져올 것: 예약률, Block·물리치료 전환률, 진료실별 비교, 환자별 수납 장부 **전부**. **한 번에**(명세 하나·배포 하나).
- 장부는 **비트에서 자동으로 채우고 직원이 틀린 칸만 고침**.
- 이름 줄·고친 칸은 **접수 PC 한 대 안에만**(도우미가 그 PC에 암호화 보관, CLAUDE.md 아키텍처 규칙과 같음). 서버엔 마감 때 합계·비율 숫자만.
- 자리: **새 탭 '수납일지'**(업무일지와 따로 마감).
- 예약: 의원이 **앞으로 비트에 예약을 적음**(10월 비트 예약은 내원 약 2,090건 중 97건뿐이었음). 종류는 **비트 예약 메모 말로 자동 분류**(말은 설정에서 바꿈). **직원이 장부에서 직접 고를 수도 있음**(사용자 추가 요청 "예약도 수기로도 입력할 수 있게") — 직접 고른 값이 비트보다 이김, 비트에 없는 예약도 입력.
- '예약하고 감'은 **그날 마감 때 고정**. **마감 풀기 가능, 지난 날 늦은 마감 허용**(늦은 마감 표시).
- 예약률은 엑셀처럼 **주사치료·진료(경과)만** 셈(예약 안 하고 가심·기타는 뺌).
- Block·물리치료: **통계 처방 묶음 중 하나를 지정**. 통계 탭 비율은 **비트에서 바로**(장부에서 고친 체크는 통계에 안 들어감).
- 재진+Block 비율 분모는 **엑셀과 같이 Block 전체**(초진+Block은 초진, 90일+Block은 90일초진으로 나눔).
- 진료실 1~4 = **원장님**(비트 진료실 칸 비어 있음 → 처방 의사로 나눔).
- 결제는 **현금|카드|계좌|미수 금액 칸**, 0원은 FREE.
- 지출(현금·카드·기타·현금(주차지원) 줄): **수납일지에만**. 환자 정보가 아니라 서버 저장.
- 인쇄·엑셀 내려받기: **필요 없음**.
- 접수 PC **한 대**에서만 고치고 마감.
