# claim-learn 시안 메모

- 문제(2026-11-28 사용자): 청구 메모가 원하는 대로 안 나올 때 매번 손으로 고친다. 사용자의 목표는 "커스텀이 자유로워야 하고 처음 설정이 번거롭더라도 나중에 쓸 때는 사람이 거의 수정하는 일 없게"이다. 건초내주사는 부위가 하나만 필요한데 다른 부위까지 나온다.
- 결정은 `specs/claim-learn/requirements.md` '이미 정한 것'에 있다(grill 문답 2026-11-28).
- 시안 `index.html`은 한 파일이다. 상태는 `?s=`로 고른다:
  - `memo`: 메모 단계(빈칸 맨 위·후보 단추·확인 필요·학습 꼬리표·하루 두 번·[학습하기])
  - `learn`: 학습 창
  - `why`: [왜 이렇게?]
  - `first`: 처음 학습
  - `list`: 설정 › 병원 문구 › 학습 탭
  - `dates`: 날짜 목록([이 날만]·오늘 포함·목록 밖)
  - `default`: 병원 문구 없는 병원
  - `connect`: 연결 길(청구에서 옴·확인 중·새로 고침·다시 등록·어느 창)
  - `errors`: 도우미 멈춤·저장 파일 깨짐·입력 결과 [날짜 목록으로]
- 색은 앱 토큰(`src/app/globals.css :root`)만 쓴다. 이름·차트·증상 글은 모두 지어낸 값이다. 화면은 PC 너비(1440)만 그린다.
- 승인: (기다림)

## 화면 글
아래 글은 구현과 한 글자도 다르지 않다. `{…}`는 채우는 값이다.

### 학습 창
- 제목: `학습 고치기 — 다음에도 이렇게 쓸까요?` (‘저절로 학습’ 띠의 [조건 바꾸기]로 연다)
- 설명: `고친 줄을 학습해 두면, 조건이 맞는 다음 진료에 저절로 이렇게 나와요.`
- 고친 줄 머리: `고친 줄` · 줄 종류 꼬리표: `바꿈` / `더함` / `뺌` · 줄의 코드 글: `처방 {코드, 코드}`
- 조건 머리: `이럴 때 쓰기` · 작은 글: `켠 조건이 모두 맞을 때만 써요.`
- 조건 이름: `처방 코드` · `부위` · `차트에 쓴 말` · `함께 한 다른 시술` · `진료한 원장님`
- 차트에 쓴 말 칸 자리 글: `예: C-arm`
- 문장 머리: `학습할 문장` · 바뀌는 칸 단추: `{좌우}` `{레벨}` `{부위}`
- 문장 작은 글: `환자마다 다른 칸은 단추로 바꿔 두세요. 다음 진료의 값이 들어가요.`
- '조건 없음': `조건을 하나 이상 골라 주세요.`
- '글자 그대로'(노란): `‘{글자}’가 글자 그대로 있어요. 다른 환자에게도 ‘{글자}’로 나와요.` + 단추 `{좌우}로 바꾸기` / `{레벨}로 바꾸기` / `{부위}로 바꾸기`
- '전체에 적용'(파란): `이 고침은 모든 메모의 {좌우 표기|부위 표기|고정 문구|레벨 사이 글자}예요. 모든 메모에서 ‘{옛}’을 ‘{새}’로 바꿀까요?` + 단추 `모든 메모에` · `이 학습만`
- 단추: `취소` · `저장` (저장 중 `저장 중…`)
- 저장 뒤 알림: `학습했어요. 처음 3번은 ‘확인 필요’로 보여 드려요.`

### 저절로 학습 (메모를 고쳐 저장하면)
- 띠(파란): `학습했어요. 다음에 같은 처방·부위면 이렇게 써요. 처음 3번은 ‘확인 필요’로 보여 드려요.` + 단추 `이번만 고친 거예요` · `조건 바꾸기`
- '이번만'(회색): `이번 고침만 저장했어요. 학습은 하지 않았어요.`
- '개인정보라 학습 안 함'(노란, 띠에 덧붙임): `전화번호·주민번호 같은 글이 있는 줄 {n}개는 학습하지 않았어요.`
- 저장 실패: `E-LEARN-SAVE` 안내 + 단추 `다시 저장`
- 모양 고침이면 띠에 '전체에 적용' 물음(학습 창 글과 같음)과 `모든 메모에` · `이 학습만`

### 메모 단계
- 메모 칸 아래: [메모 고치기]뿐(따로 누르는 [학습하기] 단추는 없다. 고쳐 저장하면 ‘저절로 학습’ 띠)
- 상세 머리 단추: `왜 이렇게?`
- 목록·상세 표시: `확인 필요` · 꼬리표 `학습: {이름}`
- 상세 노란 줄: `새 학습이 쓰인 메모예요. 맞으면 그대로 복사·입력하세요. (남은 확인 {n}번)`
- 목록 표시: `빈칸 {n}`
- 빈칸 후보 단추: 좌우 `Rt` `Lt` `both`(병원 표기가 한글이면 `우측` `좌측` `양측`) · 부위는 부위 이름 단추 + `직접 쓰기`
- '하루 두 번' 표시: `하루 두 번` · 안내: `이 환자는 이날 두 번 진료했어요. 그날 처방이 두 메모에 똑같이 들어가니 맞는지 봐 주세요.`
- [처음 학습] 단추(메모 단계 위 도구 줄): `처음 학습`
- '손 간 정도'(도구 줄): `이 기간 메모 {n}건 · 학습이 쓴 메모 {m}건 · 사람이 고친 메모 {k}건 ({p}%)`

### 왜 이렇게?
- 머리: `이 메모가 이렇게 나온 까닭`
- 줄 출처: `학습: {이름}` 또는 `병원 문구 › {탭} › {칸 이름}`
- 덧붙임: `처방 {코드}` · `차트: {차트 줄}`
- 출처를 못 찾은 줄: `출처 모름`
- 아래 작은 글: `출처를 누르면 그 설정으로 가요.`

### 처음 학습
- 제목: `처음 학습`
- 설명: `자주 나온 진료부터 하나씩 봐요. 맞으면 [맞아요], 다르면 [고치기]로 고쳐 학습해요. 언제든 [그만]하고 나중에 이어서 할 수 있어요.`
- '덮은 비율': `확인한 종류가 불러온 진료의 {p}%예요 ({k} / {n} 종류)`
- 종류 머리: `{종류 이름} · 진료 {n}건`
- 칸 이름: `차트` · `처방` · `지금 메모`
- 단추: `맞아요` · `고치기` · `건너뛰기` · `그만`
- '한 달 불러오기': `처음 학습은 한 달쯤 불러온 진료로 하면 좋아요. 지금 불러온 기간이 짧아요.` + 단추 `지난 30일 불러오기`
- 다 봄: `불러온 진료의 종류를 다 봤어요.`

### 설정 › 병원 문구 › 학습 탭
- 탭 이름: `학습` (‘메모 시험’ 탭 뒤)
- 표 머리: `이름` · `할 일` · `조건` · `문장` · `남은 확인` · `만든 날`
- 할 일 값: `줄 바꿈` / `줄 더함` / `줄 뺌`
- 켜고 끄기: `켜짐` / `꺼짐` · 단추 `고치기` · `지우기`
- 지우기 확인: `‘{이름}’ 학습을 지울까요?` + `지우기` · `취소`
- '학습 없음': `아직 학습이 없어요. 청구 메모를 고쳐 저장하면 저절로 학습해요. 청구 화면에서 [처음 학습]을 해 보세요.`
- '한도': `학습은 {N}개까지 둘 수 있어요. 쓰지 않는 학습을 지운 뒤 더해 주세요.`
- ‘시술별 문구와 약’ 탭 새 칸: 이름 `건초내주사로 알아볼 차트 말` · 풀이 `차트 줄에 이 말이 있으면 건초내주사 부위로 봐요. 쉼표로 나눠 적어요.`

### 병원 문구 없는 병원
- '기본 문구' 띠: `아직 우리 병원 문구가 없어 기본 문구로 만들었어요. 처음 학습을 하면 우리 병원 메모 모양에 맞춰져요.` + 단추 `처음 학습` · `병원 문구 설정`

### 날짜 목록
- 줄 끝 단추: `이 날만` (화면 읽기 이름 `{M/d (요일)} 이 날만`)
- '목록 밖': `목록에 없는 날짜예요. [자료 불러오기]를 누르면 보여요.`
- '오늘 포함'(노란): `오늘도 들어 있어요. 오늘 진료가 더 있을 수 있어요.`

### 연결 길
- '청구에서 옴' 띠: `청구 점검을 하려면 이 PC 연결을 먼저 마쳐야 해요. ({까닭})` · 까닭: `도우미가 없어요` / `도우미를 업데이트해야 해요` / `확장을 업데이트해야 해요` / `도우미 연결이 끊겼어요`
- '연결 확인 중': `이 PC 연결을 확인하는 중…`
- '새로 고침': `확장을 설치했으면 이 화면을 새로 고쳐야 알아봐요.` + 단추 `이 화면 새로 고침`
- '다시 등록': `이 PC에 저장된 자료가 지금 등록한 병원(요양기관기호)과 달라요. 병원이 바뀌었으면 이 PC를 다시 등록해 주세요.` + 단추 `이 PC 다시 등록`
- '어느 창': `지금 열린 다른 창: ‘{화면 이름}’` (여럿이면 `‘수납일지’ · ‘통계’`처럼 ` · `로 잇는다)

### 도우미 등록 확인 창 (0.15.0)
- '전 병원 파일 보관'(옮길 파일이 있을 때 한 줄 더함): `전에 쓰던 병원의 저장 파일 {n}개는 지우지 않고 따로 보관해요.`

### 오류·알림
- `E-HELPER-STOPPED`: 무엇 `도우미가 일하는 중에 멈췄어요` · 고치기 `[다시 불러오기]를 눌러 주세요. 또 멈추면 이 번호를 알려 주세요.`
- '저장 파일 깨짐' 띠: `이 PC에 저장된 {YYYY년 M월} 고친 메모·완료 표시를 읽지 못해 빈 채로 시작했어요. 이 달 메모는 다시 확인해 주세요.`
- `E-LEARN-PERSONAL`: 무엇 `학습 문장이나 차트 말에 전화번호·주민번호·메일 같은 글이 있어요` · 고치기 `그 글을 지우고 다시 저장해 주세요.`
- `E-LEARN-SAVE`: 무엇 `학습을 저장하지 못했어요` · 고치기 `잠시 뒤 다시 저장해 주세요.`
- 입력 결과 화면 단추: `날짜 목록으로`
