# 시안 메모: 서식 탭 환자 안내문 (forms-guide)

- 파일: `index.html` — `?s=posters` 예시 6장 · `?s=icons` 그림 16개 · `?s=screen` 서식 화면(직접 눌러 보기, `go=1|5|6|new|busy|number|over`) · `?s=one&n=1~6` 한 장 크게(사진용)
- 기준: 요청서(2026-11-15) 디자인 규격(원본 1240×1754 → 794×1123, ×0.640)과 부록 CSS. 참고 PNG 세 장은 대화에 오지 않아 CSS 값으로 그렸다
- 사용자 결정(2026-11-15): 기본형 + AI 정리 · 로고색 고정 · 그림 16개에서 AI가 고름 · '윗줄 작게' 첫 판에 받기

## 시안에서 정한 값
- 글자 폭: 안내문 글꼴(Pretendard Black)의 실제 글자 폭을 잰 표(한글 0.87em 등) — 큰 문구가 원본처럼 크게 나온다
- 칸 한도: 머리표 10 · 작은 제목 14 · 큰 문구 각 8 · 흰 상자 윗줄 16 · 아랫줄 14 · 띠 제목 16 · 줄 28(도수치료 첫 줄 27자) · 아래 작은 글 28
- '윗줄 작게'(도수치료): 작은 제목에 붙어 보여 윗줄을 67 → 80px로 키우고 8 띄움. 아랫줄은 150px에서 시작
- 그림 자리: 오른쪽 아래 170×170, 흰 원 받침 + 진회색 테두리 + 번짐 없는 그림자(흰 상자와 같은 모양). 그림이 있으면 흰 상자는 폭 499까지
- 로고: 흰 칸 가운데 400×68(휴진 안내 340×58보다 조금 크게 — 흰 칸이 169로 넉넉하다)
- 띠 넘침: 줄 높이를 최소까지 줄여도 넘치면 칸 아래 까닭 + 저장·뽑기 막힘(`go=over`)
- 숫자 어긋남: AI 답에 메모에 없는 숫자가 있으면 `E-AI-FAILED`(지금 문구 그대로, `go=number`)
- 무릎 그림은 처음 그린 것이 알아보기 어려워 다리 모양으로 다시 그림

## 승인
- 승인: 2026-11-15, 사용자가 시안 사진 5장(예시 6장·도수치료·그림 16개·서식 화면·띠 넘침)과 명세 요약을 보고 `/sdd approve forms-guide` 입력

## AI 그림 칸 더함 (2026-11-15, 첫 승인 뒤)
- 사용자 요청 "그림도 새로 생성할 수 있게 해" → 답 "AI가 도형으로 그리기"·"이번 판에 넣기"
- `?s=screen&go=draw`: 그림 고르기 아래 '새로 그릴 것'(20자) + [AI로 그림 그리기] + "적은 낱말만 AI로 보내요. 마음에 안 들면 다시 눌러 새로 그려요". 그리면 고르기에 'AI로 그린 그림: <그릴 것>'이 생기고 미리보기에 들어간다 · `go=drawing`: '그리는 중…'
- `?s=icons` 아래 'AI로 그린 그림 (예)': 휠체어·우산·계단 — 앱이 받는 모양(도형·색 이름·숫자) 그대로 손으로 그린 예. 실제 AI 그림은 이보다 들쭉날쭉할 수 있다
- 승인: 2026-11-15, 사용자가 사진 2장(draw-1440·icons-ai-crop)과 "[새로 만들기]를 누르면 '새로 그릴 것' 칸도 비워진다"는 한 가지 차이를 보고 "진행해"
- 시안과 다른 점(사용자 확인): [새로 만들기]·열기·지우기 뒤 '새로 그릴 것'도 비운다(시안은 남겨 둠)
