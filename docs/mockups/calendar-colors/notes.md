# 시안: 예약 탭 다듬기 (calendar-colors)

- 파일: `index.html` 한 장(① 설정 색판 ② 주 보기 칸 ③ 폰 목록 띠 ④ 시작 칸 쳐서 넣기 ⑤ 오른쪽 빈 줄). 이름·숫자는 지어낸 것.
- 결정
  - 색: 고를 색 10 → 20(사용자 고름 '고를 색 늘리기'). 새 색 빨강·노랑·초록·민트·자주·와인·진초록·연보라·산호·검정, 회색은 맨 끝. 칸 모양 그대로
  - 시작: 글 칸 + 고르기 목록, 10분 단위(서버 검사 그대로), 진료 전 새벽 시각은 오후로 봄
  - 같은 시간: 예약 칸 폭을 줄여 오른쪽 20px 빈 줄, 누르면 그 시각 더하기
- 승인: 2026-11-17 ①~③ 사용자 "이대로 만들기". ④⑤는 사용자 "ㅇㅇ 진행해"(두 요청 이해 확인 뒤) — 명세 승인과 함께 받음
