# sunap-kinds(다음 예약 종류 직접 만들기) 시안 메모

- 바탕: 승인된 수납일지 시안(`docs/mockups/sunap-ilji`) + 줄 세우기 시안(sunap-sort). 모양·토큰·위 회색 상태 줄은 그대로.
- 상태: `?s=open`(장부: 새 종류 칩·예약률 글) · `kinds`(설정: 다음 예약 종류) · `pick`(예약 직접 고르기, 윤○○ 줄에서 도수치료를 고르는 중).
- 누를 수 있는 곳: [설정] → 목록 고치기·[저장](장부·카드 글이 바로 바뀜), 장부의 아무 '다음 예약' 칸 → 고르기 판, 제목 줄 세우기(바탕 그대로).
- 이름은 ○○, 차트번호·금액·메모 말은 모두 지어낸 값.
- **건강생활유지비(처음 요청의 바뀜 B)는 뺐다** — 사용자 결정(2026-11-17): 그 내원은 다른 0원 줄처럼 'FREE · 0원'으로 보이고, 도우미만 고치면 되어 화면은 안 바뀜.

## 정한 것(이 시안의 기본값 — 사용자 확인 필요)
- 설정의 '예약 메모 말' 세 줄(주사치료·진료(경과)·기타)을 **'다음 예약 종류' 목록**으로 바꿈. 한 종류 = 이름 · 메모 말(쉼표로 나눔) · 예약률 ○ 넣음/✕ 뺌 · ▲▼ 순서 · 지우기.
- 기본 종류 셋(주사치료·진료(경과)·기타)은 **이름만 바꿀 수 있고 지울 수 없음**. 지우기 자리에 흐린 '기본' 글자.
- 위에 있을수록 먼저 맞춰 봄(메모에 두 종류 말이 다 있으면 위 종류). 같은 말을 두 종류에 적어도 막지 않음(위 종류가 이김).
- 종류는 **기본 셋을 포함해 10개까지**(새로 7개). 10개가 차면 [+ 종류 더하기]가 흐려짐.
- 새 종류는 **목록 맨 아래**에 이름 빈칸·메모 말 빈칸·**예약률 ✕ 뺌**으로 생기고, 이름 칸에 바로 글자를 넣을 수 있음. 예시 목록은 기타를 맨 아래로 옮겨 둔 모습(주사치료 → 진료(경과) → 도수치료 → 체외충격파 → 기타).
- 이름은 10자까지, 비우면 저장 안 됨, '예약 안 하고 가심'·'종류 모름'을 포함해 같은 이름 금지. 메모 말 하나는 20자까지(지금 앱과 같음), 겹친 말은 하나로, 전각 쉼표(，)도 받음. **메모 말을 비우면** 그 종류는 직접 고를 때만 씀.
- 바꿀 수 없는 줄 둘('예약 안 하고 가심'·'종류 모름')은 목록 아래 흐린 칸에 예약률 ✕로 보여 줌.
- 지금 앱 설정에 있던 노란 점선 상자(정해진 말이 없는 예약은 아직 안 정함)는 뺌 — '종류 모름'을 위 흐린 칸에 예약률 ✕로 적어 둠. '지출 종류' 칸도 지금 앱처럼 없음.
- 예약률 ○·✕를 바꾸면 **아직 마감 안 한 날부터** 새로 셈. 마감한 날 숫자는 그대로(마감을 풀고 다시 마감하면 새 설정으로).
- 종류를 지우면(시안 동작): 비트 메모로 그 종류가 됐던 줄 → '종류 모름', 직접 그 종류를 고른 줄 → 비트 따라가기 값으로 돌아감.
- 칩 색: 주사치료 파랑 · 진료(경과) 청록(바탕 그대로) · **기타와 새로 만든 종류는 모두 회색**. 장부 아래 설명 줄에 한 줄 더함.
- 고르기 판: 비트 따라가기 · 예약 안 하고 가심 · (가는 선) · 설정 목록 순서대로 모든 종류, 오른쪽에 그 종류의 예약률 ○/✕. 팁 한 줄 더함(아래 글자). 판은 칸 아래에 자리가 없으면 칸 위로 뜸(고르는 줄을 덮지 않게).
- 장부 줄 세우기 '종류 순'은 **설정 목록 순서** → 종류 모름 → 예약 안 하고 가심(늘 맨 뒤).
- 설정 판 너비는 지금처럼 480px. 폰에서는 종류 한 칸이 세 줄(이름·순서 / 예약률 / 메모 말).

## 화면 글자(그대로 씀)
설정 판 '다음 예약 종류'
- 제목: `다음 예약 종류`
- 설명 1: `비트 예약 메모에 이 말이 있으면 그 종류로 정해요. 위에 있을수록 먼저 맞춰 봐요(메모에 말이 둘 다 있으면 위 종류). 말은 쉼표(,)로 나눠 적어요.`
- 설명 2: `예약률 ○ 넣음인 종류만 초진·90일 예약률에 세요. 주사치료·진료(경과)·기타는 기본 종류라 이름은 바꿀 수 있지만 지울 수는 없어요.`
- 칸 제목(PC): `이름` · `예약률` · `순서` / 폰은 단추 앞에 `예약률`
- 이름 칸 빈 글: `이름 (예: 도수치료)`
- 예약률 단추: `○ 넣음` / `✕ 뺌`
- 순서 단추: `▲` `▼` (읽어 주는 이름 `N번째 종류 위로`/`아래로`)
- `지우기` / 기본 종류는 `기본`(마우스를 올리면 `기본 종류라 지울 수 없어요`)
- 메모 말: `메모에 이 말이 있으면` + 빈 글 `예: 도수, 수기 (비우면 직접 고를 때만 써요)`
- `+ 종류 더하기` · `종류는 10개까지 만들 수 있어요 · 지금 5개` · 다 차면 `10개를 다 만들었어요. 더 만들려면 안 쓰는 종류를 지워 주세요.`
- 흐린 칸: `늘 있는 줄 · 바꿀 수 없어요` / `예약 안 하고 가심` — `비트에 다음 예약이 없을 때` — `예약률 ✕` / `종류 모름` — `비트 예약은 있는데 메모에 맞는 말이 없을 때` — `예약률 ✕`
- 아래: `예약률 ○·✕를 바꾸면 아직 마감 안 한 날부터 새로 세요. 마감한 날 숫자는 그대로예요(마감을 풀고 다시 마감하면 새 설정으로 세요).`
- 잘못 적었을 때: 칸 아래 `이름을 적어 주세요` · `같은 이름이 이미 있어요` · `말 하나는 20자까지 적을 수 있어요`, 저장 단추 위 `빨간 칸을 고쳐 주세요`
- 저장 뒤 알림: `설정을 저장했어요`
- 그대로 둔 것: `수납일지 설정`, Block·물리치료 처방 묶음 두 칸, `취소`·`저장`

고르기 판
- 선택지: `비트 따라가기`(아래 `지금: 11/21 (토) 예약 있음 · 종류 모름`) · `예약 안 하고 가심` `예약률 ✕` · 각 종류 `예약률 ○`/`예약률 ✕` (예시: 주사치료 ○ · 진료(경과) ○ · 도수치료 ○ · 체외충격파 ✕ · 기타 ✕)
- 팁(그대로): `직접 고르면 비트 예약보다 이 값을 써요. 비트에 없는 예약(전화·종이 예약)도 여기서 고르면 돼요. 마감을 풀었다 다시 해도 직접 고른 값은 그대로예요.`
- 팁(새로): `종류를 더하거나 예약률 ○·✕를 바꾸려면 [설정] → 다음 예약 종류에서 해요.`

장부·카드
- 예약률 아래 글: `초진 9명 중 6명 · 주사치료·진료(경과)·도수치료 예약만` (예약률 ○인 종류 이름을 설정 순서대로 ·로 이음). ○가 하나도 없으면 `예약률에 넣는 종류가 없어요`
- 알림 띠: `예약 종류 모름 2줄 — 비트 예약은 있는데 메모에 설정한 말이 하나도 없어요. 다음 예약 칸을 눌러 직접 고르거나, [설정] → 다음 예약 종류에서 종류나 말을 더해 주세요.`
- 장부 설명 줄 더함: `[도수치료] 설정에서 더한 종류·기타는 회색`
- 줄 세우기 메뉴: `종류 순 ▲` — `설정에 둔 종류 순서대로`

## 사용자에게 물을 것
1. 종류를 지울 때 그 종류로 **직접 고른 줄**은? (시안: 비트 따라가기로 돌아감. 다른 길: 쓰는 줄이 있으면 못 지우게 막기)
2. 이름을 바꾸면 **이미 마감한 날** 장부에도 새 이름으로 보여도 되나? (시안 생각: 종류를 번호로 기억해서 새 이름으로 보임. 마감한 날 예약률 숫자는 안 바뀜)
3. 새 종류의 예약률 처음 값 **✕ 뺌**이 괜찮은지(○ 넣음이 더 편한지).
4. 10개 한도에 기본 셋을 넣어 세는 것이 맞는지.
5. 새 종류 칩을 모두 회색으로 둘지, 종류마다 다른 색을 줄지.
6. 예약률 ○ 종류가 많아 아래 글이 길어지면 그대로 다 쓸지, `주사치료 외 3종류 예약만`처럼 줄일지.
7. '종류 모름'을 예약률에서 빼는 것(✕)을 이제 확정할지 — 처음 수납일지 때 "나중에 정하자"였던 것.
8. 통계 탭 '예약·전환' 칸의 `주사치료·진료(경과) 예약` 글도 설정을 따라 바뀌어야 함. 한 달 중간에 ○·✕를 바꾸면 날마다 기준이 섞이는데(마감한 날은 그날 기준) 그대로 둬도 되나?

## 만들 때 알아 둘 것(화면 밖)
- 설정 모양이 바뀜: 지금 `words: { inj, visit, etc }` → 종류 목록(번호·이름·말·예약률·순서). 서버에 저장된 설정을 새 모양으로 옮기는 일이 필요(환자 정보 없음). 기본 세 종류의 번호는 지금 inj·visit·etc를 그대로 쓰면 접수 PC에 저장된 직접 고른 값이 그대로 이어짐.
- 마감 때 서버로 가는 숫자(초진·90일 예약 수)는 모양이 그대로라 표를 바꿀 필요는 없음.

## 승인
- 2026-11-17 사용자 "이대로 만들기". 정함: 종류를 지우면 직접 고른 줄은 비트 따라가기로(비트 메모로 그 종류였던 줄은 종류 모름), 새 종류 예약률 처음 값 ✕ 뺌. 나머지 물을 것은 시안 기본값대로(10개에 기본 셋 포함, 새 종류 칩 회색, 이름 바꾸면 마감한 날도 새 이름, 예약률 글은 다 씀, 종류 모름 ✕ 확정, 통계 글도 설정 따라).
- 명세 때 바꿈: 통계 탭 글은 이름을 늘어놓지 않고 `예약률 ○ 종류 예약`으로(달 중간에 설정을 바꾸면 날마다 기준이 달라서). 저장 뒤 알림은 지금처럼 판 닫힘으로 갈음.
