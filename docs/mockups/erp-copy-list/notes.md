- 시안: `index.html` 하나로 보인다(바깥 글꼴·스크립트 없음). 2026-11-24, 갈래 `feat-erp-copy-list`

- 숫자는 모두 지어낸 예시다(환자 정보 없음). 노란 띠는 시안 단추라 앱에 없다

## 지금까지 정한 것
- 쓰는 사람: 여러 병원 팀장. 마감일지 숫자는 손으로 넣는다(원장님이 ERP 자동 채우기를 원하지 않음)
- 따로 된 크롬 확장 화면 **'ERP 마감일지 입력 목록'**. 지금 비트 숫자를 세는 ERP 도우미를 그대로 쓴다. **ERP 사이트는 건드리지 않는다**
- 흐름: 기간(시작일~끝일) → **[목록 만들기]** → 도우미가 셈 → 표(줄 = [비트 값 채우기]가 채우는 ERP 칸, ERP 차례 / 열 = 날짜 하나씩) → 숫자 칸을 누르면 복사되고 쪽지 '복사했어요' → 팀장이 ERP 칸에 직접 붙여 넣음
- **[엑셀로 받기]**: 같은 표를 .xlsx로 받는다(시안은 쪽지에 파일 이름만 보임)
- 숫자는 쉼표 없이 보인다(350000). ERP 칸에 그대로 붙여 넣으려고
- 못 채운 칸은 비우고 까닭을 짧게 붙인다(cells.ts why: unpicked · unknown · held · noName)
- **[설정 열기]**: 지금 있는 코드 설정 화면을 연다

## 상태 (주소 끝 `?s=`)
| s= | 보이는 것 |
|---|---|
| `empty` | 기간 고르기(오늘 날짜) + 파란 안내 |
| `loading` | '비트에서 읽는 중…' · '3일 중 1일' · 진행 막대 · [그만두기]. 기간 칸과 단추는 막힘 |
| `ready` (기본) | 2026-11-01 ~ 11-03 표. 빈 칸 까닭 네 가지가 모두 있음 |
| `copied` | ready + 11/2 환자현황 재진을 막 복사함(쪽지 보임), 앞서 복사한 신환 · 90일초진은 초록 ✓ |
| `error` | 도우미 연결 안 됨(E-HELPER-MISSING 글). 띠에서 '이 PC 등록 안 됨'(E-BIT-NOT-REGISTERED) · '도우미가 예전 판'(E-HELPER-BAD-MESSAGE) 글로 바꿔 볼 수 있음(`&e=unregistered` · `&e=old`) |
| `long` | 2026-10-01 ~ 10-31(31일). 표 상자만 옆으로 밀리고, 항목 칸은 왼쪽에, 날짜 줄은 위에 붙어 있음 |

- `&o=screen`: 업무일지 1 상자를 ERP 화면 차례로 보인다(아래 '정할 것' 1)
- 시안에서 [목록 만들기]를 누르면 고른 기간으로 세는 중 → 목록이 된다. 날짜 칸 확인 글도 나온다

- 기타1 ERP 줄 이름은 '크라이오'

## 시안이 정한 것
- 빈 칸 까닭: 줄 전체가 같은 까닭이면 항목 칸 오른쪽에 짧은 꼬리표, 어떤 날만 비면 그 칸 안에 작은 글. 마우스를 올리면 긴 글. 표 아래 '빈 칸 까닭'에 네 가지 긴 글
- 누른 칸은 파란 테두리, 앞서 복사한 칸은 초록 ✓(이 화면에만, 저장하지 않음. 목록을 다시 만들면 지움)
- 쪽지: '복사했어요' + '{월/일} · {묶음} {줄} {열} · {값}', 1.8초 뒤 사라짐. 묶음 이름은 [비트 값 채우기]의 짧은 이름(치료현황 · 치료별 건수 · 연령별)
- 진료 0건인 날(시안: 일요일 · 10/3 · 10/5 · 10/9)도 열로 보이고 머리에 '진료 0건', 숫자는 흐리게(복사는 됨)
- 날짜 머리 '11/2 (월)', 일요일은 주황
- 표 상자는 화면 높이에 맞추고 안에서 위아래 · 옆으로 밀림(날짜 줄 · 항목 칸 고정). 표가 넓을 때만 '표를 옆으로 밀면…' 한 줄
- 오류 · 세는 중 · 목록 전에는 [엑셀로 받기]가 막힘. 오류 뒤에는 [목록 만들기]로 다시 함
- 업무일지 2 낱칸 7개의 묶음 머리는 ERP 묶음 이름 '운영 지표(치료사별·금액)'를 설정 화면처럼 '운영 지표'로 줄였다. 치료별 매출은 하나뿐인 열 이름 '금액(원)'을 묶음 머리에 붙였다
- [설정 열기]는 화면 머리 오른쪽

## 정할 것
1. **업무일지 1 상자 차례**: 지금 채우기 함수 차례는 환자현황 → 진료 · 치료현황 → 외래 수입 → 입원수입이다. ERP 화면(4열)은 진료 · 치료현황 → 외래 수입 → 입원수입 → 환자현황(`specs/erp-closing-fill/notes/erp-closing-fields.md` 2절). 시안 기본은 함수 차례. 띠의 [ERP 화면 차례]로 견줘 보고 고른다(업무일지 2는 둘이 같다)
2. **씨암 · SONO를 같이 받은 진료**: 목록은 날마다 물을 수 없다. 시안은 설정에 지난번 고른 대로 넣고 한 줄로 알린다. 고른 적이 없을 때 어떻게 할지
3. 설정을 한 번도 저장하지 않았을 때 기존 글 '처음 한 번 설정 화면에서 코드를 확인하고 [저장]을 눌러 주세요.'를 보일지(시안에 없음)
4. 경고 줄(환불 · 수납이 끝나지 않은 진료 · 생년월일 없는 환자 등)을 목록에 보일지(시안에 없음)
5. 진료 0건인 날을 목록에서 뺄지(시안은 흐리게 보임)
6. 기간 길이 제한(시안은 없음. 하루씩 세서 길면 오래 걸림)
7. 엑셀 모양(제안): 같은 줄 · 열 + '빈 칸 까닭' 열, 숫자는 숫자 칸(쉼표 없음), 파일 이름 'ERP마감일지_입력목록_{시작일}_{끝일}.xlsx'
