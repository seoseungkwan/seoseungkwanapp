# library(자료실 탭) 시안 메모

- 파일: `index.html` 한 파일(CSS·JS 안에 있음, 글꼴만 `src/app/fonts/` Pretendard를 상대 경로로 불러옴). 상태는 `?s=…`로 고른다.
- 모양: 앱 토큰(`src/app/globals.css :root`)과 `components/ui/classes.ts`(단추·칩·표·패널·확인 창) 그대로. 머리·탭 줄·[더보기] 판은 앱 틀(`AppShell`·`TabBar`·`MoreMenu`) 그대로.
- PC 화면만 만든다. 폰 모양·폰 사진은 없다(폰에서는 PC 화면 그대로, 넓은 표는 표 칸만 옆으로 밀림).
- 자료는 모두 지어낸 값(파일 이름·크기·날짜). 오늘은 **2026-11-25 (수) 10:40**으로 고정.
- 이 시안은 helper-download 시안(`docs/mockups/helper-download`)의 '설치 파일' 칸 둘(관리자 화면·설정 탭)을 대신한다.
- 승인: 2026-11-25, 사용자 "ㅇㅋ"(시안 html·관리자·올리기 창·설정 탭 사진을 본 뒤)

## 상태 (`?s=`)
| 값 | 보이는 것 |
|---|---|
| `user` (기본) | 원장(관리자 아님)이 [더보기] → 자료실을 연 모습. [받기]만 있음 |
| `admin` | 관리자: 오른쪽 위 [파일 올리기], 줄마다 [지우기], 표 아래 한 줄 안내 |
| `upload` | 올리기 창: 파일을 고른 뒤(precheck-helper-0.14.0.zip). 이름은 파일 이름으로 채워짐 |
| `uploading` | 올리는 중 62%. 칸 잠김, [취소]로 멈춤 |
| `too-big` | 50MB 넘는 파일(63.4MB)을 골랐을 때 오류 카드, [올리기] 눌리지 않음 |
| `done` | 다 올라간 뒤: 창 닫힘, 표 위 알림, 새 줄 잠깐 파랗게, 0.14.0이 최신·0.13.3은 옛 판으로 |
| `delete` | 옛 판 펼치고 0.11.0 [지우기] → 확인 창 |
| `empty` | 파일이 하나도 없을 때(관리자 화면). 관리자가 아니면 [파일 올리기] 없이 "관리자가 파일을 올리면 여기에 보여요." |
| `error` | 목록을 읽지 못함: 오류 카드(무엇이 · 어떻게 고치나 · 번호) + [다시 읽기] |
| `settings` | 설정 탭: 옛 '비트 PC 연결 · 설치 파일' 받기 표 자리에 작은 칸 "설치 파일은 자료실에서 받아요 [자료실 열기]" |
| `admin-tab` | 관리자 화면(가입 승인): 옛 '설치 파일' 올리기 표 자리에 같은 작은 칸 |
| `menu` | [더보기] 판을 연 모습. 자료실은 주소록 다음·설정 앞(관리자는 입지 분석 다음) |
| `desk` | 데스크 계정: [더보기]가 없어 탭 띠 맨 끝(예약 다음)에 자료실 |

시안 안에서 눌러 볼 수 있는 것: 분류 칩, 옛 판 보기·접기, [받기](알림만), [파일 올리기] → [파일 고르기](예시 파일 셋이 차례로 바뀜) → [올리기](올리는 중 → 끝), [취소], [지우기] → 확인, [더보기] 열기·닫기, [자료실 열기], [다시 읽기].

## 사용자 결정 (2026-11-25)
- 올리기·지우기는 관리자만. 받기는 승인된 사람 모두(데스크 포함).
- 어떤 파일이든 올릴 수 있고, 한 파일에 50MB까지.
- 관리자 화면과 설정 탭의 옛 '설치 파일' 칸은 자료실로 합친다(두 곳 모두 자료실로 가는 단추 하나 있는 작은 칸이 됨).
- PC 화면만(폰 모양 없음, 사진도 PC 폭만).

## 화면 기본값 (시안에 그대로 넣은 것)
- 새 탭 '자료실'(주소 `/library`), [더보기] 묶음 안, 승인된 사람 모두에게 보임.
- 머리: 제목 '자료실' + 파일 수 + 한 줄 "의원 PC에 깔 파일과 설명서를 여기서 받아요."
- 분류 칩: 전체 · 설치 파일 · 설명서 · 그 밖. 칩 숫자는 그 분류의 파일 수(옛 판 포함).
- 표: 이름(아래에 설명 한 줄) · 분류 · 크기 · 올린 날 · [받기]. 새로 올린 것 먼저.
- 판 번호 붙은 설치 파일(`precheck-helper-X.Y.Z.zip`·`precheck-extension-X.Y.Z.zip`)은 종류마다 가장 높은 판에 '최신', 나머지는 그 아래 "옛 판 N개 보기"로 접음. 판 묶기는 올릴 때의 파일 이름으로 본다(이름 칸을 고쳐도 그대로).
- 관리자만: 오른쪽 위 [파일 올리기], 줄마다 [지우기] + 확인 창.
- 올리기 창: 파일 고르기 · 이름(파일 이름으로 채움, 고칠 수 있음) · 분류(설치 파일 / 설명서 / 그 밖) · 설명 한 줄(선택) · [취소] [올리기]. 올리는 중 막대, 50MB 넘으면 오류, 끝나면 알림.
- 오류 문구는 `lib/errors.ts` 모양(무엇이 · 어떻게 고치나 · 번호).

## 시안에서 정한 것 (기본값에 없던 것)
- 분류는 파일 끝을 보고 먼저 골라 둔다: zip·exe·msi → 설치 파일, pdf·hwp·docx·pptx → 설명서, 나머지 → 그 밖. 바꿀 수 있다.
- 설명 한 줄은 60자까지.
- 큰 파일은 고르자마자(올리기 전에) 막는다.
- 최신 판을 지울 때 확인 창에 "지우면 ○○이 최신이 되고, 비트 PC 연결 화면의 [도우미 내려받기]도 그 판을 줘요."를 더한다(마지막 한 판이면 "…눌리지 않아요").
- 판 번호 붙은 파일을 올린 뒤 알림 둘째 줄은 "비트 PC 연결 화면의 [도우미 내려받기]도 이 판을 줘요."
- 데스크는 [더보기]가 없어 탭 띠 맨 끝에 '자료실' 탭을 하나 더 둔다(데스크 탭 셋 → 넷).
- 상태 셋 더함: `done`(끝 알림을 보이려고), `menu`(탭 자리를 보이려고), `desk`(데스크가 들어가는 길을 보이려고).
- 설정 탭 작은 칸에서 옛 [비트 PC 연결 확인하러 가기 →] 줄은 뺐다(설정 안 메뉴에 [비트 PC 연결]이 이미 있음).
- 관리자 화면 옛 칸의 "Claude가 바탕화면 도우미-설치파일 폴더에 zip을 놓아 둬요…" 안내와 이름 모양·5MB 제한은 없어진다(어떤 파일이든 50MB까지).

## 만들 때 알아 둘 것 (시안에는 안 보임)
- 자료실은 모든 의원이 같은 하나를 본다(옛 설치 파일 보관함처럼). 관리자가 올리고 지우면 모든 의원에 똑같이 보인다.
- 비트 PC 연결 화면의 [확장 내려받기]·[도우미 내려받기]는 그대로 두고, 자료실의 그 종류 최신 판을 준다.
- '관리자만 보는 탭' 목록(`tab_access`)은 줄이 없는 새 탭을 관리자만으로 본다. 자료실은 모두에게 보여야 하므로 대시보드·설정처럼 늘 보이는 탭으로 둔다.
- 관리자가 다른 의원을 보는 중(admin-view)에는 [파일 올리기]·[지우기]를 그리지 않는다(읽기만). [받기]는 그대로.
- 같은 이름의 파일이 이미 있으면 올리지 않고 알린다(오류 번호 E-LIBRARY-FILE-EXISTS).
- 오류 번호(새): E-LIBRARY-READ-FAILED(목록) · E-LIBRARY-FILE-SIZE(50MB 넘음) · E-LIBRARY-FILE-EXISTS · E-LIBRARY-UPLOAD-FAILED · E-LIBRARY-DOWNLOAD-FAILED · E-LIBRARY-DELETE-FAILED.

## 시안 표시용 (만들지 않음)
- 맨 위 회색 머리(시안 이름·상태 고르기·설명 줄).
- 노란 점선 테두리와 노란 '바뀜 · …' 표시(새로 생기거나 바뀌는 자리).
- 관리자 화면·설정 탭의 '(지금 칸 그대로 · 바뀌지 않음)' 회색 자리 칸.
- [받기]를 누르면 뜨는 "(시안이라 실제로 받지는 않아요)" 알림.
