# 시안 메모: logo-fit (서식 로고 자동 맞추기)

- 파일: `index.html` 한 장. 페이지 안 JS가 `specs/logo-fit/design.md` 2절(선 떼기 → 흰 배경 지우기 → 여백 자르기)·4절(자리 340×100, 400×110, 흰 빛 없음)을 그대로 돌린다.
- 기본 로고: 페이지가 그린 가상 세로형 로고(흰 배경). `?logo=<파일>`로 다른 그림. 2026-11-19 사용자가 보낸 실제 로고(1080×501, 밝은 회색 배경, 오른쪽 끝 검은 1점 세로줄)로 찍은 사진은 저장소에 넣지 않았다(그림 파일은 scratchpad에만).
- 보이는 것: 진료일정 안내(AI 배경·테마 배경)·환자 안내문·가로형 투명 로고, 지금/바뀐 뒤. [로고 자리(점선) 보기]로 새 자리 표시.
- 결정 반영: 2026-11-19 사용자 "그라데이션 없애" → 휴진 안내 AI 배경의 로고 뒤 흐린 흰 빛을 없앤다(바뀐 뒤 그림에서 뺌).

## 승인
- 승인: 2026-11-19, 사용자 "이 시안대로 먼저 (추천)" — 흰 빛 없앤 판("그라데이션 없애"·"흰빛없야" 반영). 글씨·로고 크기·색 조절은 다음 시안으로 따로(밀어서 %, 로고 색 원래·흰·검정·직접, 글씨 색 제목·본문 따로).
