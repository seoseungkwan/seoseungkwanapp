# claim-memo-fit 시안 메모

- 문제(2026-11-16 사용자): 메모 확인(3단계) 오른쪽 상세에서 증상·처방내역을 보려면 매번 내려야 해서 불편. "이거까지 한번에 보고싶어"(증상 8줄 + 처방 11줄 전체).
- 사용자 화면: 가로 1440 창, 두 칸 높이 약 533px.
- 처음 그린 A(위만 줄이기)·B(지금 폭에서 세 칸)는 처방이 5~6줄밖에 안 보여 버림.
- 시안(바꾼 뒤), lg(1024) 이상만:
  - 청구 화면만 본문 너비 제한(max-w-7xl)을 풂.
  - 환자 목록: 표시(! 메모 바꿈 등)를 오른쪽 끝에서 차트번호 바로 뒤로 붙이고 360 → 272px(한 줄 그대로, 보기 단추 여백만 좁힘). 2026-11-16 사용자 "왼쪽으로만 밀어"(이름 위로 두 줄은 안 함).
  - 오른쪽 머리 한 줄(이름·표시·진료일·차트·점검 경고 … 입력할 사람 n / N · 앞/다음 · 키보드).
  - 아래 세 칸: ① 복사(완료)·상태 줄·[메모 고치기][바꾸지 않기]·우리 메모·비트 메모(300px, 메모 두 칸이 남은 높이를 반씩) ② 증상(1fr) ③ 처방(1fr). 칸마다 따로 내리고 표 머리는 붙어 있음. 2026-11-16 사용자 "처방내역은 옆에 조금 잘려도 되니까 우리메모 비트메모 크기 좀 키워줘"(220 → 300px)
  - 복사 단추 밑 기본 안내(ready 글)는 없앰. 복사함·복사 못 함·완료 등 다른 상태 줄은 그 일이 있을 때만 같은 자리. 메모 두 칸은 똑같이 반씩. 2026-11-16 사용자 "누르면 우리메모가 복사되고 완료로 바뀌어요 이것도 없애서 위로도 좀 키워 칸 똑같이하고"
  - 증상은 자르지 않고 줄바꿈으로 다 보임. 2026-11-16 사용자 "증상은 다 보이게 하고" → 증상 칸을 처방 칸에서 넓힘(1440 창에서 증상 약 327px·14줄까지 내리지 않고 보임, 처방 약 409px). 1.1:1.6(증상 300px)은 14줄이 잘려 버림.
  - 2026-11-16 사용자 "증상을 오른쪽으로 좀 더 키워도 돼" → 증상:처방 1:1(1440 창에서 각 약 368px). 증상 글이 거의 한 줄씩, 14줄도 여유. 처방명은 많이 잘리고 짧은 이름으로 구분.
  - 처방명은 한 줄, 길면 끝을 … 로 자르고 title로 전체, 짧은 이름은 늘 보임.
  - 처방의 짧은 이름이 처방명과 같으면 안 씀.
  - 글자·칸·순서·움직임은 그대로. lg 미만(폰·좁은 화면)은 그대로.
