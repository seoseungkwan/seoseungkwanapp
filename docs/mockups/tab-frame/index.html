탭 틀 시안

앱 위쪽에 탭 12개를 한 줄로 놓습니다. 대시보드 탭은 없고, 로그인하면 통계가 먼저 열립니다.

  • 탭 순서통계 · 청구 · 고시·공지 · 환자 · 매출 · AI 리포트 · 서식 · 직원 · 업무일지 · 재고 · 주소록 · 설정
  • 휴대폰탭 줄을 옆으로 밀어서 봅니다. 끝이 흐려 보이면 탭이 더 있다는 뜻이에요. 아래 휴대폰 화면에서도 밀어 볼 수 있어요.
  • 새 글 점고시·공지에 새 글이 있으면 탭 이름 옆에 작은 파란 점이 생깁니다.
  • 도구 단추도구가 여러 개인 탭은 맨 위에 도구 단추 줄이 먼저 나옵니다. 통계와 매출은 차트가 이어지는 한 페이지입니다.
  • 준비 중아직 만들지 않은 탭도 보이고, 누르면 "준비 중인 기능입니다" 화면이 나옵니다.

이 페이지의 숫자, 공지 제목, 이름은 모두 지어낸 예시입니다. 실제 공지가 아니며 환자 정보는 없습니다.

새 글에는 "새 글" 표시가 붙고, 탭 이름 옆에도 점이 생깁니다.

화면 4

화면 5

계정 메뉴
