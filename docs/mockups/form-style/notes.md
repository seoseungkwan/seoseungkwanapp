# 시안 메모: form-style (서식 글씨·로고 크기·색 조절)

- 파일: `index.html` 한 장. 진료일정 안내·환자 안내문 탭, '글씨·로고' 칸(제목 글씨·본문 글씨·강조 색(진료일정 안내만)·로고)과 A4 미리보기. 그림은 실제 배치 값(진료일정안내 120·안내 두 줄 27·카드 33/46/50, 안내문 큰 문구 109·줄 글 34)을 줄여 그린 것이다.
- 페이지 안 JS: logo-fit 규칙으로 로고를 손질하고, 로고 색(옅은 점 뺀 4비트 묶음 많이 쓴 차례, 서로 떨어진 4개)을 뽑고, [자동] 색을 로고 색으로 그린다.
- `?logo=<파일>`로 로고, `?s=`로 처음 값(`dark` 어두운 AI 배경 + 흰 로고, `big` 크게, `small` 작게, `locked` 배경이 남은 로고 — 로고 색 고르기 막힘), `?tool=guide`로 환자 안내문 탭. 사용자 실제 로고로 찍은 사진은 저장소에 넣지 않았다(scratchpad에만).
- 시안에서만 있는 것: '(시안에서만) 어두운 AI 배경으로 보기' 칸, '강조 색' 제목 옆 설명 글("— 지금 '배경' 칸의 '글자 색'이 이리로 옮겨 와요"). 실제 화면 글자는 `specs/form-style/requirements.md`의 글자가 이긴다(도움말 글 포함).

## 결정 흐름
- 2026-11-19 사용자 "글씨 크기 내가 조절할 수 있게 해 색깔이랑" → 고른 것: 로고·글씨 둘 다, 두 서식 다, 밀어서 조절(%), 로고 색 원래·흰·검정·직접, 글씨 색 제목·본문 따로.
- 첫 시안(자동/직접 고르기 두 버튼) 뒤 사용자 "색깔 로고색 따라 갈 수 있게 하고 색깔 다양성 많이 하게 해" → 색 고르기를 [자동]/[원래 색] + 로고에서 뽑은 색 + 기본 색 16가지 + 직접 고르기로 바꿈. 로고 색 흰색·검은색은 기본 색 칩으로 고른다. 진료일정 안내의 '글자 색'은 '강조 색'으로 이 칸에 옮김.
- [로고 색으로 맞추기] 버튼 시안과 '자동 = 로고 색' 중 사용자가 "로고 열면 자동으로 로고 색"을 골라 버튼을 뺐다.

## 승인
- 승인: 2026-11-19, 사용자 "로고 열면 자동으로 로고 색" — 색 칩 시안(로고 색 + 기본 색 16 + 직접)에서 [로고 색으로 맞추기] 버튼 없이 [자동]이 로고 색을 따르는 판.
- 승인: 2026-11-19, 사용자 "이렇게 막기 (추천)" — 배경이 남은 로고(`?s=locked`)는 로고 색 고르기를 막고 '배경이 있는 로고라 색을 바꿀 수 없어요. 원래 색으로 그려요'를 보인다(명세 검토에서 나온 상태, AC-6801.8).
