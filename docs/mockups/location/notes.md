# location(입지 분석 탭) 시안 메모

- 파일: `index.html` 한 파일(CSS·JS 안에 있음, 글꼴만 `src/app/fonts/` Pretendard를 상대 경로로 불러옴). 서버 없이 파일을 바로 열어도 된다.
- 사진: 작업 임시 폴더 `scratchpad/location-shots/` — 상태마다 `<상태>-1440.png`, 그리고 `scan-1024.png`·`candidate-1024.png`. 모두 8000px 아래라 한 장씩.
- 모양: 앱 토큰(`src/app/globals.css :root`)과 `docs/UI_GUIDE.md` 그대로. 흰 바탕 한 장, 상자 대신 1px 선, 파란 강조 하나, 굵기 400·500·600, 모서리 4px(떠 있는 판만 8px). 앱 머리 줄·탭 줄은 주소록 시안과 같다.
- **PC 화면만.** 폰 전용 모양은 없다. 넓은 표(진료 시간 빈틈·협상표·출처 표)는 표 칸만 옆으로 밀린다. 1440·1024 너비 모두 가로 넘침 0, 콘솔 오류 0.
- 자료는 모두 지어낸 값: 동 이름(가람동·하늘동…12곳), 건물 `예시빌딩`·`예시타워`·`예시프라자`, 의원 `예시○○정형외과`, 중개사 `예시부동산 김예시`, 전화 `010-0000-00xx`. 오늘은 **2026-11-22 (일)** 로 고정. 지도는 손으로 그린 동 모양(진짜 지도 아님).
- 출처 이름(기관·자료 이름)은 가안이다. 조사 일꾼 결과가 나오면 맞춘다. 화면 숫자마다 아래 작은 글씨 `출처 짧은 이름 · 기준 날짜`가 붙고, 누르면 `?s=sources#src-<열쇠>`의 그 줄로 간다(노랗게 표시).
- `&c=A|B|C`로 후보를 고른다(후보 자세히·개원 준비·한 장 보고서). 후보 C는 경기도라 낮 인구가 '이 지역은 자료 없음'으로 보이고, 예상 환자 두 계산이 크게 달라 조심 표시가 뜬다.
- 화면 위 회색 띠(상태 단추 + 설명 한 줄)는 시안에만 있다. 앱에는 없다.
- **승인: 2026-11-22, 사용자 "이대로 만들기".** 함께 정한 것:
  - 도수치료 값 견주기는 그대로 둔다. 2026-07 관리급여 기사가 있지만 공개 자료에 값이 있을 때만 보여 준다.
  - 한의원은 경쟁 의원 수에서 빼고 따로 한 줄로 둔다(시안 그대로).
  - 대시보드 새 경쟁 의원 알림에는 **[닫기]를 둔다**(시안에서 더할 것). 다음 달에 새 의원이 있으면 다시 뜬다.
  - 개원 비용 칸의 매물 값은 참고 글로만 보인다('빈칸에서 직접' 결정을 따름).
  - 출처 이름은 `specs/location/research/` 조사 결과대로 고친다.

## 누를 수 있는 것(시안 안에서 움직임)
- 위 탭 6개(동네 훑기·후보 자세히·매물·후보 견주기·개원 준비·근거와 출처), 후보 단추 A·B·C, [후보 더하기] 판 열기·닫기(Esc도)

- 개원 비용·손익분기 칸에 숫자를 넣으면 합계·손익분기가 바로 계산됨, [시안에서만: 예시 숫자 넣어 보기]
- 건물 요건 ○✕? 칸 누르기, 점검표 체크, 메모 더하기, 매물 [매물 저장]·[후보로 저장]
- 숫자 아래 출처 글씨 → 근거와 출처의 그 줄

## 사용자가 정한 것 (시안에 그대로 넣음)
- 새로 개원하는 입장: 새 자리 찾기 + 그 자리 둘레 살펴보기. 볼 사람은 **관리자만**. 지역은 전국(낮 인구는 서울만).
- 후보 고르기: 넓게 훑고(동마다 점수 색 지도 + 추천 동) 깊게 보기. 후보는 주소·지도 찍기·붙여 넣은 매물 세 길.
- 살필 범위는 후보마다 직접(300m~3km).
- 매물은 저절로 긁어 오지 않음 → [네이버 부동산에서 보기] 새 창 + 마음에 드는 것만 붙여 넣기, 평수로 거르기.
- 예상 환자는 두 계산 나란히, 크게 다르면 조심 표시. 개원 비용은 빈칸에서 직접(기본 숫자 안 채움).
- 점수 무게는 기본 30·25·20·15·10 + 막대로 조절.
- 진행 상태(보는 중 → 중개사 연락 → 보러 감 → 계약 검토, 내려놓음)·날짜별 메모, 새 경쟁 의원 개업·폐업 대시보드 알림(한 달 한 번), 중개사를 주소록에 넣기, 보고서 PDF 저장.
- 매물 값 견주기, 개원 일정표, 보러 갈 때 점검표 + 사진, 임대 조건 협상표, 비급여 진료비, 진료 시간 빈틈, 위험 신호 맨 위, 홍보할 아파트 순서, 물리치료사·간호조무사 월급 수준.
- 숫자마다 출처·기준 날짜, '근거와 출처' 화면(사용자 "관련근거써주고 자료 어디서 가져왔는지").
- 자료 열쇠는 공공데이터포털 + 카카오 지도(무료), 사용자가 이 칸에 직접 넣음.

## 시안에서 내가 정한 기본값 (사용자 확인 필요)
1. **점수 계산**: 항목마다 `0~100 점 × 무게 ÷ 무게 합`을 버림한 뒤 더한다. 무게 합이 100이 아니어도 비율로 계산(합 100을 강제하지 않음). 동 점수는 동 전체 값, 후보 점수는 그 자리 둘레(살필 범위) 값.
2. **경쟁 의원 수와 진료 시간 빈틈**은 정형외과·마취통증의학과·재활의학과만 센다. 한의원은 따로 한 줄로만 보인다.
3. **살필 범위 기본 1km**, 후보마다 따로 기억. 후보를 저장한 날 받은 값으로 굳혀 두고 기준 날짜를 함께 보인다(견주기 표 아래 'A 11월 15일 · B 11월 16일 · C 11월 14일').
4. **예상 환자 두 계산 차이가 30%를 넘으면** 조심 표시(후보 C 129명·64명에서 보임). 손익분기는 '하루 몇 명'으로 소수 첫째 자리까지 버림, 원장 몫(원장 월급)은 들어 있지 않다고 적음.
5. **대시보드 입지 알림**은 무상 수리 알림 바로 아래 따로 한 칸, [닫기] 없음, 관리자 계정만, 한 달에 한 번. 줄을 누르면 그 후보 자세히의 경쟁 의원 묶음으로.
6. 탭 자리: [더보기] 판의 주소록 다음, 설정 앞. 탭 안 작은 탭 6개 차례는 일하는 차례(훑기 → 자세히 → 매물 → 견주기 → 준비 → 근거).
7. 개원 일정표는 개원일에서 거꾸로 센 14가지 할 일(계약 150일 전 … 개원 당일), 날짜는 고칠 수 있음. 건물 요건 표 기본은 '?'(모름)이고 누를 때마다 ○ → ✕ → ? 로 바뀜.
8. 한 장 보고서의 진행 메모는 최근 2개만, 출처는 맨 아래 작은 글씨 한 덩어리.
9. 매물 값 견주기: 평당 월세 = 월세 ÷ 전용 평수, 상권 평균은 한국부동산원 임대동향조사(가안) 값과 견줌.

## 사용자에게 물을 것
1. 대시보드 입지 알림에 **[닫기]** 가 있어야 할까요? (시안: 없음 — 무상 수리 알림과 같은 모양)
2. 개원 비용 칸에 매물의 보증금·월세를 **참고 글로만** 보일까요, 아니면 **[넣기] 단추**로 한 번에 채울까요? (시안: 참고 글로만 — '빈칸에서 직접'을 지키려고)
3. **한의원**을 경쟁 의원 수에서 뺄까요? (시안: 빼고 따로 한 줄)
