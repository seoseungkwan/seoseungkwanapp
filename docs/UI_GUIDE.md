# UI 디자인 가이드

> 2026-10-28에 사용자가 승인한 랜딩 목업에서 뽑았다. 승인본: `docs/mockups/landing/landing-mockup.dc.html` (그림은 같은 폴더 `images/`, 안 쓰는 히어로 영상은 저장소 밖 `~/seoseungkwan/landing-approved/unused/`)
> 이 파일은 Claude Design 캔버스 형식(`.dc.html`)이라 `support.js` 없이는 브라우저에서 열리지 않는다. 화면으로 볼 때는 캔버스 링크(https://claude.ai/artifact/DGDm4TMh13MFF8PWF97w1p)를 쓰고, 저장소 사본은 구현할 때 값을 확인하는 기준으로 쓴다
> 사용자가 따로 줄 UI/UX md 파일(plan.md §12)이 오면 앱 화면 쪽을 보강한다. 부딪히면 plan.md가 이긴다.

## 디자인 원칙
1. 밝은 화면만 쓴다. 다크 모드는 만들지 않는다 **(사용자)**
2. 한 가지 색으로 통일하지 않는다. 섹션·카드마다 포인트 색을 달리해 생동감을 준다 **(사용자)**
3. 숫자가 움직여야 한다. 차트·숫자는 값에 따라 실제로 변하는 코드 애니메이션으로 보여 준다(영상·정지 그림 아님) **(사용자)**
4. AI와 개인정보 보호를 눈에 띄게 보여 준다. 개인정보 문구는 plan.md §4·§6에 정한 사실만 쓴다
5. PC 기준으로 설계하고, 폰은 보기 화면만 맞춘다(plan.md §3)

### 승인된 화면에서 허용한 것 (템플릿 기본 금지였지만 사용자가 승인)
- 보라 `#6D5DF5`: 주로 AI 영역(AI 섹션, AI 카드, AI 칩)에 쓴다. 승인된 화면에서 그 밖에 쓴 곳은 로고 아이콘, 히어로·시작하기 섹션의 빛과 떠다니는 점, 히어로 차트의 "숫자는 예시" 칩, 통계 그림의 막대 일부, 개인정보 흐름에서 AI로 가는 연결선과 "집계만" 글자, 시작 3단계의 03(번호와 카드 배경 `#F1EFFF`), 월말 보고 타일이다. 이 밖으로 넓히지 않는다
- 위쪽 메뉴 띠의 `backdrop-filter: blur(14px)`: 띠 하나에만 쓴다
- 섹션 배경의 연한 원형 빛(`radial-gradient`, 투명도 0.08~0.16): 히어로·AI·시작하기 섹션에만 쓴다

## 컴포넌트
### 버튼
```
Primary  : 남색 #0B1530 배경, 흰 글자, 굵게, radius 999px, min-height 44px(메뉴) / 52~56px(본문)
Secondary: 흰 배경, 테두리 rgba(109,93,245,0.35), 보라 글자 #5546E0 (AI로 가는 버튼)
글자 링크: #3D4A66, 패딩으로 클릭 영역 44px 이상
```

### 카드
```
기본    : 흰 배경, 테두리 1px rgba(11,21,48,0.08), radius 20px, padding 28px, 그림자 0 10px 30px rgba(11,21,48,0.05)
떠 있는 숫자 카드: radius 16px, padding 16px 18px, 그림자 0 16px 40px rgba(11,21,48,0.12), 위아래로 천천히 뜬다
AI 카드 : 테두리 1.5px rgba(109,93,245,0.35~0.45), 보라 계열 그림자
색 카드 : 위 표의 연한 배경을 카드 배경으로 쓴다(섹션 안에서 카드마다 다른 색)
```

### 칩·라벨
```
padding 6px 12px, radius 8px, 14px 굵기 600, 연한 배경 + 같은 색 진한 글자
예시 표시 칩은 작은 규격: padding 4px 10px, 12~13px. "숫자는 예시"는 radius 6px + 보라 점선 테두리, "방금 생성 · 예시"는 radius 999px
```

### 입력 필드
```
min-height 46px, padding 0 14px, radius 12px, 테두리 1px rgba(11,21,48,0.15), 흰 배경
<label>을 반드시 붙인다(보이지 않게 숨겨도 됨)
```

## 레이아웃
- 내용 최대 너비: `1200px`, 좌우 여백 `24px`
- 섹션 위아래 여백: 대체로 `96~120px`(히어로 위 80px, 이어지는 섹션 아래 40~48px), 섹션 안 큰 덩어리 사이 `44~56px`(기능 행 사이는 96px), 카드 사이 `16~20px`
- 두 칸 배치는 `flex-wrap`으로 만들어 좁은 화면에서 아래로 쌓이게 한다
- 제목·본문은 왼쪽 정렬이 기본이다. 승인된 목업에서 가운데 정렬한 곳은 그대로 따른다: 마지막 시작하기(CTA) 섹션, 개인정보 흐름 그림의 연결선 글자, 흐름 카드 중 "병원 PC · 브라우저"·"서버" 카드의 제목 줄("AI 분석" 카드 제목은 왼쪽)
- 위쪽 메뉴 띠는 화면 위에 붙어 따라온다(sticky)

허용(모두 `prefers-reduced-motion: reduce`에서 멈추고, 멈춘 화면도 그대로 읽혀야 한다):
- 숫자·차트: 몇 초(약 2.6s)마다 값이 바뀌고, 막대·도넛은 `transition 1.2s`로 따라 움직인다. 히어로는 영상이 아니라 이 코드 차트다(plan.md §2-10의 히어로 배경 영상을 사용자가 차트로 바꿨다. 만든 영상은 저장소 밖 `~/seoseungkwan/landing-approved/unused/`에 보관)

- 히어로 배경의 떠다니는 점(7~9초), 기능 그림의 막대 출렁임(3초), 흐르는 연결선
- 급여표 위를 지나가는 스캔 띠(3.5초)
- AI: 리포트 위 반짝이는 띠(2.2초), 리포트 항목이 하나씩 나타남, 답 쓰는 중 점 3개, 반짝이 아이콘 살짝 커짐
- 그림 타일: 천천히 위아래로 뜸

그 외 화면 전환·튀는 효과는 쓰지 않는다.

## 그림 (Higgsfield)
- 타일 그림: 깔끔한 플랫 벡터 일러스트, 타일마다 한 색(주사 파랑, 물리치료 청록, 비급여 초록, 월말 보고 보라), 사람·글자·잎사귀 없음
- 기능 01·02 그림: 밝은 사무실 책상 실사 사진(통계: 노트북 차트와 척추·무릎 모형, 급여: 계산기·서류·태블릿)이다. 화분이 보이지만 승인된 그대로 쓴다. 위의 사진·잎사귀 금지는 타일 그림에만 해당한다
- 색만 바꿀 때는 새로 만들지 않고 기존 그림의 색상(hue)만 돌린다
- 새 스타일을 정할 때는 2~3개 시안(장당 0.25 크레딧)을 먼저 보여 주고 고르게 한다
- 영상·이미지는 우리 쪽(`public/`)에 둔다. 상업적 사용 가능 여부는 공개 전에 요금제 약관으로 확인한다(plan.md §6-6)

## 문구
- 우리 쪽을 가리킬 때는 "병원"이 아니라 **"의원"**("우리 의원"), 전자차트는 **"EMR"**로 쓴다(사용자가 고침)
- 개인정보 문구는 사실만: "환자 개인정보는 절대 병원 PC 밖으로 나가지 않습니다", "0건" — 근거는 plan.md §4. "병원 PC"는 승인된 목업 그대로 둔다. 쓰인 곳은 3곳이다: 히어로 아래 문장("환자 개인정보는 병원 PC 밖으로 나가지 않습니다"), 개인정보 섹션 제목("절대" 포함, 사용자가 고침), 개인정보 흐름 카드 제목("병원 PC · 브라우저")
- 서비스 이름·문의 메일은 정해질 때까지 `[서비스 이름]`, `[이메일 주소]`

# 보고서·PPT 양식

> 월간보고 PPT(.pptx)의 모양. 값의 기준은 `src/lib/report/template.ts`(얼려 둔 한 곳, ADR-016)이고, 쪽 모양은 검토용 PPT 목업(https://claude.ai/artifact/Amc46niE2pgiJos22MmQdN), 색은 그래프 보고서 목업의 인쇄용 색(`docs/ai-report-style-notes.md`)에서 왔다. 명세: `specs/ai-report/`
> 위의 앱·랜딩 화면 규칙과 따로 간다(PPT는 받은 PC에서 열리는 파일이라 앱 글꼴·카드 그림자를 쓰지 않는다).

## 원칙
- 모양은 코드가, 글은 AI가. 색·글꼴·쪽 순서·글자 수 한도는 양식 정의에만 있고 AI가 바꿀 수 없다
- 숫자·늘고 준 폭·그래프·표·그래프 결론 줄은 코드가 계산한다. AI는 '한눈에' 4문장과 '다음 할 일' 1~3문장만 쓴다
- AI 글은 글자로만 넣는다(HTML·마크다운 없음). 가짜 숫자로 만든 PPT는 표지·바닥글에 '예시'를 붙인다

## 글꼴·모양
- 글꼴: 맑은 고딕 하나. 모든 글자 조각에 이름 `맑은 고딕`을 직접 적는다(테마 글꼴 포함). 굵기는 보통·굵게(700)뿐 — 제목은 굵게
- 크기(pt, 목업 px ÷ 2): 표지 제목 48 · 쪽 제목 28 · 큰 숫자 48 · 본문·AI 문장·단위·증감 18 · 표·계산 기준·끝 이름·표지 병원 이름 14 · 꼬리표·설명 줄·바닥글·축 12
- 그림자 없음 · 선 1px(0.75pt) · 모서리 둥글기 10px(카드·상자·꼬리표)
- 숫자는 오른쪽 정렬로 줄을 맞춘다(고정폭 글꼴 대신). 천 단위 쉼표, 단위는 숫자 뒤('3,412명')

## 숫자·글투
- 증감률 '+11.5%' · '−9.0%'(빼기는 U+2212) · 신환율은 %p('−2.7%p') · 비교가 0이면 '신규' · 화살표 ↑ ↓
- 퍼센트는 소수 첫째 자리까지, 그 아래는 버린다
- 잠정인 달은 비교하지 않는다('잠정이라 비교 안 함'). 비교할 달이 없으면 '비교 없음'
- AI 문장: '~늘었어요', '확인해 보세요' 같은 해요체 한 문장, 숫자를 앞에. 원인 짐작은 '추정', 덜 모인 숫자는 '잠정'
- 계산 기준·설명 줄: '· '로 시작하는 개조식, '~합니다' 또는 명사로 끝
