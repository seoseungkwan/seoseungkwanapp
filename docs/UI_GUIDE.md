# 랜딩

## 디자인 원칙
1. 밝은 화면만 쓴다. 다크 모드는 만들지 않는다 **(사용자)**
2. 차분하게 만든다(Linear의 절제 + Stripe의 데이터 중심). 중립 회색에 강조색은 파랑 하나만 쓰고, 섹션마다 색을 바꾸지 않는다 **(사용자, 2026-10-30. 2026-10-28의 "한 가지 색으로 통일하지 않는다"를 바꿈)**
3. 그림 대신 제품 화면을 보여 준다. 일러스트·사진 없이, 앱 화면을 줄여 그린 미리보기를 쓴다. 미리보기 속 숫자에는 "예시"를 붙인다 **(사용자, 2026-10-30)**
4. 숫자가 움직인다. 히어로 미리보기의 예시 숫자만 2.6초마다 바뀐다(코드 애니메이션, `heroFrames.ts`). 그 밖에는 움직이는 것이 없다 **(사용자)**
5. 규칙은 한 벌이다. 글자 크기·간격·카드 모양·정렬은 아래 표 값만 쓴다
6. 휴대폰은 1줄, 태블릿은 2줄, PC는 12칸으로 나눈다. 휴대폰에서도 메뉴가 보인다
7. AI와 개인정보 보호는 문구와 구조(리포트 미리보기·흐름도)로 보여 준다. 개인정보 문구는 plan.md §4·§6에 정한 사실만 쓴다

## 간격·틀
| 어디 | PC | 태블릿 | 휴대폰 |
|------|------|------|------|
| 섹션 위아래 | 96 | 80 | 56 |
| 히어로 위아래 | 88 · 96 | 64 · 80 | 32 · 56 |
| 섹션 제목과 내용 사이 | 48 | 40 | 32 |
| 카드와 카드 사이 | 16 | 16 | 12 |
| 카드 안쪽 | 24 | 24 | 16 |
| 화면 좌우 여백 | 24 | 24 | 16 |
| 내용 최대 폭 | 1200 | | |

- 간격은 4px 단위다
- 시안 설명 카드에는 휴대폰 섹션 여백 64·카드 안쪽 20이 적혀 있다. 하지만 사용자가 승인한 시안 화면(CSS)은 56·16이고, 화면 값을 따른다
- 섹션 바탕은 흰색과 회색(`canvas`)이 번갈아 온다: 흰 히어로·약속 띠 → 회색 `#ai` → 흰 `#ortho` → 회색 `#features` → 흰 `#privacy` → 회색 `#how` → 흰 `#start`
- 제목·본문은 모두 왼쪽 정렬이다(가운데 정렬 없음)

## 화면 폭과 칸
- 휴대폰(767px 이하)은 1줄이다
- 태블릿(768~1023px)은 2줄이다. 짧은 카드 3장은 3칸 그대로 둔다
- PC(1024px 이상)는 12칸이다
- CSS는 휴대폰 값을 먼저 쓰고, `@media (min-width: 768px)`·`@media (min-width: 1024px)` 두 가지로만 바꾼다
- 칸 수(휴대폰 → 태블릿 → PC):

  | 덩어리 | 칸 수 |
  |------|------|
  | 정형외과 카드 | 1 → 2 → 4 |
  | 기능 작은 카드 | 1 → 3 |
  | AI 약속·개인정보 약속 | 1 → 2 → 4 |
  | 시작 3단계 | 1 → 3 |
  | 약속 띠 | 1 → 3 |
  | 히어로(PC) | 12칸 중 글 6칸 · 단추 5칸 |
  | 기능 카드 | 1 → 반반 → 5:7 |
  | 개인정보 흐름 | 세로 → PC 가로 |

- 가로 스크롤은 없다(390·768·1440에서 확인). 넘칠 수 있는 표만 제 감싸개 안에서 옆으로 밀린다
- 휴대폰에서는 짧은 카드 여러 장(정형외과 4장, 기능 작은 카드 3장)을 테두리 하나 안에 선으로 나눈 목록으로 보여 준다

## 위쪽 메뉴
- 화면 위에 붙어 따라온다(sticky). 흰 바탕에 아래 1px 선이고, 그림자·blur는 없다
- 휴대폰은 두 줄이다
  - 윗줄 48px: 로고 + [구글로 시작하기](36px 단추, 누름 영역 44px)
  - 아랫줄 46px: 섹션 링크 4개. 옆으로 밀어서 보고, 스크롤바는 숨긴다
  - 메뉴 단추·서랍은 없다
- 태블릿·PC는 한 줄 64px이다: 로고 · 링크 4개 · 단추
- 섹션 제목이 메뉴에 가리지 않게 섹션에 `scroll-margin-top`(휴대폰 96px, 태블릿부터 64px)을 준다

## 모양
### 카드·항목
- 카드: 흰 바탕, 1px `line`, 모서리 6px, 안쪽 24px(휴대폰 16px), 그림자 없음
- 항목(글 목록): 테두리 상자 없이 위 1px 선 + 위 여백 20px(휴대폰 16px), 그 아래 제목과 본문

### 단추
```
주 단추  : ink 바탕, 흰 글자, 500, 모서리 6px. 올리면 ink-2
보조 단추: 흰 바탕, 1px line, ink 글자. 올리면 canvas
높이    : 히어로·시작하기 44px(좌우 20px, 15px) / 메뉴 36px(좌우 14px, 14px)
초점    : 2px accent 고리, 2px 띄움
```

### 칩
앱과 같다. 높이 22px, 좌우 7px, 12px 500, 모서리 4px, 1px 테두리(기본 투명).

| 칩 | 글자 / 바탕 / 테두리 |
|------|------|
| 중립 | `ink-2` / `surface` / `line` |
| 예시 | `muted` / `surface` / `line` |
| 완료 | `ok` / `ok-soft` |
| 살펴볼 것 | `danger` / `danger-soft` |
| 추정 | `muted` / `canvas` / `line` |

### 아이콘
- 인라인 SVG, 16~20px, 선 굵기 1.5(체크 1.8, 로고 2.4)
- 색은 `currentColor`(`ink-2`)이고, `aria-hidden="true"`
- 꼭 필요한 곳에만 쓴다: 약속 띠, 히어로 개인정보 줄, 흐름 카드, 기능 작은 카드, 파일 놓는 칸, 보내기, 확정 칩

## 제품 화면 미리보기
- 앱 시안 A + 블루(아래 '앱 화면')를 줄여서 다시 그린다. 실제 앱 컴포넌트는 쓰지 않는다(단추·링크·입력·시계 없음)
- 미리보기마다 "예시"·"숫자는 예시"·"방금 생성 · 예시" 칩을 붙인다. 이름·금액처럼 모르는 값은 `[ ]`로 둔다
- 섹션별 미리보기:

  | 섹션 | 그리는 것 |
  |------|------|
  | 히어로 | 위쪽 띠·탭 줄·"대시보드" 제목 + KPI 3장(오늘 외래·신환율·AI 한 줄 요약) + "월별 추이" 패널(도넛 + 막대 6개) |
  | AI | 리포트 패널(항목 3개 + 채팅 칸) |
  | 정형외과 | 카드마다 두 줄짜리 숫자 조각 |
  | 기능 | 환자 통계(파일 놓는 칸·비율 줄·처방 그룹 막대), 급여표 |
  | 개인정보 | 흐름도(병원 PC → 서버 → AI) |

- 앱 화면의 탭 이름·KPI 모양이 크게 바뀌면 랜딩 미리보기도 따로 고친다(복제본이라 저절로 따라가지 않는다)

## 움직임
- 히어로 미리보기의 예시 숫자: 2.6초마다 값이 바뀐다. 도넛·막대·신환율 막대는 0.6초 동안 따라 움직인다
- 단추 바탕색은 0.15초 동안 바뀐다
- 그 밖의 애니메이션은 없다
- 모션 줄이기 설정이면 모두 멈추고(전역 규칙 + 타이머 없음), 화면은 틱 0 값으로 읽힌다

## 그림
- 랜딩에는 그림(일러스트·사진·영상)을 쓰지 않는다 **(사용자, 2026-10-30)**
- 예전 Higgsfield 그림 6장은 `docs/mockups/landing/images/`에 승인 기록으로만 남는다

## 문구
- 우리 쪽은 "병원"이 아니라 **"의원"**("우리 의원")으로 쓰고, 전자차트는 **"EMR"**로 쓴다(사용자가 고침)
- 개인정보 문구는 사실만 쓴다: "환자 개인정보는 절대 병원 PC 밖으로 나가지 않습니다", "0건". 근거는 plan.md §4다

  - 영문 소제목을 뺐다

## 원칙
1. 밝은 화면만 쓴다 **(사용자)**
2. 색은 아낀다. 화면 대부분은 잉크 회색 글자와 1px 선이다. 강조색(파랑)은 아래 정해진 곳에만 쓴다
3. 데이터가 먼저다. 13~14px 글자, 4px 단위 간격, 36px 표 줄로 빽빽하게 (ERP 밀도)
4. 숫자는 고정폭 숫자(`tabular-nums`)이고 표에서는 오른쪽 정렬
5. 그림자는 떠 있는 층(계정 메뉴·툴팁·확인 창)에만. 제자리 덩어리는 1px 선으로 나눈다
6. 빈 상태는 조용하게: 패널 안 회색 안내 한두 줄 + 글자 단추 하나. 그림·큰 아이콘 없음
7. PC(1440px) 기준으로 설계하고, 폰(390px)은 보기 화면 + 44px 누름 영역
