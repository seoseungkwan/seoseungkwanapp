# UI 디자인 가이드

> 2026-10-28에 사용자가 승인한 랜딩 목업에서 뽑았다. 승인본: `docs/mockups/landing/landing-mockup.dc.html` (그림은 같은 폴더 `images/`, 안 쓰는 히어로 영상은 저장소 밖 `~/seoseungkwan/landing-approved/unused/`)
> 이 파일은 Claude Design 캔버스 형식(`.dc.html`)이라 `support.js` 없이는 브라우저에서 열리지 않는다. 화면으로 볼 때는 캔버스 링크(https://claude.ai/artifact/DGDm4TMh13MFF8PWF97w1p)를 쓰고, 저장소 사본은 구현할 때 값을 확인하는 기준으로 쓴다
> 사용자가 따로 줄 UI/UX md 파일(plan.md §12)이 오면 앱 화면 쪽을 보강한다. 부딪히면 plan.md가 이긴다.
> **앱 화면**(로그인·가입 신청·승인 대기·오류·앱 틀·대시보드·관리자)은 맨 아래 [앱 화면](#앱-화면) 절만 따른다. 그 위의 절은 모두 랜딩용이다.

## 디자인 원칙
1. 밝은 화면만 쓴다. 다크 모드는 만들지 않는다 **(사용자)**
2. 한 가지 색으로 통일하지 않는다. 섹션·카드마다 포인트 색을 달리해 생동감을 준다 **(사용자)**
3. 숫자가 움직여야 한다. 차트·숫자는 값에 따라 실제로 변하는 코드 애니메이션으로 보여 준다(영상·정지 그림 아님) **(사용자)**
4. AI와 개인정보 보호를 눈에 띄게 보여 준다. 개인정보 문구는 plan.md §4·§6에 정한 사실만 쓴다
5. PC 기준으로 설계하고, 폰은 보기 화면만 맞춘다(plan.md §3)

# 앱 화면

> 2026-10-29 사용자 승인. 배치: **시안 A** `docs/mockups/app-redesign/A.jpg`. 색: **블루 팔레트** `docs/mockups/app-redesign/palette-blue.html`(원본 https://claude.ai/artifact/759XodQPMJkyCHdQiRFLNK, 시안 A를 1:1로 다시 그린 화면이라 크기·간격 값도 이 파일이 기준). 폰 배치: "진료 기록지" 시안의 폰 화면(https://claude.ai/artifact/RRP5YUhtnXzc5cJRdmpCjV)을 블루 색으로 바꿔 쓴다.
> 문구·순서는 그대로 `docs/mockups/auth/*.dc.html`이 기준이다. 시안 속 병원 이름·숫자·파일·할 일은 모두 예시다.
> 스타일링은 Tailwind CSS v4(ADR-015). 토큰은 `src/app/globals.css`의 `@theme`, 반복 모양(단추·입력란·칩·패널·표)은 `src/components/ui/classes.ts`.
> 위 랜딩 절의 원칙 2(섹션마다 다른 포인트 색)·포인트 색 표·999px 단추·20px 카드·Space Grotesk는 앱 화면에 쓰지 않는다.

## 원칙
1. 밝은 화면만 쓴다 **(사용자)**
2. 색은 아낀다. 화면 대부분은 잉크 회색 글자와 1px 선이다. 강조색(파랑)은 아래 정해진 곳에만 쓴다
3. 데이터가 먼저다. 13~14px 글자, 4px 단위 간격, 36px 표 줄로 빽빽하게 (ERP 밀도)
4. 숫자는 고정폭 숫자(`tabular-nums`)이고 표에서는 오른쪽 정렬
5. 그림자는 떠 있는 층(계정 메뉴·툴팁·확인 창)에만. 제자리 덩어리는 1px 선으로 나눈다
6. 빈 상태는 조용하게: 패널 안 회색 안내 한두 줄 + 글자 단추 하나. 그림·큰 아이콘 없음
7. PC(1440px) 기준으로 설계하고, 폰(390px)은 보기 화면 + 44px 누름 영역

## 토큰 (`globals.css` `@theme`)
Tailwind 기본 색은 `--color-*: initial`로 지우고 아래만 둔다. 흰 글자는 `text-surface`.

| 토큰 | 값 | 쓰는 곳 |
|------|------|------|
| `ink` | `#111827` | 제목, 값, 표 값, 주 단추 바탕, 툴팁 바탕 |
| `ink-2` | `#374151` | 본문, 탭 글자, KPI 이름, 표 머리, 표의 보조 칸(규격·시각), 아이콘 |
| `muted` | `#6B7280` | 보조 글, 개수("총 6건"), 시각, 빈 값 "—", 대기 칩 글자 |
| `line` | `#E5E7EB` | 1px 선, 카드·패널·계정 단추 테두리, 표 줄 |
| `canvas` | `#F7F8FA` | 앱 바탕, 표 머리, 읽기 전용 칸, 올림(hover) 바탕 |
| `surface` | `#FFFFFF` | 위쪽 띠, 탭 띠, 카드·패널, 입력란 |
| `accent` | `#2563EB` | 아래 '강조색 쓰는 곳'만 |
| `accent-soft` | `#EAF1FE` | '진행중' 칩 바탕 |
| `ok` / `ok-soft` | `#166534` / `#E7F6EC` | 완료·승인됨 칩 |
| `danger` / `danger-soft` | `#C2410C` / `#FFF1E8` | 재고 3 이하 숫자, 거절됨 칩, 입력 오류, 오류 카드 |
| `warn` | `#B45309` | 재고 4~8 숫자 |

- **강조색 쓰는 곳**: 지금 탭(글자·밑줄), 초점 고리, 링크·글자 단추, 체크한 체크 상자, '진행중' 칩. 승인된 팔레트 화면은 지난주 대비 증감 숫자에도 썼다(통계 숫자가 들어올 때 쓴다). 이 밖에는 쓰지 않는다
- 범주 칩(구분)은 중립 회색이다. 범주마다 색을 달리하지 않는다
- 재고 숫자 색: 3 이하 `danger`, 4~8 `warn`, 굵기 600, 아래에 범례("재고 3 이하"·"재고 4~8"). 실제 기준(품목별 최소 수량, plan.md §2-5)은 재고 기능 명세에서 다시 정한다
- 입력란·체크 상자 테두리는 `muted`를 55% 섞은 값(`border-muted/55`, 팔레트 화면의 체크 상자와 같은 값)
- 대비(흰 바탕): ink 17.7:1, ink-2 10.3:1, muted 4.8:1, accent 5.2:1, danger 5.2:1, warn 5.0:1. 칩: accent/accent-soft 4.6:1, danger/danger-soft 4.7:1. **ok/ok-soft는 4.49:1로 4.5:1에 조금 못 미친다**(승인된 값 그대로 둠, 바꿀지는 사용자 결정)

## 모서리·선·그림자·간격
- 모서리 두 가지: `rounded-card` 6px(카드·패널·단추·입력란·계정 단추·계정 메뉴·확인 창), `rounded-chip` 4px(칩·툴팁·체크 상자)
- 선: 모두 1px `line`. 굵은 선은 지금 탭 밑줄(3px `accent`) 하나
- 그림자: `shadow-float` 하나(`0 1px 2px` + `0 6px 16px`, ink 6%·10%), 떠 있는 층에만. 확인 창 뒤 가림막은 ink 36%
- 간격: 4px 단위. 본문 좌우 24px(폰 16px), 덩어리 사이 16px(폰 12px), KPI 카드 사이 12px

## 앱 틀 (시안 A)
- **위쪽 띠**(화면 위에 붙어 따라옴): 흰 바탕, 아래 1px 선, 높이 64px, 좌우 24px. 왼쪽: 로고 마크 26px + `[서비스 이름]`(logo 600) · 세로 선(1px×22px) · 병원 이름(lead 500). 오른쪽: 한국 시각 "2026년 10월 29일 (목) 09:42 (KST)"(table, muted) · 계정 단추(높이 38px, 1px 선, 사람 아이콘 + 로그인한 구글 이메일 + 아래 화살표)

| 상태 | 모양 |
