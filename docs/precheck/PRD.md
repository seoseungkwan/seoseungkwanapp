# 청구 사전점검 PRD

양지바른 사전점검의 기능을 우리 앱으로 가져온다. 2026-10-30 grill-me 인터뷰에서 정한 내용이다.

- 상태: 초안. 명세(`/sdd`)는 전체를 한 번 쓰고 한 번만 승인받는다. 단계마다 승인받지 않는다 **(사용자)**.
- 문서 순서: 루트 `plan.md` → 이 문서(무엇을·왜) → 같은 폴더 `plan.md`(어떻게·순서)

## 1. 한 줄 요약
총괄이 비트 PC에서 우리 웹사이트 하나로 다음을 처리한다. 청구메모 점검·작성, 비트 자동 입력, 심평원 파일 대조, 환자 연락 명단, 통계 추가분. **양지바른은 켜지도 설치하지도 않는다.**

## 2. 왜 만드나 **(사용자)**
- **한 곳에서 모아 보려고.** 통계, 매출, 청구를 우리 앱 하나에서 본다.
- **독립적으로 쓰려고** ("양지바른 안켜도", "독립적으로 쓰고싶어"). 우리 앱이 양지바른 없이 혼자 돈다.
- **화면은 모두 새로 만든다** ("UI UX 싹다 바꿀거야"). 가져오는 것은 규칙과 계산뿐이다. 화면은 우리 앱 디자인(A 배치 + 블루)으로 만들고, 화면마다 목업을 승인받는다.

## 3. 누가 · 어디서 · 언제 **(사용자)**
- **총괄 한 사람이 쓴다.** 직원 계정이나 권한 나누기는 만들지 않는다(루트 `plan.md §0` 원칙 1).
- **비트 PC에서** 청구와 환자 연락을 한다. **집과 휴대폰에서는** 통계, 건수, 설정만 본다.
- **청구메모는 며칠에 한 번 모아서** 한다.

## 4. 가져오는 것 **(사용자)**

| 묶음 | 기능 |
|---|---|
| 청구 | **삭감 예방 사전점검**: 규칙 262개, 고시 근거, 규칙별·환자별 엑셀 · **청구메모 문장 만들기** · **추천 상병·상병 확인** · **심평원 청구 파일(SAM) 대조·월말 마감** · **비트 자동 입력**(꼭 된다: "비트 자동입력되어야해") |
| 환자 연락 | **F/U 목록** · **정기 주사 문자 명단** · **문자 문구**(고치고 복사만 한다. 자동 발송은 없음) |

## 5. 빼는 것 **(사용자)**
- 팀장 도구(아침 브리핑, 법정 점검·교육, 재고·유효기간, 근무·연차, 일일 마감·목표, 치료 회차)
- 구매·운영(쿠팡 구매, 개원·운영 체크리스트, 업체·장비·매뉴얼)
- 지식·안내(고시 검색, 원무 안내 30편, 정책 소식)
- 원장님 잠금, 원격 접속 PC 목록, 자리 비움 잠금
- **비상용 화면.** 인터넷이나 서버가 멈추면 돌아올 때까지 기다린다.

## 6. 쓰는 흐름

### 6-1. 처음 한 번 준비
1. 비트 PC에 우리 **크롬 확장 프로그램**과 **도우미**를 설치한다.
2. 우리 앱에 로그인하고, [연결 확인]으로 비트를 읽을 수 있는지 본다.

### 6-2. 청구메모 (며칠에 한 번)
1. 청구 화면을 연다. **아직 입력이 안 된 날짜가 먼저** 보인다. 진료가 없는 날은 나오지 않는다.
2. 기간을 고르고 [자료 불러오기]를 누른다. 도우미가 비트에서 한 달 자료와 12개월 이력을 읽어 온다.
3. 환자마다 점검 경고(확인 필요·알림·참고)와 고시 근거, 추천 상병, 메모 초안을 본다. 고친 내용은 곧바로 PC에 저장되므로, 창을 닫아도 이어서 할 수 있다.
4. [비트에 입력]을 누르면 **PC 확인 창**이 뜬다. 예: "10/27~10/29, 32명 입력할까요?" [확인]을 눌러야 입력된다.
5. 결과는 완료, 확인 필요, 건너뜀(이유 포함)으로 나온다. 건너뛴 것만 [다시 하기]로 다시 입력할 수 있다.

### 6-3. 월말 마감
심평원 청구 파일을 불러와 메모와 대조한다. 미완료, 빠진 것, 확인 표시가 남은 것을 모아 보고 고친다.

### 6-4. 환자 연락
F/U 목록과 정기 주사 문자 명단을 본다. 문자 문구를 복사해서 보내고 연락했다고 표시한다.

### 6-5. 밖(집·휴대폰)에서 보기
- **날짜별 메모 입력 현황**, **월말 마감 남은 일**, **연락 남은 건수**, 이 세 가지를 건수로만 본다. 마지막으로 바뀐 시각을 함께 보여 준다.
- 삭감 위험 경고와 환자 자료는 보이지 않는다.

### 6-6. 설정 바꾸기
점검 규칙 켜기·끄기·등급, 병원 문구, 문자 문구를 바꾼다. 설정은 서버에 있으므로 휴대폰에서도 바꿀 수 있다. 작업 중에 바뀌면 "설정이 바뀌었어요, 다시 점검하세요"를 띄운다.

## 7. 지킬 원칙
- **환자 정보는 의원 PC 밖으로 나가지 않는다**(루트 `plan.md §0` 원칙 3). 서버에는 6-5의 건수와 6-6의 설정만 간다.
- **비트 입력은 PC 확인 창을 거친다** **(사용자)**. 웹 코드가 잘못되거나 해킹돼도 몰래 입력되지 않게 하기 위해서다.
- **점검 규칙의 원본은 우리 앱이다** **(사용자)**. 고시가 바뀌면 우리 앱에서만 고친다.
- **같은 환자를 두 번 입력하지 않는다.** 입력 전에 비트에 이미 들어간 메모와 비교한다. 손으로 넣어 둔 메모가 있으면 "이미 있음"으로 건너뛴다.

## 8. 잘 안 될 때 (Claude 판단)

| 상황 | 화면 |
|---|---|
| 도우미나 확장이 없거나 꺼짐 | 설치·연결 안내 |
| 비트 자료가 일부만 옴 | 점검을 멈추고 "다시 불러오세요". 반쪽 자료로 점검하지 않는다 |
| 입력 도중 멈추거나 PC가 꺼짐 | 다시 열면 이어서 한다. 비트와 비교해 이미 들어간 것은 건너뛴다 |
| 비트 화면이 바뀜(비트 업데이트) | 자동 입력을 멈추고 이유를 보여 준다 |
| 로그인 만료 | 다시 로그인하면 이어서 한다(고치던 내용은 PC에 있음) |
| 서버가 잠깐 안 됨 | 건수는 나중에 다시 올린다. 설정은 마지막으로 받은 것을 쓴다 |
| 청구 화면을 창 두 개로 엶 | 두 번째 창은 "다른 창에서 작업 중"으로 막는다 |
| 도우미 버전이 웹과 안 맞음 | "도우미를 업데이트하세요" |
| 달을 넘기는 기간(10/30~11/2) | 고를 수 있다. 월말 마감은 달마다 따로 한다 |
| 인터넷이나 서버가 멈춤 | 기다린다(비상용 없음) |
