# 매출 탭 의원 PC 확인표

> 총괄님이 의원 PC에서 직접 보고 적는 표예요. 두 번에 나눠 해요.
> - **먼저 할 것**: 앱 없이 비트 화면만 봐요(5~10분). ①은 끝났고, ②·③은 의원 PC에서 시간 될 때 적어요.
> - **매출 탭에서 볼 것**: 매출 탭이 다 만들어지면 의원 PC에서 해요. 처음 가져오기에 걸린 시간(③)은 매출 탭을 처음 열 때 재고, 나머지는 숫자가 보인 뒤에 봐요.
>
> 빈 칸에는 예/아니오·같음/다름, 처방 코드 글자, 비트 화면·칸 이름, 본 달, 분·날 수만 들어가요. 금액을 적는 칸은 없어요.

## 1. 먼저 할 것 (앱 없이, 비트 화면만, 5~10분)
①은 끝났고, ②·③은 의원 PC에서 시간 될 때 적어요. 비어 있어도 매출 탭을 만드는 일을 막지 않아요.

### ① 총진료비가 세 금액을 더한 값인가요
비트 **외래환자경영통계**의 **어제 하루** 화면으로 확인해 답을 받았어요. 더 할 일은 없어요. 금액은 적지 않아요.

| 확인할 것 | 예/아니오 |
|---|---|
| 총진료비 = 조합청구액(공단부담금) + 본인부담금 + 비급여 | 아니오 (2026-11-01 확인) |

### ② 치료 다섯 가지의 처방 코드
이 의원 비트에서 치료마다 처방 코드를 봐요. 아래 글자가 든 코드면 '같음', 아니면 '다름'이에요. 매출 탭에 처음 보이는 제안 묶음에만 쓰여서, 달라도 치료 묶음 고치기 화면에서 고칠 수 있어요.

| 치료 | 이 글자가 든 코드 | 같음/다름 | 다르면 이 의원 코드 글자 |
|---|---|---|---|
| 도수치료 | `도수` | | |
| 체외충격파 | `ESWT` | | |
| C-arm 주사 | `CARM1` | | |
| 초음파 | `SONO1` | | |
| 냉동치료 | `CRYO` | | |

### ③ 미수발생·지역화폐가 보이는 곳
업무일지를 비트 숫자로 채우려고 찾아요. 금액이 보이는 비트 화면 이름과 칸 이름만 적어요. 못 찾으면 '못 찾음'이라고 적어요.

| 무엇 | 비트 화면 이름 | 칸 이름 |
|---|---|---|
| 미수발생 | | |
| 지역화폐 | | |

## 2. 매출 탭에서 볼 것 (③은 매출 탭을 처음 열 때, 나머지는 숫자가 보인 뒤)
의원 PC에서 매출 탭을 처음 열기 전에 시계를 봐 두세요. ③은 처음 가져오기에 걸린 시간이에요. 의원 PC에서 탭을 열면 가져오기가 저절로 시작되고, 다시 잴 수 없어요. 그래프가 그려지면 다시 시계를 보고 걸린 분을 ③ 칸에 적어요.

- 폰이나 비트에 연결되지 않은 PC에서 먼저 봐도 가져오기는 시작되지 않아요. ③은 그대로 잴 수 있어요.
- 새 버전을 깔라는 안내가 나오면 먼저 깔고, 시계를 본 뒤 다시 열어요.

숫자가 보이면 매출 탭과 비트 화면을 나란히 열고 나머지 칸을 봐요.

### ①·⑤를 볼 달('본 달') 고르기
매출 합계에는 '확인 필요한 날'의 금액이 빠지고, 공단부담·비급여와 급여·비급여·기타에는 '나눔을 못 한 날'의 금액도 빠져요. 그래서 그런 날이 있는 달은 칸이 맞아도 비트와 달라 보여요. 아래 순서로 본 달을 골라요.

1. 매출 탭에서 달을 ‹ ›로 지난달부터 거꾸로 넘기며(최근 13달 안에서) '확인 필요한 날'이 '없음'이고 급여·비급여·기타 덩어리에 '나눔을 못 해서' 안내가 없는 달을 찾아요. 이번 달과 '자료 없음'인 달은 빼요. 그 달이 본 달이고, 비트 외래환자경영통계를 그 달 1일부터 말일까지로 열어요. 그런 달이 여럿이면 건강생활유지비가 0원이 아닌 달을 고르면 더 좋아요. 어느 달로 봤는지 아래 표에 달만 적어요.
2. 그런 달이 없으면 끝났고 숫자가 있는 달 가운데 두 가지 날('확인 필요한 날'과 '나눔을 못 한 날')을 합쳐 가장 적은 달을 본 달로 골라요. 그 달도 합쳐 5일을 넘으면 더하지 말고 3으로 가요. 그 날들을 뺀 나머지 기간을 비트에서 하나씩 열어 칸마다 계산기로 더해 매출 탭과 견줘요. 매출은 '확인 필요한 날'만 빼고, 공단부담·비급여·급여·기타는 두 가지 날을 모두 빼요. 그래서 매출과 나머지 칸은 따로 열어요(예: 14일이 확인 필요, 5일이 나눔 못 함이면 매출은 1일~13일과 15일~말일, 나머지 칸은 1일~4일과 6일~13일과 15일~말일). 나눔을 못 한 날의 날짜는 급여·비급여·기타 덩어리의 안내에 있어요. 더한 금액도 어디에도 적지 않아요.
3. 그 달도 두 가지 날을 합쳐 5일을 넘거나 끝났고 숫자가 있는 달이 하나도 없으면 더하지 말고 ①의 공단부담·비급여와 ⑤ 첫째 줄을 '다름'으로, 본 달을 '없음'으로 적고 ①의 매출 줄과 ⑤ 둘째 줄은 비운 채 Claude에게 알려 주세요. 금액을 읽는 칸의 뜻이 틀렸을 수 있다는 표시예요. 매출은 그 뜻이 틀려도 맞아야 하는 칸이라 '다름'으로 적지 않아요. 어디를 볼지는 Claude가 말로 알려 줘요.

①·⑤의 '같음'은 만 원 자리까지 같다는 뜻이에요. 매출 탭은 만 원 아래를 버려 보여 주니까 비트 금액도 만 원 아래를 버리고 견줘요.

| 확인할 것 | 적는 것 | 결과 |
|---|---|---|
| 본 달 | 달만 (없으면 '없음') | |

### 표에 적기

| 확인할 것 | 매출 탭에서 볼 곳 | 비트에서 볼 곳 | 같음/다름 |
|---|---|---|---|
| ① 본 달 매출 | 매출 추이의 본 달 | 외래환자경영통계의 총진료비 | |
| ① 본 달 공단부담 | 급여·비급여·기타의 공단부담 | 외래환자경영통계의 조합청구액 | |
| ① 본 달 비급여 | 급여·비급여·기타의 비급여 | 외래환자경영통계의 비급여 | |
| ② 지난달 환자 수 | 환자 1인당 평균 진료비의 환자 수 | 비트 통계의 실인원 | |

- 다르면 '다름'만 적고 금액은 적지 않은 채 Claude에게 알려 주세요. Claude는 그 화면을 볼 수 없고 사진도 보내지 않으니까, 어느 칸을 볼지 Claude가 말로 알려 줘요.
- ② 환자 수는 확인 필요한 날도 세니까 지난달 그대로 봐요. 매출 탭의 달을 지난달로 돌려 놓고, 비트 외래환자경영통계는 **지난달 1일부터 말일까지**로 열어요.

| 확인할 것 | 매출 탭에서 볼 곳 | 적는 것 | 결과 |
|---|---|---|---|
| ③ 처음 가져오기에 걸린 시간 | 가져오기('13달 가운데 n달')가 시작된 때부터 숫자가 보일 때까지 | 분 | |
| ④ 확인 필요한 날 (지난달) | 매출 추이의 '확인 필요한 날' | 날 수 | |
| ④ 확인 필요한 날 (그 전 달) | 매출 추이의 '확인 필요한 날' | 날 수 | |
| ④ 확인 필요한 날 (그 전전 달) | 매출 추이의 '확인 필요한 날' | 날 수 | |

- 확인 필요한 날이 많으면(한 달에 5일 넘게) Claude에게 알려 주세요. 직접 입력 칸을 다시 의논해요.

⑤를 보기 전에 매출 탭과 비트를 모두 **본 달**로 되돌려요.

- 본 달을 '본 달 고르기' 2번으로 골랐으면 비트는 1일~말일이 아니라 2번의 '나머지 칸' 기간으로 하나씩 열어 칸마다 계산기로 더해요. 매출 탭의 급여·비급여·기타에는 그 날들이 이미 빠져 있어서, 1일~말일로 열면 칸이 맞아도 '다름'으로 나와요.
- 이때 ⑤ 둘째 줄의 건강생활유지비도 같은 기간으로 봐요. 연 기간 가운데 하나라도 0원이 아니면 '예'예요.
- 본 달이 '없음'이면 ⑤는 3번에 적은 대로 두고 다음으로 넘어가요.

| 확인할 것 | 매출 탭에서 볼 곳 | 비트에서 볼 곳 | 결과 |
|---|---|---|---|
| ⑤ 첫째 줄: 본 달 급여·비급여·기타 (같음/다름) | 급여·비급여·기타의 세 칸 | 외래환자경영통계의 요양비용총액·비급여·(100/100미만총액 + 전액본인부담) | |
| ⑤ 둘째 줄: 본 달 건강생활유지비가 0원이 아닌가요 (예/아니오) | 비트만 봐요 | 외래환자경영통계의 건강생활유지비 | |

- 첫째 줄의 기타는 100/100미만총액과 전액본인부담 두 칸을 계산기로 더해 견줘요. 이번에 새로 맞춘 계산이라 비트와 같은지 확인해요. 셋 가운데 하나라도 다르면 '다름'이에요.
- 둘째 줄은 0원이 아니면 '예', 0원이면 '아니오'. 금액은 적지 않아요.
- 현금·카드·계좌이체·미수입금·신환·재진은 매출 탭에 없어요. 업무일지 탭의 확인표(업무일지 4단계)에서 맞춰 봐요.

## 3. 적는 것과 적지 않는 것
- 예/아니오·같음/다름, 다를 때의 처방 코드 글자(먼저 할 것 ②), 비트 화면·칸 이름(먼저 할 것 ③), 본 달, 걸린 시간·날 수만 적어요. 금액과 환자 정보는 적지 않아요.
- 환자 이름·차트번호는 어디에도 적지 않아요. 비트 화면을 사진으로 찍거나 복사해서 보내지 않아요.

---

결과를 다 적으면 Claude에게 **"매출 확인표 다 했어"**라고 말하면 돼요.
