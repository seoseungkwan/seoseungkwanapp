# 매출 탭 의원 PC 확인표

> 총괄님이 의원 PC에서 직접 보고 적는 표예요. 두 번에 나눠 해요.
> - **먼저 할 것**: 앱 없이 비트 화면만 봐요(5~10분). 매출 탭의 계산을 만들기 전에 해 주세요.
> - **매출 탭에서 볼 것**: 매출 탭이 다 만들어져 의원 PC에서 숫자가 보인 뒤에 해요.
>
> 빈 칸에는 예/아니오·같음/다름·분·날 수만 들어가요. 금액을 적는 칸은 없어요.

## 1. 먼저 할 것 (앱 없이, 비트 화면만, 5~10분)

### ① 총진료비가 세 금액을 더한 값인가요
비트 **외래환자경영통계**를 **어제 하루**로 열어요. 화면의 총진료비·조합청구액(공단부담금)·본인부담금·비급여를 봐요.

| 확인할 것 | 예/아니오 |
|---|---|
| 총진료비 = 조합청구액(공단부담금) + 본인부담금 + 비급여 | 아니오 (2026-11-01 확인) |

- 계산기로 더해 보고 예/아니오만 적어요. 금액은 적지 않아요.
- 이 답을 Claude에게 알려 주시면 매출 탭의 급여 계산 방법이 정해져요.

### ② 치료 다섯 가지의 처방 코드
이 의원 비트에서 치료마다 처방 코드를 봐요. 아래 글자가 든 코드면 '같음', 아니면 '다름'이에요.

| 치료 | 이 글자가 든 코드 | 같음/다름 | 다르면 이 의원 코드 글자 |
|---|---|---|---|
| 도수치료 | `도수` | | |
| 체외충격파 | `ESWT` | | |
| C-arm 주사 | `CARM1` | | |
| 초음파 | `SONO1` | | |
| 냉동치료 | `CRYO` | | |

### ③ 미수발생·지역화폐가 보이는 곳
업무일지를 비트 숫자로 채우려고 찾아요. 금액이 보이는 비트 화면 이름과 칸 이름만 적어요. 못 찾으면 '못 찾음'이라고 적어요.

| 무엇 | 비트 화면 이름 | 칸 이름 |
|---|---|---|
| 미수발생 | | |
| 지역화폐 | | |

## 2. 매출 탭에서 볼 것 (매출 탭이 숫자를 보인 뒤)
의원 PC에서 매출 탭과 비트 화면을 나란히 열고 봐요. 비트 외래환자경영통계는 **지난달 1일부터 말일까지**로 열어요.

| 확인할 것 | 매출 탭에서 볼 곳 | 비트에서 볼 곳 | 같음/다름 |
|---|---|---|---|
| ① 지난달 매출 | 매출 추이의 지난달 | 외래환자경영통계의 총진료비 | |
| ① 지난달 공단부담 | 급여·비급여의 공단부담 | 외래환자경영통계의 조합청구액 | |
| ① 지난달 비급여 | 급여·비급여의 비급여 | 외래환자경영통계의 비급여 | |
| ② 지난달 환자 수 | 환자 1인당 평균 진료비의 환자 수 | 비트 통계의 실인원 | |

- 다르면 '다름'만 적고 금액은 적지 않아요. 차이는 Claude와 화면을 함께 보며 찾아요.
- '확인 필요한 날'이 있으면 그날 금액이 빠져서 '다름'이 나올 수 있어요. 그래도 '다름'만 적으면 돼요.

| 확인할 것 | 매출 탭에서 볼 곳 | 적는 것 | 결과 |
|---|---|---|---|
| ③ 처음 가져오기에 걸린 시간 | '13달 가운데 n달'이 13달이 될 때까지 | 분 | |
| ④ 확인 필요한 날 (지난달) | 매출 추이의 '확인 필요한 날' | 날 수 | |
| ④ 확인 필요한 날 (그 전 달) | 매출 추이의 '확인 필요한 날' | 날 수 | |
| ④ 확인 필요한 날 (그 전전 달) | 매출 추이의 '확인 필요한 날' | 날 수 | |

- 확인 필요한 날이 많으면(한 달에 5일 넘게) Claude에게 알려 주세요. 직접 입력 칸을 다시 의논해요.
- 현금·카드·계좌이체·미수입금·신환·재진은 매출 탭에 없어요. 업무일지 탭의 확인표(업무일지 4단계)에서 맞춰 봐요.

## 3. 적는 것과 적지 않는 것
- 예/아니오·같음/다름, 다를 때의 처방 코드 글자(먼저 할 것 ②), 비트 화면·칸 이름(먼저 할 것 ③), 걸린 시간·날 수만 적어요. 금액과 환자 정보는 적지 않아요.
- 환자 이름·차트번호는 어디에도 적지 않아요. 비트 화면을 사진으로 찍거나 복사해서 보내지 않아요.

---

결과를 다 적으면 Claude에게 **"매출 확인표 다 했어"**라고 말하면 돼요.
