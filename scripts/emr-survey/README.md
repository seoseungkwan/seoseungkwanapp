# EMR 폴더 조사 도구 (emr-survey)

의사랑·이지스 같은 EMR이 PC 안 어느 폴더에 어떤 파일을 두는지 **모양만** 알아보는 도구다.
폴더를 **읽기만** 하고, 실제 파일 이름과 환자 값은 보고서에 적지 않는다. 결과 보고서를 보고 그 EMR을 어떤 길로 붙일지 정한다(`docs/emr/README.md`).

- 요구사항: `specs/emr-choice/requirements.md` REQ-7105, 설계: `design.md` 7절
- 필요한 것: 윈도우 PowerShell 5.1(윈도우 10·11에 기본으로 있음). 따로 설치할 것 없음

## 쓰는 법

1. `emr-survey.ps1`을 그 PC의 아무 곳(예: 바탕화면)에 둔다. **조사할 EMR 폴더 안에는 두지 않는다.**
2. 시작 메뉴에서 'PowerShell'을 열고 파일을 둔 곳으로 간다(예: `cd $HOME\Desktop`).
3. 조사할 폴더를 주고 실행한다.

```powershell
powershell -ExecutionPolicy Bypass -File emr-survey.ps1 -Path "C:\조사할\EMR폴더"
```

- 보고서는 바탕화면에 `emr-survey-YYYYMMDD-HHmm.txt`로 생기고 화면에도 나온다.
- 다른 곳에 두려면 `-Out "D:\emr-survey.txt"`를 붙인다. 보고서 자리는 조사하는 폴더 **밖**이어야 한다(안이면 '보고서를 조사하는 폴더 안에 쓸 수 없어요'로 멈춘다).
- 폴더가 없으면 '폴더를 찾지 못했어요'로 멈춘다. 두 경우 모두 아무것도 쓰지 않는다.
- 파일이 많으면 몇 분 걸릴 수 있다(20만 개, 폴더 깊이 8단계까지만 본다).
- 보안 프로그램이 스크립트를 막으면(빨간 글 '실행할 수 없습니다' 등) 그 PC 관리자·보안 업체에 물어본다. 설정을 억지로 끄지 않는다.
- Access 칸이 '드라이버 없음'이면 32비트 PowerShell(`C:\Windows\SysWOW64\WindowsPowerShell\v1.0\powershell.exe`)로 같은 명령을 한 번 더 돌려 본다.

## 읽는 것

- 폴더 전체: 파일 수·크기 합·하위 폴더 수·가장 최근 고친 시각
- 확장자별 묶음: 개수·크기 합·가장 최근 고친 시각(많은 차례). 정해 둔 확장자 목록에 있거나 10개 이상 파일에 있는 확장자만 그대로 적고, 나머지는 '(그 밖 확장자)'로 센다
- 파일 앞 바이트로 알아본 종류: SQLite·Access/Jet·DBF·ZIP(xlsx 등)·OLE2(xls 등)·SQL Server 데이터 파일·글자 파일·모름
- 이름 모양(많은 차례 30개): 확장자만 그대로 두고 숫자는 9, 한글은 가, 영문은 a, 그 밖 글자는 x로 바꾼 것(예: `가가가_99999999.jpg`)
- 표 모양 파일(종류마다 가장 최근 5개)의 **칸 이름**: DBF 머리 칸, CSV·TXT 첫 줄, XLSX 시트 이름과 첫 시트 첫 줄, SQLite 파일 안 표·칸 이름, Access 표·칸 이름(임시 폴더에 복사본을 만들어 읽고 바로 지움)
- 이 PC에 설치된 SQL Server 서비스 이름과 상태(켜져 있음·꺼져 있음)

## 읽지 않는 것

- 둘째 줄부터의 값(환자 이름·차트번호·전화 등). 첫 줄도 값처럼 보이면(숫자 3자 이상, 칸 이름 낱말이 아닌 한글) 칸 수와 모양만 적는다
- 실제 파일 이름·폴더 이름(모양만 적는다)
- 파일 전체: 앞부분만 읽는다(보통 64KB, SQLite는 2MB까지, XLSX는 20MB 이하만)
- SQL Server에 붙지 않는다(서비스 이름만 본다). 비밀번호·접속 정보도 찾지 않는다
- 폴더 안에는 아무것도 쓰거나 고치거나 지우지 않는다. 파일은 다른 프로그램과 함께 열기로 열어서 EMR이 켜져 있어도 방해하지 않는다

## 보내기 전에 꼭

보고서는 그 PC 밖으로 보내도 되게 만들었지만, **보내기 전에 한 번 훑어본다.**

- 칸 이름은 영문·숫자·밑줄로만 된 이름(30자 이하)과 정해 둔 한글 낱말(환자·성명·차트·접수 등)로 된 이름만 그대로 나온다.
- 한계: 영문만으로 된 값(사람 이름을 로마자로 쓴 것 등)이 첫 줄에 있으면 칸 이름처럼 보여 그대로 나올 수 있다. **영문 이름처럼 보이는 칸이 있으면 그 부분을 지우고 보낸다.**
- '조사한 폴더' 줄에는 실행할 때 준 경로가 그대로 나온다.

## 결과로 다음에 할 일

1. 보고서를 보며 `docs/emr/README.md` 5장 **체크리스트**(나. 폴더, 다. DB, 라. 자료 칸 찾기)를 채운다.
2. 같은 문서 4장 표(폴더에서 본 것 → 먼저 할 길)로 길을 고른다.
   - CSV·XLSX·TXT 내보내기 파일이 보이면 → 브라우저 폴더 읽기
   - SQLite·Access·DBF·SQL Server 데이터 파일이 보이면 → 도우미가 읽는 길
   - 모름(알아볼 수 없는 형식)이 대부분이면 → 업체에 내보내기 메뉴·허락을 묻는다
3. 같은 문서 6장 **만들 때 순서**대로 만든다(파일 내보내기 읽기 → 브라우저 폴더 읽기 → 도우미 읽기). 시험에는 칸 이름만 본뜬 가짜 파일을 `fixtures/`에 만들어 쓴다. 실제 환자 파일은 커밋하지 않는다.
