# 청구 사전점검 도우미 설치 안내

이 프로그램은 크롬의 청구 사전점검 화면이 비트(DrBIT)와 이야기할 수 있게 이어 주는 작은 도우미입니다.
비트가 깔린 PC에 한 번 설치하면 됩니다. **관리자 권한은 필요 없습니다.**

같은 설치로 **접수 현황**(직원 휴대폰에서 비트 접수 상태를 보는 화면)도 함께 깔리고 켜집니다.
아래 **접수 현황** 칸을 꼭 한 번 읽어 주세요.

## 설치하기

1. 받은 `precheck-helper-<버전>.zip` 파일을 오른쪽 클릭 → **모두 압축 풀기**를 누릅니다.
   (zip을 열기만 하고 안에서 바로 누르면 설치되지 않습니다. 꼭 풀어 주세요.)
2. 푼 폴더에서 `install.cmd`를 두 번 누릅니다.
3. 파란 창 **"Windows의 PC 보호"**(SmartScreen)가 뜨면 **추가 정보** → **실행**을 누릅니다.
   서명하지 않은 프로그램이라 처음 한 번 이 경고가 뜹니다.
4. 검은 창에 **"도우미를 설치했습니다."**가 보이면 끝입니다. 엔터를 누르면 창이 닫힙니다.
5. 처음 설치하면 설치 중이나 끝난 뒤 **"Windows 보안 경고"** 창이 뜹니다. **개인 네트워크**에 체크하고 **[허용]**을 누릅니다.
   (아래 **접수 현황 → 처음 한 번: 방화벽 창**)

**크롬을 다시 켤 필요는 없습니다.** 열어 둔 청구 화면이 있으면 새로고침(F5)만 하세요.

## 새 버전으로 바꾸기

새 zip을 받아 위와 같은 순서로 설치합니다. 켜져 있던 도우미와 접수 현황은 설치가 알아서 끄고 새것으로 바꾼 뒤,
접수 현황을 다시 켭니다. 그동안 몇 초 직원 휴대폰에 "지금 볼 수 없어요"가 나왔다가 저절로 돌아옵니다.

- 고치던 메모·완료 표시는 그대로 남습니다.
- **비트 자동 입력이 돌고 있을 때는 설치하지 마세요.** 설치가 도우미를 끄기 때문에 입력이 중간에 멈춥니다.
  입력이 끝난 뒤 크롬의 청구 화면을 닫고 설치하세요.

## 접수 현황 (직원 휴대폰 화면)

접수 현황은 이 PC(총괄 PC)가 비트의 오늘 접수 상태를 읽어, **병원 와이파이**에 연결된 직원 휴대폰·태블릿에 보여 주는 프로그램입니다.
인터넷이나 우리 웹사이트로는 아무것도 보내지 않습니다. 휴대폰 화면은 **5초마다** 저절로 바뀝니다.

### 켜기·끄기

- **켜기**: 설치하면 바로 켜지고, 앞으로 이 PC에 윈도우로 로그인하면 **저절로 켜집니다**. 따로 누를 것은 없습니다.
  창이 뜨지 않는 프로그램이라 화면에 아무것도 안 보여도 켜져 있습니다.
- 비트에 아직 로그인하지 않았거나 비트 자료를 읽을 수 없으면 휴대폰에 "지금 볼 수 없어요"가 나옵니다. 읽을 수 있게 되면 저절로 다시 나옵니다.
- 꺼진 것 같으면 바탕 화면의 **접수 현황 주소**를 누릅니다. 꺼져 있었으면 다시 켜집니다.
- **잠깐 끄기**: `Ctrl`+`Shift`+`Esc`로 **작업 관리자**를 열고 → **세부 정보** → `PrecheckReception.exe`를 오른쪽 클릭 → **작업 끝내기**.
  다시 켜려면 바탕 화면의 **접수 현황 주소**를 누르거나, 윈도우에 다시 로그인합니다.
- **로그인할 때 켜지지 않게 하기**: 윈도우 **설정 → 앱 → 시작 프로그램**에서 `PrecheckReception`을 끕니다.
- **아예 없애기**: 아래 **지우기**를 합니다. 접수 현황도 함께 지워집니다.

### 처음 한 번: 방화벽 창

- 접수 현황이 처음 켜질 때 **"Windows 보안 경고"** 창이 뜨면 **개인 네트워크**에 체크하고 **[허용]**을 누릅니다.
  이것을 눌러야 직원 휴대폰이 이 PC의 접수 현황을 열 수 있습니다.
  이어서 "변경을 허용하시겠어요?" 같은 확인 창이 뜨면 **[예]**를 누릅니다.
- 이 PC의 네트워크가 **공용**으로 되어 있으면 휴대폰에서 열리지 않습니다. **개인**으로 바꿉니다:
  윈도우 **설정 → 네트워크 및 인터넷** → 연결된 와이파이(또는 이더넷) → **네트워크 프로필 유형**을 **개인 네트워크**로 고릅니다.
  바꾼 뒤 휴대폰에서 다시 열어 봅니다.

### 처음 한 번: 이 PC 주소 고정

- 공유기 관리 화면에서 이 PC의 주소를 고정합니다. 메뉴 이름은 공유기마다 다릅니다: **DHCP 예약**, **고정 IP 할당**, **수동 IP 할당**.
- 고정하지 않으면 공유기가 이 PC 주소를 바꿀 수 있고, 그러면 직원 휴대폰 홈 화면 아이콘이 열리지 않습니다.
- 공유기 관리 화면에 들어가는 법을 모르면 공유기 이름(모델)을 알려 주세요. 순서를 알려 드립니다.

### 처음 한 번: 직원 휴대폰에 열기

1. 이 PC 바탕 화면의 **접수 현황 주소**를 누릅니다. 브라우저에 "접수 현황 주소 보내기" 화면이 열립니다.
2. **[주소 복사]**를 누릅니다. 단추 글이 "복사했어요"로 바뀌면 됩니다.
3. **직원 단톡방**(카카오톡)에 붙여 넣어 보냅니다.
4. 직원은 휴대폰을 **병원 와이파이**에 연결한 채로 단톡방의 주소를 누릅니다.
5. 카카오톡 안에서 열리면 **오른쪽 위 메뉴** → **다른 브라우저로 열기**를 누릅니다.
6. 열린 브라우저에서 **홈 화면에 추가**합니다.
   - 아이폰(사파리): 아래 공유 단추 → **홈 화면에 추가**
   - 갤럭시: 메뉴 → **홈 화면에 추가**
7. 다음부터는 휴대폰 홈 화면의 아이콘만 누르면 열립니다.

이 주소는 병원 와이파이 안에서만 열립니다. 밖에서는 열리지 않아 환자 정보가 보이지 않습니다.

### 알림 소리: 화면을 한 번 눌러 주세요

- 접수 현황 화면을 열면 아무 곳이나 **한 번 누릅니다**.
- **아이폰은 처음 한 번 화면을 눌러야 새 접수 알림 소리가 납니다.** 갤럭시도 한 번 눌러야 진동이 옵니다.

### 꼭 지켜 주세요: 잠금이 없습니다

- 접수 현황에는 **비밀번호(잠금)가 없습니다.** 직원 와이파이에 들어온 기기면 누구나 환자 이름과 접수 상태를 볼 수 있습니다.
- 그래서 **직원 와이파이 비밀번호를 손님(환자)에게 알려 주면 안 됩니다.** 손님용 와이파이가 따로 있으면 그것을 알려 주세요.

### 설치 뒤 한 번: 비트가 느려지지 않는지 보기

휴대폰이 5초마다 새로 읽을 때 접수 PC의 비트가 느려지지 않는지 이 의원 PC에서 직접 봐야 합니다.

1. 진료 시간에 직원 휴대폰 **두 대 이상**에 접수 현황을 열어 두고(지금 **5초**마다 바뀝니다) **30분쯤** 둡니다.
2. 그동안 **접수 PC의 비트가 느려지지 않는지** 봅니다(접수·수납 화면이 평소처럼 빨리 넘어가는지).
3. 느려지지 않으면 알려 주세요. **3초**마다 바뀌는 판으로 바꿔 드리면, 같은 방법으로 한 번 더 30분쯤 봅니다.
4. 어느 때든 느려지면 바로 알려 주세요. 간격을 다시 늘립니다. 그동안 휴대폰의 접수 현황 화면을 모두 닫아 두면 비트를 읽지 않습니다.

### 잘 안 될 때 (접수 현황)

- 휴대폰에서 안 열리면 차례로 봅니다.
  1. 휴대폰이 **병원 와이파이**에 연결되어 있나요? (데이터나 손님용 와이파이로는 열리지 않습니다)
  2. 이 PC가 켜져 있고 윈도우에 로그인되어 있나요?
  3. 방화벽 창에서 **개인 네트워크**에 **[허용]**을 눌렀고, 이 PC 네트워크가 **개인**인가요?
  4. 공유기에 **기기끼리 막기**(무선 격리·AP 격리라고도 합니다)가 켜져 있으면 끕니다.
  5. 이 PC 주소가 바뀌었으면 바탕 화면 **접수 현황 주소**를 다시 눌러 새 주소를 보내고, 홈 화면에 다시 추가합니다.
- 방화벽 창을 그냥 닫았거나 **[취소]**를 눌렀으면: 시작 단추에서 "방화벽"을 찾아 **Windows Defender 방화벽을 통해 앱 또는 기능 허용** →
  **설정 변경** → 목록의 `PrecheckReception`에서 **개인**에 체크 → **확인**.
- 바탕 화면 **접수 현황 주소**를 눌렀는데 브라우저가 안 열리면, 브라우저 주소 칸에 `http://127.0.0.1:47200/link`를 넣어 봅니다.
- 그래도 안 되면 그 화면을 사진으로 찍어 보내 주세요.

## 지우기

1. 파일 탐색기 주소 칸에 `%LOCALAPPDATA%\Seoseungkwan\PrecheckHelper`를 넣고 엔터를 누릅니다.
2. 그 폴더의 `uninstall.ps1`을 오른쪽 클릭 → **PowerShell에서 실행**을 누릅니다.
   (윈도우 11에서는 오른쪽 클릭 → **더 많은 옵션 표시** 안에 있습니다.)
3. **"고치던 메모·완료 표시가 지워집니다. 지울까요?"**라고 물으면
   - 다 지우려면 `Y`를 누르고 엔터
   - 남겨 두려면 그냥 엔터 (다시 설치하면 이어서 쓸 수 있습니다)

지우기는 켜져 있던 접수 현황도 끄고, 로그인 때 켜는 **시작 항목**과 바탕 화면의 **접수 현황 주소**도 지웁니다.

## 어디에 설치되나요 (참고)

- 프로그램: `%LOCALAPPDATA%\Seoseungkwan\PrecheckHelper\`
- 작업 저장(고치던 메모·완료 표시): 같은 폴더 안 `data\` — 이 PC의 윈도우 계정으로 암호화되어 있습니다
- 크롬 연결 등록: 사용자 레지스트리 `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.seoseungkwan.precheck`
- 접수 현황 프로그램: 같은 폴더의 `PrecheckReception.exe` (도우미와 같은 `data\` 폴더를 씁니다)
- 접수 현황 시작 항목(로그인 때 켜기): 사용자 레지스트리 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`의 `Seoseungkwan.PrecheckReception`
- 바탕 화면 바로 가기: **접수 현황 주소** (`PrecheckReception.exe --link`, 이 PC 브라우저로 주소 보내기 화면을 엽니다)

## 잘 안 될 때

- 설치 창에 **"설치하지 못했습니다"**가 뜨면, 크롬의 청구 화면을 닫고 다시 `install.cmd`를 누르세요.
- 그래도 안 되면 그 창을 사진으로 찍어 보내 주세요. 청구 화면에 나온 오류 번호(예: `E-HELPER-MISSING`)도 함께 알려 주세요.
