PT 후 진료 종이 - 읽어 주세요


■ 이것은 무엇인가요?

대기 환자가 많을 때 물리치료를 먼저 받으러 가는 환자에게 손으로 써 주던
'PT 후 진료' 종이를, 버튼 몇 번으로 빅솔론 프린터에서 뽑아 주는 작은 프로그램입니다.
비트 접수 화면에서 원장님 증상 기록의 주사 차수(예: 오)무릎 3차)를 '접수메모(당일)' 칸에
넣어 주는 [주사 차수] 버튼도 함께 들어 있습니다.

- [주사 차수] 버튼을 쓸 접수 PC마다 설치합니다.
  빅솔론 프린터가 없는 PC에서는 노란 [PT 먼저] 버튼은 쓰지 않으면 됩니다.
- 설치할 때 윈도우가 묻는 창에서 [예]를 한 번 누릅니다(비트가 관리자 권한으로 돌아서,
  비트 칸에 글을 넣으려면 이 프로그램도 같은 권한이 필요해요). 그 뒤로는 묻지 않습니다.
- 뽑은 기록·넣은 메모는 남기지 않습니다. 환자 이름·기록은 비트에서 읽어 화면과 종이에만 씁니다.


■ 설치하기

1. 받은 zip 파일을 오른쪽 클릭 → [모두 압축 풀기]를 누릅니다.
   (zip을 열기만 하고 안에서 바로 누르면 설치되지 않습니다. 꼭 풀어 주세요.)
2. 푼 폴더에서 '설치.cmd'를 두 번 누릅니다.
3. 파란 창 "Windows의 PC 보호"가 뜨면 [추가 정보] → [실행]을 누릅니다.
   (서명하지 않은 프로그램이라 처음 한 번 이 경고가 뜹니다.)
4. "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 뜨면 [예]를 누릅니다.
   ([아니요]를 누르면 설치되지 않습니다. 설치.cmd를 다시 누르면 됩니다.)
5. 새 검은 창에 "설치했어요."가 보이면 아무 키나 눌러 창을 닫습니다.
   이제 컴퓨터를 켤 때마다 프로그램이 저절로 켜집니다(그때는 묻는 창이 뜨지 않습니다).

새 버전도 같은 순서로 설치하면 됩니다. 맞춰 둔 설정은 그대로 남습니다.


■ 쓰는 법

1. 비트 창을 맨 앞에 띄우면, 창 오른쪽 위(최소화 단추 왼쪽)에 노란 [PT 먼저] 버튼이 붙어 있습니다.
   비트가 꺼져 있거나 최소화돼 있으면 버튼도 안 보입니다.
2. [PT 먼저]를 누르고 차트번호를 칩니다. 환자 이름이 나오는지 봅니다.
   (이름이 나와야 [뽑기]가 눌립니다. "없는 차트번호예요"가 나오면 번호를 다시 봐 주세요.)
3. 치료 항목과 치료 부위를 누릅니다. 여러 개 골라도 됩니다.
   - 오른·왼·양을 먼저 누르고 부위를 누르면 "오른 어깨"처럼 들어갑니다.
   - 잘못 고른 부위는 ✕를 눌러 뺍니다.
   - 하나도 안 골라도 뽑힙니다. 그 칸은 비어서 나오니 손으로 쓰면 됩니다.
4. [뽑기]를 누르면 종이 1장이 나오고 창이 닫힙니다.


■ 주사 차수 버튼 쓰는 법

1. 비트 접수 화면에서 환자를 불러옵니다.
2. '접수메모(당일)' 칸 오른쪽의 초록 [주사 차수] 버튼을 누르거나 F8을 누릅니다.
3. 최근 30일 원장님 증상 기록에서 주사 차수를 찾아 칸 끝에 넣어 줍니다(예: 오)무릎 3차).
   칸에 글이 있으면 뒤에 '/'를 붙여 넣습니다. 저장은 평소처럼 직접 누릅니다.
4. 넣지 않을 때는 칸 아래에 짧은 알림이 2~3초 떴다가 사라집니다.
   (기록이 없을 때, 계획한 주사가 끝났을 때, 계획보다 일찍 왔을 때, 이미 적혀 있을 때 등)
   "메모 칸에 넣지 못했어요. 직접 적어 주세요: …"가 뜨면 보이는 글을 손으로 적어 주세요.
5. 넣은 글이 기록과 다르면 고친 뒤 저장해 주세요. 증상 기록 글을 읽어 만드는 것이라
   부위·번호가 틀릴 수 있습니다.


■ 처음 한 번 맞추기

1. [PT 먼저] 버튼을 마우스 오른쪽으로 누르고 [설정]을 고릅니다.
2. '프린터' 칸에 빅솔론(BIXOLON) 프린터가 골라져 있는지 봅니다.
   (먼저 [시험 1장]을 누르기 전에) [프린터 종이 설정]을 눌러 '용지 유형'을 '연속'으로 고르고
   [확인]을 누릅니다. 이어진 롤 종이에서 종이가 길게 계속 나오지 않게 하는 설정이고,
   이 프로그램이 뽑을 때만 쓰입니다(프린터 기본 설정은 그대로).
   그래도 종이가 길게 계속 나오면 아래 '빅솔론에 직접 보내기'에 체크하고 [시험 1장]을 누릅니다.
   (프린터 드라이버를 거치지 않고 빅솔론에 '이어진 종이, 이 길이'를 직접 알려 줍니다)
3. [시험 1장]을 눌러 빈 양식을 한 장 뽑아 봅니다.
   종이가 너무 길거나 짧으면 '종이 길이'(mm)를 바꾸고 다시 [시험 1장]을 누릅니다.
   잘 맞으면 [저장]을 누릅니다.
4. [PT 먼저] 버튼이 비트의 단추를 가리면, '버튼 자리'의 [◀ 왼쪽으로] [오른쪽으로 ▶]로
   옮긴 뒤 [저장]을 누릅니다.
5. [주사 차수] 버튼이 비트의 단추나 글을 가리면, 설정 창 맨 아래 '주사 차수 단추 자리'로
   옮깁니다. 단축키(F8)는 '주사 차수 단축키'에서 F4·F10·F11로 바꿀 수 있습니다.


■ 버튼이 안 보일 때

- 비트 창을 한 번 눌러 맨 앞으로 띄워 보세요.
- 그래도 안 보이면 프로그램이 꺼진 것입니다. 컴퓨터를 다시 켜거나, 설치할 때 푼 폴더의
  '설치.cmd'를 한 번 더 두 번 누르면 다시 켜집니다.
- [주사 차수] 버튼은 비트 접수 화면이 맨 앞에 있을 때만 보이고, F8도 그때만 듣습니다.


■ 지우기

1. 설치할 때 푼 폴더에서 '지우기.cmd'를 두 번 누릅니다.
2. 검은 창에서 아무 키나 누르고, 묻는 창에서 [예]를 누르면 프로그램과 자동 켜기가 지워집니다.
   맞춰 둔 설정(목록·프린터·종이 길이·버튼 자리)은 남아서, 다시 설치하면 그대로 씁니다.


■ 어디에 설치되나요 (참고)

- 프로그램: %LOCALAPPDATA%\PtSlip\app
- 설정: %LOCALAPPDATA%\PtSlip\settings.json, 주사 차수 단추 자리·단축키는
  %LOCALAPPDATA%\PtSlip\memo-settings.json (환자 정보는 들어가지 않습니다)
- 자동 켜기: 작업 스케줄러의 'PtSlip' 작업(로그온 때, 높은 권한)
  (예전 판의 시작프로그램 'PT 후 진료 종이' 바로가기는 설치할 때 지웁니다)
